> State which rule(s) you are applying.
> You may not need to simplify your answer.
>
> a. $\dfrac{d}{dx}\,\dfrac{\tan(2x)}{\sqrt{x}}$
> b. $\left.\dfrac{d}{dx}\,\cos^3\left(x^2\right)\right|_{x=\sqrt{\pi}/2}$

**The answers.**

## 1. What this question is really testing

| the reflex being tested | where it comes from |
| :--- | :--- |
| choosing a rule without hesitating | Q8.1, and it is the same test here |
| **saying out loud which rule you chose** | **only here, in the whole question bank** |
| never dropping the inner derivative | Q8.2b, Q8.3 a/b/c/e, and part (b) below |
| the quotient rule in the order $u'v - uv'$ | Q8.2c, Q8.2d, Q8.3b, Q8.3d, and part (a) below |
| differentiating with letters and substituting last | Q8.2d, Q8.3's Family 7, and part (b) below |
| knowing when to stop simplifying | all four Q8 items |

**The two parts are a deliberate pair, not two random derivatives.**
Part (a) is a *breadth* test and part (b) is a *depth* test, and between them they force you to name every rule the course teaches except the product rule.

| | part (a) | part (b) |
| :--- | :--- | :--- |
| shape | one quotient, two different pieces | one composite, three layers |
| rules forced | quotient, chain, power, constant multiple | chain (twice), power |
| what it tests | can you name **several different** rules in one answer | can you name the **same** rule twice without collapsing it into one |
| the answer is | an expression | a single number |
| the risk | writing the quotient rule backwards | dropping the inner $2x$ |

Read that table as the reason neither part is optional practice.
They fail in different ways, and a student comfortable with (a) is not automatically safe on (b).

**Part (b) is asked at a designed point, and the design is the giveaway.**
$x=\frac{\sqrt\pi}{2}$ looks awkward until you square it: $x^2 = \frac{\pi}{4}$ exactly, verified to $10^{-15}$.
An examiner who wanted an ugly number would not have chosen a value whose square is the one angle where $\sin$ and $\cos$ agree.
So the moment you see $\sqrt\pi/2$, expect $\pi/4$ to appear, and expect the arithmetic at the end to be clean.
That is a reading skill, and section 8's Family 6 collects every version of it.

**What "no credit" looks like on this question.**
It does not appear on item 2.
The whole question set prints exactly four "no credit" clauses, at MT1 item 3, MT2 item 4, MT2 item 7, and **Final 2 item 1**, which is Q8.4's immediate neighbour on the page.
Item 1 is the one that says no credit will be given for unjustified answers.
That is worth stating plainly, because "state which rule(s) you are applying" reads like a justification demand and sits directly underneath a real one.
It is not the same thing: item 2 asks you to name your rules, and it attaches no stated penalty for not doing so.
Section 5 says what follows from that, and flags honestly where the reasoning stops.

## 2. The four things you must have cold

### 2.1 The rule names a marker will recognise

You cannot be graded on producing a name you do not have.
This is the entire list, and it is short.

| the name to write | when you write it | the form to quote if you want to be safe |
| :--- | :--- | :--- |
| **Power rule** | a piece is $x^n$, any constant $n$, including $\frac12$ and $-\frac12$ | $\frac{d}{dx}x^n = nx^{n-1}$ |
| **Constant multiple rule** | a constant sits in front | $(cf)' = cf'$ |
| **Sum / difference rule** | terms are added or subtracted | $(f\pm g)' = f'\pm g'$ |
| **Product rule** | two $x$-dependent factors multiplied | $(uv)' = u'v + uv'$ |
| **Quotient rule** | a division | $\left(\frac uv\right)' = \frac{u'v-uv'}{v^2}$ |
| **Chain rule** | a function of a function | $\frac{d}{dx}f(g(x)) = f'(g(x))\,g'(x)$ |

Two names people reach for that are **not** standard in this course, and are worth not inventing under pressure:

- *"Generalized power rule"* for $\frac{d}{dx}[g(x)]^n = n[g(x)]^{n-1}g'(x)$.
  It is a real name in some textbooks, and this course's files never use it.
  It is a special case of the chain rule, so if you write it, write it **as** a chain rule: "by the chain rule, in its power form".
- *"Reciprocal rule"* for $\frac{d}{dx}\frac1v = -\frac{v'}{v^2}$.
  Also real, also never used in this course's files.

**How much of this vocabulary the course actually supplies, counted out of `MATH265_Review.md`:**

| name | times it appears | |
| :--- | ---: | :--- |
| Chain rule | 42 | the most-named rule by a wide margin |
| Quotient rule | 24 | |
| Product rule | 19 | |
| Power rule | 17 | |
| Constant multiple | 4 | |
| **Sum rule** | **0** | never named, though the exam paper's own summary lists it |
| **Difference rule** | **0** | same |
| **Generalized power rule** | **0** | confirming the advice above |
| **Reciprocal rule** | **0** | same |

Those counts were extracted from the file, not typed.
Read the table as one fact: **the working vocabulary this course gives you is about five names wide**, and four of those five carry almost all the weight.
That is good news for an exam answer, because it means a complete rule list for any question in category 8 is a short list drawn from a small pool.

### 2.2 The granularity question: does one "chain rule" cover three layers?

This is the only genuinely ambiguous thing about Q8.4, so it is worth settling rather than guessing at in the exam room.

Part (b), $\cos^3\left(x^2\right)$, has three layers.
Two of them are chain-rule steps and one is a power-rule step.
There are three defensible ways to write the rule list:

| granularity | what you would write for (b) | the risk |
| :--- | :--- | :--- |
| **coarse** | "chain rule" | if the marker wants one name per step, this understates the work by two thirds |
| **per step** | "chain rule (applied twice), and the power rule" | none that I can see |
| **per layer, named** | "chain rule with a power outer, then chain rule with a $\cos$ outer, then the power rule on $x^2$" | none, other than time |

**Write the middle one, and let the algebra display the third.**
The reason is a cost asymmetry rather than a piece of knowledge.
Naming one rule too finely costs you a few seconds of writing.
Naming it too coarsely costs marks if, and only if, the marker was counting steps.
Since you cannot know which marker you have, and the extra precision is nearly free, the fine-grained list is the dominant strategy.

**Being honest about the limits of that advice.**
No marking scheme, rubric, or part-mark breakdown exists in any of the course files.
That was checked: the words "rubric", "marking scheme" and "part marks" do not appear in the question bank, the papers, or the review file.
So every claim in this document about *how much* naming earns is inference from the printed instruction, and is flagged as such wherever it appears.
What is **not** inference is the instruction itself, which is printed verbatim on the paper and in the bank: *"State which rule(s) you are applying."*

**The one thing that is certain from the wording.**
The printed "(s)" is plural.
A question expecting a single rule name would not have written it, so a *list* is what the examiner has in mind, and a one-word answer on a part that visibly uses three rules is the reading that fights the wording.

### 2.3 The layer ledger is already the answer

This is Q8.3's notation, and Q8.4 is the question that shows why it was worth building.
Add one column to it and the ledger stops being a private scratchpad and becomes the graded answer.

```
   y = cos^3( x^2 )

   layer  what it is        its derivative        THE RULE NAME
   -----  ---------------   -------------------   ----------------------------
     1    ( ___ )^3         3( ___ )^2            chain rule, power outer
     2    cos( ___ )        -sin( ___ )           chain rule, named outer
     3    x^2               2x                    power rule

   y' = product of column 3  =  3 cos^2(x^2) * (-sin(x^2)) * 2x
                             =  -6x cos^2(x^2) sin(x^2)

   the rule list = column 4, read downwards.  Nothing extra to do.
```

**That is the whole trick of this question.**
Q8.3 taught you to write the ledger so you would stop losing factors.
Q8.4 asks for exactly the information the ledger's last column already holds.
If you are keeping the ledger, naming the rules costs you nothing at all, which is why the summary table above calls this "free".

The count still works as a check, unchanged from Q8.3: three layers must give three factors, and the answer $-6x\cos^2\left(x^2\right)\sin\left(x^2\right)$ has exactly three, once you notice the $6$ is $3\times 2$ and not a fourth factor.

### 2.4 One quotient identity, and why part (a) does not need it

Q8.1's Family 2 recorded that $\frac{d}{dx}\frac{ax+b}{cx+d} = \frac{ad-bc}{(cx+d)^2}$ has a constant numerator.
Part (a) is **not** of that shape, because $\tan(2x)$ is not linear, so the shortcut does not apply and the full quotient rule is required.
It is worth knowing that it does not apply, rather than discovering it halfway through.

What part (a) does need is the derivative of the denominator written as a power:

$$\sqrt{x} = x^{1/2}, \qquad \frac{d}{dx}x^{1/2} = \tfrac12 x^{-1/2} = \frac{1}{2\sqrt x}$$

That is the **power rule**, and naming it is one of the three names part (a) wants.
It is also the single most-forgotten name on this question, because $\sqrt x$ does not look like $x^n$ until you rewrite it.

## 3. The universal procedure, with names attached

> **Step 1 - Ask what the LAST operation is, and write its rule name down immediately.**
> Not after you finish, not in your head.
> The name goes on the page at the moment you decide it, because that is the only moment you are certain of it.
>
> **Step 2 - Write the rule with blanks before filling anything in.**
> For part (a), write $\dfrac{u'v-uv'}{v^2}$ first, then name $u$ and $v$.
> Committing to the order before the algebra distracts you is what stops the quotient rule coming out backwards.
>
> **Step 3 - Recurse, naming each piece's rule as you reach it.**
> Every recursion adds one line to the ledger and one name to the list.
>
> **Step 4 - Assemble, and do not touch the algebra.**
> At this point the derivative is written and the marks are earned.
>
> **Step 5 - Substitute the number, if one was given, and only now.**
> Part (b) gives a point.
> Differentiate with letters all the way to the end, then put the number in.
> Substituting first turns the function into a constant, whose derivative is zero, which is the single most destructive mistake available on this question.
>
> **Step 6 - Read your rule list back and check it against the algebra.**
> This is the step that exists only on Q8.4.
> Every name you wrote must correspond to something visible in your answer, and every rule your answer used must have a name.
> Section 5 gives the two-way audit.
>
> **Step 7 - Check numerically, avoiding the poisoned points.**
> Section 6.

**The tree for part (a).**

```
                  y = tan(2x) / sqrt(x)
                            |
            LAST operation performed is a DIVISION
                            |
                   >>> QUOTIENT RULE <<<
                     (u'v - uv') / v^2
                  /                      \
        u = tan(2x)                  v = sqrt(x) = x^(1/2)
             |                              |
   LAST op: tan applied to 2x        LAST op: x to a constant power
             |                              |
     >>> CHAIN RULE <<<              >>> POWER RULE <<<
   outer tan -> sec^2                 v' = (1/2) x^(-1/2)
   inner 2x  -> 2                        = 1/(2 sqrt(x))
   u' = 2 sec^2(2x)
      (the 2 is the CONSTANT MULTIPLE rule inside the chain)

   rule list to write down:  quotient, chain, power.
```

Three names, one per branch of the tree, and they come straight off the picture.

## 4. Q8.4 worked, part by part

### Part (a) - $\dfrac{d}{dx}\,\dfrac{\tan(2x)}{\sqrt x}$

**Route A - the quotient rule, which is what the question is fishing for.**

The last operation is a division, so this is the quotient rule with

$$u = \tan(2x), \qquad v = \sqrt x = x^{1/2}$$

$u' = 2\sec^2(2x)$ by the **chain rule**, outer $\tan$ giving $\sec^2$, inner $2x$ giving $2$.
$v' = \frac12 x^{-1/2} = \frac{1}{2\sqrt x}$ by the **power rule**.

$$y' = \frac{u'v - uv'}{v^2} = \frac{2\sec^2(2x)\sqrt x - \tan(2x)\cdot\dfrac{1}{2\sqrt x}}{x}$$

**That is a complete answer and it is where you should stop.**
The printed permission covers you, and every line past here is risk without reward.

If you do want the single cleared fraction, multiply numerator and denominator by $2\sqrt x$:

$$y' = \frac{4x\sec^2(2x) - \tan(2x)}{2x^{3/2}}$$

The two forms were checked as an identity across every sample point and agree to $10^{-16}$ relative, so both are right and the first is cheaper.

**Route B - the product rule, after rewriting the denominator.**

Write $y = \tan(2x)\cdot x^{-1/2}$ and the last operation becomes a multiplication.

$$y' = 2\sec^2(2x)\cdot x^{-1/2} + \tan(2x)\cdot\left(-\tfrac12 x^{-3/2}\right)$$

This is the **same answer**, verified as an identity against Route A, but the rules you name are different: **product**, chain, power, instead of **quotient**, chain, power.
That is the interesting thing about this route and it is why section 8 gives it a family of its own.
On a question that grades the rule list, changing your route changes your answer to the graded question, and both lists are correct because both describe what you actually did.

**Which route, and why.**

| route | rules to name | algebra | verdict |
| :--- | :--- | :--- | :--- |
| **A, quotient rule** | quotient, chain, power | one fraction, denominator $x$ | **use this one.** The question presents a fraction, so a quotient rule is the expected reading and needs no explanation |
| B, product rule | product, chain, power | two terms, negative exponents | correct and equally valid; costs a sentence to justify the rewrite, and negative fractional exponents invite slips |
| C, logarithmic differentiation | chain, plus $\ln$ rules not yet taught | long | not available; this is a Unit 4 technique and the paper is testing Unit 3 |

**Values to hold.**
At the designed point $x=\pi/8$, where $2x = \pi/4$, the arithmetic is clean: $\sec^2(2x) = 2$ exactly and $\tan(2x)=1$, so $4x\sec^2(2x) = 4\cdot\frac\pi8\cdot 2 = \pi$ and

$$y'\left(\tfrac\pi8\right) = \frac{\pi - 1}{2\left(\frac\pi8\right)^{3/2}} \approx 4.3512801365$$

with $y(\pi/8) \approx 1.5957691216$.
At $x=1.1$, $y \approx -1.3098889$ and $y' \approx 6.1014403$.

### Part (b) - $\left.\dfrac{d}{dx}\,\cos^3\left(x^2\right)\right|_{x=\sqrt\pi/2}$

**First, read the expression correctly.**
$\cos^3\left(x^2\right)$ means $\left[\cos\left(x^2\right)\right]^3$.
It does **not** mean $\cos\left(x^6\right)$, and it does not mean $\cos\left(\cos\left(\cos\left(x^2\right)\right)\right)$.
The superscript sits on the function name, so it is an outer cube; Q8.2 section 2.2 is the place this was taught, and it decides which rule sits at the top.

**Route A - the ledger, which is what to write.**

Three layers, three lines, three names, as set out in section 2.3:

$$y' = 3\left[\cos\left(x^2\right)\right]^2\cdot\left(-\sin\left(x^2\right)\right)\cdot 2x = -6x\cos^2\left(x^2\right)\sin\left(x^2\right)$$

Now, and only now, substitute.
At $x=\frac{\sqrt\pi}{2}$ we have $x^2 = \frac{\pi}{4}$ exactly, so

$$\cos^2\left(\tfrac\pi4\right) = \left(\tfrac{\sqrt2}{2}\right)^2 = \tfrac12, \qquad \sin\left(\tfrac\pi4\right) = \tfrac{\sqrt2}{2}$$

$$y'\left(\tfrac{\sqrt\pi}{2}\right) = -6\cdot\frac{\sqrt\pi}{2}\cdot\frac12\cdot\frac{\sqrt2}{2} = -\frac{6\sqrt{2\pi}}{8} = -\frac{3\sqrt{2\pi}}{4} \approx -1.8799712060$$

**Route B - the triple product rule.**

Since $\cos^3\left(x^2\right) = \cos\left(x^2\right)\cos\left(x^2\right)\cos\left(x^2\right)$, the product rule for three factors gives three identical terms:

$$y' = 3\cdot\left[-2x\sin\left(x^2\right)\right]\cos^2\left(x^2\right)$$

Verified identical to Route A.
The rules named here are **product** and **chain**, not power and chain.
It is longer and it is correct, and it exists in this document mainly to make the point in Family 3: the rule list is a property of your route, not of the function.

**Route C - the triple-angle identity.**

Using $\cos^3 u = \frac{3\cos u + \cos 3u}{4}$ with $u=x^2$:

$$y = \frac{3\cos\left(x^2\right)+\cos\left(3x^2\right)}{4}, \qquad y' = \frac{-3\sin\left(x^2\right)-3\sin\left(3x^2\right)}{4}\cdot 2x$$

Verified identical to Route A at every sample point, and the two *functions* were checked equal to $2\times10^{-16}$ first, so the identity itself is not being assumed.
Do not use it.
It replaces a rule you know with an identity you have to recall correctly, and it earns the same marks.

**Which route, and why.**

| route | rules to name | verdict |
| :--- | :--- | :--- |
| **A, chain twice + power** | chain (twice), power | **use this one.** Shortest, and its ledger is the rule list |
| B, triple product | product, chain | correct, longer, and the three identical terms are easy to miscount |
| C, triple-angle identity | chain, plus a memorised identity | correct and pointless; a recall risk for no gain |

**The tidier cousin worth knowing.**
The same derivative asked at $x=\sqrt{\pi/3}$ gives $-\frac{3\sqrt3\sqrt{\pi/3}}{4}$, which simplifies to $-\frac{3\sqrt\pi}{4}\approx -1.3293403882$, because $\sqrt{\pi/3}\cdot\sqrt3 = \sqrt\pi$.
If your answer at a designed point still has nested radicals, look once for a collapse like that before writing it down.

## 5. The exam-ready write-up, and what a marker accepts as a rule name

### The policy

Q8.1's simplification policy applies unchanged: simplifying has zero marginal reward and non-zero marginal risk, so stop when the derivative is written.
Q8.4 adds a second policy alongside it, and the two point in opposite directions:

> **Simplify as little as you can. Name as much as you can.**
>
> Algebra past the derivative is unpaid risk.
> Naming past the minimum is paid, or at worst free, because the question asked for it in writing.

That asymmetry is the whole of this section.
Nothing else in category 8 has a component where doing *more* is the safe direction.

**One thing the naming demand does not change.**
It is not a demand for simplification, and it is not a demand for a proof.
The item still prints "You may not need to simplify your answer", so an unsimplified derivative with a correct rule list is a complete answer.

### What counts as naming a rule

| this counts | this is weaker | this does not count |
| :--- | :--- | :--- |
| "By the **quotient rule**, with $u=\tan 2x$ and $v=\sqrt x$" | "quotient rule" written in the margin | writing $\frac{u'v-uv'}{v^2}$ with no name attached |
| "By the **chain rule**, outer $\tan$, inner $2x$" | "chain" | the correct answer with no words at all |
| "By the **power rule** on $x^{1/2}$" | "power" | naming a rule you did not use |

The middle column is not wrong, and under time pressure it is what you should fall back to.
The right column is the one to avoid, and its last entry is the one people do not expect: **naming a rule you did not use is worse than naming nothing**, because it is a positive claim about your method that the marker can see is false.

### The short form, which is what to write if time is tight

> **a.** By the **quotient rule** with $u=\tan(2x)$, $v=\sqrt x$; $u'=2\sec^2(2x)$ by the **chain rule**, $v'=\frac{1}{2\sqrt x}$ by the **power rule**:
> $$y' = \frac{2\sec^2(2x)\sqrt x - \tan(2x)\cdot\frac{1}{2\sqrt x}}{x}.$$
>
> **b.** By the **chain rule** applied twice, with the **power rule** on the inner $x^2$:
> $$y' = -6x\cos^2\left(x^2\right)\sin\left(x^2\right).$$
> At $x=\frac{\sqrt\pi}{2}$, $x^2=\frac\pi4$, so $y' = -6\cdot\frac{\sqrt\pi}{2}\cdot\frac12\cdot\frac{\sqrt2}{2} = -\frac{3\sqrt{2\pi}}{4}$.

That is roughly ninety seconds of writing and it answers both halves of the question.

### The full-credit form, which adds the clauses that show the method

> **a.** The outermost operation is a division, so this is the **quotient rule**,
> $$\left(\frac uv\right)' = \frac{u'v - uv'}{v^2}, \qquad u = \tan(2x),\quad v = \sqrt x = x^{1/2}.$$
> The numerator needs the **chain rule**: the outer function is $\tan$, whose derivative is $\sec^2$ evaluated at the unchanged inner function, and the inner function $2x$ has derivative $2$ by the **constant multiple** and **power** rules, so $u' = 2\sec^2(2x)$.
> The denominator needs the **power rule** with $n=\frac12$, so $v' = \frac12 x^{-1/2} = \frac{1}{2\sqrt x}$.
> Assembling,
> $$y' = \frac{2\sec^2(2x)\sqrt x - \tan(2x)\cdot\dfrac{1}{2\sqrt x}}{x},$$
> which may be cleared to $\dfrac{4x\sec^2(2x)-\tan(2x)}{2x^{3/2}}$, valid for $x>0$.
>
> **b.** The outermost operation is a cube of a function, so this is the **chain rule** in its power form, $\frac{d}{dx}[g(x)]^n = n[g(x)]^{n-1}g'(x)$ with $g(x)=\cos\left(x^2\right)$ and $n=3$.
> Differentiating $g$ needs the **chain rule** a second time, with outer $\cos$ giving $-\sin$ and inner $x^2$ giving $2x$ by the **power rule**.
> The three layers give three factors:
> $$y' = 3\cos^2\left(x^2\right)\cdot\left(-\sin\left(x^2\right)\right)\cdot 2x = -6x\cos^2\left(x^2\right)\sin\left(x^2\right).$$
> Substituting last, at $x=\frac{\sqrt\pi}{2}$ we have $x^2=\frac\pi4$, where $\cos^2\left(\frac\pi4\right)=\frac12$ and $\sin\left(\frac\pi4\right)=\frac{\sqrt2}{2}$:
> $$y'\left(\tfrac{\sqrt\pi}{2}\right) = -6\cdot\frac{\sqrt\pi}{2}\cdot\frac12\cdot\frac{\sqrt2}{2} = -\frac{3\sqrt{2\pi}}{4}\approx -1.880.$$

Note how little of that is extra work.
Every clause is something you had to decide anyway; the only difference is that the decision is now on the paper instead of in your head.

### The two-way naming audit

Before you move on, read the answer and the rule list against each other in both directions.
It takes about ten seconds and it catches the failure mode that is unique to this question.

| direction | the question to ask | what a failure looks like |
| :--- | :--- | :--- |
| **list to algebra** | for each name I wrote, where is it visible in my answer? | you wrote "product rule" but your answer is a single fraction |
| **algebra to list** | for each rule my answer used, did I name it? | your answer has $\frac{1}{2\sqrt x}$ in it, which came from the power rule, and "power rule" is nowhere on the page |

The second direction is the one that catches real omissions, and on part (a) it catches the specific one people make: the power rule on $\sqrt x$ is used by everyone and named by almost nobody.

## 6. Verify before you commit

### The inherited check, and the two points you must not use

The check is Q8.1's, unchanged:

> Compute $\dfrac{f(x+0.001)-f(x-0.001)}{0.002}$ and compare with your $y'(x)$.
> Agreement to three or four significant figures means the derivative is right.

Measured on this question:

| part | $x$ | $f(x)$ | your $y'(x)$ | what the calculator shows | relative error |
| :--- | :--- | :--- | :--- | :--- | ---: |
| a | $1.1$ | $-1.3098889$ | $6.1014403$ | $6.1014981$ | $9.5\times10^{-6}$ |
| a | $\pi/8$ | $1.5957691$ | $4.3512801$ | agrees to 6 figures | |
| b | $\sqrt\pi/2$ | $0.3535534$ | $-1.8799712$ | $-1.8799644$ | $3.6\times10^{-6}$ |

Both clear five significant figures at $h=0.001$, which is the value Q8.2 measured as the optimum on a ten-digit machine.

**Now the part that is specific to Q8.4, and it is the most valuable paragraph in this document.**

Q8.3 established that a dropped chain factor is **invisible exactly where that factor equals 1**.
Both of this question's most likely errors have such a point, and both of those points are numbers a student would naturally choose.

| part | the likely error | the factor that goes missing | it equals 1 at | so the check silently passes at |
| :--- | :--- | :--- | :--- | :--- |
| a | forgetting the power rule and writing $v'=1$ | $\dfrac{1}{2\sqrt x}$ | $x = \dfrac14$ | $x = 0.25$ |
| b | dropping the innermost chain factor | $2x$ | $x = \dfrac12$ | $x = 0.5$ |

Both were measured.
At $x=0.25$ the wrong part (a) answer and the right one are both $3.0085756823$, agreeing to $10^{-12}$: the check certifies a wrong derivative.
At $x=0.5$ the wrong part (b) answer and the right one are both $-0.6967820395$, agreeing to $10^{-14}$.

Move one step away and the same errors are loud.
At $x=1.1$ the part (a) slip reads $6.7549663$ against the true $6.1014403$.
At the exam's own point $x=\frac{\sqrt\pi}{2}$ the part (b) slip reads $-1.0606602$ against the true $-1.8799712$, because $2x = 1.77245$ there and not 1.

**The instruction that follows: never check at $x = \frac14$ or $x = \frac12$ on this question.**
Use $x=1.1$, or use the exam's own point for part (b), which is conveniently far from every blind spot.
More generally, pick a check point *after* looking at your chain factors, not before.

**What the check cannot do here.**
It confirms the derivative and says nothing at all about the rule list, which is half the marks on this question.
There is no numerical check for naming.
The two-way audit in section 5 is the only check that exists for that half, which is why it is written as a procedure rather than left to care.

### The factor count, unchanged from Q8.3

> Count the ledger layers.
> Count the factors in your answer.
> They must match.

| part | layers | factors that must be present |
| :--- | ---: | :--- |
| a, numerator | 2 pieces | $2\sec^2(2x)$ must carry the inner $2$; $\frac{1}{2\sqrt x}$ must be present, not $1$ |
| b | 3 | $\cos^2\left(x^2\right)$, $\sin\left(x^2\right)$, and the $2x$ folded into the $6$ |

For part (b) the coefficient is the count made visible: $6 = 3\times 2$, where the $3$ is the outer cube and the $2$ is the inner $x^2$.
An answer with a $3$ in front has lost the inner layer, and an answer with a $2$ in front has lost the outer one.

### The cheap structural invariants

| part | invariant | why it holds |
| :--- | :--- | :--- |
| a | $\sec^2(2x)$ appears, never $\sec^2 x$ | the outer derivative leaves the inner argument untouched |
| a | the answer blows up as $x\to 0^+$ | $v=\sqrt x\to 0$, so the quotient's pole is real and the derivative inherits it |
| a | the answer has poles wherever $\tan(2x)$ does | differentiating never removes a pole; it deepens it |
| b | $y'$ vanishes at $x=0$, $\sqrt{\pi/2}$ and $\sqrt\pi$ | one zero per ledger factor: the $2x$, the $\sin\left(x^2\right)$, and the $\cos^2\left(x^2\right)$ |
| b | $y'<0$ just right of $x=0$ | $\cos^3$ is falling away from its maximum |
| b | $\cos^2\left(\frac\pi4\right)=\frac12$, not $\frac{\sqrt2}{2}$ | squaring $\frac{\sqrt2}{2}$ gives $\frac12$; forgetting to square is a common arithmetic slip |

That last row is worth a second look, because it is a pure arithmetic trap sitting at the end of an otherwise finished problem.
$\frac{\sqrt2}{2}\approx 0.707$ and $\frac12 = 0.5$, and using the wrong one changes the final answer by a factor of $\sqrt2$.

## 7. Answer-entry rules

Both exams are Möbius, answer-only and machine-marked, so a correct method with a bad keystroke scores zero.

| do | do not |
| :--- | :--- |
| write every multiplication with an explicit `*` | rely on juxtaposition: `6xcos` is not `6*x*cos` |
| use `pi` for $\pi$ and `sqrt( )` for roots | type `3.14` or `1.772` |
| bracket the whole denominator: `/(2*x^(3/2))` | write `/2*x^(3/2)`, which divides by 2 and then multiplies |
| bracket fractional exponents: `x^(3/2)` | write `x^3/2`, which is $\frac{x^3}{2}$ |
| enter part (b) exactly, as `-3*sqrt(2*pi)/4` | round to `-1.88` unless the question asks for a decimal |
| preview the rendered expression before submitting | trust the typing |

**The single most expensive typo on this question is the missing bracket around a fractional exponent.**
`x^3/2` and `x^(3/2)` are different expressions, they both parse, and neither produces an error message.
Möbius will simply mark you wrong.

**On equivalence.** The grader tests mathematical equivalence, so for part (a) the raw quotient-rule form and the cleared fraction are both accepted, and there is no reason to clear it.
For part (b), all three of `-3*sqrt(2*pi)/4`, `-(3/4)*sqrt(2)*sqrt(pi)` and `-3*sqrt(pi)/(2*sqrt(2))` were verified equal to $10^{-14}$.

**A note that matters only on this question.** Möbius cannot grade a rule name, so on the machine-marked version of this question the naming instruction has nothing to attach to.
Where the naming earns marks is on a written or scanned answer.
Write the names anyway: it costs seconds, and you do not get to choose which version you sit.

## 8. The variation catalog

Read each table as **structure**, not as a list of facts.
In almost every family below the answers are generated by one shape with a small number of moving parts, and once you see the shape the individual rows stop needing memory.

### Family 0 - the naming demand itself

The trigger is the sentence "state which rule(s) you are applying", or "justify your steps", or "show which rule you used".
The tool is the ledger with a name column.

| what the question says | what it wants | the minimum that answers it |
| :--- | :--- | :--- |
| "state which rule(s) you are applying" | a list of rule names | one name per ledger line |
| "show your work" | the intermediate lines | the assembled unsimplified derivative |
| "justify your answer" | reasons, not just names | name plus the $u$ and $v$ you chose |
| "no credit for unjustified answers" | the strongest form | full-credit write-up, section 5 |

The fourth row is Final 2 item 1, not this question, and the distinction is the whole reason section 1 goes to the trouble of listing where the four "no credit" clauses actually are.

### Family 1 - counting the chain rules

The trigger is a composite and a question that asks how many rules you used.
The tool is the layer count, and the rule is: **for a pure composite, the number of chain-rule applications is the number of layers minus one.**

| function | layers | chain rules | the derivative |
| :--- | ---: | ---: | :--- |
| $\cos^3 x$ | 2 | 1 | $-3\cos^2 x\sin x$ |
| $\cos^3\left(x^2\right)$ | 3 | 2 | $-6x\cos^2\left(x^2\right)\sin\left(x^2\right)$ |
| $\cos^3\left(\sqrt{x}\right)$ | 3 | 2 | $-\dfrac{3\cos^2\left(\sqrt x\right)\sin\left(\sqrt x\right)}{2\sqrt x}$ |
| $\sqrt{1+\sqrt{1+x}}$ | 3 | 2 | $\dfrac{1}{4\sqrt{1+\sqrt{1+x}}\sqrt{1+x}}$ |

The first two rows are the pair to hold, because they differ by exactly one layer and one factor, and both were verified.
$\cos^3 x$ needs one chain rule and $\cos^3\left(x^2\right)$ needs two, which is precisely the distinction the naming instruction is testing.

### Family 2 - a trig function of a linear inner

The trigger is $\sin(kx)$, $\tan(kx)$, $\sec(kx)$: one chain rule, and the inner derivative is a constant.
The tool is the chain rule, and the point of the family is that **a constant chain factor never equals 1 unless $k=1$**, so dropping it is always visible numerically.

| function | derivative | the factor people drop |
| :--- | :--- | :--- |
| $\tan(2x)$ | $2\sec^2(2x)$ | the $2$ |
| $\sin(3x)$ | $3\cos(3x)$ | the $3$ |
| $\sec(2x)$ | $2\sec(2x)\tan(2x)$ | the $2$ |
| $\cos(kx)$ | $-k\sin(kx)$ | the $k$, and the minus sign |

This is the easiest family to check and the one where a numeric check is guaranteed to work, which is the opposite of Family 5's situation.

### Family 3 - one answer, two rule lists

This is Q8.4's signature family and it exists nowhere else in the category.
The trigger is a function that can be attacked more than one way.
The tool is a decision, and the point is that **the rule list you write must match the route you took**.

| function | route 1, and its names | route 2, and its names | verified identical |
| :--- | :--- | :--- | :--- |
| $\dfrac{\tan 2x}{\sqrt x}$ | quotient, chain, power | rewrite as $\tan(2x)x^{-1/2}$: product, chain, power | yes |
| $\dfrac{x^2+1}{\sqrt x}$ | quotient, power | split into $x^{3/2}+x^{-1/2}$: **power rule only** | yes |
| $\dfrac{1}{(x+3)^2}$ | quotient, chain | rewrite as $(x+3)^{-2}$: chain only | yes |
| $\dfrac{x^2\sin 2x}{x}$ | quotient, product, chain | cancel first: product, chain | yes |
| $\cos^3\left(x^2\right)$ | chain twice, power | triple product: product, chain | yes |

**Row 2 is the one to study.**
$\frac{x^2+1}{\sqrt x}$ looks like a quotient rule and is not: split it into $x^{3/2}+x^{-1/2}$ and the answer is $\frac32 x^{1/2}-\frac12 x^{-3/2}$ by the power rule alone.
Naming the quotient rule there is not wrong if you used it, but it is more work for the same marks, and the split is the answer an examiner is hoping to see.
Row 4 makes the same point more sharply: cancelling the $x$ first removes an entire rule from your list.

**The general lesson, and it is the reason this family exists.**
On Q8.1 through Q8.3 a smarter route saved you time.
Here it also changes the graded rule list, so the route is part of the answer.

### Family 4 - a trig or composite over a power of $x$, which is Q8.4(a)

The trigger is a quotient whose denominator is $x^n$ for some constant $n$, fractional included.
The tool is the quotient rule, with a chain rule inside the numerator and a power rule on the denominator.

| function | derivative | names |
| :--- | :--- | :--- |
| $\dfrac{\tan 2x}{\sqrt x}$ | $\dfrac{4x\sec^2 2x - \tan 2x}{2x^{3/2}}$ | quotient, chain, power |
| $\dfrac{\sin 3x}{\sqrt x}$ | $\dfrac{6x\cos 3x - \sin 3x}{2x^{3/2}}$ | quotient, chain, power |
| $\dfrac{\tan x}{x}$ | $\dfrac{x\sec^2 x - \tan x}{x^2}$ | quotient, power |
| $\dfrac{\cos 2x}{x^2}$ | $\dfrac{-2x\sin 2x - 2\cos 2x}{x^3}$ | quotient, chain, power |
| $\dfrac{\sec 2x}{x^{1/3}}$ | $2\sec 2x\tan 2x\,x^{-1/3} - \tfrac13\sec 2x\,x^{-4/3}$ | quotient or product, chain, power |
| $\dfrac{\sqrt x}{\tan 2x}$ | $\dfrac{\frac{\tan 2x}{2\sqrt x} - 2\sqrt x\sec^2 2x}{\tan^2 2x}$ | quotient, power, chain |
| $\dfrac{\sin x}{x^{3/2}}$ | $\dfrac{x\cos x - \frac32\sin x}{x^{5/2}}$ | quotient, power |
| $\dfrac{x^2+1}{\sqrt x}$ | $\tfrac32 x^{1/2} - \tfrac12 x^{-3/2}$ | **power rule only**, after splitting |

All eight verified against complex-step.
**Read the first four rows as one shape.** Clearing the $\frac{1}{2\sqrt x}$ always multiplies through by $2\sqrt x$ and always lands on a denominator of $2x^{3/2}$, and the numerator is always $(\text{inner derivative})\cdot 2x\cdot(\text{outer}) - (\text{original numerator})$.
Row 6 is the same problem upside down and it is much messier, which is itself the lesson: a root on top is easier than a root on the bottom.

### Family 5 - a power of a trig of a composite, which is Q8.4(b)

The trigger is $\left[\text{trig}(\text{something})\right]^n$ with something that is not just $x$.
The tool is two chain rules and a power rule, and the ledger keeps them apart.

| function | derivative | coefficient, and where it comes from |
| :--- | :--- | :--- |
| $\cos^3\left(x^2\right)$ | $-6x\cos^2\left(x^2\right)\sin\left(x^2\right)$ | $3\times 2$ |
| $\sin^3\left(x^2\right)$ | $6x\sin^2\left(x^2\right)\cos\left(x^2\right)$ | $3\times2$, and no minus sign |
| $\cos^5\left(x^2\right)$ | $-10x\cos^4\left(x^2\right)\sin\left(x^2\right)$ | $5\times2$ |
| $\sin^4\left(x^3\right)$ | $12x^2\sin^3\left(x^3\right)\cos\left(x^3\right)$ | $4\times3$ |
| $\tan^3(2x)$ | $6\tan^2(2x)\sec^2(2x)$ | $3\times2$ |
| $\sec^2(3x)$ | $6\sec^2(3x)\tan(3x)$ | $2\times3$ |
| $\cos^2\left(\sqrt x\right)$ | $-\dfrac{\cos\sqrt x\sin\sqrt x}{\sqrt x}$ | $2\times\frac12 = 1$, so no coefficient survives |
| $\cos^3 x$ | $-3\cos^2 x\sin x$ | $3\times1$, two layers only |

All eight verified.
**The whole table is one formula.** The coefficient is always (outer power) times (inner derivative's coefficient), the trig power always drops by one, the argument never changes, and the sign is the sign of the outer trig function's derivative.
There are only two magnitudes doing real work here, the outer power and the inner exponent, and every number in the third column is their product.
Row 7 is the one to notice: when the inner is $\sqrt x$, the $\frac12$ cancels the outer $2$ and the coefficient disappears, which looks like a dropped factor and is not.

### Family 6 - a derivative evaluated at a designed point

The trigger is the vertical bar, $\big|_{x=a}$, with an $a$ that looks strange.
The tool is: differentiate with letters, substitute last, and expect the strangeness to cancel.

| function and point | why that point | the value |
| :--- | :--- | ---: |
| $\cos^3\left(x^2\right)$ at $\frac{\sqrt\pi}{2}$ | $x^2 = \frac\pi4$ | $-\frac{3\sqrt{2\pi}}{4} \approx -1.8799712060$ |
| $\cos^3\left(x^2\right)$ at $\sqrt{\pi/3}$ | $x^2=\frac\pi3$ | $-\frac{3\sqrt\pi}{4} \approx -1.3293403882$ |
| $\cos^5\left(x^2\right)$ at $\frac{\sqrt\pi}{2}$ | $x^2=\frac\pi4$ | $-\frac{5\sqrt{2\pi}}{8}\approx -1.5666426716$ |
| $\sin^3\left(x^2\right)$ at $\sqrt{\pi/6}$ | $x^2=\frac\pi6$ | $\frac{3\sqrt{2\pi}}{8}\approx 0.9399856030$ |
| $\tan^3(2x)$ at $\frac\pi8$ | $2x=\frac\pi4$ | $12$ exactly |
| $\cos^2\left(\sqrt x\right)$ at $\frac{\pi^2}{16}$ | $\sqrt x = \frac\pi4$ | $-\frac2\pi \approx -0.6366197724$ |
| $\frac{\tan 2x}{\sqrt x}$ at $\frac\pi8$ | $2x=\frac\pi4$ | $\frac{\pi-1}{2(\pi/8)^{3/2}}\approx 4.3512801365$ |
| $\frac{\sin 3x}{\sqrt x}$ at $\frac\pi6$ | $3x=\frac\pi2$ | $-\frac{1}{2(\pi/6)^{3/2}}\approx -1.3196904407$ |

All eight verified.
**Read the second column, not the third.** Every point in this family was chosen so that the *inner function* lands on a special angle, and the outer arithmetic is then one of a handful of exact values.
The skill is recognising $\frac{\sqrt\pi}{2}\Rightarrow\frac\pi4$ and $\sqrt{\pi/3}\Rightarrow\frac\pi3$ and $\frac{\pi^2}{16}\Rightarrow\frac\pi4$ instantly.

**Row 8 is a warning, and it earned its place by refuting a draft of this document.**
An earlier version of the verification claimed the value $-\frac{\pi}{2(\pi/6)^{3/2}}$ there.
At $x=\frac\pi6$ the angle $3x$ is $\frac\pi2$, so $\cos(3x)=0$ and the entire $6x\cos(3x)$ term dies, leaving only $-\sin(3x)=-1$ and no $\pi$ at all.
The check refuted the claim and the derivative was right the whole time.
When a designed point makes a factor vanish, the surviving expression is usually much simpler than you expected, so recompute rather than pattern-matching the previous row.

### Family 7 - naming when a rule is nested inside another rule

The trigger is a rule whose $u$ or $v$ needs its own rule.
The tool is a sentence structure, and it is the one thing in section 5's full-credit form that is not obvious.

> "By the **quotient rule** with $u=\dots$ and $v=\dots$, where $u'$ requires the **chain rule** and $v'$ the **power rule**."

Write the outer rule first and subordinate the inner ones to it.
Listing them flat, as "quotient, chain, power", is acceptable, but the subordinated version shows the marker the *structure* you saw, and the structure is what the last-operation test produces.

| function | flat list | structured sentence |
| :--- | :--- | :--- |
| $\frac{\tan 2x}{\sqrt x}$ | quotient, chain, power | quotient, whose numerator needs the chain rule and whose denominator needs the power rule |
| $\frac{\sqrt{x^2-1}}{x^2-2x-8}$ | quotient, chain | quotient, whose numerator needs the chain rule |
| $\sec^2\left(\frac{x+1}{x-2}\right)$ | chain, chain, quotient | chain with a power outer, then a chain with a $\sec$ outer, whose inner needs the quotient rule |
| $\sin x\cos\left(\sin x^2\right)$ | product, chain, chain | product, whose second factor is a three-layer chain |

Rows 2 to 4 are Q8.3's parts (d), (e) and (a), which is the point: if Q8.4's naming instruction had been printed on Final 1 instead, this is what it would have demanded there.

### Family 8 - where naming goes wrong while the calculus goes right

The trigger is a correct derivative and a wrong label.
This family has no mathematics in it at all, which is exactly why it is easy to skip and expensive to skip.

| the labelling error | what it looks like | why it happens |
| :--- | :--- | :--- |
| naming a rule you did not use | "product rule" written above a quotient-rule computation | reciting the rule list instead of reading your own work |
| omitting the power rule on a root | naming "quotient, chain" on part (a) | $\sqrt x$ does not look like $x^n$ |
| collapsing two chain rules into one | naming "chain rule" once on part (b) | the two applications are adjacent and feel like one move |
| naming rules for a route you abandoned | naming "quotient" after you rewrote as a product | the list was written before the algebra settled |
| naming nothing | a correct bare derivative | forgetting the second sentence of the question |

**The last row is the most common and the most avoidable.**
The instruction to name the rules is the *second* sentence of a three-sentence question, and it is easy to read the first and third and skip the middle.
Underline it when you first read the paper.

## 9. The trap list

Ranked by how often each one actually costs marks on this question.

1. **Not naming the rules at all.**
   The question asks in writing, the request is easy to read past, and it is half of what makes this item different from the other three.
   Cost: whatever the naming is worth, which is unknown because no rubric exists, but it is not zero on a question that asks for it.
2. **Dropping the inner $2x$ in part (b).**
   You write $-3\cos^2\left(x^2\right)\sin\left(x^2\right)$ and it looks completely reasonable.
   At the exam's own point it gives $-1.0606602$ instead of $-1.8799712$.
   Catch it with the factor count: three layers, three factors, and the coefficient must be $6$.
3. **Substituting $x=\frac{\sqrt\pi}{2}$ before differentiating.**
   Then you are differentiating the constant $\cos^3\left(\frac\pi4\right)$ and the answer is $0$.
   This is a total loss on part (b) and it comes from reading the vertical bar as an instruction about when to substitute rather than where to evaluate.
4. **Writing the quotient rule as $uv' - u'v$.**
   The sign flips and the answer is exactly wrong.
   Write $\frac{u'v-uv'}{v^2}$ with blanks before naming $u$ and $v$, every time.
5. **Forgetting the power rule on $\sqrt x$ and using $v'=1$.**
   Invisible at $x=\frac14$, which is why section 6 forbids checking there.
6. **Squaring errors at $\frac\pi4$.**
   $\cos^2\left(\frac\pi4\right)=\frac12$, not $\frac{\sqrt2}{2}$.
   Getting this wrong scales the final answer by $\sqrt2$ and it happens at the very last step, when attention is lowest.
7. **Misreading $\cos^3\left(x^2\right)$ as $\cos\left(x^6\right)$.**
   These are different functions, not just different derivatives: at $x=1$ they are $0.158$ and $0.540$.
8. **Naming a rule you did not use.**
   A false positive claim about your method, and worse than silence.
9. **Simplifying part (a) into a single fraction and slipping.**
   The permission not to simplify is printed; take it.
10. **Bracketing errors in Möbius.**
    `x^3/2` is not `x^(3/2)`, and neither raises an error.

## 12. Closing the category: one procedure for all four questions

This is the last tutorial in category 8, so it is worth saying plainly what the four of them add up to.

### The single decision procedure

Everything in the category is one loop, and the four questions each stress a different part of it.

> 1. **If a point is given, ignore it** until step 5.
> 2. **Ask what the last operation is.** That names the rule. Write the name down.
> 3. **Write the rule with blanks**, then fill in $u$ and $v$, or the outer and inner.
> 4. **Recurse** on every piece the rule handed you, adding one ledger line and one name per turn, until every piece is $x^n$ or a constant.
> 5. **Assemble**, then substitute the point if there was one, then run the second differentiation if one was asked for.
> 6. **Count**: layers against factors.
> 7. **Check** with a centred difference at $h=0.001$, at a point you chose *after* looking at your chain factors.
> 8. **Stop simplifying.** Name generously, simplify stingily.

Steps 1 to 4 are Q8.1's.
Step 5's second clause is Q8.2's.
Steps 4 and 6, in ledger form, are Q8.3's.
Step 2's "write the name down" and step 8's second clause are Q8.4's.
There is nothing else.

### Which question teaches what

| the idea | taught in | why it lives there |
| :--- | :--- | :--- |
| the **last-operation test** for rule selection | **Q8.1** | the cheapest item, so the machinery is learned where the stakes are lowest |
| the **simplification policy** | **Q8.1** | all four items print the same permission |
| the **eight-second centred-difference check** | **Q8.1** | it is the only check that works across the whole category |
| running the procedure **twice**, and the rule changing under you | **Q8.2** | the only item asking for a second derivative |
| the **measured $h$** for a difference check, and why smaller is not safer | **Q8.2** | a second difference divides by $h^2$, so it is where the measurement matters |
| the **layer ledger** and the **factor count** | **Q8.3** | the only item with three-deep nesting on every part |
| a **dropped factor is invisible where that factor is 1** | **Q8.3** | the deep-nesting item is where dropped factors happen |
| the **rule-name vocabulary** and its granularity | **Q8.4** | the only item that grades the names |
| **the route changes the rule list**, so the route is part of the answer | **Q8.4** | only meaningful once naming is graded |
| **name generously, simplify stingily** | **Q8.4** | the two policies only collide here |
