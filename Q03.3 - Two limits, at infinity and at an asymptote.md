# Q3.3 - Two limits, at infinity and at an asymptote

**The question (Final Exam 2, Q1, 8 points).**
Evaluate the following limits, no credit will be given for unjustified answers.
If a limit does not exist explain why.

- a. $\displaystyle\lim_{x \to \infty}\left(\frac{3x^2 - 4}{4 + 2x + 2x^4}\right)\sin(x)$
- b. $\displaystyle\lim_{x \to 5\pi/2}\tan x$

**The answers.**

$$\textbf{(a)}\quad \lim_{x \to \infty}\left(\frac{3x^2-4}{4+2x+2x^4}\right)\sin x = 0
\qquad\text{by the Squeeze Theorem}$$

$$\textbf{(b)}\quad \lim_{x \to 5\pi/2}\tan x \ \textbf{ does not exist},
\qquad \lim_{x\to 5\pi/2^{-}}\tan x = +\infty,\quad \lim_{x\to 5\pi/2^{+}}\tan x = -\infty$$

**What to type into Möbius:** `0` for part (a).
For part (b) there is no number to type: the answer is that the limit does not exist, and the
one-sided values are what earn the marks.
See Section 7, because this is the one question on the paper where the *answer* is a sentence.

## 0. The 30-second version

Two different questions wearing one number.
Part (a) asks what the graph does far to the right, part (b) asks what it does next to a wall.

```
(a)  lim (3x^2-4)/(2x^4+2x+4) * sin(x)   as x -> inf
  -> sin(x) has NO limit, so the product law is ILLEGAL. Do not use it.
  -> but |sin(x)| <= 1 always, so sin(x) is BOUNDED
  -> the rational part: deg 2 on top, deg 4 on bottom, so it -> 0
  -> bounded x vanishing = SQUEEZE.  -R(x) <= R(x)sin x <= R(x),  both ends -> 0
  ANSWER 0

(b)  lim tan x   as x -> 5pi/2
  -> is 5pi/2 an asymptote of tan? tan blows up at pi/2 + k*pi.

  -> the two sides disagree, so you may not even write "= inf"

```

## 1. What this question is really testing

This is question 1 of Final Exam 2 and it carries 8 points for two limits.
That is 4 points each, which is the highest per-limit value anywhere on the four sample papers:
Q3.1 spreads 5 limits over its allocation and Q3.2 spreads 6.
The examiner has deliberately picked the two limits that cannot be done by substituting and
factoring, and has then written "no credit will be given for unjustified answers" across the top.

The single insight that makes both parts one question: **each part is an asymptote question.**

| Part | What it is really asking | Asymptote language |
| :--- | :--- | :--- |
| (a) | what does the graph settle down to far to the right | does it have a **horizontal** asymptote, and at what height |
| (b) | what does the graph do as it approaches a value the function cannot take | it has a **vertical** asymptote there, and which way does each side go |

That is why the same paper also asks Q4.1, "find the vertical and horizontal asymptotes".
Q4.1 is this question with the wrapper removed.
If you can do Q3.3 you can do Q4.1 in one line, and the reverse is also true.

| Reflex | Where it comes back |
| :--- | :--- |

## 2. The five things you must have cold

None of these can be derived under time pressure.
They have to be recall.

### 2.1 The degree rule for a rational function as $x \to \pm\infty$

Compare only the **leading** terms.
Everything else is noise.

| Case | Limit | Example |
| :--- | :--- | :--- |
| $\deg(\text{top}) < \deg(\text{bottom})$ | $0$ | $\dfrac{3x^2-4}{2x^4+2x+4} \to 0$ |
| $\deg(\text{top}) = \deg(\text{bottom})$ | ratio of leading coefficients | $\dfrac{3x^2+1}{2x^2-5} \to \dfrac32$ |
| $\deg(\text{top}) > \deg(\text{bottom})$ | $\pm\infty$, sign from the leading coefficients | $\dfrac{5-2x^3}{x^2+2} \to -\infty$ |

The mechanism, if you ever need to show it, is: divide top and bottom by the highest power in the
**bottom**.

$$\frac{3x^2-4}{2x^4+2x+4} = \frac{\dfrac{3}{x^2}-\dfrac{4}{x^4}}{2+\dfrac{2}{x^3}+\dfrac{4}{x^4}}
\longrightarrow \frac{0-0}{2+0+0} = 0$$

The rate matters more than you would think, so it is worth knowing: this one behaves like
$\tfrac{3}{2}x^{-2}$.
Verified: $x^2 R(x) \to 3/2$.

### 2.2 The Squeeze Theorem, and the exact shape you need it in

If $g(x) \le f(x) \le h(x)$ near the point of interest, and $g$ and $h$ both tend to the same $L$,
then $f$ tends to $L$ as well.

The only version this course asks for is the corollary:

$$\textbf{bounded} \times \textbf{something that tends to } 0 \ = \ 0$$

Concretely, if $|u(x)| \le M$ for all $x$ and $v(x) \to 0$, then $u(x)v(x) \to 0$, because

$$-M\lvert v(x)\rvert \ \le\ u(x)v(x)\ \le\ M\lvert v(x)\rvert$$

and both outer expressions tend to $0$.

**Bounded is load-bearing.**
It is not enough for one factor to merely "not blow up fast".
Verified contrast: $R(x)\cdot x^3 \to \infty$ even though $R(x) \to 0$, because $x^3$ is not bounded.

### 2.3 Where each trig function has its vertical asymptotes

This table is the whole of part (b), and it contains the trap that costs the most marks.

| Function | Equals | Asymptotes where | Period | Do all asymptotes look alike? |
| :--- | :--- | :--- | :--- | :--- |
| $\tan x$ | $\dfrac{\sin x}{\cos x}$ | $\cos x = 0$, so $x = \dfrac{\pi}{2}+k\pi$ | $\pi$ | **Yes.** Always $+\infty$ left, $-\infty$ right |
| $\cot x$ | $\dfrac{\cos x}{\sin x}$ | $\sin x = 0$, so $x = k\pi$ | $\pi$ | **Yes.** Always $-\infty$ left, $+\infty$ right |
| $\sec x$ | $\dfrac{1}{\cos x}$ | $x = \dfrac{\pi}{2}+k\pi$ | $2\pi$ | **No.** They alternate with $k$ |
| $\csc x$ | $\dfrac{1}{\sin x}$ | $x = k\pi$ | $2\pi$ | **No.** They alternate with $k$ |

The reason is the period, and it is worth one sentence of thought rather than memorising four rows.
$\tan$ and $\cot$ repeat every $\pi$, and their asymptotes are also spaced $\pi$ apart, so every
asymptote is a translate of every other one and they must all behave identically.
$\sec$ and $\csc$ repeat every $2\pi$ while their asymptotes are spaced $\pi$ apart, so consecutive
asymptotes are *not* translates of each other and the signs flip between them.

All of this is verified: 5 $\tan$ asymptotes and 4 $\cot$ asymptotes all identical, and $\sec$ and
$\csc$ confirmed alternating at three consecutive asymptotes each.

### 2.4 "Does not exist" versus "$= \infty$", which are not the same answer

This distinction is worth marks on this specific question and students routinely lose them.

Strictly, $\lim = +\infty$ already means the limit does not exist as a real number.
But it says *more* than "does not exist": it says the function grows without bound in a single,
definite direction.
The convention this course uses, visible in the sample papers, is to give the most informative true
statement.

| Situation | What to write | Example |
| :--- | :--- | :--- |
| Both one-sided limits are $+\infty$ | $= +\infty$, and add "grows without bound" | $\dfrac{\cos \pi x}{(x-2)^2}$ at $x=2$ |
| Both are $-\infty$ | $= -\infty$ | $-\dfrac{1}{x^2}$ at $x=0$ |
| The two sides have **opposite** signs | **DNE**, and quote both one-sided values | $\tan x$ at $5\pi/2$, which is part (b) |
| The two sides are finite but different | **DNE**, jump discontinuity | $\dfrac{\lvert x\rvert}{x}$ at $0$ |
| The function oscillates forever | **DNE**, and say it oscillates | $\sin x$ as $x \to \infty$ |

For part (b) you must not write $\infty$.
Writing "$=\infty$" claims both sides go the same way, and here they do not.

### 2.5 The two facts about $\sin$ and $\cos$ that this question uses

$$\lvert \sin x\rvert \le 1 \quad\text{and}\quad \lvert\cos x\rvert \le 1 \quad \text{for every real } x$$

and, separately,

$$\lim_{x\to\infty}\sin x \ \text{ does not exist, because } \sin x \text{ keeps returning to } -1 \text{ and } +1.$$

Both facts are used in part (a), and they pull in opposite directions.
The second one forbids the product law.
The first one rescues the problem anyway.
Verified: sampling $\sin$ over $x \in [1000, 1007]$ fills $[-1, 1]$, so no limit exists.

## 3. The universal procedure

> **Step 1. Substitute, at least in your head.**
> Put the target value in and see what shape you get. That shape names the method.
>
> **Step 2. Classify by the shape.** Use the table below. Do not start algebra before this step.
>
> **Step 3. Apply the one tool the shape names.**
>
> **Step 4. If anything came out infinite or undefined, test the two sides separately.**
> A one-sided test is the only way to tell $+\infty$ from DNE.
>
> **Step 5. Sanity check the magnitude and the sign independently of the algebra.**
>
> **Step 6. Write the justification sentence, or type the answer and preview it.**

### The classify table

This is Step 2, and it is the whole skill.

| What substitution gives you | You are in | Tool |
| :--- | :--- | :--- |
| a number | nothing special | that number is the answer, done |
| $\dfrac{0}{0}$ | an indeterminate form | factor, then conjugate, then common denominator, then trig identity |
| $\dfrac{k}{0}$ with $k \ne 0$ | a **pole**, not an indeterminate form | test both sides for the sign; never try to factor |
| $\dfrac{\infty}{\infty}$ or a rational as $x\to\pm\infty$ | end behaviour | compare degrees (Section 2.1) |
| $(\text{bounded}) \times (\text{something} \to 0)$ | a squeeze | the answer is $0$ |
| $(\text{bounded}) \times (\text{something} \to L\neq 0)$ | oscillation that never settles | **DNE**, and say it oscillates |
| a trig function at its own asymptote | a pole again | rewrite as $\sin/\cos$ and test both sides |

Part (a) is row 5.
Part (b) is row 3, reached through row 7.

**The most common single error on this whole topic** is treating $\tfrac{k}{0}$ as if it were
$\tfrac{0}{0}$ and hunting for a factor to cancel.
There is nothing to cancel.
$\tfrac{k}{0}$ with $k\ne0$ is always an infinite one-sided behaviour, and the only remaining
question is the sign on each side.

## 4. Q3.3 worked several ways

### Part (a), Route A - squeeze, which is the intended route

Name the rational factor so you can talk about it.

$$R(x) = \frac{3x^2-4}{4+2x+2x^4}, \qquad \text{so the question is } \lim_{x\to\infty} R(x)\sin x.$$

**Step 1.** $R(x) \to 0$ by the degree rule: top degree 2, bottom degree 4.

**Step 2.** For $x > 2/\sqrt3 \approx 1.1547$ the numerator $3x^2-4$ is positive, and the denominator
is positive for all $x>0$, so $R(x) > 0$ once $x$ is past that point.
Since we are taking $x\to\infty$, we may assume $x$ is past it.

**Step 3.** Because $-1 \le \sin x \le 1$ and $R(x) > 0$, multiplying through by $R(x)$ preserves the
inequalities:

$$-R(x) \ \le\ R(x)\sin x\ \le\ R(x)$$

**Step 4.** Both outer functions tend to $0$.
By the Squeeze Theorem the middle one does too.

$$\lim_{x\to\infty}\left(\frac{3x^2-4}{4+2x+2x^4}\right)\sin x = 0$$

Verified three ways: the inequality $|R(x)\sin x| \le R(x)$ holds on 4000 samples across
$[10, 1490]$ with zero violations; the supremum of $|R\sin|$ over a *full period* of $\sin$ shrinks
like $1.5/x^2$; and the same conclusion holds as $x \to -\infty$.

### Part (a), Route B - the product law, which is illegal here

It is worth writing this out once, because it is the route most students take and it is not a slip
of arithmetic, it is an invalid step.

$$\lim (R(x)\sin x) \overset{?}{=} \left(\lim R(x)\right)\cdot\left(\lim \sin x\right)
= 0 \cdot \left(\lim_{x\to\infty}\sin x\right)$$

The product law requires **both** limits to exist.
$\lim_{x\to\infty}\sin x$ does not exist, so the law does not apply and the line above is not
mathematics.

It happens to reach the right answer, which is exactly why it is dangerous: it will be marked wrong
on a paper that says "no credit for unjustified answers", and the identical reasoning gives the
*wrong* answer on the variation in Family 3 below, where the rational factor tends to $3/2$ instead
of $0$.

You may write "$0 \times \text{bounded} = 0$" as shorthand for the squeeze, and that is fine.
You may not write "$0 \times \lim \sin x$".

### Part (a), Route C - L'Hôpital, which does not apply

Substituting gives $0 \cdot (\text{no limit})$, which is not $\tfrac00$ and not $\tfrac\infty\infty$.
L'Hôpital's rule has no indeterminate quotient to work on.
If you force the expression into a quotient as $\dfrac{\sin x}{1/R(x)}$, the top has no limit, so the
hypotheses still fail, and differentiating produces $\dfrac{\cos x}{(1/R)'}$, which oscillates
forever and never converges.
The rule cannot resolve this one.

### Part (a), Route D - bound first, then compare

A slightly different framing that some find faster.
Since $|\sin x| \le 1$,

$$0 \le \left\lvert R(x)\sin x \right\rvert \le \lvert R(x)\rvert = R(x) \longrightarrow 0,$$

so $|R(x)\sin x| \to 0$, and a quantity whose absolute value tends to $0$ tends to $0$.
This is the same squeeze with the modulus taken first, and it is one line shorter to write.

### Part (a), route comparison

| Route | Valid | Lines | Risk |
| :--- | :--- | :--- | :--- |
| A, squeeze with explicit inequalities | yes | 4 | none, but you must state $R>0$ to keep the inequality direction |
| B, product law | **no** | 1 | right answer, zero marks, and it fails outright on the Family 3 variation |
| C, L'Hôpital | **no** | - | hypotheses not met; leads nowhere |
| D, squeeze on the modulus | yes | 3 | none; avoids the sign-of-$R$ discussion entirely |

**Use Route D under pressure, and Route A if the paper wants the Squeeze Theorem named.**
Route D sidesteps having to argue that $R(x)>0$, because $|R(x)|$ is non-negative by construction.

### Part (b), Route A - rewrite as $\sin/\cos$ and test the sides

**Step 1.** Is $5\pi/2$ actually an asymptote?
$\tan$ blows up where $\cos = 0$, that is at $x = \tfrac\pi2 + k\pi$.
Setting $\tfrac\pi2+k\pi = \tfrac{5\pi}{2}$ gives $k\pi = 2\pi$, so $k = 2$.
Yes, it is.

**Step 2.** Substitute to see the shape.

$$\tan\frac{5\pi}{2} = \frac{\sin(5\pi/2)}{\cos(5\pi/2)} = \frac{1}{0}$$

This is $k/0$ with $k = 1 \ne 0$, so it is a pole, not an indeterminate form.
There is nothing to factor.
Verified: $\sin(5\pi/2)=1$, $\cos(5\pi/2)=0$.

**Step 3.** Test each side by asking only about the sign of $\cos$.

Just to the **left** of $5\pi/2$, the angle is in the second quadrant of its turn
(coterminal with just under $\pi/2$), where $\cos$ is small and **positive**.
So $\tan = \dfrac{\approx 1}{0^+} \to +\infty$.

Just to the **right**, the angle has passed $5\pi/2$, where $\cos$ is small and **negative**.
So $\tan = \dfrac{\approx 1}{0^-} \to -\infty$.

**Step 4.** The two one-sided limits differ, and they differ in sign, so the two-sided limit does not
exist and cannot be written as $\pm\infty$.

$$\lim_{x\to 5\pi/2^{-}}\tan x = +\infty,\qquad \lim_{x\to 5\pi/2^{+}}\tan x = -\infty,
\qquad \lim_{x\to 5\pi/2}\tan x \ \text{DNE}$$

Verified at $h = 10^{-3}, 10^{-5}, 10^{-7}$, and the *size* checked too:
$\tan(5\pi/2 - h) \approx +1/h$ and $\tan(5\pi/2+h)\approx -1/h$.

### Part (b), Route B - reduce to a coterminal angle first

$$\frac{5\pi}{2} = 450^\circ = 360^\circ + 90^\circ, \quad\text{so } \frac{5\pi}{2}
\text{ is coterminal with } \frac{\pi}{2}.$$

$\tan$ has period $\pi$, so $\tan\left(\tfrac{5\pi}{2}\right) = \tan\left(\tfrac{\pi}{2}\right)$ and
the behaviour near $5\pi/2$ is an exact copy of the behaviour near $\pi/2$.
You already know the graph of $\tan$ near $\pi/2$: it climbs to $+\infty$ on the left and comes up
from $-\infty$ on the right.
Done.

This is the fastest route if you trust your picture of $\tan$, and it is worth two lines of writing.
Verified: subtracting $2\pi$ lands exactly on $\pi/2$, and all five $\tan$ asymptotes tested behave
identically.

### Part (b), Route C - the derivative or graph-shape argument

$\tan' = \sec^2 x > 0$ everywhere it is defined, so $\tan$ is increasing on each of its branches.
An increasing function on $\left(\tfrac{3\pi}{2}, \tfrac{5\pi}{2}\right)$ that is unbounded must run
to $+\infty$ at the right end of that interval, which is the left-hand approach to $5\pi/2$.
By the same argument on the next branch it comes from $-\infty$.

Correct, but it takes longer than Route B and needs the branch endpoints stated carefully.
Use it only as a check.

### Part (b), route comparison

| Route | Valid | Lines | Risk |
| :--- | :--- | :--- | :--- |
| A, $\sin/\cos$ and sign of $\cos$ | yes | 4 | none; it is the only route that also works for $\sec$ and $\csc$ |
| B, coterminal reduction to $\pi/2$ | yes | 2 | you must know the graph near $\pi/2$ cold, and that $\tan$ has period $\pi$ not $2\pi$ |
| C, monotonicity | yes | 5 | slow, and easy to fumble which branch you are on |

**Use Route B under pressure and confirm with Route A's sign test.**
Route B gets you there in two lines, and Route A's "what is the sign of $\cos$ on each side" is the
eight-second check that catches a flipped answer.
Do not rely on Route B alone for $\sec$ or $\csc$, where coterminal reduction is not enough because
their asymptotes alternate.

## 5. The exam-ready write-up

These are the sentences that earn the method marks.
Learn the shape, not the words.

**Part (a), four sentences.**

> The factor $\dfrac{3x^2-4}{4+2x+2x^4}$ has numerator of degree 2 and denominator of degree 4, so it
> tends to $0$ as $x\to\infty$.
> The factor $\sin x$ has no limit as $x\to\infty$, so the product rule for limits cannot be applied.
> However $\lvert\sin x\rvert\le 1$ for all $x$, so
> $\left\lvert\dfrac{3x^2-4}{4+2x+2x^4}\sin x\right\rvert \le \dfrac{3x^2-4}{4+2x+2x^4}$ for
> $x > 2/\sqrt3$, and the right-hand side tends to $0$.
> By the Squeeze Theorem the limit is $0$.

Sentence two is the one that is worth marks and the one everybody omits.
It is the sentence that shows you knew the easy route was illegal.

**Part (b), four sentences.**

> $\tan x = \dfrac{\sin x}{\cos x}$ is undefined where $\cos x = 0$, that is at
> $x = \dfrac{\pi}{2}+k\pi$, and $\dfrac{5\pi}{2} = \dfrac{\pi}{2}+2\pi$ is such a point.
> At $x = \dfrac{5\pi}{2}$ we have $\sin x = 1$ and $\cos x = 0$, so this is of the form $1/0$ and not
> an indeterminate form.
> As $x \to \dfrac{5\pi}{2}^{-}$, $\cos x \to 0^{+}$, so $\tan x \to +\infty$; as
> $x \to \dfrac{5\pi}{2}^{+}$, $\cos x \to 0^{-}$, so $\tan x \to -\infty$.
> The one-sided limits are different, so the limit does not exist; $x = \dfrac{5\pi}{2}$ is a vertical
> asymptote.

Sentence four is the "explain why" the question explicitly asked for.
Note it does *not* say "$= \infty$", because that would be a false claim about both sides.

## 6. Verify before you commit

Eight seconds each, and between them they catch nearly every error available on this question.

**Part (a): the magnitude check.**
At $x = 100$, $R(x) \approx 1.5/100^2 = 1.5\times10^{-4}$, and $\sin$ can only scale that by at most
$1$.
So the expression is already smaller than $0.0002$ at $x=100$, and it keeps shrinking like $1/x^2$.
An answer of $0$ is plausible; an answer of $3/2$ or $\infty$ is not.

**Part (a): the two cheap invariants.**

1. **The bounded factor can never change the limit of a vanishing factor.** If your answer is
   non-zero, you have used the oscillating factor as if it grew. It cannot: it lives in $[-1,1]$.
2. **Degrees.** $2 < 4$, so the rational part is heading to $0$, not to a ratio. If you wrote $3/2$
   you compared the wrong pair of terms, which is the Family 3 answer, not this one.

**Part (b): the sign check, done independently of the algebra.**
Do not re-derive it.
Picture the graph of $\tan$ near any asymptote: it goes *up* on the left and comes *up from below* on
the right.
Now check that your algebra says the same thing.
Two independent routes to the same sign is what makes this a check rather than a restatement.

**Part (b): the "is it even an asymptote" invariant.**
Before doing any sign work, confirm $\cos$ is actually $0$ there.
Verified trap: at $x = 2\pi$ and $x = 3\pi$, $\tan$ is perfectly well behaved and the answer is
simply $0$.
A number containing $\pi$ is not automatically an asymptote.

**The numbers worth memorising outright.**

$$\frac{5\pi}{2} = 450^\circ \equiv 90^\circ, \qquad \tan\!\left(\frac{\pi}{2}+k\pi\right)
\text{ undefined}, \qquad \cot(k\pi) \text{ undefined}, \qquad \frac{3}{2} = \text{the } R \text{ rate}$$

If you can say "450 degrees is 90 degrees" without hesitating, part (b) takes twenty seconds.

## 8. The variation catalog

This is the part that makes the question repeatable.
Read each table as **structure**, not as a list of facts to memorise.
Everything below has been numerically verified.

The ten families are organised by the tool they force, and they fall into two halves that mirror the
two halves of Q3.3: families 0, 1, 3, 6, 7 and 8 are about $x \to \pm\infty$, and families 2, 4, 5
and 9 are about approaching a finite point.

### Family 0 - a pure rational function at infinity

**Trigger.** A ratio of polynomials, $x\to\pm\infty$, and no trig anywhere.

**Tool.** The degree rule from Section 2.1. Do not divide anything out longhand.

**Worked shape.** Read the two leading terms, ignore everything else, done in one line.

| Limit | Degrees | Answer | Why |
| :--- | :--- | :--- | :--- |
| $\lim_{x\to\infty}\dfrac{3x^2-4}{2x^4+2x+4}$ | $2 < 4$ | $0$ | bottom wins |
| $\lim_{x\to\infty}\dfrac{x^2-1}{x^3+x}$ | $2 < 3$ | $0$ | bottom wins |
| $\lim_{x\to\infty}\dfrac{2x+1}{x^2}$ | $1 < 2$ | $0$ | bottom wins |
| $\lim_{x\to\infty}\dfrac{3x^2+1}{2x^2-5}$ | $2 = 2$ | $\dfrac32$ | $3/2$, leading coefficients |
| $\lim_{x\to\infty}\dfrac{4x^3-x}{2x^3+7}$ | $3 = 3$ | $2$ | $4/2$ |
| $\lim_{x\to\infty}\dfrac{5-2x^3}{x^2+2}$ **[Q3.2d]** | $3 > 2$ | $-\infty$ | top wins, leading coefficient $-2$ |
| $\lim_{x\to-\infty}\dfrac{5-2x^3}{x^2+2}$ | $3 > 2$ | $+\infty$ | odd power flips the sign |

**Read this as structure.** There are only three answers in the whole family: $0$, a ratio, or
$\pm\infty$. Which one you get is decided before you write anything, by comparing two integers.

### Family 1 - bounded times vanishing, at infinity. This is Q3.3(a)

**Trigger.** A factor that oscillates and never settles ($\sin$, $\cos$, of anything) multiplied by a
factor that tends to $0$.

**Tool.** Squeeze. The answer is always $0$.

**Worked shape.** State the bound, state that the other factor vanishes, invoke the Squeeze Theorem.

| Limit as $x\to\infty$ | Vanishing factor | Answer |
| :--- | :--- | :--- |
| $\left(\dfrac{3x^2-4}{2x^4+2x+4}\right)\sin x$ **[Q3.3a]** | $\sim 1.5/x^2$ | $0$ |
| $\dfrac{\sin x}{x}$ | $1/x$ | $0$ |
| $\dfrac{\cos x}{x^2+1}$ | $1/(x^2+1)$ | $0$ |
| $\dfrac{\sin x}{x^2}$ | $1/x^2$ | $0$ |
| $\left(\dfrac{2x+1}{x^2}\right)\cos(x^3)$ | $\sim 2/x$ | $0$ |
| $\dfrac{\sin x + \cos x}{\sqrt x}$ | $\sqrt2/\sqrt x$ | $0$ |

**Read this as structure.** Every entry has the same answer, $0$, and the same one-line reason.
The only thing that varies is the decoration inside the oscillating factor, and it never matters:
$\cos(x^3)$ is exactly as bounded as $\cos x$.
That is the point of the family, and it is why the examiner can dress it up freely.

### Family 2 - bounded times vanishing, at a finite point

**Trigger.** Oscillation at a *point* rather than at infinity, which in practice means
$\sin(1/x)$ or $\cos(1/x)$ as $x\to 0$.

**Tool.** The same squeeze. The answer is again $0$.

| Limit as $x\to 0$ | Bound used | Answer |
| :--- | :--- | :--- |
| $x\sin\dfrac1x$ | $\lvert \cdot\rvert \le \lvert x\rvert$ | $0$ |
| $x^2\cos\dfrac1x$ | $\lvert \cdot\rvert \le x^2$ | $0$ |
| $x^2\sin\dfrac{1}{x^3}$ | $\lvert \cdot\rvert \le x^2$ | $0$ |
| $\sqrt x\,\sin\dfrac1x$ (from the right) | $\lvert \cdot\rvert \le \sqrt x$ | $0$ |

**Read this as structure.** The oscillating factor gets wilder as you go down the table, and the
answer does not move, because wildness is irrelevant once you know the amplitude is capped at 1.

### Family 3 - bounded times NON-vanishing. The trap twin of Family 1

**Trigger.** Looks exactly like Family 1, but the other factor tends to something **non-zero**.

**Tool.** No squeeze is available. The answer is DNE, because the product oscillates forever.

| Limit | Amplitude tends to | Answer |
| :--- | :--- | :--- |
| $\lim_{x\to\infty}\sin x$ | $1$ | DNE, oscillates in $[-1,1]$ |
| $\lim_{x\to\infty}\cos x$ | $1$ | DNE, oscillates in $[-1,1]$ |
| $\lim_{x\to\infty}\left(\dfrac{3x^2+1}{2x^2-5}\right)\sin x$ | $\dfrac32$ | DNE, oscillates in $\left[-\tfrac32,\tfrac32\right]$ |
| $\lim_{x\to 0}\sin\dfrac1x$ | $1$ | DNE, oscillates in $[-1,1]$ |
| $\lim_{x\to\infty} x\sin x$ | grows | DNE, unbounded oscillation |

**This is the most important family in the document,** because it is one character away from Q3.3(a)
and has a different answer.
Change the exponent in Q3.3(a)'s denominator from $2x^4$ to $2x^2$ and the answer stops being $0$ and
becomes DNE.
The illegal Route B from Section 4 gives $0$ for every row of this table, all of them wrong.
Verified: all five rows sampled and confirmed to fill their stated interval.

### Family 4 - a trig function at its own asymptote. This is Q3.3(b)

**Trigger.** $\tan$, $\cot$, $\sec$ or $\csc$ evaluated at a point where its denominator vanishes.

**Tool.** Rewrite as $\sin/\cos$, confirm the numerator is non-zero, then test the sign of the
denominator on each side.

| Limit | Left | Right | Answer |
| :--- | :--- | :--- | :--- |
| $\tan x$ at $\pi/2$ | $+\infty$ | $-\infty$ | DNE |
| $\tan x$ at $3\pi/2$ | $+\infty$ | $-\infty$ | DNE |
| $\tan x$ at $5\pi/2$ **[Q3.3b]** | $+\infty$ | $-\infty$ | DNE |
| $\tan x$ at $-\pi/2$ | $+\infty$ | $-\infty$ | DNE |
| $\tan x$ at $7\pi/2$ | $+\infty$ | $-\infty$ | DNE |
| $\cot x$ at $0$ | $-\infty$ | $+\infty$ | DNE |
| $\cot x$ at $\pi$ | $-\infty$ | $+\infty$ | DNE |
| $\cot x$ at $2\pi$ | $-\infty$ | $+\infty$ | DNE |
| $\sec x$ at $\pi/2$ | $+\infty$ | $-\infty$ | DNE |
| $\sec x$ at $3\pi/2$ | $-\infty$ | $+\infty$ | DNE, **signs flipped** |
| $\sec x$ at $5\pi/2$ | $+\infty$ | $-\infty$ | DNE, flipped back |
| $\csc x$ at $0$ | $-\infty$ | $+\infty$ | DNE |
| $\csc x$ at $\pi$ | $+\infty$ | $-\infty$ | DNE, **signs flipped** |
| $\csc x$ at $2\pi$ | $-\infty$ | $+\infty$ | DNE, flipped back |

**Read this as structure, and count the distinct behaviours: there are only two.**
Either it is $+\infty$ then $-\infty$, or it is $-\infty$ then $+\infty$.
The whole table is generated by two rules: $\tan$ and $\cot$ never change (period $\pi$), while
$\sec$ and $\csc$ alternate at consecutive asymptotes (period $2\pi$).

**The squared and absolute versions do not split**, and there the answer is a legitimate $+\infty$:

| Limit at $5\pi/2$ | Both sides | Answer |
| :--- | :--- | :--- |
| $\tan^2 x$ | $+\infty$ | $= +\infty$, not DNE-with-disagreement |
| $\sec^2 x$ | $+\infty$ | $= +\infty$ |
| $\lvert\tan x\rvert$ | $+\infty$ | $= +\infty$ |
| $-\tan^2 x$ | $-\infty$ | $= -\infty$ |

**And the trap pair, which is the sharpest variation the examiner has available:**

| Limit | Answer | Why it catches people |
| :--- | :--- | :--- |
| $\lim_{x\to 5\pi/2}\cot x$ | $0$ | the *same* $5\pi/2$ that destroys $\tan$ is an ordinary point for $\cot$ |
| $\lim_{x\to 2\pi}\tan x$ | $0$ | a multiple of $\pi$, but $\cos(2\pi)=1\neq0$, so no asymptote |
| $\lim_{x\to 3\pi}\tan x$ | $0$ | same |
| $\lim_{x\to \pi}\sec x$ | $-1$ | ordinary point, just substitute |
| $\lim_{x\to \pi/2}\csc x$ | $1$ | ordinary point, just substitute |

Never conclude "asymptote" from the shape of the number.
Check that the denominator is actually zero.
Verified: all five of these are ordinary two-sided limits with the stated finite values.

### Family 5 - a rational function at a zero of the denominator

**Trigger.** $x \to a$ finite, and the denominator vanishes at $a$.

**Tool.** Factor and cancel first. Then look at the **multiplicity** of the surviving denominator
factor: even means both sides agree, odd means they disagree.

$$\textbf{even multiplicity} \Rightarrow \text{same sign both sides} \Rightarrow \ =\pm\infty
\qquad\qquad \textbf{odd multiplicity} \Rightarrow \text{signs flip} \Rightarrow \textbf{DNE}$$

| Limit | After cancelling | Multiplicity | Answer |
| :--- | :--- | :--- | :--- |
| $\lim_{x\to-2}\dfrac{3x^2-2x-16}{(x+2)^2}$ **[Q3.1b]** | $\dfrac{3x-8}{x+2}$, top $\to-14$ | odd | DNE, $+\infty$ left, $-\infty$ right |
| $\lim_{x\to3}\dfrac{2x^2-x+1}{x-3}$ **[Q3.1c]** | nothing cancels, top $=16$ | odd | DNE, $-\infty$ left, $+\infty$ right |
| $\lim_{x\to2}\dfrac{\cos \pi x}{(x-2)^2}$ **[Q3.2f]** | top $=\cos2\pi=1>0$ | even | $=+\infty$ |
| $\lim_{x\to0}\dfrac{1}{x^2}$ | - | even | $=+\infty$ |
| $\lim_{x\to0}-\dfrac{1}{x^2}$ | - | even | $=-\infty$ |
| $\lim_{x\to0}\dfrac{1}{x}$ | - | odd | DNE |
| $\lim_{x\to-2}\dfrac{1}{(x+2)^3}$ | - | odd | DNE |
| $\lim_{x\to1}\dfrac{x+1}{(x-1)^2}$ | top $\to2>0$ | even | $=+\infty$ |
| $\lim_{x\to1}\dfrac{x^2-1}{x-1}$ | $x+1$, fully cancels | none left | $2$, no asymptote at all |

**The Q3.1b row is the one to study.** A squared denominator looks like it guarantees $+\infty$, and
it does not: the numerator also vanishes there, one factor of $(x+2)$ cancels, and what survives has
**odd** multiplicity.
So the answer is DNE, not $+\infty$.
Cancel first, then count. Verified.

### Family 6 - radicals at infinity

**Trigger.** A square root with $x\to\pm\infty$.

**Tool.** For a difference, multiply by the conjugate. For a quotient, divide by $\lvert x\rvert$ and
remember that $\sqrt{x^2} = \lvert x\rvert$, which is $-x$ when $x<0$.

| Limit | Tool | Answer |
| :--- | :--- | :--- |
| $\lim_{x\to\infty}\left(\sqrt{x^2+1}-x\right)$ | conjugate | $0$ |
| $\lim_{x\to\infty}\left(\sqrt{x^2+x}-x\right)$ | conjugate | $\dfrac12$ |
| $\lim_{x\to\infty}\left(\sqrt{x^2+4x}-x\right)$ | conjugate | $2$ |
| $\lim_{x\to\infty}\dfrac{\sqrt{4x^2+1}}{x+1}$ | divide by $x$ | $2$ |
| $\lim_{x\to-\infty}\dfrac{\sqrt{4x^2+1}}{x+1}$ | divide by $\lvert x\rvert = -x$ | $-2$ |
| $\lim_{x\to\infty}\dfrac{\sqrt{x^2+1}}{x}$ | divide by $x$ | $1$ |
| $\lim_{x\to-\infty}\dfrac{\sqrt{x^2+1}}{x}$ | $\sqrt{x^2}=-x$ | $-1$ |
| $\lim_{x\to\infty}\dfrac{x}{\sqrt{x^2+1}}$ | divide by $x$ | $1$ |
| $\lim_{x\to-\infty}\dfrac{2x+1}{\sqrt{x^2+3}}$ | $\sqrt{x^2}=-x$ | $-2$ |

**Read this as structure.** The first three rows show that a difference of the form
$\sqrt{x^2+bx}-x$ tends to $b/2$, which is worth knowing as a formula.
The paired rows show the only real trap in the family: $\sqrt{x^2}$ is $\lvert x\rvert$, so at
$-\infty$ every answer picks up a minus sign.
Verified $\sqrt{(-5)^2} = 5$, not $-5$.

### Family 7 - approaching negative infinity

**Trigger.** $x\to-\infty$ rather than $+\infty$.

**Tool.** The same rules, but track the sign through every odd power and every radical.

| Limit | Answer | Contrast at $+\infty$ |
| :--- | :--- | :--- |
| $\lim_{x\to-\infty}\dfrac{5-2x^3}{x^2+2}$ | $+\infty$ | $-\infty$ |
| $\lim_{x\to-\infty}\dfrac{x^4}{1-x^3}$ | $+\infty$ | $-\infty$ |
| $\lim_{x\to-\infty}\dfrac{1}{x^3}$ | $0$, from below | $0$, from above |
| $\lim_{x\to-\infty}\dfrac{3x^2-4}{2x^4+2x+4}$ | $0$ | $0$ |
| $\lim_{x\to-\infty}\left(\dfrac{3x^2-4}{2x^4+2x+4}\right)\sin x$ | $0$ | $0$ |

**Read this as structure.** Even powers are blind to the sign of $x$ and odd powers are not.
Q3.3(a) is blind to it, so the answer would still be $0$ if the examiner sent $x$ the other way.
That makes "$x \to -\infty$" a cheap variation for them to write and a free mark for you.

### Family 8 - the same formula at $0$ and at infinity

**Trigger.** An expression that appears in both a $x\to0$ and a $x\to\infty$ question.

**Tool.** Notice which one you are in. These have *different answers* for the same formula, which is
what makes the family worth its own section.

| Formula | As $x\to 0$ | As $x\to\infty$ |
| :--- | :--- | :--- |
| $\dfrac{\sin 3x}{x}$ | $3$, by $\dfrac{\sin u}{u}\to1$ | $0$, by squeeze |
| $x\sin\dfrac1x$ | $0$, by squeeze | $1$, by $u = 1/x$ then $\dfrac{\sin u}{u}\to1$ |
| $\sin\dfrac1x$ | DNE, oscillates | $0$ |

Two more from the sample papers, for the $x\to0$ technique:

| Limit | Answer | Move |
| :--- | :--- | :--- |
| $\lim_{x\to0}\dfrac{\sin 3x}{x^2-x}$ **[Q3.1e]** | $-3$ | $\dfrac{\sin3x}{3x}\cdot\dfrac{3}{x-1} \to 1\cdot\dfrac{3}{-1}$ |
| $\lim_{x\to0}\dfrac{x^2}{1-\cos 2x}$ **[Q3.2b]** | $\dfrac12$ | $1-\cos2x = 2\sin^2 x$, then $\dfrac{x^2}{2\sin^2x}\to\dfrac12$ |

**Read this as structure.** The middle row is the sharpest thing in this document:
$x\sin(1/x)$ is $0$ at the origin and $1$ at infinity.
The formula tells you nothing. Only the arrow does.
Verified both directions.

### Family 9 - the two limits restated as an asymptote question

**Trigger.** The words "find the vertical and horizontal asymptotes" instead of "evaluate the limit".
Same mathematics, different wrapper.

**Tool.** Horizontal asymptotes are $\lim_{x\to\pm\infty}$. Vertical asymptotes are the surviving
zeros of the denominator after cancelling.

For $f(x)=\dfrac{x^2-3x-4}{x^2-16}$, which is **Q4.1** on this very paper:

| Question | Answer | Reason |
| :--- | :--- | :--- |
| Horizontal asymptote | $y = 1$ | degrees equal, leading coefficients $1/1$ |
| Vertical asymptote | $x = -4$ only | $f = \dfrac{(x-4)(x+1)}{(x-4)(x+4)} = \dfrac{x+1}{x+4}$ |
| Behaviour at $x=-4$ | DNE, $+\infty$ left, $-\infty$ right | odd multiplicity |
| Behaviour at $x=4$ | $\dfrac58$ | the factor cancelled, so it is a **hole**, not an asymptote |

More instances:

| Function | Horizontal | Vertical |
| :--- | :--- | :--- |
| $\dfrac{2x^2+1}{x^2-1}$ | $y=2$ | $x=1$ and $x=-1$, both DNE |
| $\dfrac{1}{x-2}$ | $y=0$ | $x=2$, DNE |
| $\dfrac{3x^2-4}{2x^4+2x+4}$, from **Q3.3(a)** | $y=0$ | none for $x>0$ |
| $\tan x$ | **none**, it never settles | $x=\dfrac{\pi}{2}+k\pi$, every one DNE |

**Read this as structure.** The last row is Q3.3 in a single line: part (a) is the horizontal-asymptote
column and part (b) is the vertical-asymptote column.
And note the cheap trick worth remembering: $\tan$ has no horizontal asymptote precisely *because*
of Family 3, it oscillates forever.

## 9. The trap list

Ranked by how often each one actually costs marks on this question.

1. **Using the product law on part (a).** $\lim \sin x$ does not exist, so the law does not apply.
   You get the right number and no marks, and the identical step gives the wrong answer on Family 3.
   Write the bound instead.
2. **Answering $+\infty$ for part (b).** The two sides disagree in sign, so no single infinite value
   is correct. The answer is DNE, with both one-sided values quoted.
3. **Not testing both sides at all.** Once you reach $k/0$, the sign work *is* the question.
   Skipping it turns a 4-point answer into a guess.
4. **Treating $k/0$ as $0/0$** and hunting for a factor to cancel. There is nothing to cancel and
   the time is gone.
5. **Assuming a squared denominator forces $+\infty$.** Q3.1b squares $(x+2)$ and the answer is still
   DNE, because the numerator vanishes too and one factor cancels. Cancel first, then count parity.
6. **Assuming any $\pi$-flavoured number is an asymptote.** $\tan$ at $2\pi$ is $0$, and $\cot$ at
   $5\pi/2$ is $0$. Check that the denominator actually vanishes.
7. **Applying $\tan$'s period to $\sec$.** $\tan$ and $\cot$ have period $\pi$ and behave identically
   at every asymptote; $\sec$ and $\csc$ have period $2\pi$ and alternate.
8. **Forgetting $\sqrt{x^2}=\lvert x\rvert$ at $-\infty$**, which silently flips the sign of every
   answer in Family 6.
9. **Comparing the wrong terms in the degree rule.** It reads leading terms only. For Q3.3(a) that
   is $3x^2$ against $2x^4$, giving $0$; not $(3-4)$ against $(2+2+4)$.
10. **Reaching for L'Hôpital.** Neither part of Q3.3 is an indeterminate quotient. Part (a) is
    $0\times\text{bounded}$ and part (b) is $1/0$. The rule applies to neither.
11. **Writing "DNE" with no reason** on a paper that says in bold that unjustified answers score
    zero.

Twelve problems.
Do them cold, with no notes, in fifteen minutes.

7. $\displaystyle\lim_{x\to0}x^3\cos\frac1x$
8. $\displaystyle\lim_{x\to 7\pi/2}\sec x$
9. $\displaystyle\lim_{x\to\infty}\frac{x^3+1}{x^2+1}$
10. $\displaystyle\lim_{x\to4\pi}\tan x$
11. $\displaystyle\lim_{x\to\infty}\left(\sqrt{x^2+4x}-x\right)$
12. $\displaystyle\lim_{x\to2\pi}\csc^2 x$

### Answer key

Every answer below was verified numerically.

| # | Answer | Decimal | Family and method |
| :--- | :--- | :--- | :--- |
| 1 | $\dfrac43$ | $1.3333$ | **F0**, degrees equal, $4/3$ |

**Score sign separately from magnitude.**
They are different failure modes and they need different fixes.

- If you got the **magnitude** wrong (said $0$ where the answer was $3/2$, or $\pm\infty$ where it
  was finite), you misread the classify table. Re-read Section 3.
- If you got the **sign or the direction** wrong (said $+\infty$ where it was $-\infty$, or missed an
  alternation), your problem is Family 4 and Family 6. Re-read Section 2.3 and the $\sqrt{x^2}$ rule.
- If you wrote $\pm\infty$ where the answer was DNE, or the reverse, your problem is Section 2.4 and
  nothing else. That single table is worth more marks on this question than any algebra.

Items 3, 6, 8, 10 and 12 are the five that separate a 4 from a 2 on part (b).

## 11. The one-page decision tree

```
Evaluate a limit.
|
+-- Where is x going?
|
+== TO INFINITY (or minus infinity) ==========================================
|   |
|   +-- Is there an OSCILLATING factor (sin, cos of anything)?
|   |     YES -> what does the OTHER factor do?
|   |            -> 0        : SQUEEZE. answer 0.          [F1]
|   |            -> L != 0   : DNE, oscillates in [-L, L]. [F3]
|   |            -> infinity : DNE, unbounded oscillation. [F3]
|   |     NO  -> continue
|   |
|   +-- Any SQUARE ROOT?
|   |     YES -> difference? multiply by the CONJUGATE.    [F6]
|   |            quotient?   divide by |x|, and remember
|   |                        sqrt(x^2) = |x| = -x when x<0. [F6]
|   |
|   +-- Otherwise it is a RATIONAL function: compare DEGREES. [F0]
|         top < bottom -> 0
|         top = bottom -> ratio of LEADING coefficients
|         top > bottom -> +-infinity, sign from leading coefficients
|         then, if x -> -infinity, re-check every ODD power for a sign flip. [F7]
|
+== TO A FINITE POINT a =====================================================
    |
    +-- SUBSTITUTE first. What came out?
    |
    +-- a number          -> that is the answer. Done.
    |
    +-- 0/0               -> factor, conjugate, common denominator,
    |                        trig identity. Then substitute again.
    |                        If everything cancels it is a HOLE, not an asymptote. [F5]
    |
    +-- k/0 with k != 0   -> a POLE. Do NOT factor.
    |                        Cancel first, then count the MULTIPLICITY of the
    |                        surviving denominator factor:
    |                          EVEN -> same sign both sides -> "= +-infinity"  [F5]
    |                          ODD  -> signs flip           -> "DNE"           [F5]
    |
    +-- a trig function undefined at a  -> rewrite as sin/cos. [F4]
    |                        tan, cot : period pi,  EVERY asymptote identical
    |                        sec, csc : period 2pi, asymptotes ALTERNATE
    |                        First confirm cos (or sin) is really 0 at a.
    |                        tan at 2pi is 0. cot at 5pi/2 is 0. Do not guess.
    |
    +-- oscillation at a (sin(1/x)) -> is it multiplied by something -> 0?
                             YES -> SQUEEZE, answer 0.  [F2]
                             NO  -> DNE, oscillates.    [F3]

FINALLY, before you commit:
  1. Magnitude plausible? (Section 6)
  2. Sign derived a SECOND, independent way?
  3. Is it "= +-infinity" or "DNE"? Those are different answers. (Section 2.4)
  4. Written paper: write the justification sentence. (Section 5)
     Mobius: type it with explicit *, radians, every bracket, and PREVIEW.
```
