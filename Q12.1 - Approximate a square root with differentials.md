## 2. The four things you must have cold

**1. The linearization, and the differential, which are one formula in two costumes.**

| Written as | Says | Use it when |
| :--- | :--- | :--- |
| $L(x) = f(a) + f'(a)(x-a)$ | the tangent line at $a$, as a function | you are asked for the **line**, or for $f$ at several nearby points |
| $f(a + dx) \approx f(a) + f'(a)\,dx$ | the same line, evaluated once | you are asked for **one number** |
| $dy = f'(a)\,dx$, $\Delta y \approx dy$ | just the **change**, not the value | you are asked for an **error** or a change |

They are not three formulas.
$dy$ is the second one with $f(a)$ moved to the other side.
The exam uses all three wordings: "use differentials", "use linearization", "estimate the error".

**2. The derivative of a root, in the form you actually need.**

| $f(x)$ | $f'(x)$ | $f'(a)$ at the usual anchors |
| :--- | :--- | :--- |
| $\sqrt{x} = x^{1/2}$ | $\dfrac{1}{2\sqrt{x}}$ | $f'(4) = \tfrac14$, $f'(9) = \tfrac16$, $f'(16) = \tfrac18$, $f'(25) = \tfrac1{10}$, $f'(100) = \tfrac1{20}$ |
| $\sqrt[3]{x} = x^{1/3}$ | $\dfrac{1}{3x^{2/3}}$ | $f'(8) = \tfrac1{12}$, $f'(27) = \tfrac1{27}$, $f'(64) = \tfrac1{48}$ |
| $x^{1/n}$ | $\dfrac{1}{n\,x^{(n-1)/n}}$ | $f'(32)$ for $n=5$ is $\tfrac1{80}$ |

Read the middle column as **structure, not as three facts**: for $f = x^{1/n}$ the derivative at a perfect $n$-th power $a = m^n$ is always $\dfrac{1}{n\,m^{n-1}}$, a unit fraction.
That is why the anchor is always a perfect power - it is the only way $f'(a)$ comes out clean too.

**3. Concavity decides the direction of the error, and nothing else does.**

| $f''(a)$ | shape | tangent line sits | your estimate is |
| :--- | :--- | :--- | :--- |
| $f'' < 0$ | concave down | **above** the curve | too **big** |
| $f'' > 0$ | concave up (convex) | **below** the curve | too **small** |

This does not depend on which way $dx$ points.
For $\sqrt{x}$, $f''(x) = -\dfrac{1}{4x^{3/2}} < 0$ on the whole domain, so **every square-root estimate by this method is too big**, whether you step up or step down.
Verified on 72 anchor-and-offset pairs, both directions, all 72 above the curve.

**4. The size of the error, so you know what the answer is worth.**

$$\text{true} - \text{estimate} = \frac{f''(\xi)}{2}(dx)^2 \quad \text{for some } \xi \text{ between } a \text{ and } a+dx$$

For $\sqrt{x}$ that is $\left|\text{error}\right| \le \dfrac{(dx)^2}{8\,a^{3/2}}$ when $dx > 0$.
Here: $\dfrac{0.04}{8 \cdot 27} = \dfrac{0.04}{216} = 0.0001852$.
The error actually observed is $0.0001832$, which is 98.9 percent of the bound.
**The error is second order in $dx$**: halve the step and the error drops by four.
Measured at $dx = 0.4, 0.2, 0.1, 0.05$ - the ratio came out 4.00 every time.

## 3. The universal procedure

> 1. **Name $f$.** The quantity asked for must be $f$ of something. $\sqrt{9.2}$ means $f(x) = \sqrt{x}$ evaluated at $9.2$.
> 2. **Choose the anchor $a$.** The nearest point where $f(a)$ is exact and you know it without a calculator. This step is the whole question.
> 3. **Write $dx = (\text{target}) - a$.** Keep the sign. If $dx$ is not small, go back to step 2.
> 4. **Differentiate once and evaluate at $a$**, not at the target.
> 5. **Form $dy = f'(a)\,dx$** and add it to $f(a)$.
> 6. **State the direction** from the sign of $f''$, and the size from $(dx)^2 f''/2$.
> 7. **Round to what the question asks**, and no further.

Step 2 in detail, because it is where the marks are.

| Target | Ask yourself | Anchor | Why |
| :--- | :--- | :--- | :--- |
| $\sqrt{9.2}$ | nearest perfect square? | $9$ | $\sqrt9 = 3$; $16$ is 6.8 away |
| $\sqrt{16.4}$ | nearest perfect square? | $16$ | $\sqrt{16} = 4$ |
| $\sqrt[3]{26.8}$ | nearest perfect cube? | $27$ | $\sqrt[3]{27} = 3$; step *down* |
| $\sin 62^\circ$ | nearest special angle? | $60^\circ = \pi/3$ | $\sin 60^\circ = \sqrt3/2$ |
| $(2.01)^5$ | nearest round base? | $2$ | $2^5 = 32$ |
| $1/1.002$ | nearest round base? | $1$ | $1/1 = 1$ |
| $f(4.02)$, $f$ named | the question hands it to you | $4$ | it printed $f(4)$ for you |

**The test for a good anchor is not "is it round", it is "do I know $f(a)$ exactly".**
$a = 9$ is chosen for $\sqrt{9.2}$ not because 9 is tidy but because $\sqrt9 = 3$ on the nose.

## 4. Q12.1 worked four ways

### Route A - differentials, the wording the exam uses

$$f(x) = \sqrt{x}, \qquad a = 9, \qquad dx = 0.2$$
$$f(9) = 3, \qquad f'(x) = \frac{1}{2\sqrt{x}}, \qquad f'(9) = \frac{1}{2\cdot 3} = \frac16$$
$$dy = f'(9)\,dx = \frac16 \cdot \frac{1}{5} = \frac{1}{30}$$
$$\sqrt{9.2} \approx f(9) + dy = 3 + \frac{1}{30} = \frac{91}{30} \approx 3.0333$$

### Route B - linearization, the wording Q12.2 uses

$$L(x) = f(9) + f'(9)(x - 9) = 3 + \frac{1}{6}(x-9)$$
$$L(9.2) = 3 + \frac{1}{6}(0.2) = 3 + \frac{1}{30} = \frac{91}{30}$$

Identical, because it is the same line.
Route B is worth knowing because it answers "estimate $\sqrt{9.1}$ **and** $\sqrt{9.3}$" in one go, and because Q9.1's tangent line is literally this object.

### Route C - factor out the anchor (the binomial form)

$$\sqrt{9.2} = \sqrt{9\left(1 + \tfrac{0.2}{9}\right)} = 3\sqrt{1 + \tfrac{1}{45}}$$

Linearize $\sqrt{1+u}$ at $u = 0$, where it is $1 + \tfrac{u}{2}$:

$$\approx 3\left(1 + \frac{1}{90}\right) = 3 + \frac{1}{30}$$

Same answer, exactly, and this route is the fastest when the target is written as a percentage change ("estimate $\sqrt{x}$ if $x$ rises 2 percent").

### Route D - one Newton step, which is the same arithmetic

Newton's method on $g(x) = x^2 - 9.2$ from $x_0 = 3$:

$$x_1 = x_0 - \frac{g(x_0)}{g'(x_0)} = 3 - \frac{9 - 9.2}{6} = 3 + \frac{0.2}{6} = \frac{91}{30}$$

**This is not a coincidence.**
Linearizing $\sqrt{x}$ at $a$ gives $\sqrt a + \dfrac{N - a}{2\sqrt a} = \dfrac{1}{2}\left(\sqrt a + \dfrac{N}{\sqrt a}\right)$, which is exactly one Babylonian / Newton step.
Verified identical to machine precision at ten separate $(a, N)$ pairs.
Worth knowing because Q13.1 is Newton's method, and this tells you the two questions are neighbours.

### Route comparison

| Route | Steps | Where it goes wrong | Verdict |
| :--- | :--- | :--- | :--- |
| A differentials | 4 | none - shortest path | **use this one under pressure** |
| B linearization | 5 | an extra $(x-9)$ to carry and mis-sign | use when several targets share one anchor |
| C binomial | 5 | needs the $\sqrt{1+u} \approx 1 + u/2$ fact recalled | use for percentage-change wording |
| D Newton step | 4 | you must invert the problem to $x^2 = 9.2$ | use as a **check**, not as the answer |
| Calculator | 1 | the stem says "use differentials" - method instruction | **scores zero** |

**Use Route A.**
It is what the stem names, it is the fewest symbols, and it puts $f'(9)$ and $dx$ side by side where the marks are.

Route D is the best self-check in the whole question, because it uses none of the same algebra.
If $\tfrac12(3 + 9.2/3)$ does not give your answer, one of them is wrong.

## 5. The exam-ready write-up

There is **no published marking scheme** for this course - zero occurrences of "rubric", "marking scheme" or "part marks" across all four course files, re-verified this run - so what follows is inference about which sentences make the method visible, not a claim about points.

Six lines. Write all six.

> Let $f(x) = \sqrt{x}$.
> Take $a = 9$, since $\sqrt{9} = 3$ exactly and $9$ is the nearest perfect square to $9.2$; then $dx = 0.2$.
> $f'(x) = \dfrac{1}{2\sqrt{x}}$, so $f'(9) = \dfrac{1}{6}$.
> $dy = f'(9)\,dx = \dfrac{1}{6}(0.2) = \dfrac{1}{30}$.
> Therefore $\sqrt{9.2} \approx f(9) + dy = 3 + \dfrac{1}{30} = \dfrac{91}{30} \approx 3.0333$.
> Since $f''(x) = -\dfrac{1}{4x^{3/2}} < 0$, $f$ is concave down and the tangent line lies above the curve, so this estimate is slightly too large.

The second line is the one most students skip and it is the only line that shows you **chose** the anchor rather than being handed it.
The sixth line costs eight seconds and is the only line that shows you know what an approximation is.

## 6. Verify before you commit

**Magnitude check.** $3^2 = 9$ and $3.1^2 = 9.61$. Since $9 < 9.2 < 9.61$, the answer must sit in $(3, 3.1)$. $3.0333$ does. This kills every gross slip in section 9 in about four seconds.

**The Newton cross-check.** $\tfrac12\!\left(3 + \tfrac{9.2}{3}\right) = \tfrac12(3 + 3.0\overline{6}) = 3.0\overline{3}$. Agrees.

**Square it back.** $\left(\tfrac{91}{30}\right)^2 = \tfrac{8281}{900} = 9.2011\ldots$, which is a little **above** 9.2 - confirming the estimate is a little too big, exactly as concavity predicted. This is the best single check in the question: it verifies the value *and* the direction at once.

**Numbers worth memorising for this family.**

| Fact | Value |
| :--- | :--- |
| $f'(a)$ for $\sqrt{x}$ at $4, 9, 16, 25, 100$ | $\tfrac14, \tfrac16, \tfrac18, \tfrac1{10}, \tfrac1{20}$ |
| $1^\circ$ in radians | $\pi/180 \approx 0.01745$ |
| $2^\circ$ in radians | $\pi/90 \approx 0.03491$ |
| $\sqrt{1+u} \approx 1 + u/2$ | for small $u$ |
| $(1+u)^n \approx 1 + nu$ | for small $u$ |
| error $\approx \tfrac12 f''(a)(dx)^2$ | second order |

**The check that CANNOT fail, and why it matters.**
A spot-check at $dx = 0$ agrees with the truth for five of the eight standard wrong answers, because they all differ from the truth only by a factor multiplying $dy$, and $dy$ is zero there.
**Never sanity-check this method at the anchor itself.**
This is the exact analogue of the zero-rate blind spot in related rates: at $dV/dt = 0$ every wrong cone formula gives zero too.

| Do | Do not |
| :--- | :--- |
| `91/30` | `91/3 0` - a stray space |
| `3+1/30` | `3+1/2*sqrt(9)` - this is $3 + 1.5$; the bracket around $2\sqrt9$ is not optional |

| `3.0333` if a decimal is demanded | `3.0332` - that is the *true* value, not the estimate the method gives |
| `3.033` if three places are asked | `3.03` - $3\times10^{-3}$ away, outside a $10^{-4}$ tolerance |
| Type `*` between every factor, then **Preview** | assume the box knows what you meant |

**The single most expensive typo is `1/2*sqrt(9)` for $f'(9)$.**
It evaluates to $1.5$ rather than $0.1\overline{6}$ - a factor of nine - and gives $3.3$, which is still inside the plausible range for a square root and so will not look wrong.
Write $f'(9)$ as `1/6` and the typo cannot happen.

**The second most expensive is entering the true value.**
If the box wants four decimals, the answer this method produces is `3.0333`, not `3.0332`.
The true $\sqrt{9.2}$ is $3.03315018$, which rounds to $3.0332$ - see section 8, Family 7.
The question asked for the differential estimate, so `3.0333` is the answer even though it is the less accurate number.

**The signs are generated by concavity, not by memory.**
On $(0, \pi/2)$, $\sin'' = -\sin < 0$ and $\cos'' = -\cos < 0$, so both overshoot; $\tan'' = 2\sec^2 x \tan x > 0$, so tan undershoots.
"Trig always overestimates" is **false** - the two tan rows prove it.

**Only two distinct increments appear** in the whole family: $\pi/180 \approx 0.0174533$ and $\pi/90 \approx 0.0349066$. Learn those two numbers and the family costs nothing.

**The catastrophic slip is using $dx = 2$ instead of $2^\circ$.**
$\sin 62^\circ$ then comes out $1.866$, which is not even in $[-1,1]$. It is 0.98 away from the truth. If your trig estimate leaves $[-1,1]$, you forgot to convert.

**Trigger.** $(2.01)^5$, $1/1.002$, $(1.97)^3$, $(8.06)^{2/3}$ - a power of a number near a round base.
**Tool.** $f = x^p$, $f'(a) = p\,a^{p-1}$. The over/under rule is entirely the sign of $p(p-1)$.

**The rule that generates every direction in this table:** $x^p$ is convex for $p>1$ or $p<0$ (undershoot), and concave for $0<p<1$ (overshoot).
So every root overshoots and every whole power and every reciprocal undershoots.
$(8.06)^{2/3}$ is the only concave row, and it is the only "over".

**$(1.02)^{10}$ is this family's warning.**
$dx = 0.02$ is tiny, and the estimate is still 1.6 percent low, because $f''(1) = 90$.
**A small $dx$ does not by itself make a good estimate** - the error is $\tfrac12 f''(dx)^2$, and $f''$ gets a vote.

### Family 3 - a named $f$ with the anchor supplied

**Trigger.** "Let $f(x) = \frac{x-1}{\sqrt{x}}$. (a) Find the tangent line at $(4, f(4))$. (b) Use differentials to estimate $f(4.02)$."
**Tool.** Nothing new - but notice (a) and (b) are the **same computation asked twice**.

$$f(x) = \frac{x-1}{\sqrt x} = x^{1/2} - x^{-1/2}, \qquad f'(x) = \frac{1}{2\sqrt x} + \frac{1}{2x^{3/2}}$$
$$f(4) = \frac{3}{2}, \qquad f'(4) = \frac14 + \frac1{16} = \frac{5}{16}$$
$$\text{tangent: } y = \frac32 + \frac{5}{16}(x-4) = \frac{5}{16}x + \frac14$$
$$f(4.02) \approx \frac32 + \frac{5}{16}\cdot\frac{1}{50} = \frac32 + \frac{1}{160} = \frac{241}{160} = 1.50625$$

True value $1.5062391$, error $-1.090\times10^{-5}$, an overshoot as $f'' < 0$ predicts.
**Evaluating the part-(a) line at $4.02$ gives the part-(b) answer.** Verified identical.
Rewriting $\frac{x-1}{\sqrt x}$ as $x^{1/2} - x^{-1/2}$ before differentiating avoids the quotient rule entirely - that is the only real work in the question.

| :--- | :--- | ---: | :--- | ---: | ---: | ---: |
| adjacent | $25\cot\theta$ | $25/\sqrt3 = 14.4338$ | $-25\csc^2\theta\,d\theta = -\dfrac{5\pi}{54}$ | $-0.29089$ | $-0.28944$ | $2.0153\%$ |
| hypotenuse | $25\csc\theta$ | $50/\sqrt3 = 28.8675$ | $-25\csc\theta\cot\theta\,d\theta = -\dfrac{5\pi}{108}$ | $-0.14544$ | $-0.14362$ | $0.5038\%$ |

**The ratio of the two percentage errors is exactly $\sec^2 60^\circ = 4$.**
That is an identity, not a coincidence of these numbers: $\dfrac{\text{pct}_{\text{adj}}}{\text{pct}_{\text{hyp}}} = \sec^2\theta$ for every $\theta$, verified at $\pi/6$, $\pi/4$, $0.9$ and $1.3$ as well.
**The adjacent side is always the more sensitive of the two**, and past $45^\circ$ it is dramatically so.

**The 25 cm never appears in either percentage.** A percentage error is dimensionless and the constant cancels - which is why this part can be answered without touching the 25 at all.

### Family 5 - relative and percentage error for a power

**Trigger.** "A sphere's radius is measured as 10 cm with a possible error of 0.05 cm. Estimate the error in the volume, and the percentage error."
**Tool.** Divide $dy = f'(a)dx$ by $y = f(a)$. For $f = x^n$ every constant cancels:

$$\frac{dy}{y} = n\,\frac{dx}{x}$$

| Situation | $n$ | Absolute | Relative |
| :--- | ---: | :--- | :--- |
| sphere $V = \tfrac43\pi r^3$, $r = 10 \pm 0.05$ | 3 | $dV = 4\pi r^2 dr = 20\pi = 62.832$ | $3(0.05/10) = 1.5\%$ |
| cube $V = s^3$, $s = 12 \pm 0.1$ | 3 | $dV = 3s^2 ds = 43.2$ | $3(0.1/12) = 2.5\%$ |
| circle $A = \pi r^2$ | 2 | $dA = 2\pi r\,dr$ | $2\,dr/r$ |
| $\sqrt{x}$ | $1/2$ | | $\tfrac12 dx/x$ |
| $1/x$ | $-1$ | | $-dx/x$ |

**A relative error is multiplied by the exponent, and the constant in front is irrelevant.**
A sphere and a cube both give $3\,ds/s$, though their volumes differ by a factor of $\tfrac{4\pi}{3}$ against $1$.
That is the one sentence this family is testing.

The law is a property of powers only: for $\sin$, $\dfrac{dy}{y} = \cot(a)\,da$, which depends on $a$ and is not a constant multiple of $da/a$.

### Family 6 - "is your estimate too big or too small? justify"

**Trigger.** The question asks for the *direction*, with or without the number.
**Tool.** The sign of $f''$ on the interval, and one sentence about the tangent line.

| $f$ | $f''$ | Concavity | Estimate is |
| :--- | :--- | :--- | :--- |
| $\sqrt x$, $\sqrt[3]{x}$, $x^p$ for $0<p<1$ | $<0$ | down | too big |
| $x^n$ for $n>1$, $e^x$ | $>0$ | up | too small |
| $1/x$, $x^{-1/2}$ (for $x>0$) | $>0$ | up | too small |
| $\sin x$, $\cos x$ on $(0,\pi/2)$ | $<0$ | down | too big |
| $\tan x$ on $(0,\pi/2)$ | $>0$ | up | too small |
| $\ln x$ | $<0$ | down | too big |

**Answer it with the tangent line, not with the arithmetic.**
"$f'' < 0$ on this interval, so $f$ is concave down, so the tangent line lies above the graph, so the estimate exceeds the true value."
That sentence works without computing anything, and it works for negative $dx$ too.

**The trap:** the direction is not decided by the sign of $dx$. Both $\sqrt{9.2}$ (step up) and $\sqrt{24.6}$ (step down) overestimate.

### Family 7 - the error bound, and how many decimal places you may claim

**Trigger.** "Estimate to four decimal places", or "how accurate is your estimate", or "bound the error".
**Tool.** $\left|\text{error}\right| \le \dfrac{M}{2}(dx)^2$ where $M = \max|f''|$ **on the interval between $a$ and the target**.

| Target | Bound | Actual error | Ratio | Estimate to 4dp | True to 4dp |
| :--- | ---: | ---: | ---: | ---: | ---: |
| $\sqrt{9.2}$ | $1.852\times10^{-4}$ | $1.832\times10^{-4}$ | 0.989 | 3.0333 | **3.0332** |
| $\sqrt{16.4}$ | $3.125\times10^{-4}$ | $3.087\times10^{-4}$ | 0.988 | 4.0500 | **4.0497** |
| $\sqrt{4.1}$ | $1.563\times10^{-4}$ | $1.543\times10^{-4}$ | 0.988 | 2.0250 | **2.0248** |
| $\sqrt{101}$ | $1.250\times10^{-4}$ | $1.244\times10^{-4}$ | 0.995 | 10.0500 | **10.0499** |
| $\sqrt[3]{8.3}$ | $3.125\times10^{-4}$ | $3.061\times10^{-4}$ | 0.980 | 2.0250 | **2.0247** |

**The bound is tight** - within 2 percent of the observed error every time - so it is worth quoting.

**Use the endpoint where $|f''|$ is largest, not automatically the anchor.**
For a root, $|f''|$ *decreases* with $x$, so when $dx > 0$ the anchor is the correct endpoint, but when $dx < 0$ it is not.
Worked instance: for $\sqrt{48.6}$ from $a = 49$, the anchor-based bound is $5.8309\times10^{-5}$ and the actual error is $5.8548\times10^{-5}$ - **the anchor bound is violated**. Using $48.6$ instead gives $5.9030\times10^{-5}$, which holds.

**Now the finding that matters most for Q12.3.**
Across all 21 entries in Families 0 and 1, **only 5 give four correct decimal places**, and 17 give three.
$\sqrt{9.2}$, $\sqrt{16.4}$ and $\cos 62^\circ$ - all three of category 12's four-decimal demands - are **wrong in the fourth decimal**.

So when F1 item 2 says "estimate each of the values below **to four decimal places**", it can only mean *write four decimals down*.
It cannot mean *guarantee four correct ones*, because the method cannot do that here, and the marker's own answer will be the differential value.
**Write the estimate to four places. Do not "improve" it toward the true value** - $3.0333$ is the answer, not $3.0332$.

One subtlety, since it looks like a contradiction: $(32.2)^{1/5}$ agrees with its true value at **four** places and disagrees at **three**, because $2.0025$ sits exactly on a three-place rounding tie. Rounding boundaries are not nested. Do not infer three-place accuracy from four-place agreement.

## 9. The trap list

Ranked by how often each actually costs marks.

1. **Evaluating $f'$ at the target instead of the anchor.** $f'(9.2)$ rather than $f'(9)$ gives $3.0329690$, which is off by $+1.8\times10^{-4}$ - *the same size as the correct answer's error, in the opposite direction*. It looks completely plausible. Worse, it becomes invisible as $dx \to 0$, so shrinking the step cannot expose it. The rule: **the anchor is where you know things; the target is where you want an answer. $f$ and $f'$ are both evaluated at the anchor.**

2. **Forgetting the $\tfrac12$ in $\dfrac{d}{dx}\sqrt x$.** Gives $3.0667$ - inside the plausible band, and exactly twice the correct $dy$. Kill it with the magnitude check: $3.0667^2 = 9.404$, not $9.2$.

3. **Using degrees where the formula needs radians** (Family 1). $\sin 62^\circ \approx 1.866$. The tell is an answer outside $[-1,1]$.

4. **Choosing a "prettier" anchor rather than a nearer one.** $a = 9.61 = 3.1^2$ is a genuinely exact anchor, and it is 3.94 times worse than $a=9$ because it is twice as far. $a = 16$ is 638 times worse. **Nearest wins, always** - the error goes as $(dx)^2$.

5. **Spot-checking at the anchor.** $dx = 0$ hides five of the eight standard wrong answers. See section 6.

6. **Reporting $dy$ instead of $f(a) + dy$.** Answer $0.0333$. The magnitude check catches it instantly.

7. **Sign slip on a negative $dx$.** For $\sqrt{24.6}$ from 25, $dx = -0.4$, and adding $+0.04$ gives $5.04$ instead of $4.96$. Write $dx = \text{target} - a$ every time and let the sign fall out.

8. **Claiming the true value.** Writing $3.0332$ because you checked on a calculator. The question asked for the differential estimate.

9. **Getting the over/under backwards** by reasoning from $dx>0$ instead of from $f''<0$.

10. **The invisible one: $f'(a) = 1$.** At $a = 1/4$ for $\sqrt x$, forgetting to multiply by $f'(a)$ is undetectable. Nothing catches this except doing it right.

## 11. The one-page decision tree

```
"approximate / estimate / use differentials / use linearization"
    |
    +-- Is a NUMBER wanted, or a CHANGE / ERROR?
    |     |
    |     +-- a NUMBER  ->  f(a+dx) ~ f(a) + f'(a) dx          (families 0,1,2,3)
    |     +-- a CHANGE  ->  dy = f'(a) dx alone                (family 4)
    |     +-- a PERCENT ->  dy/y = n dx/x for a power          (family 5)
    |
    +-- CHOOSE a: nearest point where f(a) is EXACT
    |     root         -> nearest perfect square / cube / n-th power
    |     trig         -> nearest special angle, IN RADIANS
    |     power / 1/x  -> nearest round base, usually 1 or 2
    |     named f      -> the question already gave you f(a)
    |     CHECK: is f'(a) a unit fraction or a small integer?
    |            if not, you probably picked the wrong a
    |
    +-- dx = target - a     KEEP THE SIGN.  degrees -> radians HERE.
    |
    +-- f'(a), evaluated AT THE ANCHOR (never at the target)
    |
    +-- answer = f(a) + f'(a) dx        leave it as an exact fraction
    |
    +-- DIRECTION from f''(a):   f'' < 0 -> too big     f'' > 0 -> too small
    |                            (NOT from the sign of dx)
    |
    +-- SIZE, if asked:  |error| <= (max |f''| on the interval)/2 * dx^2
    |                    for a root with dx < 0 use the FAR endpoint
    |
    +-- check:  square it back / one Newton step / is it in the obvious bracket?
    +-- preview: 91/30 , brackets round every denominator
```
