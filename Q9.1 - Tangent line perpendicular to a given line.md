# Q9.1 - Tangent line perpendicular to a given line

**The question (Midterm Exam 1, item 6, 4 points).**
"Find the values of $x$ such that tangent line to the curve $f(x) = 3x^2 + 4x - 3$ is perpendicular to the line $y = 6x + 2$."

**The answer.** $x = -\dfrac{25}{36} \approx -0.694444$

**What to type into Möbius:** `-25/36`

**Provenance.** MT1 prints the point value inline at the end of the stem, which is that paper's convention; item 6 is worth **4 points**, the lightest item on MT1.
MT1 carries exactly one printed "no credit will be given" clause and it sits on item 3, not here, so there is no method restriction on this question.

**Verification.** 177 assertions, 0 failures, 15 of them seeded controls proving the gates can bite.
The derivative is checked two independent ways (complex-step at $h=10^{-30}$, and a bounded Richardson centred-difference ladder), the root count is checked two independent ways (a numpy companion-matrix census and a 400,001-sample sign-change sweep over $[-50,50]$), and the tangent line is confirmed by *evaluating* both the curve and the line at the tangent point rather than by trusting the algebra.
Harness section: `Work\knowledge\topics\math265-answer-verification.py`.

What is genuinely new here is **geometry on top of the derivative**, and it is three separate skills:

1. Reading a slope off a line that may not be printed as $y = mx + b$.
2. Turning "perpendicular" into a number, via $m_1 m_2 = -1$.
3. Solving $f'(x) = m$ and knowing how many answers to expect.

**Here is the thing worth internalising before anything else.**
On this question the differentiation is one line and it is worth almost nothing.
$f' = 6x + 4$ is a first-week power rule.
Every mark that gets lost on this family is lost in the three skills above, and the single largest loss is reporting the wrong *kind* of object: an $x$ when a line was demanded, or a line when an $x$ was demanded.

## 0. The 30-second version

```
  READ the given line          ->  m_given          (from y=mx+b, or Ax+By=C, or two points)
  FLIP it                      ->  m_req = -1/m_given          (perpendicular)
                                   m_req =  m_given            (parallel)
                                   m_req =  0                  (horizontal)
  SOLVE f'(x) = m_req          ->  every real root, not the first one
  ANSWER what was asked        ->  x?  the point (x, f(x))?  or the LINE y = m_req(x - x0) + f(x0)?
```

Q9.1 in four lines:

```
  y = 6x + 2                ->  m_given = 6
  perpendicular             ->  m_req  = -1/6
  f' = 6x + 4 = -1/6        ->  6x = -25/6  ->  x = -25/36
  the stem says "values of x"    ->  report x = -25/36 and stop
```

That is the entire 4 points.
If it needs a lookup it is too long, and this does not.

## 1. What this question is really testing

| the reflex being tested | where it comes back |
| :--- | :--- |
| the derivative *is* the slope of the tangent, at that $x$ | Q10.2 (tangent to an implicit curve), Q12.x (linearization), every optimization question |
| $m_1 m_2 = -1$, and the ability to apply it in the right direction | Q10.1 vertical-tangent arguments, normal lines |
| solving $f'(x) = k$, an equation in $x$ | critical points ($k = 0$), Mean Value Theorem, increasing/decreasing intervals |
| counting the roots of that equation | the single biggest mark loss in this family |
| answering the question that was asked, not the one you solved | every worded question on both papers |

**The honest summary.**
This is a 4-point item that is 90 percent reading comprehension and 10 percent calculus.
The examiner is checking that "perpendicular" reaches you as the number $-1/6$ and not as the number $6$, $-6$, or $+1/6$.

Note the wording carefully: **"the values of $x$"**, plural.
Here there is exactly one, because $f$ is quadratic and therefore $f'$ is linear.
The plural is a habit of phrasing, not a hint, and it is the same stem used when the answer *is* plural.
Do not manufacture a second answer to satisfy the grammar, and do not assume there is only one when the curve is a cubic.

## 2. The four things you must have cold

### 2.1 The derivative is the slope, at a point

$$f'(a) = \text{the slope of the tangent line to } y = f(x) \text{ at } x = a.$$

$f'$ is a *function of $x$*, so "the slope of the tangent" is not one number, it is a number for every $x$.
That is exactly why "find the $x$ where the slope is $m$" is a solvable equation and not a lookup.

For Q9.1: $f'(x) = 6x + 4$, so the tangent slope at $x = 0$ is $4$, at $x = 1$ is $10$, at $x = -2/3$ is $0$.
The slope sweeps every real number exactly once as $x$ runs over the reals, which is the structural reason this question has exactly one answer.

### 2.2 The perpendicular condition

| relationship | condition on the slopes | the number to use |
| :--- | :--- | :--- |
| parallel | $m_1 = m_2$ | $m_{\text{req}} = m_{\text{given}}$ |
| perpendicular | $m_1 m_2 = -1$ | $m_{\text{req}} = -\dfrac{1}{m_{\text{given}}}$ |
| horizontal tangent | slope is $0$ | $m_{\text{req}} = 0$ |
| vertical tangent | slope undefined | $f'$ blows up; a polynomial never has one |

$m_1 m_2 = -1$ is the form to memorise, not $m_2 = -1/m_1$.
The product form is symmetric, so it cannot be applied backwards, and it doubles as a check: multiply your answer's slope by the given slope and you must get $-1$ exactly.

**The two degenerate cases, which the product form cannot express.**

- Perpendicular to a **vertical** line $x = c$: the tangent must be **horizontal**, so $f'(x) = 0$.
  A vertical line has no slope, so $-1/m$ is meaningless; go to the geometry instead.
- Perpendicular to a **horizontal** line $y = c$: the tangent must be **vertical**, so $f'$ must be undefined or infinite.
  A polynomial's derivative is a polynomial, which is finite everywhere, so **no such $x$ exists**.

### 2.3 Reading a slope off any form of a line

This is the step the question hides, and the reason a 4-point item can go to zero.

| the line as printed | slope $m$ | perpendicular slope $-1/m$ |
| :--- | :--- | :--- |
| $y = 6x + 2$ | $6$ | $-\tfrac16$ |
| $y = \tfrac12 x + 3$ | $\tfrac12$ | $-2$ |
| $2x - 3y = 6$ | $\tfrac23$ | $-\tfrac32$ |
| $4x + 2y - 7 = 0$ | $-2$ | $\tfrac12$ |
| through $(1,3)$ and $(4,9)$ | $\dfrac{9-3}{4-1} = 2$ | $-\tfrac12$ |
| $x = 5$ | undefined (vertical) | tangent must be horizontal, $f' = 0$ |
| $y = 7$ | $0$ | tangent must be vertical; impossible for a polynomial |

For $Ax + By = C$ the slope is $-A/B$.
Derive it once and then use it: $By = -Ax + C$, so $y = -\tfrac{A}{B}x + \tfrac{C}{B}$.
Do **not** read $A$ as the slope, which is the standard misfire on $2x - 3y = 6$.

### 2.4 Point-slope form, and when a line is demanded

$$y - y_0 = m(x - x_0) \qquad\text{equivalently}\qquad y = m(x - x_0) + y_0.$$

You need three things and you have to fetch them in this order:

1. $m$, from the perpendicularity condition.
2. $x_0$, from solving $f'(x_0) = m$.
3. $y_0 = f(x_0)$, from the **original** $f$, never from $f'$.

Step 3 is where the marks go.
Evaluating $f'$ instead of $f$ at $x_0$ is the single most common wrong point in this family, and it produces a line that has the right slope and touches nothing.

## 3. The universal procedure

> **Step 1 - Read the condition and name the required slope $m_{\text{req}}$.**
> Perpendicular means $-1/m_{\text{given}}$, parallel means $m_{\text{given}}$, horizontal means $0$.
> Write $m_{\text{req}}$ down as a single number before you touch the calculus.
>
> **Step 2 - Differentiate $f$.**
> Use the Q8.1 classify table. This is normally the easiest line on the page.
>
> **Step 3 - Solve $f'(x) = m_{\text{req}}$.**
> Move everything to one side and solve as an equation in $x$.
>
> **Step 4 - Count the roots and justify the count.**
> Degree of $f'$ tells you the maximum. A discriminant, a factorisation, or the shape of $f'$ tells you the actual number.
>
> **Step 5 - Answer the object that was asked for.**
> $x$ values, points $(x, f(x))$, or the equation of a line. Re-read the stem before you write the final line.

### The classify table: how many answers should you expect?

| $f$ is | $f'$ is | $f'(x) = m$ has | typical count |
| :--- | :--- | :--- | :--- |
| linear | constant | no solution, or all $x$ | 0 or infinitely many |
| **quadratic** | **linear** | **exactly one root, always** | **1** |
| cubic | quadratic | 0, 1, or 2 roots, by discriminant | usually 2 |
| quartic | cubic | 1, 2, or 3 roots | 1 or 3 |
| $1/x$ | $-1/x^2$ | 0 roots if $m > 0$, 2 roots if $m < 0$ | 0 or 2 |
| $\sqrt{x}$ | $\tfrac{1}{2\sqrt x}$ | 1 root if $m > 0$, none otherwise | 0 or 1 |
| $e^x$ | $e^x$ | 1 root if $m > 0$, none otherwise | 0 or 1 |
| $\sin x$ | $\cos x$ | infinitely many, unless an interval is given | interval-bounded |

**Read that table as one idea, not eight facts.**
The number of tangent points is the number of times the *slope function* $f'$ hits the horizontal level $m_{\text{req}}$.
So sketch $f'$, draw the line $y = m_{\text{req}}$ across it, and count crossings.
Everything in the table follows from that one picture.

## 4. Q9.1 worked three ways

Given: $f(x) = 3x^2 + 4x - 3$, and the line $y = 6x + 2$.

### Route A - slope first, then solve (use this one)

**Step 1.** The given line is already in $y = mx + b$ form, so $m_{\text{given}} = 6$.
Perpendicular gives

$$m_{\text{req}} = -\frac{1}{6}.$$

**Step 2.** By the power rule,

$$f'(x) = 6x + 4.$$

**Step 3.** Set the slope equal to what is required:

$$6x + 4 = -\frac16.$$

**Step 4.** Solve.

$$6x = -\frac16 - 4 = -\frac{1}{6} - \frac{24}{6} = -\frac{25}{6}, \qquad x = -\frac{25}{36}.$$

**Step 5.** $f'$ is linear with nonzero leading coefficient, so this is the only root.
The stem asks for values of $x$, so the answer is $x = -\tfrac{25}{36}$ and nothing else is required.

### Route B - the quadratic slope formula

For $f(x) = ax^2 + bx + c$ you have $f'(x) = 2ax + b$, so solving $f'(x) = m$ once and for all gives

$$\boxed{\,x = \frac{m - b}{2a}\,}$$

Here $a = 3$, $b = 4$, $m = -\tfrac16$:

$$x = \frac{-\tfrac16 - 4}{6} = \frac{-\tfrac{25}{6}}{6} = -\frac{25}{36}.$$

One substitution, no rearranging.
Worth carrying for any quadratic, and it makes the "exactly one root" claim visible: the formula is a function of $m$, so every $m$ gets exactly one $x$.

### Route C - from the vertex, by symmetry

The vertex sits where the slope is zero, at $x_v = -\dfrac{b}{2a} = -\dfrac{4}{6} = -\dfrac23$.
Moving $\Delta x$ to the right of the vertex changes the slope by $2a\,\Delta x$, so the slope $m$ occurs at

$$x = x_v + \frac{m}{2a} = -\frac23 + \frac{-\tfrac16}{6} = -\frac{24}{36} - \frac{1}{36} = -\frac{25}{36}.$$

This route is slower to write but it is the best *sanity* route, because it tells you immediately which side of the vertex the answer belongs on.
The required slope $-\tfrac16$ is slightly negative, and $a > 0$ so the slope increases with $x$, so the answer must sit **just left of** $-\tfrac23$.
It does: $-0.6944$ against $-0.6667$.

### The route comparison

| route | steps | what it costs | what it buys | risk |
| :--- | :--- | :--- | :--- | :--- |
| **A - slope first** | 4 | one line of algebra | works for every $f$, not just quadratics | fumbling $-\tfrac16 - 4$ |
| B - the $\frac{m-b}{2a}$ formula | 1 | memorising a formula | fastest for a quadratic; makes the root count obvious | useless the moment $f$ is a cubic |
| C - from the vertex | 3 | finding the vertex first | the sign/side sanity check comes free | two chances to drop a sign |

**Under exam pressure, use Route A**, and carry Route C's "which side of the vertex" as the check.
Route B is a legitimate accelerator on a quadratic, but it does not generalise, and this family's harder variants are all cubics and rationals.
Do not spend exam time deriving Route B if you have not already memorised it.

### The unasked extras, in case the variant demands them

The tangent point is

$$f\!\left(-\tfrac{25}{36}\right) = 3\cdot\frac{625}{1296} - \frac{100}{36} - 3 = \frac{625 - 1200 - 1296}{432} = -\frac{1871}{432} \approx -4.331019,$$

and the tangent line, in point-slope and then slope-intercept form, is

$$y = -\frac16\left(x + \frac{25}{36}\right) - \frac{1871}{432} \;=\; -\frac{x}{6} - \frac{1921}{432}, \qquad -\frac{1921}{432} \approx -4.446759.$$

Both were confirmed by evaluating the curve and the line at $x = -\tfrac{25}{36}$ and finding the same value to $10^{-14}$, and by confirming that $f(x) - \text{tangent}(x)$ has a **double** root there, which is what tangency means and what a mere crossing would not give.

## 5. The exam-ready write-up

### The short form, which is what to write if time is tight

> The line $y = 6x + 2$ has slope $6$.
> A perpendicular line has slope $-\tfrac16$.
> $f'(x) = 6x + 4$, so $6x + 4 = -\tfrac16$, giving $x = -\tfrac{25}{36}$.

Three sentences, and every method mark is present: the given slope, the perpendicular condition, the derivative, the equation, the answer.

### The full-credit form, which adds the clauses a marker looks for

> The slope of the tangent line to $f$ at $x$ is $f'(x)$.
> Differentiating, $f'(x) = 6x + 4$.
> The given line $y = 6x + 2$ is in slope-intercept form, so its slope is $m_1 = 6$.
> Two lines are perpendicular exactly when $m_1 m_2 = -1$, so the tangent must have slope $m_2 = -\tfrac16$.
> Setting $f'(x) = -\tfrac16$ gives $6x + 4 = -\tfrac16$, hence $6x = -\tfrac{25}{6}$ and $x = -\tfrac{25}{36}$.
> Since $f'$ is linear with slope $6 \neq 0$, it takes the value $-\tfrac16$ exactly once, so $x = -\tfrac{25}{36}$ is the only such value.

The last sentence is the one most students skip, and on a stem that says "values" it is the sentence that answers the question completely.
It costs eight words and it is the difference between "solved an equation" and "answered the question".

### Where correct calculus still loses marks here

| what happens | why it costs |
| :--- | :--- |
| the answer is given as $-0.69$ | a 4-point item, machine-marked, and $-0.69$ is outside any reasonable tolerance of $-0.694444\ldots$ |
| the slope $-\tfrac16$ is reported as the answer | that is $m_{\text{req}}$, an input, not the $x$ that was asked for |
| the tangent *line* is given when $x$ was asked for | extra work, and on a machine-marked box it is simply wrong |
| $x$ is given when the *line* was asked for | the variant most likely to appear next; see Family 8 |
| the root count is never addressed | on a cubic variant this is the whole question |

## 6. Verify before you commit

### The eight-second check, inherited from Q8.1 §6

The centred-difference check from `Q8.1 - Four derivatives, power chain and quotient rules.md`, section 6, applies unchanged and is the fastest verification available.
Do not re-derive it; just apply it at your answer.

> Take your $x_0$. Compute $\dfrac{f(x_0 + 0.001) - f(x_0 - 0.001)}{0.002}$ on the calculator.
> It must equal $m_{\text{req}}$, not merely something plausible.

At $x_0 = -\tfrac{25}{36}$ this returns $-0.1666666667$ against the required $-\tfrac16 = -0.1666666667$: agreement to ten figures, because the quotient is centred and a quadratic has no third derivative for the truncation term to bite on.

**This check is stronger here than it was in Q8.1**, and it is worth understanding why.
In Q8.1 it verified that you had differentiated correctly.
Here it verifies the *whole chain at once*: if you flipped the slope the wrong way, or read the given line's slope wrong, or made an arithmetic slip solving for $x$, the number that comes out is not $m_{\text{req}}$ and the check fires.
One calculator operation tests all four steps.

### The three-line perpendicularity check

| check | on Q9.1 | what it catches |
| :--- | :--- | :--- |
| $m_{\text{given}} \times m_{\text{req}} = -1$ | $6 \times (-\tfrac16) = -1$ | using $6$, $-6$, or $+\tfrac16$ |
| the two slopes have **opposite signs** | $6 > 0$, $-\tfrac16 < 0$ | forgetting the minus sign |
| $|m_{\text{req}}| = 1/|m_{\text{given}}|$ | $\tfrac16$ against $6$ | forgetting the reciprocal |

A perpendicular pair is always one steep and one shallow, and always one up and one down.
If both your slopes are positive, you are wrong before you have done any calculus.

### The structural invariants, which cost no arithmetic

| invariant | why it holds | on Q9.1 |
| :--- | :--- | :--- |
| the answer sits on the side of the vertex that matches the sign of $m_{\text{req}}$ | $f'$ increases when $a > 0$ | $m_{\text{req}} < 0$, so $x < -\tfrac23$, and $-0.694 < -0.667$ |
| a small $|m_{\text{req}}|$ puts the answer *near* the vertex | $x - x_v = m/(2a)$ | $|{-\tfrac16}|$ is small, and $-0.694$ is $0.028$ from the vertex |
| a quadratic gives exactly one answer | $f'$ is linear and non-constant | one root, confirmed two ways |
| the tangent line must touch, not cross | $f - \text{tangent}$ has a double root | verified: $f - T > 0$ on both sides |

The last one is the only invariant that catches a wrong *point* with a right *slope*, and it is worth 15 seconds when the variant asks for a line.

### Numbers worth holding

| | |
| :--- | :--- |
| $f'(x)$ | $6x + 4$ |
| the vertex of $f$ | $x = -\tfrac23$, $f = -\tfrac{13}{3}$ |
| the answer | $x = -\tfrac{25}{36} \approx -0.694444$ |
| the tangent point | $\left(-\tfrac{25}{36},\, -\tfrac{1871}{432}\right) \approx (-0.6944,\, -4.3310)$ |
| the tangent line | $y = -\tfrac{x}{6} - \tfrac{1921}{432}$ |
| the **parallel** answer, if the word changes | $6x + 4 = 6 \Rightarrow x = \tfrac13$ |
| the **horizontal** answer, if the word changes | $x = -\tfrac23$ |

Those last two rows are the cheapest insurance on this page.
The same curve with "parallel" instead of "perpendicular" gives $x = \tfrac13$, and with "horizontal tangent" gives $x = -\tfrac23$.
All three are one-line changes to Step 1 and nothing else.

## 7. Answer-entry rules

Both papers are Möbius, answer-only, machine-marked.
The A1 block of `MATH265-Reference-Sheets` is the authority; this is the Q9.1-specific slice of it.

| do | do not |
| :--- | :--- |
| `-25/36` | `-0.69`, which is outside tolerance |
| `-(25/36)` if the box dislikes a leading minus on a fraction | `-25/36.` with a stray period |
| type every multiplication with `*`, e.g. `-x/6-1921/432` | rely on juxtaposition anywhere |
| bracket a whole numerator and a whole denominator | `-1/6x`, which parses as $-\dfrac{1}{6x}$ |
| enter an **exact fraction** unless a decimal is requested | round; $-25/36$ is not a terminating decimal |
| if a decimal is demanded, give at least 6 figures: `-0.694444` | `-0.694`, which fails at $10^{-4}$ |
| for a **line**, enter the full equation `y=-x/6-1921/432` | enter only the slope |
| **preview the rendered expression before submitting** | submit unpreviewed |

**The single most expensive typo on this question is `-1/6x`.**
It is one missing bracket, it renders as something plausible, and it is $-\dfrac{1}{6x}$ rather than $-\dfrac{x}{6}$.
Write `-x/6` or `(-1/6)*x` and the ambiguity disappears.

**The second most expensive is answering with the wrong object.**
A box that wants an $x$ will not accept `y=-x/6-1921/432`, and a box that wants a line will not accept `-25/36`.
Re-read the stem's final clause before typing; it is the last four words that decide.

Three equivalent exact entries for the answer, all verified equal to $10^{-15}$:

$$-\frac{25}{36} \;=\; -\left(\frac{25}{36}\right) \;=\; \frac{-25}{36}$$

Enter the first.

## 8. The variation catalog

Every instance below was solved and then verified numerically: the claimed $x$ was substituted back into $f'$ and checked against the required slope by two independent derivative methods, and every root list was confirmed complete by two independent root censuses.

**Read this catalog as one procedure with a swapped Step 1.**
Families 1 through 4 change only the phrase that sets $m_{\text{req}}$.
Families 5 through 7 change only the *shape of $f$*, and therefore only the root count.
Families 8 through 12 change only *what you report at the end*.
There are three moving parts in the whole family, and each variation moves exactly one of them.

### Family 0 - identify $m_{\text{req}}$ from the phrase

The trigger is the relationship word in the stem, and it is the only thing Step 1 reads.

| phrase in the stem | $m_{\text{req}}$ | on Q9.1's line $y = 6x+2$ |
| :--- | :--- | :--- |
| perpendicular to | $-1/m$ | $-\tfrac16$ |
| parallel to | $m$ | $6$ |
| horizontal | $0$ | $0$ |
| normal to the curve is parallel to | $-1/m$ then flip again; see Family 9 | depends |
| has the same slope as | $m$ | $6$ |
| perpendicular to the $x$-axis | tangent is vertical | impossible for a polynomial |
| perpendicular to the $y$-axis | tangent is horizontal | $0$ |

**Tool it forces.** Nothing but careful reading. This is where 4 points are won or lost.

### Family 1 - perpendicular, quadratic curve

**Trigger.** "perpendicular", and $f$ is quadratic.
**Tool.** $f'$ is linear, so the equation is linear: exactly one answer, always.
**Worked shape.** $2ax + b = -1/m_{\text{given}} \Rightarrow x = \dfrac{-1/m_{\text{given}} - b}{2a}$.

| $f$ | given line | $m_{\text{given}}$ | $m_{\text{req}}$ | $x$ | decimal |
| :--- | :--- | :--- | :--- | :--- | :--- |
| $3x^2+4x-3$ | $y = 6x+2$ | $6$ | $-\tfrac16$ | $-\tfrac{25}{36}$ | $-0.694444$ |
| $2x^2-5x+1$ | $y = 4x-7$ | $4$ | $-\tfrac14$ | $\tfrac{19}{16}$ | $1.1875$ |
| $x^2-6x+4$ | $y = \tfrac12 x+3$ | $\tfrac12$ | $-2$ | $2$ | $2$ |
| $x^2$ | $y = -\tfrac{x}{8}$ | $-\tfrac18$ | $8$ | $4$ | $4$ |
| $3x^2+4x-3$ | $2x-3y=6$ | $\tfrac23$ | $-\tfrac32$ | $-\tfrac{11}{12}$ | $-0.916667$ |
| $3x^2+4x-3$ | $4x+2y-7=0$ | $-2$ | $\tfrac12$ | $-\tfrac{7}{12}$ | $-0.583333$ |

**Read the structure.** Only two magnitudes are ever in play: $m_{\text{req}}$ and the vertex position $-b/2a$.
Every answer in the table is the vertex shifted by $m_{\text{req}}/(2a)$, so the sign of $m_{\text{req}}$ alone tells you which side of the vertex to land on.

### Family 2 - parallel instead of perpendicular

**Trigger.** "parallel to", or "has the same slope as".
**Tool.** Identical procedure, with $m_{\text{req}} = m_{\text{given}}$ and no reciprocal.

| $f$ | given line | $m_{\text{req}}$ | $x$ |
| :--- | :--- | :--- | :--- |
| $3x^2+4x-3$ | $y = 6x+2$ | $6$ | $\tfrac13$ |
| $4x^2-8x+1$ | through $(1,3)$ and $(4,9)$ | $2$ | $\tfrac54$ |
| $x^3-3x+2$ | $y = 9x+1$ | $9$ | $x = \pm 2$, two answers |

**The trap.** This is the *easier* variation, and that is exactly why it is dangerous: the reflex trained on "perpendicular" flips a slope that should not be flipped.
Read the word, do not pattern-match the shape of the question.

### Family 3 - horizontal tangent

**Trigger.** "horizontal tangent", "tangent parallel to the $x$-axis", "where the slope is zero", or (in disguise) "the vertex", "the maximum", "the critical point".
**Tool.** $f'(x) = 0$.

| $f$ | $f'$ | $x$ | $y$ |
| :--- | :--- | :--- | :--- |
| $3x^2+4x-3$ | $6x+4$ | $-\tfrac23$ | $-\tfrac{13}{3}$ |
| $x^3-3x+2$ | $3x^2-3$ | $\pm 1$ | $0$ and $4$ |
| $x^3-2x^2+x$ | $3x^2-4x+1$ | $\tfrac13$ and $1$ | $\tfrac{4}{27}$ and $0$ |

This is the same question with $m_{\text{req}} = 0$, and it is the bridge to the whole of category 12 (extrema).
For a quadratic the answer always equals $-b/(2a)$, which is a free cross-check against the vertex formula.

### Family 4 - the degenerate line

**Trigger.** The given line is $x = c$ or $y = c$.
**Tool.** Geometry, because $-1/m$ is either undefined or infinite.

| given line | it is | perpendicular tangent must be | condition | on $f = 3x^2+4x-3$ |
| :--- | :--- | :--- | :--- | :--- |
| $x = 5$ | vertical | horizontal | $f'(x) = 0$ | $x = -\tfrac23$ |
| $y = 7$ | horizontal | vertical | $f'$ undefined | no solution |
| $x = 5$, **parallel** | vertical | vertical | $f'$ undefined | no solution |
| $y = 7$, **parallel** | horizontal | horizontal | $f'(x) = 0$ | $x = -\tfrac23$ |

**The tool this forces** is the sentence "a polynomial is differentiable everywhere, so its tangent is never vertical".
Write that sentence; it *is* the answer to the impossible cases, and a blank page scores nothing.

### Family 5 - a cubic curve, and the second root

**Trigger.** $f$ is a cubic, so $f'$ is a quadratic and $f'(x) = m$ is a quadratic equation.
**Tool.** The quadratic formula, plus a discriminant statement about how many roots exist.
**This is the classic lost mark in the whole family.** One root is found, the stem said "values", and the second one is never looked for.

| $f$ | condition | equation | roots | decimals |
| :--- | :--- | :--- | :--- | :--- |
| $x^3-2x^2+x$ | perpendicular to $y = -\tfrac{x}{3}+5$, so $m_{\text{req}}=3$ | $3x^2-4x+1=3$ | $x = \dfrac{2\pm\sqrt{10}}{3}$ | $-0.387426$, $1.720759$ |
| $x^3-3x+2$ | parallel to $y = 9x+1$ | $3x^2-3=9$ | $x = \pm 2$ | $-2$, $2$ |
| $x^3+x$ | perpendicular to $y = 2x$, so $m_{\text{req}}=-\tfrac12$ | $3x^2+1=-\tfrac12$ | none | see Family 6 |

For the first row the tangent points factor pleasantly, because $x^3-2x^2+x = x(x-1)^2$:

$$\left(\frac{2+\sqrt{10}}{3},\ \frac{2+7\sqrt{10}}{27}\right) \approx (1.720759,\ 0.893924), \qquad
\left(\frac{2-\sqrt{10}}{3},\ \frac{2-7\sqrt{10}}{27}\right) \approx (-0.387426,\ -0.745776).$$

**The habit that saves this mark.**
After solving, look at the degree of $f'$ and say the count out loud.
"$f'$ is a quadratic, so there are at most two, and the discriminant is positive, so there are exactly two."
Twelve words, and it is the difference between half marks and full marks.

### Family 6 - no solution exists

**Trigger.** The required slope is outside the range of $f'$.
**Tool.** State the range of $f'$ and observe that $m_{\text{req}}$ is not in it.

| $f$ | $f'$ | range of $f'$ | $m_{\text{req}}$ | verdict |
| :--- | :--- | :--- | :--- | :--- |
| $x^3+x$ | $3x^2+1$ | $[1,\infty)$ | $-\tfrac12$ | no such $x$ |
| $x^2$ | $2x$ | $\mathbb{R}$ | anything | always exactly one |
| $e^x$ | $e^x$ | $(0,\infty)$ | any $m \le 0$ | no such $x$ |
| $\sqrt x$ | $\tfrac{1}{2\sqrt x}$ | $(0,\infty)$ | any $m \le 0$ | no such $x$ |
| $1/x$ | $-1/x^2$ | $(-\infty,0)$ | any $m \ge 0$ | no such $x$ |

**Do not leave this blank.**
"No such $x$ exists, because $f'(x) = 3x^2+1 \ge 1$ for all $x$ while the required slope is $-\tfrac12$" is a complete answer and earns the marks.
The census machinery used to verify this section was itself controlled: it was shown to return two roots on a two-root polynomial and zero on $x^2+1$, so a report of "zero roots" here means zero roots and not a broken check.

### Family 7 - a curve that is not a polynomial

**Trigger.** $f$ involves a root, a reciprocal, an exponential, or a trig function.
**Tool.** The same Step 3, but the equation $f'(x) = m$ now needs the inverse of whatever $f'$ is.

| $f$ | $f'$ | condition | equation | $x$ |
| :--- | :--- | :--- | :--- | :--- |
| $\sqrt x$ | $\tfrac{1}{2\sqrt x}$ | perpendicular to $y=-4x+1$, $m_{\text{req}}=\tfrac14$ | $\tfrac{1}{2\sqrt x} = \tfrac14$ | $x = 4$ |
| $1/x$ | $-1/x^2$ | perpendicular to $y=4x$, $m_{\text{req}}=-\tfrac14$ | $-\tfrac{1}{x^2} = -\tfrac14$ | $x = \pm 2$, **two** |
| $e^x$ | $e^x$ | perpendicular to $y=-\tfrac{x}{2}$, $m_{\text{req}}=2$ | $e^x = 2$ | $x = \ln 2$ |
| $\sin x$ on $[0,2\pi]$ | $\cos x$ | perpendicular to $y=-2x$, $m_{\text{req}}=\tfrac12$ | $\cos x = \tfrac12$ | $\tfrac{\pi}{3}$, $\tfrac{5\pi}{3}$ |
| $\ln x$ | $1/x$ | parallel to $y = 3x$ | $1/x = 3$ | $x = \tfrac13$ |

**Two things this family forces that the polynomial cases do not.**

1. **A domain check.** $\sqrt x$ needs $x > 0$, $\ln x$ needs $x > 0$, $1/x$ excludes $0$.
   A root of the equation that lies outside the domain is not an answer.
2. **A root count that is not read off a degree.** $-1/x^2 = -1/4$ gives two answers from a non-polynomial, and $\cos x = \tfrac12$ gives infinitely many unless an interval is stated.
   Sketch $f'$ and count crossings; that picture works for every row of this table.

### Family 8 - the answer is a LINE, not an $x$

**Trigger.** "Find the equation of the tangent line", rather than "find the values of $x$".
**Tool.** Point-slope, using $y_0 = f(x_0)$ from the **original** function.

Worked, for $f(x) = x^2-6x+4$ perpendicular to $y = \tfrac12 x + 3$:

$$m_{\text{req}} = -2,\qquad 2x-6=-2 \Rightarrow x_0 = 2,\qquad y_0 = f(2) = -4,$$
$$y = -2(x-2) - 4 = -2x.$$

Verified by evaluating: the line and the curve both give $-4$ at $x=2$, and $f - L = x^2 - 4x + 4 = (x-2)^2$ has a double root there, so the line touches rather than crosses.

For Q9.1's own curve the corresponding line is $y = -\tfrac{x}{6} - \tfrac{1921}{432}$.

**The three failure modes, in order of frequency.**

1. Stopping at $x_0$ and never writing a line.
2. Using $f'(x_0)$ as the $y$-coordinate instead of $f(x_0)$.
3. Writing the line with the *given* slope $m_{\text{given}}$ instead of $m_{\text{req}}$.

Each one is a complete loss on a machine-marked box, and each one is caught by the same 10-second test: put $x_0$ into both your line and $f$, and demand the same number.

### Family 9 - the normal line

**Trigger.** "normal line", "the line perpendicular **to the curve**", "perpendicular to the tangent at $x = a$".
**Tool.** The perpendicular flip is applied to $f'(a)$, not to a given line's slope.

$$m_{\text{normal}} = -\frac{1}{f'(a)}.$$

For $f(x) = 3x^2+4x-3$ at $x = 1$: $f(1) = 4$, $f'(1) = 10$, so $m_{\text{normal}} = -\tfrac{1}{10}$ and

$$y = -\frac{1}{10}(x-1) + 4 = -\frac{x}{10} + \frac{41}{10}.$$

**The distinction that matters.**
In Family 1 the flip converts a *given line's* slope into the *tangent's* slope, and you then solve for $x$.
In Family 9 the flip converts the *tangent's* slope into the *normal's* slope, and $x$ was given to you.
The arrow runs the other way, and the word that tells you which is "to the line" versus "to the curve".

### Family 10 - a tangent through an external point

**Trigger.** "the tangent line to $f$ that passes through $(p,q)$", where $(p,q)$ is *not* on the curve.
**Tool.** Unknown tangency point $a$, then force the line through the given point.

$$\text{tangent at } a:\quad y = f'(a)(x-a) + f(a), \qquad \text{require } q = f'(a)(p-a)+f(a).$$

For $f(x) = x^2$ through $(0,-1)$: $-1 = 2a(0-a)+a^2 = -a^2$, so $a = \pm 1$, giving

$$y = 2x - 1 \qquad\text{and}\qquad y = -2x - 1.$$

**This is the family most likely to be mistaken for Q9.1 and solved wrong.**
There is no perpendicularity here at all, and there are usually two answers.
The tell is that a *point* is given rather than a *line*, and that the point is not on the curve.

### Family 11 - the given line is disguised

**Trigger.** The line arrives as $Ax+By=C$, as two points, as a segment, or as a description.
**Tool.** Convert to a slope before anything else. See the table in section 2.3.

| how it arrives | slope | on $f = 3x^2+4x-3$, perpendicular |
| :--- | :--- | :--- |
| $2x-3y=6$ | $\tfrac23$ | $x = -\tfrac{11}{12}$ |
| $4x+2y-7=0$ | $-2$ | $x = -\tfrac{7}{12}$ |
| through $(1,3)$, $(4,9)$ | $2$ | $6x+4=-\tfrac12 \Rightarrow x = -\tfrac{3}{4}$ |
| $x = 5$ | vertical | $x = -\tfrac23$ (horizontal tangent) |
| $y = 7$ | $0$ | no solution |

**The standard misfire** is reading $A$ as the slope of $Ax+By=C$.
On $2x-3y=6$ that gives $2$ instead of $\tfrac23$, and the whole answer follows the error silently.
Solve for $y$ every time; it costs one line.

### Family 12 - solve for a parameter

**Trigger.** The curve carries an unknown constant and a slope condition is imposed.
**Tool.** Same equation, different unknown: solve $f'(x_0) = m_{\text{req}}$ for the parameter rather than for $x$.

| set-up | equation | answer |
| :--- | :--- | :--- |
| for which $a$ does $f = ax^2+4x-3$ have a tangent of slope $-\tfrac16$ at $x=-1$? | $-2a+4=-\tfrac16$ | $a = \tfrac{25}{12}$ |
| for which $k$ is the tangent to $f=3x^2+4x-3$ at $x=1$ perpendicular to $y = kx+2$? | $10k=-1$ | $k = -\tfrac{1}{10}$ |
| for which $c$ is $y = -\tfrac{x}{6}+c$ tangent to $f = 3x^2+4x-3$? | discriminant of $f - L$ is zero | $c = -\tfrac{1921}{432}$ |

The third row is worth noticing: "tangent to" for a *line with a known slope* can be solved either by this family's method or by demanding that $f(x) - L(x)$ have a double root.
Both give $c = -\tfrac{1921}{432}$, which is the same tangent line found in section 4.

## 9. The trap list

Ranked by how often it actually costs marks in this family.

1. **Only one root found when there are two.**
   A cubic curve makes $f'(x) = m$ a quadratic, and the stem's word "values" was literal.
   *Fix:* after solving, name the degree of $f'$ and state the root count explicitly.
2. **Answering with the wrong object.**
   Reporting $x$ when a line was demanded, or a line when $x$ was demanded, or the slope $m_{\text{req}}$ when either was demanded.
   *Fix:* re-read the final clause of the stem before typing.
3. **The perpendicular flip done half-way.**
   $-6$ (negated, not reciprocated) or $\tfrac16$ (reciprocated, not negated).
   *Fix:* multiply the two slopes; it must be exactly $-1$.
4. **Not flipping at all, because the question said parallel.**
   Or flipping when it said parallel.
   *Fix:* underline the relationship word before Step 1.
5. **Reading the slope wrong off $Ax+By=C$.**
   $2x-3y=6$ has slope $\tfrac23$, not $2$ and not $-\tfrac23$.
   *Fix:* solve for $y$; never eyeball it.
6. **Using $f'(x_0)$ as the $y$-coordinate of the tangent point.**
   The point is $(x_0, f(x_0))$, always from the original function.
   *Fix:* evaluate the line and the curve at $x_0$ and demand the same number.
7. **Rounding the answer.**
   $-0.69$ is wrong, $-0.694$ is wrong at $10^{-4}$, $-\tfrac{25}{36}$ is right.
   *Fix:* enter the exact fraction.
8. **Missing the domain restriction on a non-polynomial.**
   A root of $f'(x)=m$ outside the domain of $f$ is not a tangent point.
   *Fix:* state the domain before you solve.
9. **Treating a vertical or horizontal given line with the $-1/m$ formula.**
   $-1/0$ is not an answer.
   *Fix:* switch to the geometric statement.
10. **Manufacturing a second answer because the stem said "values".**
    On a quadratic curve there is exactly one, and inventing a partner loses the mark you had.
    *Fix:* the count comes from the degree of $f'$, not from the grammar of the stem.
11. **Silent sign error in $-\tfrac16 - 4$.**
    $-\tfrac{25}{6}$, not $-\tfrac{23}{6}$ and not $\tfrac{23}{6}$.
    *Fix:* the eight-second centred-difference check catches this immediately.

Score **sign** and **magnitude** separately.
A wrong sign almost always means Step 1 (the flip) went wrong; a wrong magnitude almost always means Step 3 (the algebra) went wrong.
Those need different remediation, so a single "wrong" tells you nothing.

## 11. The one-page decision tree

```
  READ THE STEM. Underline the relationship word and the final clause.
  |
  +-- What is the required slope?
  |     "perpendicular to a LINE"      -> m_req = -1/m_given
  |     "parallel to a LINE"           -> m_req =  m_given
  |     "horizontal" / "slope zero"    -> m_req =  0
  |     "normal to the CURVE at x=a"   -> m = -1/f'(a); x is already given, go to ASSEMBLE
  |     "through the point (p,q)"      -> Family 10, solve f'(a)(p-a)+f(a) = q
  |
  +-- Is the given line disguised?
  |     Ax+By=C   -> m = -A/B      (solve for y; do not read A)
  |     two points-> m = dy/dx
  |     x = c     -> vertical: perpendicular tangent is HORIZONTAL, f'=0
  |     y = c     -> horizontal: perpendicular tangent is VERTICAL, impossible for a polynomial
  |
  +-- DIFFERENTIATE.  f'(x) = ...            (Q8.1 classify table)
  |
  +-- SOLVE f'(x) = m_req.
  |
  +-- COUNT THE ROOTS. Say the count out loud.
  |     f quadratic -> f' linear    -> exactly 1
  |     f cubic     -> f' quadratic -> 0, 1 or 2; check the discriminant
  |     non-polynomial              -> sketch f', count crossings of y = m_req
  |     m_req outside range of f'   -> none; write the sentence, do not blank
  |     domain restriction?         -> discard roots outside it
  |
  +-- ASSEMBLE what was asked.
  |     "values of x"       -> the x list
  |     "the point(s)"      -> (x, f(x)), from f, NOT from f'
  |     "the equation"      -> y = m_req (x - x0) + f(x0)
  |
  +-- CHECK.
  |     centred quotient at x0 must equal m_req         (Q8.1 section 6)
  |     m_given * m_req must equal -1 exactly
  |     the two slopes must have opposite signs
  |     for a line: line(x0) and f(x0) must be the SAME number
  |
  +-- PREVIEW the rendered answer, then submit.
```
