# Q15.1 - All maxima and minima on closed intervals

**The question (Final Exam 1, item 5, 11 points).**
"Find all maxima and minima of the functions listed below on the indicated intervals."
a. $f(x) = 2x^{5/3} - 5x^{4/3}$ on $[-1, 20]$
b. $f(x) = x + \cos x$ on $[-\pi, 2\pi]$

**The answers.**

| | part (a) $2x^{5/3}-5x^{4/3}$ on $[-1,20]$ | part (b) $x+\cos x$ on $[-\pi,2\pi]$ |
| :--- | :--- | :--- |
| absolute **maximum value** | $40\cdot 20^{2/3} - 100\cdot 20^{1/3} \approx 23.2808$ | $2\pi + 1 \approx 7.2832$ |
| attained **at the point** | $x = 20$, the right endpoint | $x = 2\pi$, the right endpoint |
| absolute **minimum value** | $-16$ | $-\pi - 1 \approx -4.1416$ |
| attained **at the point** | $x = 8$, an interior critical point | $x = -\pi$, the left endpoint |
| local extremes inside | local **max** $0$ at $x=0$ | **none** |
| critical points that are **not** extremes | none | $x = \pi/2$, where $f'$ touches zero |

**What to type into Möbius:** for part (a), `40*20^(2/3)-100*20^(1/3)` or `23.2808` for the maximum and `-16` for the minimum; for part (b), `2*pi+1` and `-pi-1`.
Say the **value** and the **point** separately every time, because they are two different answers and the marker wants both.

Q15.1 **opens** category 15, the five-question extreme-values and optimization block, which is the largest remaining group in the bank.
Its job is to own the **closed-interval method** so that the other four questions only have to add one thing each.

## 0. The 30-second version

```
    1.  f'(x)  ->  set = 0          ->  critical points
              ->  where UNDEFINED  ->  critical points too
    2.  keep only the ones INSIDE (a,b)
    3.  CANDIDATES = those critical points  +  a  +  b        <- BOTH endpoints
    4.  evaluate f at every candidate
    5.  biggest number = absolute MAX,  smallest = absolute MIN
        report the NUMBER (the value) and the x (the point), separately
```

No first-derivative test.
No second-derivative test.
No sign chart.
You compare a short list of numbers, and the largest one wins because the Extreme Value Theorem already promised you a winner exists.

### 1.2 The one idea

**Both endpoints are candidates, and a critical point is only a candidate.**

Everything that goes wrong on this question goes wrong at one of those two clauses.
Part (a) punishes you for forgetting the right endpoint: its absolute maximum is $f(20)$, and a student who tests only critical points reports $0$ at $x=0$ and is $23.28$ too low.
Part (b) punishes you for assuming a critical point must be an extreme: $x=\pi/2$ is a genuine critical point and it is neither a maximum nor a minimum.

The two parts are **designed as complements**, and the harness measured it.
Across the two parts there are four absolute extremes.
**Three of them sit at an endpoint and exactly one sits at an interior critical point.**
So the pair uses every row of the candidate table: left endpoint, interior critical point, right endpoint, and a critical point that earns nothing.

### 1.3 What the category needs from this question, and what each later question adds

Q15.1 must establish four things, because the other four questions all assume them:

1. the **closed-interval method** itself (critical points plus both endpoints, compare values, no derivative test required);
2. **why the extremes exist at all**, which is the Extreme Value Theorem and its three hypotheses;
3. the **local versus absolute** distinction, including that an endpoint extreme is normally reported as absolute;
4. the **vocabulary**: the *value* of an extreme against the *point where it occurs*.

Given those, each later question is one increment.

## 2. The five things you must have cold

### 2.1 The Extreme Value Theorem

> If $f$ is **continuous** on a **closed**, **bounded** interval $[a,b]$, then $f$ attains an absolute maximum and an absolute minimum somewhere on $[a,b]$.

Three hypotheses, and each one is load-bearing.
The harness removed them one at a time.

| hypothesis dropped | what breaks | measured |
| :--- | :--- | :--- |
| closed | $f$ on $[-1,20)$ has no maximum | the supremum $23.2808$ is approached over $200{,}000$ samples and never attained |
| bounded | $f$ on $[-1,\infty)$ has no maximum | $f(10^6) > 10^9$ |
| continuous | $1/x$ on $[-1,1]$ has neither extreme | values exceed $10^8$ arbitrarily close to $0$ |

The theorem is **one-directional**.
It promises the extremes exist.
It says nothing whatever about *where* they are, which is exactly why you still have to build a candidate list.

### 2.2 What a critical point is

$c$ in $(a,b)$ is a critical point of $f$ when **either** $f'(c) = 0$ **or** $f'(c)$ does not exist.

That "or" is half the definition and it is the half that gets dropped.
Three different things make $f'$ fail to exist, and all three are critical points:

| kind | one-sided slopes | example |
| :--- | :--- | :--- |
| corner | finite and unequal | $\lvert x^2-1\rvert$ at $x=1$: measured $-2$ and $+2$ |
| cusp | infinite and **opposite** | $(x^2-4)^{2/3}$ at $x=2$: measured $\to -\infty$ and $\to +\infty$ |
| vertical tangent | infinite and **equal** | $x^{1/3}$ at $x=0$: both $\to +\infty$ |

Part (a) has **none** of these, and that is worth knowing why: both of its exponents, $5/3$ and $4/3$, are **greater than 1**, so $f'$ has only non-negative powers of $x^{1/3}$ and is finite everywhere.
The moment an exponent drops below 1 you get an undefined derivative, which is what Q15.5 and drill D2 are for.

### 2.3 Real cube roots of negative numbers

$$(-1)^{5/3} = \left(\sqrt[3]{-1}\right)^5 = (-1)^5 = -1, \qquad (-1)^{4/3} = \left(\sqrt[3]{-1}\right)^4 = (-1)^4 = +1$$

Odd numerator keeps the sign, even numerator kills it.
Do it as "cube root first, then power", never as a decimal exponent.

This is not only a hand-arithmetic warning.
The harness confirmed that `(-1)**(4/3)` in floating point returns a **complex** number whose modulus is right and whose value is wrong, with a relative error of exactly $1.00$ against the real answer.
Any check of this family has to use $\operatorname{sign}(x)\,\lvert x\rvert ^{1/3}$.

### 2.4 Where $f'$ touching zero is different from crossing zero

$f'(c) = 0$ says the tangent is horizontal.
It does **not** say $f$ has an extreme at $c$.
An extreme needs $f'$ to **change sign**.

Part (b) is the whole lesson: $f'(x) = 1 - \sin x \ge 0$ for every $x$, with equality only at $x = \pi/2$.
So $f$ is increasing on the entire interval, and the horizontal tangent at $\pi/2$ is a flat spot on the way up.
The polynomial rehearsal is $x^4 - 4x^3$, whose $f' = 4x^2(x-3)$ has a double root at $0$; drill D9 works it.

### 2.5 The vocabulary

| the marker asks for | what it is | part (a) |
| :--- | :--- | :--- |
| the maximum **value** | a $y$-value, an output of $f$ | $\approx 23.2808$ |
| the **point** where it occurs | an $x$-value, an input | $20$ |
| the maximum **point** as a pair | $(x, f(x))$ | $(20,\, 23.2808)$ |

Writing "the maximum is $20$" is the single most expensive slip on this question, because $20$ and $23.2808$ are close enough that no sanity check catches it.
The harness measured the gap: the wrong answer is only **14.1 percent** below the right one.
On part (b) the same confusion gives $6.2832$ against $7.2832$, a difference of **exactly 1**, which looks even more like a rounding difference than an error.

## 3. The universal procedure

> **Step 1. Confirm the EVT applies.** The interval is closed and bounded, and $f$ is continuous on it. One sentence. If either fails, you are in section 8's family 6 or family 9 instead and the method changes.
>
> **Step 2. Differentiate.** Get $f'$ into a **factored** form, because you are about to set it to zero and you also want to see instantly where it blows up.
>
> **Step 3. Find where $f' = 0$.** Solve. Substitute if a fractional power makes it easier.
>
> **Step 4. Find where $f'$ is undefined.** Look for a denominator, a negative power, an absolute value, or an exponent strictly between 0 and 1. If there are none, **say so** rather than skipping the step.
>
> **Step 5. Discard critical points outside $(a,b)$.** They are not candidates. A critical point outside the interval is simply irrelevant.
>
> **Step 6. Build the candidate list: the surviving critical points, plus $a$, plus $b$.** Write the endpoints down first, before the critical points, so you cannot forget them.
>
> **Step 7. Evaluate $f$ at every candidate.** Exact values, in a table.
>
> **Step 8. Compare. Largest is the absolute max, smallest is the absolute min.** Report each as a value **and** a point.
>
> **Step 9. If the question said "all maxima and minima", also classify the interior critical points that did not win**, as local max, local min, or neither.

### 3.1 How to classify a step-4 candidate quickly

| what you see in $f'$ | is $f'$ undefined anywhere? | why |
| :--- | :--- | :--- |
| every power of $x$ is $\ge 0$ | no | nothing to divide by; part (a) |
| a negative power, e.g. $x^{-1/3}$ | yes, at $x=0$ | drill D2 |
| a denominator that vanishes in $[a,b]$ | $f$ itself is discontinuous, the EVT fails | family 5 |
| an absolute value with a zero inside | yes, a corner | drill D7 |
| $(\text{something})^{p}$ with $0<p<1$ | yes, where the something vanishes | Q15.5, drill D5 |
| $\sin$, $\cos$, polynomials only | no | part (b) |

### 3.2 Why step 9 is separate

The closed-interval method answers "what are the absolute extremes" without any derivative test at all.
It does **not** tell you what the losing critical points are.
Q15.1's stem says "find **all** maxima and minima", so the losers need naming too, and that needs a sign chart of $f'$ or a second-derivative test.
Q15.3 and Q15.5 say "absolute extreme values" instead, and there step 9 is not required.
**Read which of the two you were asked.**

## 4. Q15.1 worked

### 4.1 Part (a), $f(x) = 2x^{5/3} - 5x^{4/3}$ on $[-1, 20]$

**Step 1.** $x^{5/3}$ and $x^{4/3}$ are defined and continuous for every real $x$, since the cube root is.
$[-1,20]$ is closed and bounded.
The EVT applies, so both extremes exist.

**Step 2.**

$$f'(x) = 2\cdot\tfrac{5}{3}x^{2/3} - 5\cdot\tfrac{4}{3}x^{1/3} = \tfrac{10}{3}x^{2/3} - \tfrac{20}{3}x^{1/3} = \tfrac{10}{3}\,x^{1/3}\!\left(x^{1/3} - 2\right)$$

**Step 3.** $\frac{10}{3}x^{1/3}(x^{1/3}-2) = 0$ gives $x^{1/3} = 0$ or $x^{1/3} = 2$, so $x = 0$ or $x = 8$.

The substitution $t = x^{1/3}$ is worth naming, because it turns the whole family into a polynomial: $f = 2t^5 - 5t^4$ and $\mathrm{d}f/\mathrm{d}t = 10t^3(t-2)$, with roots $t=0$ and $t=2$.
Cube them back: $0$ and $8$.
And because $t = x^{1/3}$ is increasing, it preserves the order of values, so the comparison in step 8 could be done in $t$ as well.

**Step 4.** Every power of $x$ appearing in $f'$ is positive ($2/3$ and $1/3$).
There is no denominator and no negative power.
So **$f'$ is defined everywhere, and there are no cusps, corners or vertical tangents.**

This is worth checking rather than asserting, and the harness did.
The one-sided difference quotients at $x=0$ have closed forms:

$$\frac{f(h)-f(0)}{h} = -5h^{1/3} + 2h^{2/3}, \qquad \frac{f(0)-f(-h)}{h} = +5h^{1/3} + 2h^{2/3}$$

Both were confirmed to $10^{-14}$ over a ladder from $h = 10^{-3}$ down to $10^{-30}$.
They approach $0$ from **opposite sides**, and they agree in the limit, which is what "differentiable at $0$, with $f'(0) = 0$" means.
Note the rate: each factor-of-1000 cut in $h$ divides the quotient by only **10**, because the convergence is $O(h^{1/3})$ and not $O(h)$.
That is why a spot check at $h=10^{-6}$ shows a slope of $-0.0498$ and looks like it is not converging at all.

**Steps 5 and 6.** Both critical points are inside $(-1,20)$.

$$\text{candidates} = \{\,-1,\ 0,\ 8,\ 20\,\}$$

**Step 7.**

| $x$ | why it is a candidate | $f(x)$ exact | $f(x)$ decimal |
| :--- | :--- | :--- | :--- |
| $-1$ | left endpoint | $2(-1) - 5(1) = -7$ | $-7$ |
| $0$ | $f'=0$ | $0$ | $0$ |
| $8$ | $f'=0$ | $2(32) - 5(16) = -16$ | $-16$ |
| $20$ | right endpoint | $40\cdot 20^{2/3} - 100\cdot 20^{1/3}$ | $23.2807582317$ |

The $x=20$ value has three equivalent exact spellings, all confirmed equal to $10^{-11}$:

$$2\cdot 20^{5/3} - 5\cdot 20^{4/3} \;=\; 40\cdot 20^{2/3} - 100\cdot 20^{1/3} \;=\; 20\sqrt[3]{20}\left(2\sqrt[3]{20} - 5\right)$$

with $\sqrt[3]{20} = 2.7144176166$ and $20^{2/3} = 7.3680629973$.

**Step 8.**

- **Absolute maximum: the value $40\cdot 20^{2/3} - 100\cdot 20^{1/3} \approx 23.2808$, attained at $x = 20$.**
- **Absolute minimum: the value $-16$, attained at $x = 8$.**

**Step 9.** The sign of $f' = \frac{10}{3}x^{1/3}(x^{1/3}-2)$ comes from the two factors.

| interval | $x^{1/3}$ | $x^{1/3}-2$ | $f'$ | $f$ |
| :--- | :--- | :--- | :--- | :--- |
| $(-1, 0)$ | negative | negative | **positive** | increasing |
| $(0, 8)$ | positive, below 2 | negative | **negative** | decreasing |
| $(8, 20)$ | above 2 | positive | **positive** | increasing |

So $x=0$ is a **local maximum** with value $0$, and $x=8$ is a **local minimum** with value $-16$.
The endpoints are one-sided local extremes: $x=-1$ a local minimum, $x=20$ a local maximum.
Two sign changes, two interior extremes, and the intervals tile $[-1,20]$ breaking only at the critical points, which is Q14.1's cross-check (ii) applied here.

Note the second-derivative test would have been a poor choice.
$f''(x) = \frac{20}{9}x^{-1/3} - \frac{20}{9}x^{-2/3}$ **blows up at $x=0$**, the very point you most want classified, so the test is unusable there.
It does work at $x=8$, where $f''(8) = \frac{20}{9}\cdot\frac12 - \frac{20}{9}\cdot\frac14 = \frac59 > 0$ and confirms a local minimum.
The sign chart handles both points with one piece of machinery.

**One extra fact worth having.** $f(x) = x^{4/3}(2x^{1/3}-5)$ is zero at $x=0$ and at $x^{1/3} = 5/2$, that is $x = 125/8 = 15.625$.
So the graph dips below the axis after $x=0$, bottoms out at $(8,-16)$, and climbs back through zero at $15.625$ before reaching $23.2808$ at the right end.
That single number explains why the maximum is at the endpoint: the interval reaches past $15.625$.

### 4.2 Part (b), $f(x) = x + \cos x$ on $[-\pi, 2\pi]$

**Step 1.** A sum of a polynomial and a cosine is continuous everywhere, and $[-\pi, 2\pi]$ is closed and bounded.
The EVT applies.

**Step 2.** $f'(x) = 1 - \sin x$.

**Step 3.** $1 - \sin x = 0$ means $\sin x = 1$, so $x = \frac{\pi}{2} + 2k\pi$.
Over $[-\pi, 2\pi]$, which is only $3\pi$ long, exactly **one** of those lands inside: $k=0$, giving $x = \pi/2$.
($k=-1$ gives $-3\pi/2 < -\pi$ and $k=1$ gives $5\pi/2 > 2\pi$.)

**Step 4.** $1 - \sin x$ is defined for every $x$.
No cusps, no corners, no vertical tangents.

**Steps 5 to 7.**

| $x$ | why | $f(x)$ exact | $f(x)$ decimal |
| :--- | :--- | :--- | :--- |
| $-\pi$ | left endpoint | $-\pi - 1$ | $-4.1415926536$ |
| $\pi/2$ | $f'=0$ | $\pi/2 + 0 = \pi/2$ | $1.5707963268$ |
| $2\pi$ | right endpoint | $2\pi + 1$ | $7.2831853072$ |

**Step 8.**

- **Absolute maximum: the value $2\pi + 1 \approx 7.2832$, attained at $x = 2\pi$.**
- **Absolute minimum: the value $-\pi - 1 \approx -4.1416$, attained at $x = -\pi$.**

**Step 9, and this is the part worth marks.**
$\sin x \le 1$ for every $x$, so $f'(x) = 1 - \sin x \ge 0$ everywhere, with equality only at $\pi/2$.
Therefore $f$ is **increasing on the whole interval**, confirmed over $5000$ consecutive sample pairs.
The critical point $x=\pi/2$ is a horizontal tangent that is **neither a maximum nor a minimum**, and its value $\pi/2 \approx 1.5708$ sits strictly between the two endpoint values.
There are **no local extremes in the interior at all**.

The second-derivative test is silent here, and that is not bad luck but structural.
$f''(x) = -\cos x$, and $f''(\pi/2) = -\cos(\pi/2) = 0$.
What settles it is either the sign chart above, or the third derivative: $f'''(x) = \sin x$ and $\sin(\pi/2) = 1 \ne 0$, so $\pi/2$ is an inflection point, not an extreme.

**The touch zero is genuinely hard to find by looking, and the harness measured how hard.**
A **sign-change** census of $f'$ over $[-\pi, 2\pi]$ returns **zero** critical points at every resolution tried, from $37$ subintervals to $99{,}999$, because $f'$ never changes sign.
That is Q14.1's finding recurring exactly: *a sign-change census structurally cannot find a critical point where $f'$ touches zero without crossing.*
Only a third arm, a search for local minima of $\lvert f'\rvert$ refined by golden section, finds $\pi/2$.

And there is a coincidence in this particular interval that makes the point sharper, not weaker.
**$\pi/2$ is exactly the midpoint of $[-\pi, 2\pi]$**, since $(\pi/2 - (-\pi))/(3\pi) = 1/2$ precisely.
So any grid with an **even** number of subintervals lands on $\pi/2$ exactly, $1 - \sin x$ evaluates to a hard $0$, and a value-scan "finds" the critical point.
Any **odd** grid misses it entirely and reports a strictly positive minimum.
The verdict of a sampling test on part (b) is decided by the **parity of the grid**, which is the clearest possible statement that sampling is not a proof.
Solve $\sin x = 1$.

## 5. The exam-ready write-up

### 5.1 Part (a), short form

> $f'(x) = \frac{10}{3}x^{2/3} - \frac{20}{3}x^{1/3} = \frac{10}{3}x^{1/3}(x^{1/3}-2)$, which is defined for all $x$, so the only critical points are $x=0$ and $x=8$, both in $(-1,20)$.
> Candidates: $x = -1, 0, 8, 20$.
> $f(-1) = -7$, $f(0) = 0$, $f(8) = -16$, $f(20) = 40\cdot 20^{2/3} - 100\cdot 20^{1/3} \approx 23.281$.
> **Absolute maximum $\approx 23.281$ at $x=20$; absolute minimum $-16$ at $x=8$.**
> $f'$ changes from $+$ to $-$ at $0$ and from $-$ to $+$ at $8$, so $x=0$ is a local maximum (value $0$) and $x=8$ is a local minimum.

### 5.2 Part (b), short form

> $f'(x) = 1 - \sin x$, defined for all $x$, and zero only where $\sin x = 1$, that is $x = \pi/2 + 2k\pi$; only $x = \pi/2$ lies in $[-\pi, 2\pi]$.
> Candidates: $x = -\pi, \pi/2, 2\pi$.
> $f(-\pi) = -\pi - 1$, $f(\pi/2) = \pi/2$, $f(2\pi) = 2\pi + 1$.
> **Absolute maximum $2\pi + 1$ at $x = 2\pi$; absolute minimum $-\pi - 1$ at $x = -\pi$.**
> Since $\sin x \le 1$, $f' \ge 0$ throughout, so $f$ is increasing and $x = \pi/2$ is a horizontal tangent that is **not** an extreme.

| write `2*pi+1`, with the explicit `*` | write `2pi+1` |
| write `40*20^(2/3)-100*20^(1/3)` | write `40*20^2/3`, which Möbius reads as $(40\cdot 400)/3$ |
| use `-16`, exact | use `-16.0000001` from a decimal detour |
| list **every** point when a value is attained twice | name one of them and stop |
| bracket a fractional exponent as `(2/3)` | write `^2/3` |

**The single most expensive typo** is the missing bracket in a fractional exponent.
`20^(4/3)` is $54.288$ and `20^4/3` is $53{,}333.3$, a factor of about a thousand, and Möbius will mark the second one wrong without comment.

**Always preview.**
The exam is answer-only and machine-marked, so a right method with a bad keystroke scores zero.

## 8. The variation catalog

Ten families, grouped by **the tool the variation forces**, not by how the function looks.
Every instance below was solved twice: once by the candidate-list method, and once by a formula-blind dense sweep with a golden-section refinement that never sees the candidate list.

Read each table as **structure**, not as a list of facts.
The whole catalog contains only four distinct *shapes* of answer: both extremes at endpoints; one at an endpoint and one interior; both interior; and an extreme tied across two or more points.

### Family 0 - polynomial on a closed interval

**Trigger:** $f$ is a polynomial, an interval is given.
**Tool:** $f' = 0$, then compare. Nothing else.

| instance | interval | max | min | note |
| :--- | :--- | :--- | :--- | :--- |
| $x^3 - 3x$ | $[-2,3]$ | $18$ at $x=3$ | $-2$ at $x=-2$ **and** $x=1$ | one value, two points |
| $2x^3 - 9x^2 + 12x$ | $[0,3]$ | $9$ at $x=3$ | $0$ at $x=0$ | both at endpoints |
| $x^4 - 4x^3$ | $[-1,4]$ | $5$ at $x=-1$ | $-27$ at $x=3$ | $x=0$ is critical and **not** an extreme |
| $1/x$ | $[1,4]$ | $1$ at $x=1$ | $1/4$ at $x=4$ | **no critical points at all** |

The last row is the family's most useful member.
$f'(x) = -1/x^2$ is never zero and never undefined on $[1,4]$, so the candidate list is the two endpoints and nothing else.
A student who believes an answer must come from $f'=0$ has nowhere to go.

### Family 1 - fractional exponents, part (a)'s own family

**Trigger:** exponents like $5/3$, $4/3$, $2/3$, $1/3$.
**Tool:** substitute $t = x^{1/3}$ to get a polynomial, and evaluate negative arguments as "cube root first".

| instance | interval | max | min | note |
| :--- | :--- | :--- | :--- | :--- |
| $2x^{5/3}-5x^{4/3}$ | $[-1,20]$ | $23.2808$ at $x=20$ | $-16$ at $x=8$ | the exam |
| $2x^{5/3}-5x^{4/3}$ | $[-1,8]$ | $0$ at $x=0$ | $-16$ at $x=8$ | same function, max now **interior** |
| $2x^{5/3}-5x^{4/3}$ | $[0,8]$ | $0$ at $x=0$ | $-16$ at $x=8$ | |
| $2x^{5/3}-5x^{4/3}$ | $[8,20]$ | $23.2808$ at $x=20$ | $-16$ at $x=8$ | monotone, both extremes at ends |
| $3x^{5/3}-15x^{2/3}$ | $[-1,8]$ | $36$ at $x=8$ | $-18$ at $x=-1$ | $f'$ **undefined** at $0$ |

The last row is the discriminator for the whole family.
$f' = 5x^{2/3} - 10x^{-1/3} = 5x^{-1/3}(x-2)$ **is** undefined at $x=0$ because the exponent $2/3$ is below 1.
Its interior critical values, $f(2) = -9\cdot 2^{2/3} \approx -14.2866$ and $f(0) = 0$, are both beaten by the left endpoint $-18$.

**Rule:** an exponent below 1 gives you an undefined derivative; an exponent above 1 does not.
Part (a)'s exponents are $5/3$ and $4/3$, both above 1, which is why its cusp box is empty.

### Family 2 - the touch zero, part (b)'s own family

**Trigger:** $f' $ has a repeated root, or $f' = 1 + A\cos x$ with $\lvert A\rvert = 1$, or a squared factor.
**Tool:** a sign chart, never a second-derivative test.

| instance | interval | max | min | note |
| :--- | :--- | :--- | :--- | :--- |
| $x + \cos x$ | $[-\pi,2\pi]$ | $2\pi+1$ at $2\pi$ | $-\pi-1$ at $-\pi$ | the exam; $\pi/2$ is neither |
| $x + \sin x$ | $[-\pi,2\pi]$ | $2\pi$ at $2\pi$ | $-\pi$ at $-\pi$ | Q14.1(b); touch zeros at odd multiples of $\pi$ |
| $x + 2\cos x$ | $[0,2\pi]$ | $2\pi+2$ at $2\pi$ | $\frac{5\pi}{6}-\sqrt3 \approx 0.885943$ at $\frac{5\pi}{6}$ | $\lvert A\rvert >1$, genuine interior min |
| $x + \frac12\sin x$ | $[-\pi,\pi]$ | $\pi$ at $\pi$ | $-\pi$ at $-\pi$ | $\lvert A\rvert <1$, **no critical points** |
| $x^3$ | $[-1,2]$ | $8$ at $2$ | $-1$ at $-1$ | the cheapest touch zero there is |

**The amplitude bifurcation, and the exam sits exactly on it.**
$f'(x) = 1 + A\cos x$ vanishes when $\cos x = -1/A$, solvable only when $\lvert A\rvert \ge 1$.
Counting sign changes over $[-\pi, 2\pi]$:

| $\lvert A\rvert$ | sign changes of $f'$ | consequence |
| :--- | :--- | :--- |
| $0.5$, $0.9$ | $0$ | no critical points at all |
| $1.0$ | $0$ | critical points exist but are **not** extremes |
| $1.1$, $2$, $3$ | $3$ | genuine maximum and minimum pairs |

The count is **3**, not 2, because $[-\pi,2\pi]$ is $1.5$ periods long.
Both Q15.1(b) and Q14.1(b) sit on the $\lvert A\rvert = 1$ row, which is the only row where a critical point earns nothing.

### Family 3 - $f'$ undefined: cusps, corners, vertical tangents

**Trigger:** an absolute value, an exponent strictly between 0 and 1, or an odd root.
**Tool:** add the undefined points to the candidate list, then compare values exactly as before. You do **not** need to know which kind it is to get the answer.

| instance | interval | max | min | kind |
| :--- | :--- | :--- | :--- | :--- |
| $(x^2-4)^{2/3}$ | $[-3,3]$ | $5^{2/3} \approx 2.924018$ at $x=\pm 3$ | $0$ at $x=\pm 2$ | cusps, both answers tied |
| $(x^2+2x)^{2/3}$ | $[-2,3]$ | $15^{2/3} \approx 6.082202$ at $x=3$ | $0$ at $x=-2$ and $x=0$ | Q15.5 itself |
| $\lvert x^2-1\rvert$ | $[-2,2]$ | $3$ at $x=\pm 2$ | $0$ at $x=\pm 1$ | corners, both answers tied |
| $x^{1/3}$ | $[-1,8]$ | $2$ at $x=8$ | $-1$ at $x=-1$ | vertical tangent, **not** an extreme |

The three kinds are separated by their one-sided slopes, all measured:

| kind | left slope | right slope |
| :--- | :--- | :--- |
| corner, $\lvert x^2-1\rvert$ at $x=1$ | $-2$ | $+2$ |
| cusp, $(x^2-4)^{2/3}$ at $x=2$ | $\to -\infty$ | $\to +\infty$ |
| vertical tangent, $x^{1/3}$ at $x=0$ | $\to +\infty$ | $\to +\infty$ |

**And a warning that carries straight into Q15.5.**
A **centred** difference quotient at a cusp is nearly zero: measured $5.3\times 10^{-5}$ at $(x^2+2x)^{2/3}$, $x=0$, while both one-sided slopes exceed $150$ in magnitude at the same step.
That is an understatement by a factor above a million, and it certifies a non-differentiable point as flat.
At a **corner** the centred quotient returns the **average** of the two one-sided slopes, which is exactly $0$ only when the corner is symmetric; on an asymmetric corner it returns $1.5$, which is neither slope.
Q5.1 to Q5.3 make the same point about reading conditions; the operational version is **test one-sided slopes separately**.

### Family 4 - ties: one value, several points

**Trigger:** an even function on a symmetric interval, or a periodic function over more than one period.
**Tool:** the same method; the write-up changes, not the arithmetic.

| instance | interval | tied answer |
| :--- | :--- | :--- |
| $1/(x^2+1)$ | $[-1,1]$ | min $1/2$ at **both** endpoints (Q15.3) |
| $x^2$ | $[-3,3]$ | max $9$ at $x=\pm 3$ |
| $\cos x$ | $[-2\pi,2\pi]$ | max $1$ at **three** points, min $-1$ at **two** |

**The rule this family forces:** state the value once and list every point where it happens.
Q15.3 is in this family, so the tie is not exotic; it is on the exam.

### Family 5 - rational functions on a closed interval

**Trigger:** a quotient.
**Tool:** quotient rule, set the **numerator** to zero, and check the denominator does not vanish inside the interval.

| instance | interval | max | min |
| :--- | :--- | :--- | :--- |
| $x/(x^2+1)$ | $[0,3]$ | $1/2$ at $x=1$ | $0$ at $x=0$ |
| $x/(x^2+1)$ | $[-3,3]$ | $1/2$ at $x=1$ | $-1/2$ at $x=-1$ |
| $(x^2+1)/x$ | $[0.5,4]$ | $4.25$ at $x=4$ | $2$ at $x=1$ |

**The trap.** $(x^2+1)/x$ on $[-1,4]$ has a pole at $0$, so $f$ is not continuous there, the EVT does not apply, and there is no maximum: values exceed $10^6$ arbitrarily close to $0$.
A pole is a critical point of **no** kind, because it is not in the domain, so it never joins the candidate list.
Q4.1 is the question that teaches finding it.

### Family 6 - open or unbounded domain: the EVT does not apply

**Trigger:** a word problem with no interval printed. "Smallest perimeter." "Cheapest." "Largest area."
**Tool:** derive the domain, notice it is open, and replace the comparison with a second-derivative test or a sign chart plus a statement about the ends.

| instance | domain | answer | is there another extreme? |
| :--- | :--- | :--- | :--- |
| $P = 2w + 440/w$ (Q15.2) | $(0,\infty)$ | min $8\sqrt{55} \approx 59.3296$ at $w = \sqrt{220}$ | **no maximum**, $P$ unbounded at both ends |
| $C = 5.4w^2 + 432/w$ (Q15.4) | $(0,\infty)$ | min $16.2\cdot 40^{2/3} \approx 189.4763$ at $w = \sqrt[3]{40}$ | no maximum |
| $A = w(20-w)$, perimeter 40 | $(0,20)$ | max $100$ at $w=10$ | **no minimum**, $A \to 0$ without reaching it |
| $P = 2w + 440/w$ on $[1,100]$ | closed | max $442$ at $w=1$ | closing the domain restores the method |

The last row is the seeded control and it is the family's lesson: **the method is not wrong, the domain was open.**
Close the domain and the comparison works again.

Q15.2 and Q15.4 are both in this family, which is $16$ of category 15's $41$ printed points.

### Family 7 - trigonometric on a closed interval

**Trigger:** $\sin$, $\cos$, $\tan$ with an interval.
**Tool:** solve the trig equation, then keep only the solutions inside the interval.

| instance | interval | max | min |
| :--- | :--- | :--- | :--- |
| $\sin x + \cos x$ | $[0,\pi]$ | $\sqrt2$ at $x=\pi/4$ | $-1$ at $x=\pi$ |
| $\sin 2x$ | $[0,\pi]$ | $1$ at $x=\pi/4$ | $-1$ at $x=3\pi/4$ |
| $x - 2\sin x$ | $[0,2\pi]$ | $\frac{5\pi}{3}+\sqrt3 \approx 6.968039$ at $\frac{5\pi}{3}$ | $\frac{\pi}{3}-\sqrt3 \approx -0.684853$ at $\frac{\pi}{3}$ |

**The trap:** solve over the **given** interval, not over one period.
$\sin x = 1/2$ has **two** solutions in $[0,2\pi]$ and **four** in $[0,4\pi]$.
On Q15.1 part (b) that count is **one**, because $\sin x = 1$ has period $2\pi$ and the interval is only $3\pi$ long.

The third row is worth a second look, because it is part (b) with the amplitude turned up.
Both of its extremes are **interior**, and the right endpoint $2\pi \approx 6.2832$ **loses** to the critical point $\frac{5\pi}{3}+\sqrt3 \approx 6.9680$.
Same shape of function, opposite answer.

### Family 8 - the interval itself is the variable

**Trigger:** the same function appears twice with different intervals, or the interval contains a parameter.
**Tool:** nothing new; but realise the critical points belong to $f$ and the **answer** belongs to $f$ **and** the interval.

Take part (a)'s own function and move the right endpoint.

| interval | where the maximum is | why |
| :--- | :--- | :--- |
| $[-1, 15]$ | interior, $x=0$, value $0$ | $f(15) = -2.499846$, still negative |
| $[-1, 15.6]$ | interior, $x=0$ | $f(15.6)$ still negative |
| $[-1, 125/8]$ | **tied** between $x=0$ and $x=15.625$, value $0$ | $125/8$ is the second $x$-intercept |
| $[-1, 20]$ | right endpoint, value $23.2808$ | $20 > 125/8$ |

**Three different answers from one function**, and the switch happens at $x = 125/8 = 15.625$.
This is the cheapest available demonstration that a candidate list is not an answer.

### Family 9 - the EVT hypotheses fail

**Trigger:** a half-open or infinite interval, or a function with a jump or a pole inside.
**Tool:** say which hypothesis fails and what is therefore not guaranteed.

| instance | hypothesis lost | consequence |
| :--- | :--- | :--- |
| $x$ on $[0,1)$ | closed | minimum $0$ exists, **no maximum** |
| $x$ on $[0,\infty)$ | bounded | no maximum |
| $f = x$ on $[0,1)$, $f(1) = 0$ | continuous | closed interval, **no maximum** |
| $1/x$ on $[-1,1]$ | continuous | neither extreme exists |

Note that all four failures are one-directional.
The EVT is a guarantee and its converse is false: a function can attain both extremes while satisfying none of the hypotheses.
So "the EVT does not apply" never means "there is no answer"; it means "you have lost the guarantee and must argue".

## 9. The trap list

Ranked by how often each actually costs marks, and every entry was measured rather than guessed.

**1. Leaving an endpoint off the candidate list.**
This is the question's designed failure, and part (a) and part (b) punish it differently.
The harness scanned ten candidate-list mutilations across the two parts: **four of them HIDE**, producing the identical absolute answer, and **six SHOW**.

| mutilation | part (a) | part (b) |
| :--- | :--- | :--- |
| drop the **right** endpoint | max becomes $0$ at $x=0$, **wrong by 23.28** | max becomes $\pi/2$, **wrong** |
| drop the **left** endpoint | **hides**, same answer | min becomes $\pi/2$, **wrong** |
| drop the critical point $x=0$ | **hides** | (n/a) |
| drop the critical point $x=8$ | min becomes $-7$ at $x=-1$, **wrong** | (n/a) |
| drop the critical point $\pi/2$ | (n/a) | **hides**, it was never an extreme |

**So on part (a) only one of the two endpoint omissions is fatal, and on part (b) both are.**
That asymmetry is the pair's design, and it is the argument for always writing both endpoints down rather than deciding case by case.

**2. Reporting the point where the extreme happens as if it were the extreme.**
"The maximum is $20$" instead of "$23.2808$".
The wrong answer is only $14.1$ percent below the right one on part (a) and off by exactly $1$ on part (b), so no magnitude check will save you.
Say **value** and **point** as two separate things, every time.

**3. Assuming a critical point must be an extreme.**
$x = \pi/2$ on part (b) is a critical point, and calling it a maximum is $5.712$ below the true maximum.
This is the one classification error on part (b) that changes the answer; every other slip there hides.

**4. Forgetting to look for points where $f'$ is undefined.**
Part (a) has none, which is why it is safe to write "$f'$ is defined for all $x$" and move on.
Q15.5 has two, and drill D2 has one, and a candidate list that omits them can miss the answer outright.

**5. Getting $(-1)^{4/3}$ wrong.**
Reading it as $-1$ makes $f(-1) = +3$ instead of $-7$.
That slip **hides completely** on the absolute answer, because $3$ sits between $-16$ and $23.28$, so it costs nothing on part (a) and would cost everything on an interval where $x=-1$ was the answer.
A slip that hides is still a slip.

**6. Solving $x^{1/3} = 2$ as $x = 6$.**
$f(6) = 2\cdot 6^{5/3} - 5\cdot 6^{4/3} = -14.890491$, which is $1.11$ **above** the true minimum, so the reported minimum is too high and the error does show.

**7. Reaching for the second-derivative test.**
On part (a) $f''$ blows up at $x=0$ and the test is unusable at the very point you want classified.
On part (b) $f''(\pi/2) = 0$ and the test is silent.
The closed-interval method needs no derivative test at all, and the sign chart handles step 9 for both parts.

**8. Reading $f'' = 0$ as "therefore an inflection, therefore not an extreme".**
On part (b) that reasoning reaches the right conclusion by luck.
It is invalid in general: $x^4$ has $f''(0) = 0$ and a genuine minimum at $0$.
What settles part (b) is the sign of $f'$, or $f'''(\pi/2) = 1 \ne 0$.

**9. Including a spurious critical point.**
Solving $\sin x = 1$ as $\sin x = -1$ adds $x = 3\pi/2$, where $f = 3\pi/2 \approx 4.7124$.
That value is interior, so it changes nothing, and the error hides.

**10. Confusing "all maxima and minima" with "the absolute extreme values".**
Q15.1 says the first, so the losing critical points need classifying (step 9).
Q15.3 and Q15.5 say the second, so they do not.
The stem wording is the instruction.

Twelve problems.

Also score, separately again, whether you named the **point** as well as the **value**.

| 3 | $2\pi+2 \approx 8.283185$ | $x=2\pi$ | $\frac{5\pi}{6}-\sqrt3 \approx 0.885943$ | $x=\frac{5\pi}{6}$ | F2 with $\lvert A\rvert >1$, genuine interior minimum |

### What the key is shaped like

- **Twelve** problems across **six** families: F0, F1, F2, F3, F5, F7.
- **Three** have a tied extreme, a value with two points: numbers 1, 5 and 7.
- **Two** have no critical points at all: numbers 4 and 11.
- **Two** have a critical point that is not an extreme: numbers 9 and 12.
- **Every single one** has at least one extreme at an endpoint.

That last count is the reason the method exists.
If interior critical points were where the answers lived, you could skip the endpoints; they are not, and you cannot.

## 11. The one-page decision tree

```
"find all maxima and minima" / "absolute extreme values"
  |
  +-- is a CLOSED, BOUNDED interval given, and is f CONTINUOUS on it?
  |     |
  |     +-- NO  -> family 6 or 9. Say which hypothesis fails.
  |     |         Open domain (a word problem)? derive the domain,
  |     |         find f'=0, then use f'' or a sign chart, and say
  |     |         what happens at the OPEN ends.
  |     |
  |     +-- YES -> the EVT guarantees both extremes exist. Continue.
  |
  +-- f'(x) = ?   (factor it)
  |
  +-- solve f' = 0                      -> critical points
  +-- where is f' UNDEFINED?            -> critical points too
  |     denominator / negative power / |...| / exponent in (0,1)
  |     none of those?  WRITE "f' is defined for all x"
  |
  +-- discard any critical point OUTSIDE (a,b)
  |
  +-- CANDIDATES = a , b , surviving critical points
  |                ^^^^^   write the endpoints FIRST
  |
  +-- evaluate f at every candidate, exactly
  |
  +-- largest = absolute MAX , smallest = absolute MIN
  |     report the VALUE and, separately, the POINT
  |     tied?  one value, list EVERY point
  |
  +-- did the stem say "ALL maxima and minima"?
  |     |
  |     +-- YES -> sign chart of f'. Classify each interior critical
  |     |          point: + to - is a local max, - to + a local min,
  |     |          NO CHANGE means it is NEITHER.
  |     |
  |     +-- NO  -> stop, the absolute pair is the whole answer.
  |
  +-- CHECK:  both endpoints on the list?
  |           max value >= every candidate?
  |           did I report a VALUE and not an x?
  |           sign changes of f' == interior extremes?
  |
  +-- PREVIEW the Möbius string.  Brackets on every fractional exponent.
```
