# Q15.3 - Absolute extremes by the Extreme Value Theorem

**The question (Final Exam 2, item 3a; item 3 is worth 8 points and part (b) is the other half).**
"Use the Extreme Value Theorem to find the absolute extreme values of the function
$$f(x) = \frac{1}{x^2 + 1} \quad \text{on the interval } [-1, 1].$$"

**The answer.**
Absolute **maximum** $1$ at $x = 0$, an interior critical point.
Absolute **minimum** $\tfrac{1}{2}$ at $x = -1$ **and** $x = 1$, both endpoints.

**What to type into Möbius:** `1` for the maximum value and `1/2` for the minimum value.
If a box asks where the minimum occurs, both endpoints belong in it.

## 0. The 30-second version

```
CHECK the three hypotheses  ->  continuous?  closed?  bounded?   (all yes here)
       EVT now GUARANTEES both extremes EXIST.  It locates neither.
LIST  every candidate       ->  f' = 0,  f' undefined,  a,  b
       f' = -2x/(x^2+1)^2  ->  zero only at x = 0,  never undefined
EVAL  f at all of them      ->  f(-1) = 1/2,  f(0) = 1,  f(1) = 1/2
PICK  biggest and smallest  ->  MAX 1 at x = 0;  MIN 1/2 at BOTH x = -1 and x = 1
```

The whole method is four lines, and the first line is the one the question is actually asking about.

## 1. What this question is really testing

Q15.1 asked you to *run* the closed-interval method.
Q15.3 names the theorem, so it is asking you to *justify* it.
That is a different task and it carries its own marks.

| The reflex | Where it comes back in the paper |
| :--- | :--- |
| State the EVT's three hypotheses and check each against this function and interval | This is the phrase "by the Extreme Value Theorem" cashing out; it is not decoration |
| Know that the EVT proves existence and says nothing about location | Item 4 asks you to sketch a graph from conditions, where the same distinction decides whether you may draw a peak |
| Build a candidate list that includes both endpoints | Item 7a, the cusp question, and item 5, the box problem, where there are no endpoints at all |
| Read the minimum and maximum *values* off the table, not the *inputs* | Every extremes question on both papers |
| Hand the two values to the integral-bound property | Item 3b, which is the other half of this very item |

The last row is the point of the question's design.
Item 3 has two parts, they share 8 points, and part (b) reads
"Use the properties of the definite integral to estimate the value of the integral
$\int_{-1}^{1} \frac{1}{x^2+1}\,dx$" on the **same function over the same interval**.
The comparison property says that if $m \le f(x) \le M$ on $[a,b]$ then
$m(b-a) \le \int_a^b f \le M(b-a)$, so part (a)'s two numbers *are* part (b)'s $m$ and $M$.
Item 7 is built the same way, pairing Q15.5 with Q17.3.
Measured on the paper: exactly **two** of Final Exam 2's twelve items pair an extremes question with
an integral bound on the same function, and together they are **14 of the paper's 81 points**.

## 2. The five things you must have cold

### 2.1 The theorem, stated properly

> **Extreme Value Theorem.**
> If $f$ is continuous on a closed, bounded interval $[a,b]$, then $f$ attains an absolute maximum
> and an absolute minimum on $[a,b]$.
> That is, there exist points $c$ and $d$ in $[a,b]$ with $f(d) \le f(x) \le f(c)$ for every $x$ in
> $[a,b]$.

Three hypotheses and one conclusion.
The conclusion is an **existence** statement: there exist such points.
It does not say where they are, how many there are, or how to find them.

| Hypothesis | What it rules out | Checked here by |
| :--- | :--- | :--- |
| $f$ continuous on **all** of $[a,b]$ | jumps, poles, removable holes | $x^2+1 \ge 1$, so the denominator never vanishes |
| the interval is **closed** | a domain like $(-1,1)$ or $(0,1]$ | the brackets in $[-1,1]$ |
| the interval is **bounded** | a domain like $[0,\infty)$ | the length is $2$ |

### 2.2 The theorem that actually locates the answer

The EVT is only the existence half.
The locating half is a different result, usually called **Fermat's theorem** or the interior extremum
theorem.

> If $f$ has a local extremum at an interior point $c$ of its domain and $f'(c)$ exists, then
> $f'(c) = 0$.

Read the contrapositive, because that is the useful direction.
An interior point where $f'$ exists and is **not** zero cannot be an extremum.
So the only places an extremum can sit are: interior points where $f' = 0$, interior points where
$f'$ does not exist, and the two endpoints.
That is the candidate list, and it comes from Fermat, not from the EVT.

Notice what this means for the endpoints.
Fermat's theorem says nothing about them, because they are not interior.
On this question $f'(-1) = \tfrac{1}{2}$ and $f'(1) = -\tfrac{1}{2}$, both plainly nonzero, and both
of those points are minimisers.
**No derivative condition flags an endpoint. You add them to the list by hand or you lose them.**

### 2.3 The two derivatives

$$f(x) = \frac{1}{x^2+1} = (x^2+1)^{-1}$$

$$f'(x) = -(x^2+1)^{-2}\cdot 2x = \frac{-2x}{(x^2+1)^2}$$

$$f''(x) = \frac{6x^2 - 2}{(x^2+1)^3}$$

The chain rule and the quotient rule give the same $f'$; both spellings were checked against a
complex-step derivative at thirteen points.

| Quantity | Exact | Decimal |
| :--- | :--- | :--- |
| $f'(0)$ | $0$ | $0$ |
| $f'(1)$ | $-1/2$ | $-0.5$ |
| $f'(-1)$ | $1/2$ | $0.5$ |
| $f''(0)$ | $-2$ | $-2$ |
| $\max \lvert f' \rvert$ on $[-1,1]$ | $3\sqrt{3}/8$ | $0.6495190528$ |
| inflection points | $\pm 1/\sqrt{3}$ | $\pm 0.5773502692$ |
| $f$ at the inflection points | $3/4$ | $0.75$ |

### 2.4 Why $f'$ is never undefined here

$f'$ is a fraction whose denominator is $(x^2+1)^2$.
Since $x^2 \ge 0$ for every real $x$, we get $x^2 + 1 \ge 1$, so $(x^2+1)^2 \ge 1 > 0$.
The denominator can never be zero, so $f'$ exists everywhere.

That box on the candidate list is **empty on this question**, and it is worth one sentence in the
write-up saying so.
Q15.5's box is full, because its function is $(x^2+2x)^{2/3}$ and the exponent $2/3$ is below $1$.
The discriminator for that whole family is a single comparison: **an exponent below $1$ makes the
derivative undefined at the base's zero, an exponent above $1$ does not.**

### 2.5 The integral-bound property

> If $m \le f(x) \le M$ for all $x$ in $[a,b]$, then
> $$m(b-a) \;\le\; \int_a^b f(x)\,dx \;\le\; M(b-a).$$

Here $m = \tfrac12$, $M = 1$, $b - a = 2$, so $1 \le \int_{-1}^{1} f \le 2$.
The true value is $2\arctan 1 = \pi/2 = 1.5707963268$, comfortably inside.

## 3. The universal procedure

> 1. **Check the three hypotheses first, in writing.**
>    Continuous on the whole interval, closed, bounded.
>    If any one fails, stop: the answer is a sentence saying the theorem does not apply.
> 2. **Say the conclusion out loud.**
>    "So by the EVT both extremes exist on $[a,b]$, and they occur at a critical point or an
>    endpoint."
> 3. **Differentiate.** Simplify only enough to see the numerator and the denominator separately.
> 4. **Set the numerator of $f'$ to zero** and solve. These are the stationary points.
> 5. **Set the denominator of $f'$ to zero** and solve. These are the points where $f'$ is undefined.
> 6. **Discard any of them outside $[a,b]$.** Keep the rest.
> 7. **Write both endpoints into the list.** Every time, without deciding whether they matter.
> 8. **Evaluate $f$ at every entry.** Exact values, not decimals.
> 9. **Largest is the maximum, smallest is the minimum.** Report the *value*, then say *where*.
> 10. **If two entries tie, name both places.**

Step 1 is where the marks are on this question, and step 7 is where they are lost.

| The cue you see | Which step it lands on |
| :--- | :--- |
| "by the Extreme Value Theorem" | 1 and 2 are graded; do them explicitly |
| a denominator that can vanish | 1 fails; the answer is a sentence |
| a domain written with a round bracket | 1 fails; the extreme may not be attained |
| a domain running to $\infty$ | 1 fails; the extreme may not be attained |
| a fractional exponent below $1$ | 5 is not empty |
| "all maxima and minima" instead of "the absolute extreme values" | classify the losers too, with a sign chart |

## 4. Q15.3 worked three ways

### Route A: the closed-interval method (the one to use)

**Hypotheses.**
$x^2 + 1 \ge 1$ for all real $x$, so the denominator never vanishes and $f$ is a quotient of
polynomials with nonvanishing denominator, hence continuous on all of $\mathbb{R}$ and in particular
on $[-1,1]$.
$[-1,1]$ is closed and bounded.
By the Extreme Value Theorem, $f$ attains both an absolute maximum and an absolute minimum on
$[-1,1]$.

**Candidates.**
$f'(x) = -2x/(x^2+1)^2$.
The denominator is at least $1$, so $f'$ is defined everywhere and $f'(x) = 0$ exactly when
$-2x = 0$, that is $x = 0$, which lies in $[-1,1]$.
Candidates: $x = -1$, $x = 0$, $x = 1$.

**Table.**

| $x$ | why it is a candidate | $f(x)$ exact | $f(x)$ decimal |
| :--- | :--- | :--- | :--- |
| $-1$ | left endpoint | $1/2$ | $0.5$ |
| $0$ | interior, $f'(0) = 0$ | $1$ | $1$ |
| $1$ | right endpoint | $1/2$ | $0.5$ |

**Conclusion.**
The absolute maximum value is $1$, attained at $x = 0$.
The absolute minimum value is $\tfrac12$, attained at $x = -1$ and at $x = 1$.

### Route B: monotonicity, no table

$f'(x) = -2x/(x^2+1)^2$ has a strictly positive denominator, so its sign is the sign of $-2x$.
That is positive on $[-1,0)$ and negative on $(0,1]$.
So $f$ increases on $[-1,0]$ and decreases on $[0,1]$.
An increasing-then-decreasing function on a closed interval has its maximum at the turning point and
its minimum at whichever end is lower.
The two ends are equal here, at $f(\pm 1) = \tfrac12$, so both are minimisers.

This route is shorter and it *proves* the classification instead of asserting it, but it needs the
sign of $f'$ across the whole interval rather than at one point.

### Route C: recognise the shape

$x^2 + 1$ is a parabola with vertex $(0,1)$, increasing in $\lvert x \rvert$.
Taking a reciprocal reverses order on positive quantities, so $1/(x^2+1)$ is *decreasing* in
$\lvert x \rvert$.
So $f$ is biggest where $\lvert x \rvert$ is smallest and smallest where $\lvert x \rvert$ is
biggest.
On $[-1,1]$ that is $x = 0$ and $x = \pm 1$.
No calculus at all.

### Route comparison

| Route | Work | Proves the classification? | Handles $f'$ undefined? | Risk |
| :--- | :--- | :--- | :--- | :--- |
| A closed-interval table | differentiate, solve, three evaluations | yes, by comparison | yes, once you look for it | forgetting an endpoint |
| B sign of $f'$ | differentiate, one sign argument | yes, and more strongly | yes | you must argue over the whole interval, not sample it |
| C reciprocal of a parabola | none | yes, by order-reversal | no, it is shape-specific | it only works on functions of $\lvert x \rvert$ |

**Use Route A under pressure.**
It is the only one that generalises to every function the examiner can put in this slot, it is the
one the phrase "by the Extreme Value Theorem" is asking for, and its table is self-documenting for a
marker.
Keep Route C as an eight-second sanity check on the answer, and Route B as the thing you write when
the question says "all maxima and minima" and wants the losers classified.

## 5. The exam-ready write-up

This is what a marker wants to see when the stem names the theorem.
Six sentences.

> $f(x) = 1/(x^2+1)$.
> Since $x^2+1 \ge 1 > 0$ for every real $x$, the denominator never vanishes, so $f$ is continuous on
> all of $\mathbb{R}$ and in particular on the closed, bounded interval $[-1,1]$.
> By the Extreme Value Theorem, $f$ attains an absolute maximum and an absolute minimum on $[-1,1]$.
> $f'(x) = -2x/(x^2+1)^2$, which is defined for all $x$ and vanishes only at $x = 0$, so the
> candidates are $x = -1, 0, 1$.
> $f(-1) = 1/2$, $f(0) = 1$, $f(1) = 1/2$.
> The absolute maximum value is $1$, at $x = 0$; the absolute minimum value is $1/2$, attained at both
> $x = -1$ and $x = 1$.

Four things in there earn marks that a bare answer does not.

1. **The reason $f$ is continuous**, not just the claim.
   "The denominator never vanishes" is the whole argument and it is nine words.
2. **The words "closed" and "bounded"** attached to the interval.
   The stem named a theorem; citing its hypotheses as satisfied is the citation.
3. **"is defined for all $x$"** about $f'$.
   That is the empty box being reported as empty, which shows you looked.
4. **"attained at both"**.
   The minimum happens twice and a single-point answer is incomplete.

And one thing that does not earn marks: a second-derivative test.
It would work here, since $f''(0) = -2 < 0$, but the closed-interval comparison already settled it
and the test cannot see the endpoints at all.

## 6. Verify before you commit

**Magnitude check, three seconds.**
$f$ is one over something at least $1$, so $0 < f \le 1$ everywhere.
Any reported extreme outside $(0,1]$ is wrong on sight.
This alone kills a reported minimum of $-\tfrac12$ and a reported maximum of $2$.

**The order check.**
$f$ is decreasing in $\lvert x \rvert$.
The candidate with the smallest $\lvert x \rvert$ must have the largest $f$.
Here $\lvert x \rvert$ runs $0, 1, 1$, so $f$ must run largest, tied, tied.
It does.

**The evenness check.**
$f(-x) = f(x)$, so the table must be symmetric about $x = 0$.
If your two endpoint values differ on a symmetric interval, you have made an arithmetic slip.

**The part (b) check, which is free.**
$m(b-a) = 1$ and $M(b-a) = 2$.
The true integral is $\pi/2 = 1.5708$, which lands inside.
If you had reported $m$ or $M$ wrongly, or forgotten the $(b-a)$, the bound would exclude the truth.
Forgetting $(b-a)$ gives $[\tfrac12, 1]$, and $1.5708$ is outside it.

**Numbers worth memorising for this family.**

| Value | Exact | Decimal |
| :--- | :--- | :--- |
| $f(0)$ | $1$ | $1$ |
| $f(\pm 1)$ | $1/2$ | $0.5$ |
| $f(\pm 2)$ | $1/5$ | $0.2$ |
| $f(\pm 3)$ | $1/10$ | $0.1$ |
| $\int_{-1}^{1} f$ | $\pi/2$ | $1.5707963268$ |
| $\int_{-2}^{2} f$ | $2\arctan 2$ | $2.2142974356$ |

**What you cannot check with the value.**
The maximum value is $1$ and the function is flat there, so the *value* is almost insensitive to the
*location*.
Measured: a point $5\times 10^{-5}$ away from $x=0$ has $f$ within $2.5\times 10^{-9}$ of $1$.
So a reported maximiser that is nearly right produces a maximum that is right to nine decimal places.
**Never validate the maximiser using the maximum.**
This is the same blind spot Q15.2 recorded at its minimiser, and it is why the verification for this
page root-finds on $f'$ rather than searching for the largest value: the root-find located $x=0$ to
$5\times 10^{-61}$, while a value comparison in the same arithmetic cannot do better than
$1.49 \times 10^{-8}$, a gap of **52 orders of magnitude** that belongs entirely to the comparison and
not to the arithmetic.

## 7. Answer-entry rules

| Do | Do not |
| :--- | :--- |
| Enter `1` for the maximum value | Enter `0`, which is where it happens |
| Enter `1/2` for the minimum value | Enter `-1` or `1`, which is where it happens |
| Give both minimiser locations when asked where | Name only one endpoint |
| Use the exact fraction `1/2` | Round to `0.5` unless the box asks for a decimal |
| Keep value and location in separate boxes | Merge them into one string |

**The single most expensive typo on this question is answering the wrong question.**
The stem asks for the absolute extreme **values**.
The values are $1$ and $\tfrac12$.
The *locations* are $0$ and $\pm 1$.
Reporting $0$ where the maximum value belongs is not a rounding error, it is a different quantity,
and no magnitude check catches it because $0$ is a perfectly plausible input for this function.

**Preview the rendered answer before submitting.**
`1/2` typed into a Möbius box can be read by either of its two grading engines, and the safe habit is
to look at the preview rather than trusting the keystroke.

## 8. The variation catalog

Read each table as **structure**, not as a list of facts.
Family 0's three rows have exactly one maximum value between them, because the peak is always at
$x=0$ and $0$ is inside every symmetric interval; the minima are a single decreasing function of the
half-width.
That is one fact, printed three times.

Ten families follow.
Nine of them are drilled in section 10; family 7 is deliberately handed to Q15.5.

### Family 0: symmetric interval about an interior critical point

**Trigger.** The interval is symmetric about the stationary point.
**Tool.** The closed-interval table, and a note that the two endpoint values tie.

| Interval | max value | at | min value | at |
| :--- | :--- | :--- | :--- | :--- |
| $[-1,1]$ | $1$ | $x=0$ | $1/2$ | $x=-1$ and $x=1$ |
| $[-2,2]$ | $1$ | $x=0$ | $1/5$ | $x=-2$ and $x=2$ |
| $[-3,3]$ | $1$ | $x=0$ | $1/10$ | $x=-3$ and $x=3$ |

Generated by one formula: the minimum is $1/(c^2+1)$ at $x = \pm c$, and the maximum is always $1$.

### Family 1: the critical point is outside the interval

**Trigger.** Ask "is $0$ in $[a,b]$?" and the answer is no.
**Tool.** Monotonicity. The candidate table has only two rows.

| Interval | max value | at | min value | at |
| :--- | :--- | :--- | :--- | :--- |
| $[1,3]$ | $1/2$ | $x=1$ (left end) | $1/10$ | $x=3$ |
| $[-3,-1]$ | $1/2$ | $x=-1$ (right end) | $1/10$ | $x=-3$ |
| $[1/2,2]$ | $4/5$ | $x=1/2$ | $1/5$ | $x=2$ |

On a positive interval $f$ is decreasing, so the maximum is the left end.
On a negative interval it is increasing and the roles swap.
Evaluating $f(0)$ anyway reports a maximum of $1$ that the function never reaches on $[1,3]$, which
shows immediately.

### Family 2: the denominator vanishes inside the interval

**Trigger.** Solve denominator $= 0$ and compare the roots against $[a,b]$, before anything else.
**Tool.** The continuity hypothesis. The answer is a sentence.

| Function and interval | poles inside | verdict |
| :--- | :--- | :--- |
| $1/(x^2-1)$ on $[-2,2]$ | $x=-1$, $x=1$ | EVT does not apply; no extremes exist |
| $1/(x-1)$ on $[0,2]$ | $x=1$ | EVT does not apply; no extremes exist |
| $1/(x^2-4)$ on $[-3,3]$ | $x=-2$, $x=2$ | EVT does not apply; no extremes exist |
| $1/(x^2-4)$ on $[-1,1]$ | none | EVT applies; max $-1/4$ at $x=0$, min $-1/3$ at $x=\pm 1$ |

This is the family the hypotheses actually bite in, and it is the most likely rewording of the exam
question.
Near a pole $\lvert f \rvert$ exceeds $10^8$ within $10^{-9}$ of it, in both directions, so neither a
maximum nor a minimum exists.

The last row is the discriminator and it carries a sign trap.
Both extremes are **negative**, so the maximum is the value **closest to zero**.
Taking the largest magnitude gives $-1/3$, which is the minimum, so the answer comes out exactly
inverted.

### Family 3: scale and shift

**Trigger.** A constant multiple, or $x$ replaced by $x - c$.
**Tool.** The same table. A multiple scales both extremes and moves neither; a shift moves the peak.

| Function and interval | max value | at | min value | at |
| :--- | :--- | :--- | :--- | :--- |
| $3/(x^2+1)$ on $[-1,1]$ | $3$ | $x=0$ | $3/2$ | $x=\pm 1$ |
| $1/(x^2+4)$ on $[-2,2]$ | $1/4$ | $x=0$ | $1/8$ | $x=\pm 2$ |
| $1/((x-1)^2+1)$ on $[-1,2]$ | $1$ | $x=1$ | $1/5$ | $x=-1$ only |
| $1/((x-1)^2+1)$ on $[0,4]$ | $1$ | $x=1$ | $1/10$ | $x=4$ only |
| $1/((x-1)^2+1)$ on $[2,5]$ | $1/2$ | $x=2$ (left end) | $1/17$ | $x=5$ |

**Row three is the most important row in the whole catalog.**
Shifting the peak to $x=1$ makes $[-1,2]$ asymmetric about it, so the two endpoints no longer tie:
$f(-1) = 1/5$ and $f(2) = 1/2$.
On that instance dropping the left endpoint changes the answer.
On the exam's instance it does not.
So the fact that the endpoint omission is undetectable on Q15.3 belongs to the **symmetry**, not to
the method, and the symmetry is a property of that one interval.

### Family 4: a nonconstant numerator

**Trigger.** The numerator involves $x$, so you need the quotient rule and there may be two
stationary points.
**Tool.** Quotient rule, then the same table.

| Function and interval | $f'$ numerator | max value | at | min value | at |
| :--- | :--- | :--- | :--- | :--- | :--- |
| $x/(x^2+1)$ on $[-2,2]$ | $1-x^2$ | $1/2$ | $x=1$ | $-1/2$ | $x=-1$ |
| $x/(x^2+1)$ on $[0,3]$ | $1-x^2$ | $1/2$ | $x=1$ | $0$ | $x=0$ |
| $x/(x^2+4)$ on $[-4,4]$ | $4-x^2$ | $1/4$ | $x=2$ | $-1/4$ | $x=-2$ |
| $x^2/(x^2+1)$ on $[-1,2]$ | $2x$ | $4/5$ | $x=2$ | $0$ | $x=0$ |

Row one is family 0's **complement**: both extremes are now interior and the endpoints earn nothing,
because $f(\pm 2) = \pm 2/5$ sits strictly inside $[-1/2, 1/2]$.
Row four is family 0's **mirror**: an interior minimum and an endpoint maximum, because $f' = 2x/(x^2+1)^2$
has the opposite sign.
The general shape is worth keeping: for $x/(x^2+a^2)$ the stationary points are $\pm a$ and the
extreme values are $\pm 1/(2a)$.

Across this catalog all four possible combinations occur: interior max with endpoint min (family 0),
endpoint max with interior min (family 4 row four), both interior (family 4 row one), and both
endpoints (Q15.1 part (b), in family 9).

### Family 5: a higher power in the denominator

**Trigger.** $x^4$, or the whole denominator squared.
**Tool.** The same table, but the second-derivative test can go silent.

| Function and interval | max value | at | min value | at | $f''$ at the peak |
| :--- | :--- | :--- | :--- | :--- | :--- |
| $1/(x^4+1)$ on $[-1,1]$ | $1$ | $x=0$ | $1/2$ | $x=\pm 1$ | $0$, test silent |
| $1/(x^2+1)^2$ on $[-1,1]$ | $1$ | $x=0$ | $1/4$ | $x=\pm 1$ | nonzero |

Row one has **the same answer as the exam question and a different reason**.
$f' = -4x^3/(x^4+1)^2$ has a *triple* root at $0$, and $f''(0) = 0$, so the second-derivative test
says nothing.
That is exactly the failure Q15.1 part (b) had at $\pi/2$, now on a function whose answer looks
identical to the exam's.
What settles it in both cases is the sign chart of $f'$, and the closed-interval comparison needs
neither.

### Family 6: the EVT fails

**Trigger.** The domain is not a closed bounded interval, or $f$ is not continuous on all of it.
**Tool.** The hypotheses. The answer is a sentence, and it says *which* extreme is lost.

| Instance | hypothesis dropped | max | min |
| :--- | :--- | :--- | :--- |
| $1/(x^2+1)$ on $(-1,1)$ | closed | $1$ at $x=0$, attained | $1/2$, **not attained** |
| $1/(x^2+1)$ on $[0,\infty)$ | bounded | $1$ at $x=0$, attained | $0$, **not attained** |
| $h$ = $f$ but $h(0) = 1/2$, on $[-1,1]$ | continuous | $1$, **not attained** | $1/2$ at $x=-1,0,1$ |
| $1/x$ on $(0,1]$ | closed and bounded above | none, unbounded | $1$ at $x=1$ |
| $\tan x$ on $(-\pi/2,\pi/2)$ | closed | none | none |

The first three rows are built from **the exam's own function**, and that is why they are worth
memorising.
Each drops exactly one hypothesis and loses exactly one extreme, by a different mechanism.

- Remove the endpoints and you lose the minimum, because the minimisers *were* the endpoints.
  Every interior point has $f(x) > 1/2$ strictly; the closest an interior sample gets is
  $5.0\times 10^{-7}$ above it, and it never arrives.
- Let the interval run to infinity and you lose the minimum again, but now the infimum is $0$ and it
  is a limit at infinity rather than a value at a removed point.
  $f(10^6) = 10^{-12}$ and $f(10^9) = 10^{-18}$, and $f(x) > 0$ always.
- Puncture the peak and you lose the maximum, the complement of the first case.
  $h(x) = 1$ needs $x = 0$, where $h$ is $1/2$ instead, so the supremum $1$ is approached and never
  reached.
  The jump at $0$ is $1/2$, while on a 4001-point grid the continuous $f$ cannot change by more than
  $\max\lvert f' \rvert \times \text{spacing} = 0.6495190528 \times 0.0005 = 0.0003247595$ in one
  step, so the jump is **1539 times** the largest step continuity allows there.

**A dropped hypothesis does not force failure.**
The hypotheses are sufficient, not necessary, so when one fails the theorem is *silent*, not
negative.
Three controls: $x^2$ on the open $(-1,1)$ still attains its minimum $0$; a step function on
$[-1,1]$ is discontinuous and attains both extremes; and $f$ on the unbounded $[0,\infty)$ still
attains its maximum.
So "the domain is open, therefore there is no maximum" is a wrong sentence.
The right sentence is "the domain is open, so the EVT does not guarantee one, and here there is not."

**And the EVT locates nothing.**
The same theorem with the same guarantee gives three different answers as the interval moves:

| Interval | where the maximum sits |
| :--- | :--- |
| $[-1,1]$ | the interior point $x=0$ |
| $[1,3]$ | the left endpoint |
| $[-3,-1]$ | the right endpoint |

Three intervals, one theorem, three locations, and the theorem names none of them.

### Family 7: $f'$ undefined rather than zero

**Trigger.** An absolute value, or a fractional exponent below $1$.
**Tool.** Step 5 of the procedure, which is empty on Q15.3 and full here.

| Function and interval | the bad point | max value | at | min value | at |
| :--- | :--- | :--- | :--- | :--- | :--- |

**Trigger.** A trigonometric term, usually added to a linear one.
**Tool.** The same table, but the critical points come from a trig equation and may be many.

## 9. The trap list

Ranked by how often each actually costs marks.

1. **Reporting the location instead of the value.**
   The stem says "extreme **values**".
   The values are $1$ and $\tfrac12$; the locations are $0$ and $\pm1$.
   Reporting $0$ for the maximum is not a small error, and no magnitude check catches it, because $0$
   is a plausible *input* for this function.
2. **Naming only one endpoint for the minimum.**
   The minimum happens at $x=-1$ **and** $x=1$.
   A single-point answer has the right value and an incomplete location.
3. **Skipping the hypothesis check when the stem names the theorem.**
   "By the Extreme Value Theorem" is an instruction, not a label.
   Two sentences of hypothesis checking is the cheapest credit on the item.
4. **Not testing the denominator against the interval.**
   The reworded version of this question puts a pole inside $[a,b]$ and the answer becomes a
   sentence.
   Solve denominator $=0$ first, every time.
5. **Dropping the inner $2x$ when differentiating $(x^2+1)^{-1}$.**
   You get $f' = -1/(x^2+1)^2$, which never vanishes, so the critical-point row empties and the
   answer becomes max $=$ min $= \tfrac12$.
   That output is self-evidently broken, because a maximum equal to a minimum says the function is
   constant.
6. **Setting the denominator of $f'$ to zero instead of the numerator.**
   $(x^2+1)^2 = 0$ has no real solution, so you conclude there are no critical points and land on the
   same broken answer as trap 5, by a different route.
7. **Reaching for the second-derivative test.**
   It happens to work here, since $f''(0) = -2$, but it cannot see the endpoints, and on the very
   similar $1/(x^4+1)$ it goes silent because $f''(0)=0$.
   The closed-interval comparison needs neither.
8. **Reading a negative-valued instance's maximum as the largest magnitude.**
   On $1/(x^2-4)$ over $[-1,1]$ the extremes are $-1/4$ and $-1/3$, and the maximum is the one closer
   to zero.
9. **Assuming a dropped hypothesis means the extreme is lost.**
   $x^2$ on the open $(-1,1)$ still attains its minimum.
   The theorem is silent when a hypothesis fails, not negative.
10. **Forgetting the $(b-a)$ factor in part (b).**
    $[\tfrac12, 1]$ excludes the true $\pi/2$.

### The census, measured

Fourteen plausible mutilations of this question were scanned, with nothing excluded as degenerate.
A mutilation **hides** if it reproduces both reported values.

**Six of the fourteen hide and eight show.**

| Mutilation | verdict | why |
| :--- | :--- | :--- |
| drop the left endpoint | **hides** | the right endpoint supplies the same $1/2$ |
| drop the right endpoint | **hides** | the left endpoint supplies the same $1/2$ |
| drop both endpoints | shows | the minimum becomes $1$ |
| drop the critical point $x=0$ | shows | the maximum collapses to $1/2$ |
| report the points instead of the values | shows | maximum reported as $0$ |
| sign error in $f'$ ($+2x$ for $-2x$) | **hides** | the root is still $0$ |
| forget to square $f'$'s denominator | **hides** | the root is still $0$ |
| drop the inner $2x$ (no chain rule) | shows | zero critical points, max $=$ min $= 1/2$ |
| solve $(x^2+1)^2=0$ instead | shows | same broken answer, different route |
| misread the fraction as $1/x^2 + 1$ | shows | a different, unbounded function |
| add the inflection points as candidates | **hides** | extra candidates are harmless, $f(\pm 1/\sqrt3) = 3/4$ |
| report $f''(0)$ as the maximum | shows | $2$ instead of $1$ |
| treat $f$ as odd, so $f(-1) = -1/2$ | shows | the minimum goes below the range |
| solve it on $[0,1]$ instead of $[-1,1]$ | **hides** | numerically identical, by evenness |

**The headline is the first two rows.**
On Q15.1 part (b) *both* endpoint omissions were fatal, because its two extremes sat at *different*
endpoints.
On Q15.1 part (a) one of the two was fatal and the other was harmless by accident.
Here **both are harmless, and structurally so**, because the minimum sits at both endpoints and each
one is its twin's backup.

So Q15.3 is the question where the closed-interval method's most important step, "write down both
endpoints", cannot be checked by the answer at all.
Dropping the critical point *does* show, so the maximum's location is checkable while the minimum's
is not.

Two different hiding mechanisms are live here at once, which is unusual.

- **An endpoint** hides, because its twin has the same value.
- **The symmetry fixed point** hides, because $x=0$ is the fixed point of $x \mapsto -x$ and every
  error that preserves the evenness of $f$ keeps the maximiser sitting there.
  The sign error and the un-squared denominator both do exactly that.

The sharpest of the six is the last row.
Solving the problem on the wrong interval $[0,1]$ gives numerically the identical answer, because $f$
is even and $[0,1]$ still contains one endpoint and the critical point.
On an interval that is not symmetric about $0$, such as $[\tfrac12,1]$, it shows at once: the maximum
there is $f(1/2) = 4/5$.

## 11. The one-page decision tree

```
"absolute extreme values ... on [a,b]"
 |
 +-- Is f continuous on ALL of [a,b]?
 |     solve DENOMINATOR = 0, check the roots against [a,b]
 |     look for an absolute value, a jump, a piecewise split
 |     NO  -> the EVT does NOT apply.  Answer in a SENTENCE, and say
 |            which extreme is lost and why.  STOP.
 |     YES -> continue
 |
 +-- Is the interval CLOSED and BOUNDED?
 |     round bracket anywhere?  an infinity?
 |     NO  -> the EVT does NOT apply.  The extreme MAY still exist:
 |            check the ends by LIMIT, and say "approached, not attained"
 |            if it does not.  STOP.
 |     YES -> continue
 |
 +-- WRITE: "f is continuous on the closed bounded interval [a,b],
 |           so by the EVT both extremes exist."      <- this is graded
 |
 +-- f'(x) = ?
 |     NUMERATOR = 0   -> stationary points
 |     DENOMINATOR = 0 -> points where f' is UNDEFINED   (empty here; say so)
 |     exponent below 1, or an absolute value?  -> that box is NOT empty
 |
 +-- Keep only the candidates inside [a,b].  Discard the rest, and say why.
 |
 +-- ADD a AND b.  Always.  No exceptions, no judgement calls.
 |
 +-- Evaluate f at every candidate.  Exact values.
 |
 +-- Largest = MAX value.  Smallest = MIN value.
 |     TIE?  -> name EVERY place it occurs
 |
 +-- Report the VALUE first, then WHERE.  Two separate answers.
 |
 +-- CHECK:  magnitude plausible?  even/odd symmetry respected?
 |           if the item has an integral part, does m(b-a) <= I <= M(b-a)
 |           contain the truth?
 |
 +-- PREVIEW the entry before submitting.
```
