# Q2.1 - Graph a shifted parabola by transformations

**The question (MT1 Q3, 5 points).**
Give a labeled graph of the function $g(x)=3(x+4)^2$ by starting with the graph of a basic function, and then applying the appropriate transformations.
Explain the procedure you are using.

**Note:** No credit will be given if any other method is used.

**The answer.**
Start from the parent $y=x^2$, shift it **left 4**, then **stretch it vertically by 3**.

$$x^2 \;\longrightarrow\; (x+4)^2 \;\longrightarrow\; 3(x+4)^2$$

The labeled graph is an upward parabola with **vertex $(-4,0)$**, axis of symmetry $x=-4$, passing through $(-3,3)$, $(-5,3)$, $(-2,12)$ and $(-6,12)$, with $y$-intercept $48$.

**What to type into Möbius:** `3*(x+4)^2` for the equation, `(-4,0)` for the vertex, and `-4` for $h$ if the box asks for $h$ in $a(x-h)^2+k$.

## 0. The 30-second version

If you only remember one thing, remember this chain.

```
g(x) = 3(x+4)^2
  -> parent is y = x^2                     vertex (0,0), points (+/-1, 1), (+/-2, 4)
  -> (x+4) means x - (-4), so h = -4       shift LEFT 4:  vertex (-4, 0)
  -> the 3 is OUTSIDE, so it scales y      stretch x3:    (-3,1)->(-3,3), (-2,4)->(-2,12)
  -> label vertex + 2 symmetric pairs      done
```

The whole question is one point map: $(x,y)\mapsto(x-4,\;3y)$.
Apply it to five parent points and you have a labeled graph.

## 1. What this question is really testing

It is worth 5 of 64 points, and it is the cheapest 5 points on the paper if you know one rule and the most expensive if you improvise.
The examiner is testing four reflexes, and every one of them returns later in the course.

| Reflex | Where it comes back |
| :--- | :--- |

| Tracking *points* instead of plotting | sketch-from-conditions (Q5.1 to Q5.3), sketching $f'$ from $f$ |
| Obeying an instruction exactly | the "no credit" clause is a grading rule, not a hint |

**The grading clause is the real content of this question.**
"No credit will be given if any other method is used" means the marks are for the *procedure*, not the picture.
A perfect, correctly-shaped, correctly-labeled parabola obtained by expanding to $3x^2+24x+48$ and using $x=-b/(2a)$ scores **zero**.
That is unusual and it is deliberate: the question exists to force transformation reasoning, because transformation reasoning is what the rest of the course needs.

So the deliverable is not one graph.
It is a named parent, a named ordered list of transformations, and a graph with labeled points at each stage.

## 2. The three things you must have cold

You cannot do this question fast by deriving these.
They have to be recall.

### 2.1 The parent library

Every transformation question starts by naming one of these.
Learn the anchor points, not the shape: the shape follows from the points.
All 55 anchor points below were verified.

| Parent | Anchor points | Shape notes |
| :--- | :--- | :--- |
| $y=x$ | $(-2,-2),(-1,-1),(0,0),(1,1),(2,2)$ | line through the origin, slope 1 |
| $y=x^2$ | $(-2,4),(-1,1),(0,0),(1,1),(2,4)$ | parabola, vertex origin, **even** |
| $y=x^3$ | $(-2,-8),(-1,-1),(0,0),(1,1),(2,8)$ | inflection at origin, **odd** |
| $y=\lvert x\rvert$ | $(-2,2),(-1,1),(0,0),(1,1),(2,2)$ | corner at origin, slopes $\pm1$, **even** |
| $y=\sqrt x$ | $(0,0),(1,1),(4,2),(9,3)$ | half-parabola, domain $[0,\infty)$ |
| $y=\sqrt[3]{x}$ | $(-8,-2),(-1,-1),(0,0),(1,1),(8,2)$ | all reals, **odd** |
| $y=1/x$ | $(-2,-\tfrac12),(-1,-1),(-\tfrac12,-2),(\tfrac12,2),(1,1),(2,\tfrac12)$ | QI and QIII, VA $x=0$, HA $y=0$, **odd** |
| $y=1/x^2$ | $(-2,\tfrac14),(-1,1),(1,1),(2,\tfrac14)$ | both branches up, **even** |
| $y=\sin x$ | $(0,0),(\tfrac\pi2,1),(\pi,0),(\tfrac{3\pi}2,-1),(2\pi,0)$ | period $2\pi$, **odd** |
| $y=\cos x$ | $(0,1),(\tfrac\pi2,0),(\pi,-1),(\tfrac{3\pi}2,0),(2\pi,1)$ | period $2\pi$, **even** |
| $y=e^x$ | $(-1,1/e),(0,1),(1,e)$ | HA $y=0$ on the left |
| $y=\ln x$ | $(1/e,-1),(1,0),(e,1)$ | VA $x=0$, domain $(0,\infty)$ |

Read this table as structure, not as 55 facts.
For $x^2$, $\lvert x\rvert$ and $\sqrt x$, the anchors are just the squares and roots you already know.
For $x^2$ the heights at $1$ and $2$ units from the vertex are $1$ and $4$; after a vertical stretch by $a$ they become $a$ and $4a$.
That single sentence is what lets you label a stretched parabola without computing anything.

**Parity decides whether a reflection is visible**, and this is the fact students most often miss.

| Parent | Parity | Consequence |
| :--- | :--- | :--- |
| $x^2$, $\lvert x\rvert$, $\cos x$, $1/x^2$ | **even**, $f(-x)=f(x)$ | a reflection in the $y$-axis does **nothing at all** |
| $x$, $x^3$, $\sqrt[3]{x}$, $\sin x$, $1/x$ | **odd**, $f(-x)=-f(x)$ | reflecting in the $y$-axis gives the **same graph** as reflecting in the $x$-axis |
| $\sqrt x$, $e^x$, $\ln x$ | neither | the two reflections are genuinely different, and one of them changes the domain |

### 2.2 The canonical template

Every transformation question in this course fits one form.
Get the expression into it, and the question is over.

$$\boxed{\;y \;=\; a\,f\big(b(x-h)\big) \;+\; k\;}$$

| Parameter | Where it sits | What it does | Direction |
| :--- | :--- | :--- | :--- |
| $a$ | multiplies the **output** | vertical scale by $\lvert a\rvert$; reflect in the $x$-axis if $a<0$ | as written |
| $k$ | **added** to the output | vertical shift up $k$ | as written |
| $b$ | multiplies the **input** | horizontal scale by $\dfrac{1}{\lvert b\rvert}$; reflect in the $y$-axis if $b<0$ | **reciprocal** |
| $h$ | **subtracted** from the input | horizontal shift right $h$ | **opposite sign to what you see** |

Two of the four are counter-intuitive, and both counter-intuitions have the same cause: $b$ and $h$ act on the input, so they act *before* $f$ runs, and you have to compensate rather than copy.

**Why the horizontal shift looks backwards.**
Take $y=f(x-3)$ and ask what happens at $x=5$: you get $f(2)$.
So the height the parent had at $2$ now appears at $5$.
Every height moved 3 to the right, even though the expression says minus 3.
The rule is not a convention to memorise, it is a consequence: to *see* the parent's value later, you must *ask* for an earlier input.

For our question, $g(x)=3(x+4)^2$:

$$a=3,\qquad b=1,\qquad h=-4 \;\;(\text{because } x+4 = x-(-4)),\qquad k=0.$$

### 2.3 The master point map

This is the single most useful line in this document.
For $y=a\,f\big(b(x-h)\big)+k$, every point $(x_0,y_0)$ of the parent moves to

$$\boxed{\;(x_0,\,y_0)\;\longmapsto\;\left(\frac{x_0}{b}+h,\;\; a\,y_0+k\right)\;}$$

The $x$-coordinate is divided by $b$ then shifted by $h$; the $y$-coordinate is multiplied by $a$ then shifted by $k$.
Note that the *reciprocal* and the *sign flip* are already baked in, which is exactly why using the map is safer than reasoning verbally about "backwards".

This was verified over 6 parents $\times$ 54 parameter sets $\times$ their anchor points, 1458 combinations, zero mismatches.
It was also checked in the failing direction: writing $x_0\cdot b+h$ instead of $x_0/b+h$ misses the target curve at all 4 test anchors, so the division is load-bearing.

For Q2.1, substituting $a=3,b=1,h=-4,k=0$:

$$(x,y)\;\longmapsto\;(x-4,\;3y)$$

## 3. The universal procedure

> 1. **Name the parent.** Strip every constant off the expression until only the bare function of $x$ is left. Say its name out loud and write its anchor points.
> 2. **Factor the input.** If a coefficient multiplies $x$ *and* a constant is present inside, factor the coefficient out so the input reads $b(x-h)$. This step is where most marks are lost, and it is skipped precisely when it matters.
> 3. **Read off $a$, $b$, $h$, $k$.** Four numbers. Write them down explicitly.
> 4. **Build the point map** $(x,y)\mapsto\left(\frac{x}{b}+h,\;ay+k\right)$.
> 5. **Push 3 to 5 anchor points through it.** For a parabola use the vertex and two symmetric pairs.
> 6. **State the transformations as an ordered list**, using the order rule below. This is what the "explain the procedure" marks are for.
> 7. **Sketch and label.** Label the vertex or anchor point, the pairs you computed, and the intercepts if they are on your scale.
> 8. **Check** with Section 6, then type the answer with Section 7.

**The order rule, in one sentence.**

> On each side independently, do the **multiplication before the addition**.

Vertically: scale and reflect first, then shift.
Horizontally: scale and reflect first, then shift by $h$ (with the input already factored).
Across the two sides the order never matters, which is proved in Family 7.

**A classification table to run in step 3.**

| What you see | Which parameter | What it forces |
| :--- | :--- | :--- |
| a number added or subtracted **outside** the function | $k$ | vertical shift, same sign |
| a number multiplying the function **outside** | $a$ | vertical scale; reflect if negative |
| a number added or subtracted **inside**, no coefficient on $x$ | $h$ | horizontal shift, **opposite** sign |
| a number multiplying $x$ **inside**, nothing added | $b$ | horizontal scale by $1/\lvert b\rvert$; reflect if negative |
| a coefficient on $x$ **and** a constant, inside | $b$ and $h$ | **factor first**, then shift by $c/b$, not by $c$ |

## 4. Q2.1 worked four ways

### Route A - shift first, then stretch (use this one)

Parent $y=x^2$, anchors $(-2,4),(-1,1),(0,0),(1,1),(2,4)$.

**Stage 1, horizontal shift.**
Replace $x$ by $x+4$: $\;y=(x+4)^2$.
Since $x+4=x-(-4)$, we have $h=-4$, so the graph moves **left 4**.
Every point keeps its height and loses 4 from its $x$:

| parent | $(-2,4)$ | $(-1,1)$ | $(0,0)$ | $(1,1)$ | $(2,4)$ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| after left 4 | $(-6,4)$ | $(-5,1)$ | $(-4,0)$ | $(-3,1)$ | $(-2,4)$ |

**Stage 2, vertical stretch.**
Multiply the output by 3: $\;y=3(x+4)^2$.
Every point keeps its $x$ and triples its height:

| after left 4 | $(-6,4)$ | $(-5,1)$ | $(-4,0)$ | $(-3,1)$ | $(-2,4)$ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| after $\times 3$ | $(-6,12)$ | $(-5,3)$ | $(-4,0)$ | $(-3,3)$ | $(-2,12)$ |

The vertex does not move in stage 2, and it is worth knowing *why*: its height is $0$, and $3\times 0=0$.
A vertical stretch fixes every point on the $x$-axis and nothing else.
If the question had been $3(x+4)^2+1$, the vertex would have moved.

All ten of those coordinates were verified against the two stage equations.

### Route B - stretch first, then shift

$y=x^2 \to y=3x^2 \to y=3(x+4)^2$.

This gives **exactly the same function**, verified to agree everywhere on $[-12,4]$.
It works because a vertical operation and a horizontal operation never interfere.
It is still the worse habit, because it survives here only by luck: add a vertical shift and the same instinct produces a wrong answer, which Family 7 demonstrates.

### Route C - expand, or complete the square (correct, and worth zero)

$3(x+4)^2 = 3(x^2+8x+16) = 3x^2+24x+48$, then $x=-\dfrac{b}{2a}=-\dfrac{24}{6}=-4$, then $y=g(-4)=0$.

Verified: the expanded form is identical to $3(x+4)^2$, and the vertex formula does return $-4$.
Mathematically flawless.
**It scores zero**, because the question forbids it in writing.
This route is in this document only so that you recognise it as the trap it is: it is the method most students find faster, and it is the one being explicitly excluded.

### Route D - the two-point fit

If you already believe the vertex is $(-4,0)$, get $a$ from one more point: $a\cdot(-3+4)^2 = 3$ gives $a=3$, and $a\cdot(-2+4)^2=12$ also gives $a=3$.
Both verified.
This is not a solution method for this question, it is the **check** in Section 6 and the tool for Family 8.

### Which route, and why

| Route | Time | Risk | Earns the marks? |
| :--- | :--- | :--- | :--- |
| A, shift then stretch | ~30 s | low; matches the reading order of the expression | **Yes** |
| B, stretch then shift | ~30 s | none here, but trains a habit that fails with $k\neq0$ | Yes |
| C, expand or vertex formula | ~45 s | none mathematically | **No, explicitly zero** |
| D, two-point fit | ~15 s | assumes the vertex you were meant to derive | No, but it is the best check |

**Use Route A under pressure.**
It reads the expression outward from $x$, which is the same order the template is written in, so there is nothing extra to remember.
It also generalises without modification to every variation in Section 8, including the ones with four active parameters.

## 5. The exam-ready write-up

If the paper you sit asks for method, these are the sentences that earn the marks.
Copy the shape, not just the numbers.

> 1. The basic function is $y=x^2$, the parabola with vertex at the origin passing through $(\pm1,1)$ and $(\pm2,4)$.
> 2. Writing $g(x)=3\big(x-(-4)\big)^2$ puts it in the form $a\,f(x-h)+k$ with $a=3$, $h=-4$ and $k=0$.
> 3. **First transformation:** replacing $x$ by $x+4$ translates the graph horizontally 4 units to the **left**, moving the vertex from $(0,0)$ to $(-4,0)$ and the points $(\pm1,1)$ to $(-3,1)$ and $(-5,1)$.
> 4. **Second transformation:** multiplying by $3$ stretches the graph vertically by a factor of 3, fixing the vertex $(-4,0)$ because its height is zero, and sending $(-3,1)$ and $(-5,1)$ to $(-3,3)$ and $(-5,3)$.
> 5. The resulting graph is an upward parabola with vertex $(-4,0)$ and axis of symmetry $x=-4$, narrower than $y=x^2$ by a factor of 3, with $y$-intercept $g(0)=48$.

Five things a marker looks for that students routinely skip, and each is free:

- **Naming** the basic function rather than just drawing it.
- Stating $g(x)=3(x-(-4))^2$, which is what makes "left" defensible instead of asserted.
- Saying the transformations are applied **in that order**, since the question asks for a procedure.
- **Labeling** actual coordinates on the sketch, because "labeled graph" is in the question text.
- Saying the vertical stretch **fixes** the vertex, which shows you know why rather than that you noticed.

Do not write "shift 4" without a direction, and do not write "$h=4$".
Both lose the point they were meant to earn.

## 6. Verify before you commit

This takes eight seconds and catches nearly every error available on this question.

**The five-second core check: substitute your vertex back.**
You claim the vertex is $(-4,0)$.
Then $g(-4)$ must be $0$: $3(-4+4)^2=3\cdot0=0$. ✓
This is the whole check for a shift, and it works because the vertex is the one point whose coordinates you asserted rather than computed.

**The four cheap invariants.**

1. **Direction.** $a=3>0$, so the parabola opens **up**. Confirm your sketch does. Verified independently: $g$ rises on both sides of $x=-4$.
2. **Width.** One unit from the vertex the height is $\lvert a\rvert=3$; two units out it is $4\lvert a\rvert=12$. If your labeled points are $(-3,1)$ and $(-2,4)$, you forgot to stretch.
3. **$y$-intercept.** Set $x=0$ in the **original** expression: $g(0)=3(4)^2=48$. If your sketch crosses the $y$-axis anywhere near the origin, your shift went the wrong way.
4. **Symmetry.** For an even parent, $g(h+t)=g(h-t)$ for every $t$. Here $g(-4+t)=g(-4-t)$, verified at $t=0.5,1,2,3.7,10$. If your two labeled points at the same height are not equidistant from the axis, one of them is wrong.

**The direction test that settles left-versus-right in two seconds.**
Ask which $x$ makes the inside zero.
For $(x+4)^2$ that is $x=-4$, which is to the *left* of the origin, so the shift is left.
This never fails and it needs no rule.

**The numbers worth memorising for a stretched parabola.**
The parent heights $1,4,9$ at $1,2,3$ units from the vertex become $a,4a,9a$.
For $a=3$ that is $3,12,27$.
If a labeled height on your sketch is not $3$, $12$ or $27$, you have either mislabeled or misread $a$.

## 7. Answer-entry rules

Möbius is answer-only and machine-marked, and it runs two different parsers behind one answer box with nothing in the interface saying which one you are in.
Grading is by mathematical equivalence, so a correct answer is never rejected for its *form*, only for being *parsed* differently than you intended.

A sketch cannot be typed, so this question arrives in Möbius as multiple choice over candidate graphs, or as fill-in fields.
Both forms are covered below.

| Field it asks for | Type this | Not this |
| :--- | :--- | :--- |
| the transformed equation | `3*(x+4)^2` | `3(x+4)^2`, `3(x+4)²` |
| the vertex | `(-4,0)` | `-4,0`, `x=-4`, `(-4, 0)` with a stray space if it wants none |
| $h$ in $a(x-h)^2+k$ | `-4` | `4` |
| $k$ | `0` | blank |
| $a$ | `3` | `-3` |
| shift amount, with a separate direction field | `4` and `left` | `-4` and `left` |
| the domain | `(-inf,inf)` or `R` | `all reals` |
| the range | `[0,inf)` | `(0,inf)`, `y>=0` if it wants interval form |
| the $y$-intercept | `48` | `(0,48)` if it asks for a number |

**The single most expensive mistake available on this question is entering `4` for $h$.**
The expression shows $+4$ and the shift is 4 units, so `4` feels right twice over.
The template is $a(x-h)^2+k$, and $x+4=x-(-4)$, so $h=-4$.
The graph moves left 4, and $h=-4$; the *amount* is 4 and the *parameter* is $-4$, and the box is asking for one specific one of those.
Read the label on the field before you type.

**Two rules that are never wrong, so always use them.**

- Type the explicit `*` for every multiplication. It is valid in both parsers, so it can never cost you anything, and implicit multiplication fails silently in one of them.
- Bracket every function argument and every denominator.

**Always click the preview icon.**
An empty preview modal means broken syntax, not wrong mathematics.

**On a multiple-choice version, discriminate in this order.**
It is faster than examining all four graphs.

1. **Direction** first: is it up or down? That eliminates half the options from the sign of $a$ alone.
2. **Vertex** second: read the inside-zero, $x=-4$ here.
3. **Width** third: check the height one unit from the vertex against $\lvert a\rvert$.

Distractor graphs in this family are built by flipping exactly one of those three, so checking all three in that order is both necessary and sufficient.

## 8. The variation catalog

This is the part that makes the question repeatable.
Every entry below was numerically verified, and the order claims were verified in both directions.
The families are organised by **the tool the variation forces**, not by how the question looks.

### Family 0 - name and sketch the parent, no transformation

**Trigger:** "sketch the basic function", or a transformation question whose first step you have to supply.
**Tool:** recall from the table in Section 2.1.

There is nothing to derive here, and it is the prerequisite for all twelve families below.
If you cannot produce $\sqrt[3]{x}$ or $1/x^2$ from memory in five seconds, no amount of transformation technique will save the question.
Learn the anchor points and the parity column.

### Family 1 - pure shifts, $a=1$ and $b=1$

**Trigger:** constants added inside and outside, no coefficient anywhere.
**Tool:** the point map $(x,y)\mapsto(x+h,\,y+k)$. Nothing scales, so no order question exists.

| Function | Parent | Point map | Key point | Extra |
| :--- | :--- | :--- | :--- | :--- |
| $(x-3)^2+2$ | $x^2$ | $(x+3,\,y+2)$ | vertex $(3,2)$ | no $x$-intercept |
| $\lvert x+1\rvert-4$ | $\lvert x\rvert$ | $(x-1,\,y-4)$ | vertex $(-1,-4)$ | $x$-intercepts $3$ and $-5$ |
| $\sqrt{x-2}+1$ | $\sqrt x$ | $(x+2,\,y+1)$ | start $(2,1)$ | domain $[2,\infty)$, no $x$-intercept |
| $(x+5)^3-1$ | $x^3$ | $(x-5,\,y-1)$ | inflection $(-5,-1)$ | |

Read this as one rule, not four: **the anchor point of the parent goes to $(h,k)$**, and every other point rides along.

### Family 2 - vertical scaling, which is Q2.1's own family

**Trigger:** a coefficient **outside** the function.
**Tool:** multiply heights by $a$, and do that **before** any vertical shift.

| Function | Point map | Vertex or start | $y$-intercept |
| :--- | :--- | :--- | :--- |
| $3(x+4)^2$ **(Q2.1)** | $(x-4,\,3y)$ | $(-4,0)$ | $48$ |
| $2(x-1)^2-5$ | $(x+1,\,2y-5)$ | $(1,-5)$ | $-3$ |
| $\tfrac12\lvert x\rvert+3$ | $(x,\,\tfrac{y}{2}+3)$ | $(0,3)$ | $3$ |
| $4\sqrt x-2$ | $(x,\,4y-2)$ | $(0,-2)$ | $-2$, $x$-intercept at $x=\tfrac14$ |

Notice the $y$ column of each map: it is always "multiply, then add", in that order.
That is the whole family.

### Family 3 - reflections, and when a reflection is invisible

**Trigger:** a minus sign. The only question is **which side of $f$ it is on.**
**Tool:** a minus **outside** flips vertically ($a<0$); a minus **multiplying $x$** flips horizontally ($b<0$).

| Function | Which flip | Point map | Key point | Range |
| :--- | :--- | :--- | :--- | :--- |
| $-3\lvert x-2\rvert$ **(Q2.2)** | vertical | $(x+2,\,-3y)$ | vertex $(2,0)$ | $(-\infty,0]$ |
| $-(x+1)^2+4$ | vertical | $(x-1,\,-y+4)$ | vertex $(-1,4)$ | $(-\infty,4]$ |
| $-\sqrt x$ | vertical | $(x,\,-y)$ | start $(0,0)$ | $(-\infty,0]$ |
| $\sqrt{-x}$ | horizontal | $(-x,\,y)$ | start $(0,0)$ | $[0,\infty)$, **domain** becomes $(-\infty,0]$ |

$-3\lvert x-2\rvert$ has vertex $(2,0)$, passes $(1,-3)$ and $(3,-3)$, has $y$-intercept $-6$, opens downward, and its only $x$-intercept is $x=2$.
All verified.

**The three degeneracies that decide whether the flip is even visible.**
These are the most-missed facts in the whole topic, and all three were verified on a grid.

| Claim | Verified consequence |
| :--- | :--- |
| $(-x)^2=x^2$, and $\lvert -x\rvert=\lvert x\rvert$ | for an **even** parent, a $y$-axis reflection changes **nothing** |
| $(-x)^3=-x^3$, and $\tfrac{1}{-x}=-\tfrac1x$ | for an **odd** parent, the two reflections give the **same** graph |
| $3\lvert-(x-2)\rvert = 3\lvert x-2\rvert \neq -3\lvert x-2\rvert$ | the minus must be **outside** to turn the graph over |

That last row is the one that costs marks on Q2.2.
Verified in both directions: $3\lvert-(x-2)\rvert$ and $3\lvert x-2\rvert$ agree everywhere, and both differ from $-3\lvert x-2\rvert$.

### Family 4 - horizontal scaling, and the degeneracy that hides it

**Trigger:** a coefficient **on $x$**, with nothing added inside.
**Tool:** the scale factor is $1/\lvert b\rvert$, the **reciprocal**. $y=f(2x)$ is a **compression** to half width, not a stretch.

Here is the fact nobody tells you, and it explains why this family is under-tested and therefore dangerous.
**For power and root parents, a horizontal scaling is indistinguishable from a vertical one.**

| Function | Equals | So the "horizontal compression" is really |
| :--- | :--- | :--- |
| $(2x)^2$ | $4x^2$ | a vertical stretch by 4 |
| $\sqrt{4x}$ | $2\sqrt x$ | a vertical stretch by 2 |
| $\lvert x/2\rvert$ | $\tfrac12\lvert x\rvert$ | a vertical compression by $\tfrac12$ |
| $(x/3)^3$ | $x^3/27$ | a vertical compression by $\tfrac1{27}$ |

The general rule, verified over $b\in\{2,3,\tfrac12\}$ and $n\in\{2,3,4\}$: compressing $x^n$ horizontally by $1/b$ is the same as stretching it vertically by $b^n$.
So on a **parabola** you can never be marked wrong for confusing the two, and you will therefore never learn the difference from parabola practice.

**Where the degeneracy fails, which is where the marks are.**

| Function | What actually happens | Verified |
| :--- | :--- | :--- |
| $\sin 2x$ | period halves to $\pi$; this is **not** any vertical scaling of $\sin x$ | no constant $c$ works: $x=\tfrac\pi2$ forces $c=0$, $x=\tfrac\pi4$ forces $c=\sqrt2$ |
| $\ln 4x$ | $=\ln x+\ln 4$: a horizontal compression of $\ln$ is a vertical **shift** | agree on $[0.05,9]$ |
| $e^{3x}$ | $=(e^3)^x$: a horizontal compression of $e^x$ is a change of **base** | agree on $[-2,2]$ |

If a horizontal-scaling question appears, expect a trig, log or exponential parent, because those are the only ones where the answer differs from the vertical version.

### Family 5 - the unfactored input, where the marks actually go

**Trigger:** a coefficient on $x$ **and** a constant inside, not factored.
**Tool:** **factor $b$ out first.** The shift is $c/b$, never $c$.

This family deserves its own section because it is the single most reliable way to lose this question, and because the wrong answer looks completely reasonable.

| Function | Factored | Shift, once factored | Wrong if you scale first and then shift by $c$ |
| :--- | :--- | :--- | :--- |
| $(2x-6)^2$ | $\big(2(x-3)\big)^2=4(x-3)^2$ | right **3** | right 6 |
| $\sqrt{3x+9}$ | $\sqrt{3(x+3)}=\sqrt3\sqrt{x+3}$ | left **3** | left 9 |
| $\lvert 4x-8\rvert$ | $4\lvert x-2\rvert$ | right **2** | right 8 |
| $\sin(2x-\pi)$ | $\sin\big(2(x-\tfrac\pi2)\big)$ | right $\tfrac{\pi}{2}$ | right $\pi$ |
| $(-x+2)^2$ | $\big(-(x-2)\big)^2=(x-2)^2$ | right **2**, flip invisible | a $y$-axis flip you can see |

Read the last column precisely, because it is easy to over-learn.
It does **not** say the larger number is always wrong.
Shifting by $c$ is correct in the *unfactored* reading, provided the shift comes **first**: $\sqrt{3x+9}$ really can be built as "left 9, then compress by $\tfrac13$", and that was verified.
What fails is taking the amount from one reading and the order from the other.
Verified as a real difference: $(2x-6)^2$ and $\big(2(x-6)\big)^2$ disagree, with vertices at $3$ and $6$.

**Why the order rule matters here and only here.**
With the input written as $b(x-h)$, you must **scale then shift**.
Scale-then-shift gives $f\big(b(x-h)\big)$. ✓
Shift-then-scale gives $f(bx-h)$, which is a shift of $h/b$. ✗
Both orders can be made to work if you match the amount to the form, and mixing them is the error:

| Form you wrote | Correct order | Correct amount |
| :--- | :--- | :--- |
| $f\big(b(x-h)\big)$, factored | scale first, then shift | $h$ |
| $f(bx-c)$, unfactored | shift first, then scale | $c$ |

Factoring first removes the choice, which is why step 2 of the procedure exists.

### Family 6 - the full composite, all four parameters live

**Trigger:** more than two things happening at once.
**Tool:** the master point map. Do not reason verbally about four transformations; build the map.

**Worked shape: $y=-2\sqrt{3-x}+1$.**
Factor the input: $3-x=-(x-3)$, so $y=-2\sqrt{-(x-3)}+1$, giving $a=-2$, $b=-1$, $h=3$, $k=1$.
Point map: $(x,y)\mapsto\left(\frac{x}{-1}+3,\;-2y+1\right)=(3-x,\;-2y+1)$.
As an ordered list: reflect in the $y$-axis, shift right 3, stretch vertically by 2, reflect in the $x$-axis, shift up 1.

| Parent point | Image | On the curve? |
| :--- | :--- | :--- |
| $(0,0)$ | $(3,1)$ | ✓ starting point |
| $(1,1)$ | $(2,-1)$ | ✓ |
| $(4,2)$ | $(-1,-3)$ | ✓ |
| $(9,3)$ | $(-6,-5)$ | ✓ |

Domain $(-\infty,3]$, range $(-\infty,1]$, $y$-intercept $1-2\sqrt3$, $x$-intercept $x=\tfrac{11}4$.
All verified.

| Other instances | Point map | Key point |
| :--- | :--- | :--- |
| $\tfrac12(x+2)^3-4$ | $(x-2,\,\tfrac y2-4)$ | inflection $(-2,-4)$, passes the origin |
| $3-2\lvert x+1\rvert$ | $(x-1,\,-2y+3)$ | vertex $(-1,3)$, $x$-intercepts $\tfrac12$ and $-\tfrac52$ |

### Family 7 - does the order matter?

**Trigger:** "indicate the transformations **in the order** they are applied", or a direct conceptual question.
**Tool:** the one-sentence rule, plus the table below.

Q2.2 uses exactly that wording, so this is an examinable question in its own right, not just background.

**The two verdicts, both verified.**

| Pair of transformations | Order? | Why |
| :--- | :--- | :--- |
| any vertical with any horizontal | **does not matter** | they touch different coordinates |
| two shifts on the same axis | does not matter | additions commute; right 2 then right 3 is right 5 |
| vertical reflect with vertical stretch | does not matter | both are multiplications of $y$ |
| horizontal compress with vertical stretch | does not matter | different coordinates |
| **vertical stretch with vertical shift** | **matters** | $2x^2+5$ versus $2(x^2+5)=2x^2+10$ |
| **vertical reflect with vertical shift** | **matters** | $-x^2+4$ versus $-(x^2+4)=-x^2-4$ |
| **horizontal scale with horizontal shift** | **matters** | $4(x-3)^2$ versus $(2x-3)^2$, vertices $3$ and $\tfrac32$ |
| **horizontal reflect with horizontal shift** | **matters** | $\lvert 2-x\rvert$ versus $\lvert -x-2\rvert$ |

The pattern is exactly one line: **order matters only between a multiply and an add on the same axis.**

**And here is the fact that makes this family worth studying rather than skimming.**
Both transformation questions on the past papers are order-insensitive.

- Q2.1, $3(x+4)^2$: both orders verified identical.
- Q2.2, $-3\lvert x-2\rvert$: **all six** orderings of {shift right 2, stretch 3, reflect in $x$} were verified to reproduce $f$ exactly.

Neither has a vertical shift, so nothing can go wrong.
That is a trap disguised as good news: you can practise both past questions with sloppy order, get full marks twice, and conclude order does not matter.
Add a $+k$ and it does.
Verified: $3(x+4)^2+6$ and $3\big((x+4)^2+6\big)$ are different functions, differing by 12 everywhere.

### Family 8 - reverse direction, write the equation

**Trigger:** "the graph of $f$ is shifted..., find the new equation", or a graph with labeled points.
**Tool:** the same template, read right to left. Apply the described operations to the *expression*, in the order given.

| Described sequence | Equation | Check |
| :--- | :--- | :--- |
| $x^2$: right 5, stretch 2, down 3 | $2(x-5)^2-3$ | vertex $(5,-3)$ |
| $\lvert x\rvert$: reflect in $x$-axis, left 3, up 1 | $-\lvert x+3\rvert+1$ | vertex $(-3,1)$ |
| $\sqrt x$: compress horizontally by $\tfrac13$, up 2 | $\sqrt{3x}+2$ | start $(0,2)$ |
| **up 3 then stretch 2** | $2(x^2+3)=2x^2+6$ | **not** $2x^2+3$ |

That last row is the same order trap running backwards, and it is verified as a genuine difference.
When the question dictates an order that puts the shift first, you must obey it, and the constant gets multiplied.

**From a graph.**
Read the vertex to get $h$ and $k$, then fit $a$ from any one other labeled point.
Vertex $(2,-3)$ through $(3,-1)$: $a(1)^2-3=-1$, so $a=2$, giving $y=2(x-2)^2-3$, which was verified to pass through both $(3,-1)$ and $(1,-1)$.
The same fit applied to Q2.1's vertex $(-4,0)$ and point $(-3,3)$ recovers $a=3$.

### Family 9 - an abstract $f$, given only its graph or a few points

**Trigger:** "the graph of $y=f(x)$ is shown; sketch $y=2f(x-1)-3$." No formula is given.
**Tool:** the point map applied to the labeled points **only**. There is nothing else you can do, and nothing else you need.

This family is common, it looks harder than the others, and it is actually easier, because you cannot be tempted into expanding.

Take $f$ with labeled points $(-3,2),(-2,1),(0,-3),(2,-4),(4,2)$.

| Transformation | Point map | The five images |
| :--- | :--- | :--- |
| $2f(x-1)-3$ | $(x+1,\,2y-3)$ | $(-2,1),(-1,-1),(1,-9),(3,-11),(5,1)$ |
| $-f(x)+1$ | $(x,\,-y+1)$ | $(-3,-1),(-2,0),(0,4),(2,5),(4,-1)$ |
| $f(2x)$ | $(\tfrac x2,\,y)$ | $(-1.5,2),(-1,1),(0,-3),(1,-4),(2,2)$ |
| $f(-x)$ | $(-x,\,y)$ | $(3,2),(2,1),(0,-3),(-2,-4),(-4,2)$ |
| $f(x+3)-2$ | $(x-3,\,y-2)$ | $(-6,0),(-5,-1),(-3,-5),(-1,-6),(1,0)$ |
| $\tfrac12 f(x)$ | $(x,\,\tfrac y2)$ | $(-3,1),(-2,0.5),(0,-1.5),(2,-2),(4,1)$ |

All six maps were verified against an interpolated $f$ through those five points.
Note $f(-x)$ reverses the left-to-right order of the points, which is what makes it easy to plot in the wrong order.

### Family 10 - domain and range under transformation

**Trigger:** "state the domain and range of the transformed function."
**Tool:** horizontal operations act on the **domain** using the inverse operation; vertical operations act on the **range** using the same operation.

| Function | Domain | Range |
| :--- | :--- | :--- |
| $3(x+4)^2$ | $(-\infty,\infty)$ | $[0,\infty)$ |
| $-3\lvert x-2\rvert$ | $(-\infty,\infty)$ | $(-\infty,0]$ |
| $\sqrt{x-2}+1$ | $[2,\infty)$ | $[1,\infty)$ |
| $\sqrt{-x}$ | $(-\infty,0]$ | $[0,\infty)$ |
| $-2\sqrt{3-x}+1$ | $(-\infty,3]$ | $(-\infty,1]$ |
| $\tfrac1{x-2}+3$ | $x\neq2$ | $y\neq3$ |

Verified with a function whose domain is exactly $[-1,3]$: $f(2x)$ has domain $[-\tfrac12,\tfrac32]$, $f(x-2)$ has domain $[1,5]$, and $2f(x)-3$ has domain $[-1,3]$ unchanged while its range moves from $[0,2]$ to $[-3,1]$.

Only the parent's restriction can create a domain restriction.
$3(x+4)^2$ is defined everywhere no matter what you do to it, because $x^2$ is.

### Family 11 - parents with asymptotes

**Trigger:** the parent is $1/x$, $1/x^2$, $\ln$ or $e^x$.
**Tool:** an asymptote is a set of points, so it moves by the **same point map**. A vertical shift moves the horizontal asymptote; a horizontal shift moves the vertical one.

| Function | VA | HA | A point on each branch |
| :--- | :--- | :--- | :--- |
| $\tfrac1{x-2}+3$ | $x=2$ | $y=3$ | $(3,4)$ and $(1,2)$; $x$-intercept $\tfrac53$ |
| $\tfrac2{x+1}-1$ | $x=-1$ | $y=-1$ | $x$-intercept $x=1$ |
| $\ln(x+3)$ | $x=-3$ | none | passes $(-2,0)$ |
| $e^{x-1}-2$ | none | $y=-2$ | passes $(1,-1)$; $x$-intercept $1+\ln2$ |
| $-\tfrac1x$ | $x=0$ | $y=0$ | QII and QIV, since $-\tfrac1x=\tfrac1{-x}$ |

All verified, including the asymptotes as one-sided limits.
The most common error in this family is shifting the curve and leaving the asymptote where it was.

### Family 12 - a restricted domain

**Trigger:** the phrase "in the interval", which is in Q2.2's own wording, or a piecewise definition.
**Tool:** the endpoints are points, so they move by the point map like everything else.

If $f$ is defined on $[-1,3]$:

| Transformation | New interval | Note |
| :--- | :--- | :--- |
| $f(x-2)$ | $[1,5]$ | shifts with the same sign as the shift |
| $f(2x)$ | $[-\tfrac12,\tfrac32]$ | halves, the reciprocal again |
| $f(x/2)$ | $[-2,6]$ | doubles |
| $f(-x)$ | $[-3,1]$ | the **endpoints swap** |
| $2f(x)-3$ | $[-1,3]$ | vertical, so unchanged |

The endpoint swap under $f(-x)$ is the one to watch: writing $[3,-1]$ is not an interval.

## 9. The trap list

Ranked by how often they actually cost marks on this question.

1. **Using the vertex formula or expanding.** The question says no credit. This is the only trap on the list that scores zero with completely correct mathematics, which is why it is first.
2. **Getting the shift direction backwards.** $(x+4)^2$ shifts **left**. Test it by asking which $x$ makes the inside zero.
3. **Not factoring a coefficient out of the input.** $(2x-6)^2$ shifts right **3**, not 6. This is the biggest silent error across the whole topic.
4. **Entering $h=4$ instead of $h=-4$.** The shift *amount* is 4 and the *parameter* is $-4$. Read the field label.
5. **Forgetting the stretch when labeling.** Writing $(-3,1)$ instead of $(-3,3)$. The check is that one unit from the vertex the height equals $\lvert a\rvert$.
6. **Applying a vertical shift before a vertical stretch.** $2x^2+5$ is not $2(x^2+5)$. Multiply, then add.
7. **Treating a horizontal scale as a stretch when it is a compression.** $f(2x)$ is a compression by $\tfrac12$: the factor is the reciprocal.
8. **Putting a minus on the wrong side of $f$.** $-3\lvert x-2\rvert$ opens down; $3\lvert-(x-2)\rvert$ is just $3\lvert x-2\rvert$ and opens up.
9. **Not naming the parent function.** On a written paper this is an explicit part of "starting with the graph of a basic function".
10. **Giving an unlabeled sketch.** The question says "labeled graph". A correct curve with no coordinates is an incomplete answer.
11. **Moving the curve and leaving the asymptote.** Only in Family 11, but free marks lost when it happens.
12. **Reversing an interval.** $f(-x)$ on $[-1,3]$ lives on $[-3,1]$, not $[3,-1]$.

## 11. The one-page decision tree

```
Sketch y = <expression> by transformations?
|
+-- 0. Is a graph or a point list given instead of a formula?
|      YES -> FAMILY 9. Apply the point map to the labeled points only.
|              Nothing else is possible and nothing else is needed.
|
+-- 1. NAME THE PARENT.  Strip all constants.  Write its anchor points.
|      x, x^2, x^3, |x|, sqrt(x), cbrt(x), 1/x, 1/x^2, sin, cos, e^x, ln
|      Note its PARITY: even -> a y-axis flip is invisible
|                       odd  -> the two flips are the same graph
|
+-- 2. FACTOR THE INPUT.  <- the step that is skipped exactly when it matters
|      Is there a coefficient on x AND a constant inside?
|        YES -> rewrite as b(x - h).  The shift is c/b, NOT c.
|        NO  -> b is 1 or absent.  Carry on.
|
+-- 3. READ OFF FOUR NUMBERS from  y = a*f(b(x-h)) + k
|        a = outside multiplier    (|a| scales y;  a<0 flips vertically)
|        k = outside addend        (shift up k)
|        b = inside multiplier     (scale x by 1/|b|;  b<0 flips horizontally)
|        h = inside subtrahend     (shift RIGHT h;  x+4 means h = -4)
|
+-- 4. BUILD THE POINT MAP      (x, y) -> ( x/b + h ,  a*y + k )
|
+-- 5. PUSH 3-5 ANCHORS THROUGH IT.  Vertex/start point, plus two pairs.
|
+-- 6. STATE THE ORDER, because "explain the procedure" is worth marks.
|      On EACH axis: MULTIPLY BEFORE ADD.  Across axes: order is free.
|      Safe recital: h-scale, h-flip, h-shift, v-scale, v-flip, v-shift.
|
+-- 7. SKETCH AND LABEL the vertex and every point from step 5.
|
+-- 8. CHECK, in eight seconds:
       a. substitute the vertex back:  does it give the y you claimed?
       b. sign of a:  does the sketch open the right way?
       c. one unit from the vertex, is the height |a|?
       d. set x = 0 in the ORIGINAL:  does the sketch cross there?
       e. even parent?  is it symmetric about x = h?

  Then TYPE it:  explicit *, brackets on every argument,
  h is NEGATIVE for a left shift, and PREVIEW.
```
