# Q19.2 - Area between a cosine and a horizontal line

**The question (Final Exam 2, item 8, 4 points).** Find the area between the curves $\cos x$ and the horizontal line $y = \dfrac{1}{\sqrt{2}}$ in the interval $\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$.

**The answer.** $2\sqrt{2} - 2 \approx 0.8284271247$

**What to type into Möbius:** `2*sqrt(2)-2`

## 0. The 30-second version

```
cos x = 1/sqrt2   ->  x = +- pi/4          both INSIDE [-pi/2, pi/2]
so the region is THREE pieces, and the top curve alternates
|D| is EVEN                                ->  do [0, pi/2] and double
A = 2 * [ int_0^(pi/4) (cos x - 1/sqrt2) + int_(pi/4)^(pi/2) (1/sqrt2 - cos x) ]
  = 2 * (sqrt2 - 1) = 2 sqrt2 - 2 = 0.8284
```

The whole question is four decisions: solve for the crossings, notice both are interior, split there, and decide the orientation separately on each piece.
Everything else is one antiderivative you already know.

## 1. What this question is really testing

| The reflex being tested | Where it comes back |
| :--- | :--- |
| Solve $\cos x = c$ and pick the branch the interval asks for | every trig equation on both papers |
| Notice that a crossing is *strictly inside* the interval | Q19.8, where $\int v$ and $\int \lvert v \rvert$ differ for the same reason |
| Split the integral at the crossing and decide orientation per piece | the definition of $\int \lvert f - g \rvert$ |
| Use evenness to halve the work on purpose, not by accident | any symmetric-interval integral |
| Antidifferentiate $\cos x$ and a constant, and evaluate | Q16.x, Q17.x, Q18.1 |

Q19.1 is the same question with a parabola.
The whole of its section 3 transfers here unchanged, and this page cites it rather than repeating it: see `notes\Q19.1 - Area between a line and a parabola.md`.

**What Q19.2 adds is that the boundary curve is transcendental and periodic**, and that changes exactly three things.

1. **The intersections are solutions of $\cos x = c$, so there are infinitely many.** The interval is what selects which pair you use, and choosing the wrong pair is an error species Q19.1 cannot have.
2. **The curves genuinely cross inside the interval**, so the region splits and the $\lvert \text{top} - \text{bottom} \rvert$ question becomes live rather than theoretical. Q19.1's own page says the absolute value is "a rule you are told, that you never see fire". This is where it fires.
3. **The region is symmetric**, so half the work is free if you take it deliberately.

## 2. The four things you must have cold

**Two antiderivatives.**

| $f(x)$ | $\int f\,dx$ |
| :--- | :--- |
| $\cos x$ | $\sin x$ |
| $c$ (a constant) | $cx$ |

That is the entire integration content of this question.
The difficulty is all in the setup.

**Four cosine values, and the angles that produce them.**

| $x$ | $\cos x$ | $x$ | $\cos x$ |
| :--- | :--- | :--- | :--- |
| $0$ | $1$ | $\pi/3$ | $1/2$ |
| $\pi/6$ | $\sqrt3/2$ | $\pi/2$ | $0$ |
| $\pi/4$ | $\dfrac{1}{\sqrt2} = \dfrac{\sqrt2}{2}$ | | |

**The general solution of $\cos x = c$.**

$$\cos x = c \quad\Longrightarrow\quad x = \pm\arccos(c) + 2k\pi, \quad k \in \mathbb{Z}$$

The $\pm$ is because cosine is even, and the $2k\pi$ is because it is $2\pi$-periodic.
Verified: all fourteen members of the family $\pm\pi/4 + 2k\pi$ for $k = -3 \ldots 3$ satisfy $\cos x = 1/\sqrt2$ to $10^{-14}$, and exactly **two** of them lie in $[-\pi/2, \pi/2]$.

**Which functions are even.**
$\cos x$ is even, and a constant is even, so $D(x) = \cos x - 1/\sqrt2$ is even, and so is $\lvert D \rvert$.
Measured directly at 41 sample points across the interval, agreement to $10^{-15}$.

## 3. The universal procedure

> **1. Sketch, roughly.** You are using it to count pieces, not to read numbers off it.
>
> **2. Find the crossings exactly**, by solving $f(x) = g(x)$ algebraically.
>
> **3. Keep only the crossings strictly inside the given interval.** This step does not exist on Q19.1 and it is the whole of the new content here.
>
> **4. Decide which curve is on top on each sub-interval**, by evaluating both at one point strictly between consecutive knots.
>
> **5. Write each definite integral before evaluating it**, as $\int (\text{top} - \text{bottom})\,dx$.
>
> **6. Add the pieces.** They are all positive by construction, so there is nothing to repair.

Steps 1, 2, 4, 5 are Q19.1's procedure verbatim.
Steps 3 and 6 are what a periodic boundary adds.

### 3.1 Step 2 in detail - solving $\cos x = 1/\sqrt2$ without losing a branch

$$\cos x = \frac{1}{\sqrt2} \quad\Longrightarrow\quad x = \pm\frac{\pi}{4} + 2k\pi$$

Three separate mistakes live in this one line, and each produces a different wrong area.

| The slip | What you get | Why it happens |
| :--- | :--- | :--- |
| Taking $x = \pm 3\pi/4$ | area $1.9179486412$ | $3\pi/4$ solves $\cos x = -1/\sqrt2$, not $+1/\sqrt2$. Verified: no member of the $\pm3\pi/4$ family lies in $[-\pi/2, \pi/2]$ at all. |
| Taking the "standard" pair $\pi/4$ and $7\pi/4$ | area $4.7463757660$ | That is the pair a $[0, 2\pi]$ habit produces. $7\pi/4$ is outside the given interval. |
| Taking only $x = \pi/4$ and forgetting $-\pi/4$ | half an answer | The $\pm$ in $\arccos$ is the easiest symbol in mathematics to drop. |

**The habit that prevents all three: write the general solution first, then intersect it with the interval.**
Do not solve "the" equation; solve the family and then filter.

### 3.2 Step 3 - the periodic trap, measured

A numerical root census was run over the difference $D(x) = \cos x - 1/\sqrt2$.
It was controlled in both directions before its verdict was trusted.

| Window | Roots found | What it shows |
| :--- | :--- | :--- |
| $[-\pi/2, \pi/2]$ (the question) | **2** | $\pm\pi/4$, both to $10^{-10}$ |
| $[-\pi/8, \pi/8]$ | **0** | the routine can return zero |
| $[0, \pi/2]$ | **1** | the routine can return one |
| $[-2\pi, 2\pi]$ | **4** | the same equation, a wider window |
| $[-3\pi, 3\pi]$ | **6** | and the count keeps growing |
| $\cos x = 2$, anywhere | **0** | no solutions at all |

**Read the fourth row carefully.**
Two of those four roots, at $\pm 7\pi/4$, are not in the region and contribute nothing.
A periodic boundary makes "how many intersections are there" a question with no answer until you say *where*.
On Q19.1 you could search $[-6, 6]$ and be safe; here that would find extra roots and split the integral in places the question never asked about.

**The census has an honest failure, and grid parity decides whether you see it.**
On a tangency it finds nothing, because a curve that touches without crossing has no sign change.
Tested on $\cos x = 1$: an **even** grid, which happens to land exactly on $x = 0$, reports **1 root**, and an **odd** grid, which does not, reports **0**.
Same routine, same function, different answer.
This reproduces on a cosine what Q19.1 measured on $x^2$ against $x^4$, and the conclusion is the same: **a sign-change census is not a root-finder at a tangency, and the algebra is what settles it.**

A third instance turned up while building this page.
A grid point that lands *exactly* on a root makes the product $D(x_i) \cdot D(x_{i+1})$ equal to zero rather than negative, so the sign-change test misses the root entirely and the region silently loses a split.
It cost a wrong drill answer before it was caught.
**If you write such a census yourself, test `== 0` separately.**

### 3.3 Step 4 - orientation is decided per piece, and never at a knot

Three pieces, three separate decisions.

| Piece | Test point | $\cos x$ | $1/\sqrt2$ | On top |
| :--- | :--- | :--- | :--- | :--- |
| $[-\pi/2, -\pi/4]$ | $x = -3\pi/8$ | $0.3827$ | $0.7071$ | the **line** |
| $[-\pi/4, \pi/4]$ | $x = 0$ | $1.0000$ | $0.7071$ | the **cosine** |
| $[\pi/4, \pi/2]$ | $x = 3\pi/8$ | $0.3827$ | $0.7071$ | the **line** |

The sign of $D$ genuinely alternates $-, +, -$, which is what "the curves cross" means.
At all three test points $\lvert D \rvert > 10^{-3}$, and each test point is strictly interior to its own piece.

**Never test at a knot.** At $x = \pm\pi/4$, $D$ is exactly zero and the comparison decides nothing.
This is not a pedantic point.
The generic router written to check this page's catalog used the midpoint of each piece, and on the tangency case $y = 1$ against $\cos x$ that midpoint *is* the touch point $x = 0$, where $D = 0$ and "$D > 0$" is false.
It returned $-1.1415926536$ for an area of $\pi - 2$: the sign of the whole answer flipped, from one badly-chosen probe point.
The fix is to probe where $\lvert D \rvert$ is largest, not where the piece happens to be widest.

### 3.4 Step 6 - use the symmetry on purpose

$D$ is even, so $\lvert D \rvert$ is even, so

$$A = \int_{-\pi/2}^{\pi/2} \lvert D \rvert \, dx = 2\int_{0}^{\pi/2} \lvert D \rvert \, dx$$

Verified numerically: the half-interval integral is $0.4142135624 = \sqrt2 - 1$, exactly half the answer.

That turns three integrals into two, and it removes the third piece, which was the one most likely to be added with the wrong sign.
**Take the symmetry deliberately.**
A student who computes the half and forgets to double gets $\sqrt2 - 1 \approx 0.4142$, a positive, plausible-looking number that no check based on sign or magnitude will reject.

### 3.5 What generalises, and what is specific to a periodic boundary

| Generalises to the whole Q19 category | Specific to a periodic boundary |
| :--- | :--- |
| Sketch, solve exactly, decide orientation strictly between, integrate top minus bottom | The intersections are an infinite family, so you must filter by the interval |
| A crossing strictly inside the interval forces a split | A wider search window finds real roots that are not in the region |
| A negative answer means the orientation went the wrong way | The answer's $\pi$ terms may cancel, so "no $\pi$ in the answer" is not evidence of an error |
| Symmetry halves the work when the region is symmetric | Symmetry is nearly always available, because $\sin$ and $\cos$ are even or odd about the natural points |
| Horizontal strips are the alternative when the boundary changes curve | Horizontal strips bring $\arccos$, whose derivative is infinite at the endpoint |

The next questions in the category go elsewhere.
Q19.3, Q19.8 and Q19.9 integrate a rate; Q19.4 and Q19.5 build the integrand from a physical description; Q19.6 and Q19.7 divide by the interval length.
**Q19.8 is this page's split rule in physics clothing**: displacement is $\int v$, distance is $\int \lvert v \rvert$, and the split happens where the velocity changes sign.

## 4. Q19.2 worked five ways

Write $D(x) = \cos x - \dfrac{1}{\sqrt2}$ and $F(x) = \sin x - \dfrac{x}{\sqrt2}$, so $F' = D$.

### Route A - three pieces, the exact antiderivative (use this one)

**Piece 2, the middle lobe**, where the cosine is on top:

$$\int_{-\pi/4}^{\pi/4}\left(\cos x - \tfrac{1}{\sqrt2}\right)dx = \Big[\sin x - \tfrac{x}{\sqrt2}\Big]_{-\pi/4}^{\pi/4} = \sqrt2 - \frac{\pi\sqrt2}{4} \approx 0.3034928278$$

**Pieces 1 and 3, the outer lobes**, where the line is on top. By symmetry they are equal:

$$\int_{\pi/4}^{\pi/2}\left(\tfrac{1}{\sqrt2} - \cos x\right)dx = \frac{\pi\sqrt2}{8} - 1 + \frac{\sqrt2}{2} \approx 0.2624671485$$

**Add them.**

$$A = \left(\sqrt2 - \frac{\pi\sqrt2}{4}\right) + 2\left(\frac{\pi\sqrt2}{8} - 1 + \frac{\sqrt2}{2}\right) = 2\sqrt2 - 2$$

The two $\pi\sqrt2/4$ terms cancel exactly.
Section 6.4 explains why that is not a coincidence.

### Route B - symmetry first, two pieces

$$A = 2\left[\int_0^{\pi/4}\left(\cos x - \tfrac{1}{\sqrt2}\right)dx + \int_{\pi/4}^{\pi/2}\left(\tfrac{1}{\sqrt2} - \cos x\right)dx\right] = 2\left(\frac{\sqrt2}{2} - \frac{\pi\sqrt2}{8} + \frac{\pi\sqrt2}{8} - 1 + \frac{\sqrt2}{2}\right) = 2(\sqrt2 - 1)$$

**This is the fastest route on paper** and the cancellation is visible inside the bracket rather than only at the end.
Two integrals instead of three, and one fewer chance to get a sign wrong.

### Route C - horizontal strips in $y$

Solve for $x$: the curve is $x = \pm\arccos y$.

- **The middle lobe**, $1/\sqrt2 \le y \le 1$, has width $2\arccos y$.
- **The outer lobes**, $0 \le y \le 1/\sqrt2$, each run from $x = \arccos y$ out to $x = \pi/2$, so each has width $\pi/2 - \arccos y$.

Using $\int \arccos y \, dy = y\arccos y - \sqrt{1-y^2}$,

$$\int_{1/\sqrt2}^{1} 2\arccos y \, dy = \sqrt2 - \frac{\pi\sqrt2}{4}, \qquad 2\int_0^{1/\sqrt2}\left(\frac{\pi}{2} - \arccos y\right)dy = \frac{\pi\sqrt2}{4} - 2 + \sqrt2$$

Total $2\sqrt2 - 2$, agreeing with route A to $10^{-12}$.
**This is the wrong route to choose under exam pressure**: it needs $\arccos$, an integration by parts, and three integrals rather than two.
It is here because it is a genuinely independent check, and because family F9 in section 8 is a question where it wins.

### Route D - numerical quadrature (a check, never an answer)

Split at $\pm\pi/4$ first, then integrate each piece.
Simpson on the three pieces agrees with the closed form to $10^{-13}$; a double-exponential (tanh-sinh) rule agrees to the same.

### Route E - Archimedes' two-thirds law, and why it does not apply

Q19.1's best memorisable shortcut is $A = \frac23 \times \text{span} \times \text{largest gap}$, which is exact for a parabola against a chord.
**It is not a general law and it is wrong here.**
Applied to the whole interval it is off by more than $0.5$.

Applied to the *middle lobe only* it gives $0.3067170615$ against the true $0.3034928278$, which is **1.0624 percent high**.
That is the dangerous case: a cosine arch looks so much like a parabola that a wrong shortcut lands within one percent, and no mental check will reject it.
**Carry Archimedes as a magnitude check on parabolas only.**

### Route comparison

| Route | Integrals | Where it goes wrong | Verdict |
| :--- | :--- | :--- | :--- |
| A - three pieces | 3 | three orientation decisions, three chances to slip | correct, slightly long |
| **B - symmetry, two pieces** | **2** | you must remember to double | **use this one under pressure** |
| C - horizontal strips | 3 | needs $\arccos$ and parts | good check, bad exam route |
| D - quadrature | n/a | no closed form | verification only |
| E - Archimedes | 0 | it is a parabola law | do not use here |

All four computational routes plus the closed form agree, with a total spread of $6.7 \times 10^{-16}$.

### 6.4 Why the $\pi$ cancels - the result worth carrying

Replace the height $1/\sqrt2$ with a general $c$ in $[0,1]$ and let $a = \arccos c$.
The same three-piece calculation gives a master formula for the whole family:

$$A(c) = 4\sqrt{1-c^2} - 4c\arccos(c) + \pi c - 2$$

Checked against the catalog at 51 values of $c$ and at every named instance.
Differentiating, and using $\cos a = c$ so the two $\arccos'$ terms cancel:

$$\frac{dA}{dc} = \pi - 4\arccos(c)$$

This vanishes exactly when $\arccos c = \pi/4$, that is at $c = \dfrac{1}{\sqrt2}$, and $\dfrac{d^2A}{dc^2} = \dfrac{4}{\sqrt{1-c^2}} > 0$.

**So the question's own line height is precisely the one that minimises the area.**
The minimum value is $2\sqrt2 - 2$, confirmed as the smallest over a half-million-point sweep of $c$.

And the $\pi$ in $A(c)$ appears only inside $\pi c - 4c\arccos c = c(\pi - 4\arccos c)$, which is $c$ times the derivative.
At the stationary height that bracket is zero, so **no $\pi$ survives**.
The $\pi$ terms cancel for a reason, and the reason is that $1/\sqrt2$ was chosen, not picked at random.

Two consequences worth having.

- **"There is no $\pi$ in my answer" is not evidence of a dropped term** on this particular question. At $c = 1/2$ the answer is $2\sqrt3 - 2 - \pi/6$ and the $\pi$ is genuinely there.
- **A "find $c$ so the area is $A$" question has two answers, not one.** $A(c)$ falls to its minimum at $1/\sqrt2$ and rises again, so $A(c) = 1$ is solved by both $c = 0.4488842358$ and $c = 0.9349464147$. Family F7 in section 8 is that question, and answering it with one root is the mistake it is designed to catch.

### 6.5 Two numerical warnings, because both look like health

**A near-miss split point costs almost nothing.** Moving the split from $\pi/4$ to $\pi/4 + 0.0025$ changes the area by **0.000534 percent**, and the measured order of the error in the offset is $2.0094, 2.0047, 2.0024, 2.0012$ - second order, because $D$ vanishes at a true crossing. A *mis-identified* split at $3\pi/8$ costs **14.70 percent**. Q19.1 measured the same thing on its endpoints. **The answer cannot tell you that a nearly-right crossing was guessed rather than solved.**

**Whether unsplit quadrature looks wrong depends on the grid, not on the mathematics.** Integrating $\lvert D \rvert$ straight through both kinks with Simpson at $n = 4000$ has error $8.9 \times 10^{-16}$, which looks exact. At $n = 4002$ the same routine on the same function has error $7.3 \times 10^{-8}$. The kinks sit at one quarter and three quarters of the span, so any $n$ divisible by 8 places them on panel boundaries and the kink becomes invisible. Measured convergence orders across the kink: **4.02, 4.01, 4.00, 4.00** on an aligned ladder, and **1.78, 1.89, 1.94, 1.97, 1.99** on a mis-aligned one. A lucky grid is not a correct method.

### 6.6 What the quadrature order actually is here

Q19.1 could not measure this: its integrand was a quadratic, Simpson is exact on every cubic, and the error was zero at every $n$.
**Here it is measurable**, because the integrand is a cosine.

| Integrand | Measured Simpson order |
| :--- | :--- |
| $\cos x - 1/\sqrt2$ on the middle lobe (this question) | $4.0050,\ 4.0012,\ 4.0003,\ 4.0001,\ 4.0000$ |
| $t^{2/3}$ on $[0,1]$ (control, must not read 4) | $1.6663,\ 1.6666,\ 1.6667,\ 1.6667,\ 1.6667$ |

| $\cos x$ vs $y = 1/2$ on $[-\pi/2, \pi/2]$ | $2\sqrt3 - 2 - \pi/6$ | $0.9405028395$ |
| $\cos x$ vs $y = \sqrt3/2$ on $[-\pi/2, \pi/2]$ | $\pi\sqrt3/6$ | $0.9068996821$ |

**The structure to see.** Only three distinct answers appear, and all three come from one formula with $c = 1/\sqrt2, 1/2, \sqrt3/2$.
The third one is a bare multiple of $\pi$ with no algebraic part, which happens because at $c = \sqrt3/2$ the $4\sqrt{1-c^2} = 2$ exactly cancels the $-2$.
**Nothing in a well-formed answer to this family is predictable from its shape** - the $\pi$ can vanish, dominate, or sit alongside a surd.

### Family F2 - a sine instead of a cosine, interval shifted

**Trigger.** $\sin x$ against a constant.
**Tool.** Identical, with $x = \arcsin c$ and $\pi - \arcsin c$ as the crossings. Note the second crossing is **not** $-\arcsin c$; the reflection is about $\pi/2$, not about $0$.

| Question | Answer | Decimal |
| :--- | :--- | :--- |
| $\sin x$ vs $y = 1/2$ on $[0, \pi]$ | $2\sqrt3 - 2 - \pi/6$ | $0.9405028395$ |
| $\sin x$ vs $y = 0$ on $[0, 2\pi]$ | $4$ | $4.0000000000$ |

The first row is **the same number as F1's second row**, because $\sin x$ on $[0,\pi]$ is $\cos x$ on $[-\pi/2, \pi/2]$ shifted.
The second row is the classic: $\int_0^{2\pi}\sin x \, dx = 0$ and $\int_0^{2\pi}\lvert \sin x\rvert dx = 4$, which is the cleanest possible demonstration of why the absolute value is not decoration.

### Family F3 - no crossing at all, so no split

**Trigger.** The line is above the curve's maximum or below its minimum on the whole interval.
**Tool.** One integral. Check the orientation once, at any interior point.

| Question | Answer | Decimal |
| :--- | :--- | :--- |
| $y = 2$ vs $\cos x$ on $[-\pi/2, \pi/2]$ | $2\pi - 2$ | $4.2831853072$ |
| $\cos x$ vs $y = -1$ on $[-\pi/2, \pi/2]$ | $2 + \pi$ | $5.1415926536$ |

**The cue that puts you in this family:** compare the constant with $\max$ and $\min$ of the curve on the interval *before* solving anything.
If it is outside that range, there is nothing to solve.

### Family F4 - two trig curves crossing each other

**Trigger.** Neither boundary is constant.
**Tool.** Same procedure. $\sin x = \cos x \Rightarrow \tan x = 1 \Rightarrow x = \pi/4 + k\pi$.

| Question | Answer | Decimal |
| :--- | :--- | :--- |
| $\sin x$ vs $\cos x$ on $[0, \pi/2]$ | $2\sqrt2 - 2$ | $0.8284271247$ |
| $\sin x$ vs $\cos x$ on $[0, \pi]$ | $2\sqrt2$ | $2.8284271247$ |

**The first row is numerically identical to the exam question**, from an entirely different geometry.
That is worth noticing: if you meet $2\sqrt2 - 2$ on a paper, it does not tell you which question you solved.

### Family F5 - the interval is not given, so the crossings are the limits

**Trigger.** "Find the area enclosed by" with no interval.
**Tool.** Consecutive crossings become $a$ and $b$, and there is then no interior split by construction.

| Question | Answer | Decimal |
| :--- | :--- | :--- |
| $\cos x$ vs $y = 1/\sqrt2$ between consecutive crossings | $\sqrt2 - \pi\sqrt2/4$ | $0.3034928278$ |
| $\sin x$ vs $y = 0$ over one arch $[0, \pi]$ | $2$ | $2.0000000000$ |
| $\cos x$ vs $y = 0$ over one arch $[-\pi/2, \pi/2]$ | $2$ | $2.0000000000$ |

**On a periodic curve this family is ambiguous unless you say which pair of consecutive crossings**, and by periodicity every choice gives the same answer.
That is the one place where the infinitude of intersections costs you nothing.

### Family F6 - many periods

**Trigger.** The interval is longer than one period, or is an exact multiple of one.
**Tool.** Compute one period, multiply, then handle the leftover.

| Question | Answer | Decimal |
| :--- | :--- | :--- |
| $\lvert \cos x - 1/\sqrt2 \rvert$ over one full period $[0, 2\pi]$ | $2\sqrt2 + \pi\sqrt2/2$ | $5.0498685938$ |
| the same over $[-\pi/2, 3\pi/2]$, also a full period | $2\sqrt2 + \pi\sqrt2/2$ | $5.0498685938$ |
| $\sin x$ vs $y = 0$ on $[0, 3\pi/2]$ | $3$ | $3.0000000000$ |

The first two rows are equal because both windows have length $2\pi$, verified rather than assumed.
**Any window of length $2\pi$ gives the same total, wherever it starts.**

### Family F7 - solve for the line height from a required area

**Trigger.** "Find $c$ such that the area between $\cos x$ and $y = c$ on $[-\pi/2, \pi/2]$ is $A$."
**Tool.** The master formula $A(c) = 4\sqrt{1-c^2} - 4c\arccos c + \pi c - 2$, then solve numerically.

| Target area | Solutions | Note |
| :--- | :--- | :--- |
| $A = 1$ | $c = 0.4488842358$ **and** $c = 0.9349464147$ | two answers |
| $A = 2\sqrt2 - 2$ | $c = 1/\sqrt2$ only | the minimum, so exactly one |
| $A < 2\sqrt2 - 2$ | none | below the minimum |

**This family is the reason section 6.4 is on this page.**
$A(c)$ is not monotone, so "find $c$" has two answers, one answer, or none, and which case you are in is decided by comparing the target with $2\sqrt2 - 2$.
A student who bisects blindly finds one root and stops.

### Family F8 - a tangency, where the curves touch without crossing

**Trigger.** The constant equals the curve's extreme value on the interval.
**Tool.** No split. The difference has a repeated root and never changes sign.

| Question | Answer | Decimal |
| :--- | :--- | :--- |
| $y = 1$ vs $\cos x$ on $[-\pi/2, \pi/2]$ (touch at $x = 0$) | $\pi - 2$ | $1.1415926536$ |
| $\sec^2 x$ vs $y = 2$ on $[-\pi/4, \pi/4]$ (touch at both endpoints) | $\pi - 2$ | $1.1415926536$ |

**A tangency is invisible to a numerical search and obvious to the algebra**, which is section 3.2's measured result.
It is also where a midpoint orientation probe can land exactly on $D = 0$ and flip the sign of the answer.

### Family F9 - horizontal strips are the shorter route

**Trigger.** The region's left and right boundaries are each a single curve, but the top and bottom are not.
**Tool.** Solve for $x$ in terms of $y$, integrate in $y$.

| Question | Answer | Decimal |
| :--- | :--- | :--- |
| Middle lobe as $\int_{1/\sqrt2}^{1} 2\arccos y \, dy$ | $\sqrt2 - \pi\sqrt2/4$ | $0.3034928278$ |

The general antiderivative to have: $\int \arccos y \, dy = y\arccos y - \sqrt{1-y^2}$.
It is a by-parts, and it is the only new integration technique the whole category needs.

## 9. The trap list

Ranked by how often it actually costs the mark.

1. **Not splitting at the crossings.** Gives $-0.2214$, and then "make it positive" gives $+0.2214$, which is confidently, quietly wrong. This is the whole question.
2. **Losing the $\pm$ in $x = \pm\arccos c$.** Half the crossings, half the region, or a region in the wrong place.
3. **Forgetting to double after using the symmetry.** Gives $\sqrt2 - 1 = 0.4142$, positive and plausible.
4. **Taking the wrong branch.** $3\pi/4$ solves $\cos x = -1/\sqrt2$. Check your branch against the sign of $c$.
5. **Taking the wrong period.** $7\pi/4$ is a real solution and is not in the interval.
6. **Deciding orientation at a crossing.** $D = 0$ there and the comparison decides nothing. Test strictly between.
7. **Deciding orientation once for the whole interval** when the curves cross. Three pieces, three decisions.
8. **Splitting somewhere that is not a crossing.** Splitting at $x = 0$ changes nothing; the sign does not turn there. An unnecessary split is harmless only when there is no sign change at it - here $x=0$ is inside a piece, so the two halves still carry the same wrong sign.
9. **Degree mode.** Gives $12.69$, which at least announces itself.
10. **Reading the crossings off a sketch.** A near-miss crossing costs 0.0005 percent, so you will never be told you were guessing.
11. **Assuming a missing $\pi$ means a dropped term.** On this specific $c$ the $\pi$ cancels for a reason.

## 11. The one-page decision tree

```
Area between two curves, one of them periodic?
|
+- Is an interval given?
|    NO  -> the consecutive crossings ARE the interval    [F5]
|    YES -> keep going
|
+- Solve f(x) = g(x).  Write the GENERAL solution first:
|        cos x = c  ->  x = +- arccos(c) + 2k*pi
|        sin x = c  ->  x = arcsin(c) + 2k*pi  and  pi - arcsin(c) + 2k*pi
|        tan x = c  ->  x = arctan(c) + k*pi
|   then INTERSECT that family with the given interval.
|   (Do not search a wider window - it finds real roots that are not in the region.)
|
+- How many crossings are STRICTLY INSIDE (a, b)?
|    0  -> ONE integral.  Orientation checked once.        [F3, F8]
|    1  -> TWO integrals, split there.
|    n  -> n+1 integrals.                                  [F1, F2, F4]
|
+- Is the region symmetric about a point or a line?
|    YES -> do half and DOUBLE.  Write the 2 down NOW.     [saves a piece]
|
+- On EACH piece: pick a point strictly between the knots,
|   where |f - g| is not small, and see which is larger.
|   Integrate (top - bottom).  Never test AT a knot.
|
+- Add the pieces.  All positive by construction.
|
+- CHECK: positive?  smaller than the bounding box?
|          middle lobe about a third?
+- PREVIEW the Moebius string before submitting.
```
