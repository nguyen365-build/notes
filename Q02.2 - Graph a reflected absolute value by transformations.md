# Q2.2 - Graph a reflected absolute value by transformations

**The question (MT2 Q4, 6 points).**
Indicate the transformations in the order they are applied to the basic graph of $\lvert x \rvert$ in the interval in order to obtain the graph of the function $f(x) = -3\lvert x - 2 \rvert$.
Apply the transformations to sketch the graph of $f$, no credit will be given if other method is used.

**The answer.**
Three transformations, applied to $y = \lvert x \rvert$ in this order:

$$\textbf{1. shift right } 2 \quad\longrightarrow\quad \textbf{2. stretch vertically by } 3 \quad\longrightarrow\quad \textbf{3. reflect in the } x\text{-axis}$$

$$f(x) = -3\lvert x-2 \rvert \qquad \text{vertex } (2,\,0), \quad \text{opens downward}, \quad \text{arms of slope } +3 \text{ then } -3$$

Five points to label: $(2,0)$, $(1,-3)$, $(3,-3)$, $(0,-6)$, $(4,-6)$.

**What to write / type:** the ordered list above, in words, plus a labeled graph.
If a box asks for the function, type `-3*abs(x-2)`; for the vertex, `(2,0)`; for the $y$-intercept, `-6`.
See section 7, because on this question the marks live in the *named order*, not in a number.

## 0. The 30-second version

If you only remember one thing, remember this chain.

```
f(x) = -3|x-2|                      parent: y = |x|,  a V with vertex (0,0)

  -> read INSIDE the bars:  (x-2)   SHIFT RIGHT 2         vertex (0,0) -> (2,0)
  -> read OUTSIDE, the 3:   x3      STRETCH VERTICALLY 3  arms get 3x steeper
  -> read OUTSIDE, the -:   x(-1)   REFLECT IN THE X-AXIS the V becomes a ^
  -> label                          (2,0) and (0,-6) and (4,-6)
```

Three lines of reading, three named transformations, one labeled sketch.
There is no algebra in this question at all.
The entire task is *reading four numbers off a formula and saying what each one does*, and the marks are for saying it in an order.

## 1. What this question is really testing

This is question 4 of Midterm 2 and it is worth 6 of about 94 points.
It looks like the easiest question on the paper, and it is the one most likely to be marked zero on a fully correct graph.

That is not a paradox.
Read the grading clause again: *"no credit will be given if other method is used."*
The examiner is not buying a graph.
The examiner is buying **evidence that you can decompose a formula into named, ordered operations**, and the graph is only the receipt.
A perfect V drawn by plotting points scores nothing, because plotting points is the other method.

| The reflex being tested | Where it comes back later in the course |
| :--- | :--- |
| Inside the function affects $x$, outside affects $y$ | The chain rule: $\frac{d}{dx}f(g(x))$ is exactly "inside then outside" |
| Reading $-3\lvert x-2\rvert$ as a composition of simple steps | Q8.x derivatives, where you must see $\sec(x^2-3x)$ as outer-of-inner |
| The corner at $x=2$ | Q5.x, "continuous but not differentiable at $a$" - the answer is a corner, and this is the function that makes one |
| Naming a step rather than computing it | Q3.2 and Q7, "no credit will be given for unjustified answers" - the same examiner, the same habit |
| Knowing the parent graphs cold | Q4.1 asymptotes ($1/x$), Q5.x sketching, every curve-sketching question |

There is a second, quieter reason this question matters.
Absolute value is the cheapest way to manufacture a corner, and a corner is the cheapest way to satisfy "continuous but not differentiable".
MT1 item 5 and MT2 item 5 both ask you to *sketch a function that is continuous but not differentiable at a point*.
If you own $-3\lvert x-2\rvert$, you own that question too, and you can write the answer down in four seconds.

### A note on the wording

The question as printed says "the basic graph of $\lvert x \rvert$ **in the interval** in order to obtain".
That is an incomplete sentence in the original paper.

Do not spend exam time on it.

If your version of the paper *does* name an interval, the only extra work is to push the two endpoints through the same chain and mark them as endpoints, which is Family 8 in section 8.

## 2. The five things you must have cold

None of this is derivable under time pressure.
All of it is recall.

### 2.1 The parent graph and its anchor points

$y = \lvert x \rvert$ is a V with its vertex at the origin, made of two straight rays of slope $-1$ and $+1$.

| $x$ | $-2$ | $-1$ | $0$ | $1$ | $2$ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| $\lvert x \rvert$ | $2$ | $1$ | $0$ | $1$ | $2$ |

Carry these five points and nothing else.
The vertex tells you where the graph *is*; the two pairs either side tell you how *steep* it is and confirm the symmetry.
One point is not enough, because a single point cannot show a stretch.

### 2.2 The master template

Every transformation question in this course, for every parent function, is this one expression:

$$y = a \cdot f\big(b(x-h)\big) + k$$

Four dials. That is the whole topic.

| Dial | Where it sits | What it does |
| :--- | :--- | :--- |
| $h$ | inside, subtracted from $x$ | horizontal shift, right if $h>0$ |
| $b$ | inside, multiplying $x$ | horizontal scale by $1/b$; also reflects in the $y$-axis if $b<0$ |
| $a$ | outside, multiplying $f$ | vertical scale by $\lvert a \rvert$; also reflects in the $x$-axis if $a<0$ |
| $k$ | outside, added to $f$ | vertical shift, up if $k>0$ |

**The structural fact worth more than the table.**
Two of the four dials lie to you and two tell the truth.
The inside dials ($h$ and $b$) do the opposite of what they look like: subtracting moves *right*, multiplying by a big number *compresses*.
The outside dials ($a$ and $k$) do exactly what they look like: multiplying by 3 stretches by 3, adding 4 moves up 4.

So you never need to remember four rules.
You need to remember one rule, *inside is backwards*, and then read the formula.

### 2.3 The canonical order

This is note-sheet block A6, and it is the order to write on the exam.

> 1. horizontal shift by $h$
> 2. horizontal scale by $1/b$, reflecting in the $y$-axis if $b<0$
> 3. vertical scale by $\lvert a \rvert$
> 4. reflect in the $x$-axis if $a<0$
> 5. vertical shift by $k$

Inside first, outside second.
Within each half, scale before shift on the way out, shift before scale on the way in.

### 2.4 The atoms, as point maps

This is the version that never lies to you, and it is what I used to verify this entire document.
A transformation is a rule that takes a point and returns a point.

| Transformation | Point map |
| :--- | :--- |
| shift right $h$ | $(x,\,y) \mapsto (x+h,\;y)$ |
| shift up $k$ | $(x,\,y) \mapsto (x,\;y+k)$ |
| vertical stretch by $a$ | $(x,\,y) \mapsto (x,\;a\,y)$ |
| reflect in the $x$-axis | $(x,\,y) \mapsto (x,\;-y)$ |
| horizontal scale for $f(bx)$ | $(x,\,y) \mapsto (x/b,\;y)$ |
| reflect in the $y$-axis | $(x,\,y) \mapsto (-x,\;y)$ |

If you are ever unsure whether a claimed order is right, take one anchor point, push it through, and check the result satisfies the target equation.
That is a five-second test and it settles every argument.

### 2.5 What $\lvert\;\rvert$ does to a number

$\lvert u \rvert$ is $u$ when $u \ge 0$ and $-u$ when $u < 0$.
So $\lvert x-2 \rvert$ is $x-2$ to the right of $2$ and $2-x$ to the left of $2$.
The switch happens where the inside is zero, and *the switch point is the vertex*.

That single sentence is the fastest vertex-finder there is: **set the inside of the bars to zero and solve.**

## 3. The universal procedure

> **Step 1. Name the parent.**
> Strip every number. What is left is $\lvert x \rvert$, $x^2$, $\sqrt{x}$, $1/x$, $x^3$, $\sin x$. Say it out loud and draw it small in the corner with its anchor points.
>
> **Step 2. Force the formula into the template.**
> Get it to look exactly like $a\,f(b(x-h))+k$. If the inside is not already factored, factor it. If a sign is hiding, expose it. This step is where the marks are lost, not the sketching.
>
> **Step 3. Read the four dials.** Write down $a$, $b$, $h$, $k$ as four numbers before you say anything about the graph.
>
> **Step 4. List the transformations in the canonical order**, skipping every dial that is at its default ($a=1$, $b=1$, $h=0$, $k=0$). Name each one in words, and say the direction and the amount.
>
> **Step 5. Push three anchor points through the list, one stage at a time.** Keep a table. The vertex plus one point on each arm is enough.
>
> **Step 6. Draw and label.** Axes with scales, the final curve, the vertex coordinates, and at least two more labeled points. Then state the vertex and the range in words.

## 4. Q2.2 worked five ways

The function is $f(x) = -3\lvert x-2 \rvert$.
Forced into the template: $a = -3$, $b = 1$, $h = 2$, $k = 0$.

Two dials are at their default, so only three transformations survive.

### Route A - the canonical order (use this one)

Read the template top to bottom and drop the defaults.

**Step 1. Shift right 2.**
$y = \lvert x \rvert \longrightarrow y = \lvert x-2 \rvert$.
The V keeps its shape and slides right. Vertex $(0,0) \to (2,0)$.

**Step 2. Stretch vertically by 3.**
$y = \lvert x-2 \rvert \longrightarrow y = 3\lvert x-2 \rvert$.
Every height triples. The vertex is at height $0$ so it does not move; the arms go from slope $\mp 1$ to slope $\mp 3$.

**Step 3. Reflect in the $x$-axis.**
$y = 3\lvert x-2 \rvert \longrightarrow y = -3\lvert x-2 \rvert$.
Every height changes sign. The V becomes a $\wedge$. The vertex stays at $(2,0)$ and is now the **maximum** instead of the minimum.

Now push the anchor points through, one stage at a time.
This table is the heart of the answer, and writing it out is what shows you used transformations.

| Point on $\lvert x \rvert$ | after shift right 2 | after $\times 3$ | after reflect | on $f$? |
| :--- | :--- | :--- | :--- | :--- |
| $(0,0)$ | $(2,0)$ | $(2,0)$ | $(2,0)$ | $f(2)=0$ |
| $(1,1)$ | $(3,1)$ | $(3,3)$ | $(3,-3)$ | $f(3)=-3$ |
| $(-1,1)$ | $(1,1)$ | $(1,3)$ | $(1,-3)$ | $f(1)=-3$ |
| $(2,2)$ | $(4,2)$ | $(4,6)$ | $(4,-6)$ | $f(4)=-6$ |
| $(-2,2)$ | $(0,2)$ | $(0,6)$ | $(0,-6)$ | $f(0)=-6$ |

Every row was confirmed against a direct evaluation of $f$.

The finished graph: a $\wedge$ with its peak at $(2,0)$, rising with slope $+3$ from the lower left, falling with slope $-3$ to the lower right, crossing the $y$-axis at $-6$, sitting entirely at or below the $x$-axis.

### Route B - fuse the two vertical steps

$a = -3$ is one number, so you can call it one transformation: "vertical stretch by 3 together with a reflection in the $x$-axis", or "scale the $y$-values by $-3$".

**Step 1.** shift right 2. **Step 2.** multiply every $y$ by $-3$.

Two steps instead of three, and it is correct: pushing the parent through `[shift right 2, scale y by -3]` lands exactly on $f$.

The risk is that the question says "indicate the transformations *in the order they are applied*", which invites a list.
A two-item list where a marker expects three named operations can read as a missing step.
Fusing is defensible mathematically and slightly cheaper in marks, so do not do it.

### Route C - reflect first, or stretch first, or shift last

You may have noticed that the three operations here seem to be independent, and they are.
I checked all $3! = 6$ orderings of {shift right 2, stretch by 3, reflect in $x$-axis} by pushing the parent graph through each one.

**All six reproduce $f$ exactly.**

| Order | Reproduces $f$? |
| :--- | :--- |
| shift, stretch, reflect | yes |
| shift, reflect, stretch | yes |
| stretch, shift, reflect | yes |
| stretch, reflect, shift | yes |
| reflect, shift, stretch | yes |
| reflect, stretch, shift | yes |

That is a real and slightly uncomfortable fact.
On *this* question the order genuinely does not matter, and yet the question is explicitly about order.

Here is why the question is still fair, and it is the single most useful idea in this document.
The order is free here only because two things happen to be true at once: there is no vertical shift ($k=0$), and there is no horizontal scaling ($b=1$).

- A vertical stretch and a vertical **shift** do not commute. Stretching then shifting is not shifting then stretching.
- A horizontal scale and a horizontal **shift** do not commute either.
- But a vertical operation and a horizontal operation always commute, because one only touches $y$ and the other only touches $x$.

In Q2.2 the only horizontal operation is a shift and the only vertical operations are a stretch and a reflection, which are both just multiplication of $y$.
Nothing in the list can collide with anything else.

So: **write the canonical order anyway.** It costs nothing, it is right on this question, and it is the only order that is still right when the examiner adds a $+k$ or a $2x$. Section 8 Family 2 shows exactly what breaks when they do.

### Route D - horizontal compression instead of vertical stretch

Here is a genuine curiosity of the absolute value parent.
Because $\lvert 3x \rvert = 3\lvert x \rvert$ identically, a **vertical stretch by 3 and a horizontal compression by $\tfrac13$ produce the same graph.**

I verified both halves of this:

- $3\lvert x \rvert$ and $\lvert 3x \rvert$ agree at every test point.
- The chain `[compress horizontally by 1/3, shift right 2, reflect in x-axis]` reproduces $f$ exactly.

So an answer of "compress horizontally by $\tfrac13$, shift right 2, reflect" draws the correct graph.

Two reasons not to write it.
First, it is fragile: the compression must be done **before** the shift. I checked the other order and `[shift right 2, compress by 1/3, reflect]` does **not** give $f$; it gives $y = -\lvert x-4 \rvert$ instead. It only survives after the shift if you take the compression about the line $x=2$ rather than about the $y$-axis, which I also verified, and which no marker wants to read.
Second, the formula literally shows a $3$ on the outside. Calling an outside number a horizontal transformation invites the marker to think you cannot tell inside from outside, which is precisely the skill being examined.

Correct, and still a bad answer. Write the vertical stretch.

### Route E - the piecewise form (do not submit this)

$f(x) = -3\lvert x-2 \rvert$ splits at the vertex:

$$f(x) = \begin{cases} 3x - 6, & x < 2 \\ -3x + 6, & x \ge 2 \end{cases}$$

I confirmed this agrees with $f$ at every test point, and that the left arm has slope $+3$ and the right arm slope $-3$.

This is genuinely useful, and it is genuinely worth zero marks here.
"No credit will be given if other method is used" rules out graphing two lines.

Use it for the three things it is actually good for:

1. **Checking your sketch in eight seconds.** Slope $+3$ on the left, $-3$ on the right, meeting at $(2,0)$.
2. **One-sided limits and the corner**, which is a different exam question.
3. **The derivative**: $f'(x) = 3$ for $x<2$, $f'(x)=-3$ for $x>2$, and $f'(2)$ does not exist. I verified all three numerically. That is the "continuous but not differentiable" answer, ready to go.

### Which route, and why

| Route | Steps | Correct? | Earns the marks? | Verdict |
| :--- | :--- | :--- | :--- | :--- |
| **A - canonical order** | 3 | yes | yes | **Use this one under pressure.** It is the order on the note sheet, it generalizes to every variation, and it names three operations for a 3-operation question. |
| B - fuse the $-3$ | 2 | yes | probably | Cheaper, but a 2-item list against a 3-operation formula can read as an omission. No upside. |
| C - some other order | 3 | yes, all 6 | risky | Right here purely by accident. Breaks the moment a $+k$ appears. Do not build the habit. |
| D - horizontal compression | 3 | yes | unlikely | Mathematically identical graph, but it renames an outside number as an inside one, which is the exact error the question hunts for. |
| E - piecewise | 2 lines | yes | **no** | Explicitly excluded by the grading clause. Keep it as your private check. |

## 5. The exam-ready write-up

Copy this shape. It is six lines and it earns every available mark.

> The basic function is $y = \lvert x \rvert$, a V with vertex at the origin.
> Writing $f(x) = -3\lvert x-2\rvert$ in the form $a\lvert x-h\rvert + k$ gives $a=-3$, $h=2$, $k=0$.
> The transformations, in the order they are applied, are:
>
> 1. **Shift right 2 units**: $y = \lvert x-2 \rvert$. The vertex moves from $(0,0)$ to $(2,0)$.
> 2. **Vertical stretch by a factor of 3**: $y = 3\lvert x-2 \rvert$. Each $y$-value is tripled, so the arms become three times steeper. The vertex is unchanged because its height is 0.
> 3. **Reflection in the $x$-axis**: $y = -3\lvert x-2 \rvert$. Each $y$-value changes sign, so the V opens downward.
>
> Tracking the points $(0,0)$, $(\pm1,1)$ and $(\pm2,2)$ through the three steps gives $(2,0)$, $(1,-3)$, $(3,-3)$, $(0,-6)$ and $(4,-6)$.
> The graph is a $\wedge$ with maximum at the vertex $(2,0)$, arms of slope $+3$ and $-3$, and $y$-intercept $-6$.
> The range is $y \le 0$.

Three things in that write-up are doing real work, and none of them is the graph.

- The line **"in the form $a\lvert x-h\rvert+k$ gives $a=-3, h=2, k=0$"** proves you decomposed rather than guessed.
- Each step shows the **intermediate equation**, so the marker can see the transformation being applied to a function, not to a picture.
- The sentence about the vertex not moving under the stretch pre-empts the most common follow-up doubt.

And do not skip the last two lines. Naming the vertex and the range in words costs four seconds and is often a mark of its own.

## 6. Verify before you commit

Four checks, about eight seconds total. Do all four every time.

**1. The vertex, from the inside.**
Set the inside of the bars to zero: $x-2=0$, so $x=2$. Then $f(2) = -3\lvert 0 \rvert = 0$. Vertex $(2,0)$.
If your sketch's corner is anywhere else, the sketch is wrong, not the algebra.

**2. Direction of opening, from the sign of $a$.**
$a = -3 < 0$, so it opens **downward** and the vertex is a maximum.
Positive opens up, negative opens down. There is no third case.

**3. One easy point, ideally the $y$-intercept.**
$f(0) = -3\lvert -2 \rvert = -3(2) = -6$.
Note the two sign traps live inside that single evaluation: the bars make $-2$ into $+2$, and *then* the $-3$ makes it negative. If you got $+6$ you applied the bars after the multiplication.

**4. The magnitude sanity check.**
Move 1 unit sideways from the vertex, drop 3. Move 2, drop 6.
If your graph drops 1 for 1, you forgot the stretch. If it rises, you forgot the reflection.

### Numbers worth memorising for this exact function

| Quantity | Value |
| :--- | :--- |
| Vertex | $(2,\,0)$, a maximum |
| $y$-intercept | $(0,\,-6)$ |
| $x$-intercept | $x=2$ only (the vertex touches the axis) |
| Range | $y \le 0$ |
| Domain | all real $x$ |
| Slope left of 2 / right of 2 | $+3$ / $-3$ |
| $f(1), f(3)$ | $-3$, $-3$ |
| $f(0), f(4)$ | $-6$, $-6$ |

| Do | Do not |
| :--- | :--- |

| Say "reflect **in the $x$-axis**" | Say "flip it" or "reflect" with no axis |
| Show the intermediate equation after each step | Jump from $\lvert x \rvert$ straight to the final picture |
| Label axes, vertex, and two more points | Draw an unlabeled V |
| Type `abs(x-2)` in any expression box | Write the absolute value with vertical bars in a typed box |
| Type explicit `*`: `-3*abs(x-2)` | Type `-3abs(x-2)` |
| Bracket the whole argument | Type `abs x-2`, which parses as $\lvert x \rvert - 2$ |
| Preview every box before moving on | Trust an unpreviewed box; an empty preview means broken syntax, not wrong maths |

**The single most expensive mistake on this question** is not a typo.
It is drawing a correct graph without naming the transformations.
The clause "no credit will be given if other method is used" means the named ordered list *is* the answer and the graph is supporting evidence.
Write the list first, then draw.

On the vertical bars specifically: in a typed answer box the function is `abs(x-2)`.
The vertical bar character is not an operator in either Moebius parser, so an answer typed as
`|x-2|` will not parse, and the preview box will come back empty.

**The most expensive typo**, if a box does ask for the function, is the missing bracket.
`abs(x)-2` and `abs(x-2)` are different functions: one has its vertex at $(0,-2)$, the other at $(2,0)$.

## 8. The variation catalog

This is the bulk of the document, and the point of it.
The families are organised by **the tool the variation forces**, not by how the formula looks.

Before the tables, the structural read, because these are not 60 separate facts.

**Every question in this topic is the same four numbers.** You read $a$, $b$, $h$, $k$ off the formula and the answer writes itself.
There are only three things that can vary: *which dials are non-default*, *which parent function sits underneath*, and *which direction you are being asked to go* (formula to graph, or graph to formula).
That is the whole space. The families below are just a systematic walk through it.

**Where the signs come from.** There are exactly two sign-flipping mechanisms, and they are on opposite sides of the function.
$a<0$ flips the graph vertically. $b<0$ flips it horizontally.
Every other sign in the problem is a *direction* ($h$, $k$), not a reflection.
If you can say which of those two mechanisms is producing a minus sign you see, you cannot get a reflection question wrong.

---

### Family 0 - one dial only

**Trigger.** Exactly one number in the formula differs from the parent.
**Tool.** Name the single atom. Nothing else.
**Why it exists.** As a 2-mark warm-up, and as the building block for everything else.

| Function | Transformation | Vertex | Notes |
| :--- | :--- | :--- | :--- |
| $\lvert x-5 \rvert$ | shift right 5 | $(5,0)$ | opens up |
| $\lvert x+3 \rvert$ | shift left 3 | $(-3,0)$ | inside is backwards |
| $4\lvert x \rvert$ | vertical stretch by 4 | $(0,0)$ | steeper V |
| $\tfrac13\lvert x \rvert$ | vertical compression by $\tfrac13$ | $(0,0)$ | flatter V |
| $-\lvert x \rvert$ | reflect in the $x$-axis | $(0,0)$ | opens down |
| $\lvert x \rvert - 7$ | shift down 7 | $(0,-7)$ | now has two $x$-intercepts, $\pm 7$ |

Read this table as one fact, not six: the dial you touch tells you the transformation, and the vertex only moves when you touch $h$ or $k$.

### Family 1 - reflection plus vertical stretch plus horizontal shift

**Trigger.** The form $a\lvert x-h \rvert$ with $a<0$ and $\lvert a \rvert \ne 1$. This is Q2.2 itself.
**Tool.** The canonical 3-step list. Order is mathematically free (verified) but write the canonical one.
**Worked shape.** Shift right $h$, stretch by $\lvert a \rvert$, reflect in the $x$-axis. Vertex $(h, 0)$, always on the $x$-axis, always the single $x$-intercept.

| Function | Ordered transformations | Vertex | $y$-int | Range |
| :--- | :--- | :--- | :--- | :--- |
| $-3\lvert x-2 \rvert$ | right 2, stretch 3, reflect | $(2,0)$ | $-6$ | $y \le 0$ |
| $-\lvert x+1 \rvert$ | left 1, reflect | $(-1,0)$ | $-1$ | $y \le 0$ |
| $2\lvert x-3 \rvert$ | right 3, stretch 2 | $(3,0)$ | $6$ | $y \ge 0$ |
| $-\tfrac12\lvert x-4 \rvert$ | right 4, compress $\tfrac12$, reflect | $(4,0)$ | $-2$ | $y \le 0$ |
| $5\lvert x+2 \rvert$ | left 2, stretch 5 | $(-2,0)$ | $10$ | $y \ge 0$ |

Structure, not five facts: the vertex is always $(h,0)$, the $y$-intercept is always $a\lvert h \rvert$, and the range is decided by the sign of $a$ alone.

### Family 2 - a vertical shift joins in, and now the order matters

**Trigger.** A constant added *outside* the bars: $a\lvert x-h\rvert + k$ with $k \ne 0$.
**Tool.** Vertical stretch **before** vertical shift, always. This is the first family where a wrong order draws a genuinely different graph.
**Why it matters.** This is the most likely way the examiner upgrades Q2.2, and it is the reason the question insists on order at all.

Take $g(x) = -3\lvert x-2 \rvert + 4$.

- Correct: shift right 2, stretch by 3, reflect, **then** shift up 4. Verified: reproduces $g$.
- Wrong: shift right 2, shift up 4, **then** stretch and reflect. Verified: does **not** reproduce $g$.
- What that wrong order actually draws is $-3\big(\lvert x-2 \rvert + 4\big)$, whose vertex is at $(2,-12)$ instead of $(2,4)$. I verified both vertices.

A 16-unit error from one transposition. That is what the grading clause is protecting against.

| Function | Ordered transformations | Vertex | $x$-intercepts |
| :--- | :--- | :--- | :--- |
| $-3\lvert x-2 \rvert + 4$ | right 2, stretch 3, reflect, up 4 | $(2,4)$ | $2 \pm \tfrac43$ |
| $-3(\lvert x-2 \rvert + 4)$ | right 2, up 4, stretch 3, reflect | $(2,-12)$ | none |
| $2\lvert x-3 \rvert - 5$ | right 3, stretch 2, down 5 | $(3,-5)$ | $3 \pm \tfrac52$ |
| $-4\lvert x-1 \rvert + 8$ | right 1, stretch 4, reflect, up 8 | $(1,8)$ | $-1$ and $3$ |
| $3 - 2\lvert x+4 \rvert$ | left 4, stretch 2, reflect, up 3 | $(-4,3)$ | $-4 \pm \tfrac32$ |

**How to get the $x$-intercepts every time.** Solve $a\lvert x-h\rvert + k = 0$, so $\lvert x-h \rvert = -k/a$, so $x = h \pm \lvert k/a \rvert$ when $-k/a > 0$, and none when $-k/a < 0$.
Two intercepts, one, or none, and the sign of $-k/a$ tells you which.

Note the last row: $3 - 2\lvert x+4\rvert$ is the same thing as $-2\lvert x+4 \rvert + 3$.
Written with the constant first it looks like a different species. Rearrange to the template before you read the dials.

### Family 3 - a coefficient inside the bars

**Trigger.** $x$ is multiplied by something inside: $\lvert 2x-6 \rvert$, $\lvert \tfrac{x}{2} - 1 \rvert$, $\lvert 3x+6 \rvert$.
**Tool.** Factor the inside first. $\lvert bx + c \rvert = \lvert b \rvert \cdot \lvert x + c/b \rvert$.
**The trap.** Reading the shift off the unfactored constant.

Take $\lvert 2x-6 \rvert$. I verified $\lvert 2x-6 \rvert = 2\lvert x-3 \rvert$ identically.

Here is the precise version of the "shift before stretch" rule, and it is subtler than the note-sheet one-liner.
There are **two consistent readings, and both are correct**:

- **Factored reading:** compress horizontally by $\tfrac12$ first, *then* shift right **3**.
- **Unfactored reading:** shift right **6** first, *then* compress horizontally by $\tfrac12$.

I verified both chains reproduce $\lvert 2x-6 \rvert$, and confirmed they are literally the same map, since $\tfrac{x+6}{2} = \tfrac{x}{2}+3$.

What is fatal is **mixing the two readings**. I verified both of these fail:

- shift right 3, then compress by $\tfrac12$ → wrong (vertex lands at $1.5$)
- compress by $\tfrac12$, then shift right 6 → wrong (vertex lands at $6$)

So the rule to carry is not "shift first" or "scale first". It is: **the shift amount must match the reading you chose.** Factor and use $h$, or do not factor and use $c$, but never take $h$ from one and the position from the other.

The safe habit: **always factor.** Then $h$ is unambiguous.

| Function | Factored | Ordered transformations | Vertex |
| :--- | :--- | :--- | :--- |
| $\lvert 2x-6 \rvert$ | $2\lvert x-3 \rvert$ | compress $\tfrac12$, right 3 | $(3,0)$ |
| $\lvert 3x+6 \rvert$ | $3\lvert x+2 \rvert$ | compress $\tfrac13$, left 2 | $(-2,0)$ |
| $-\lvert 2x-4 \rvert$ | $-2\lvert x-2 \rvert$ | compress $\tfrac12$, right 2, reflect | $(2,0)$ |
| $\lvert \tfrac{x}{2}-1 \rvert$ | $\tfrac12\lvert x-2 \rvert$ | stretch horiz. by 2, right 2 | $(2,0)$ |
| $\lvert -x+5 \rvert$ | $\lvert x-5 \rvert$ | right 5 (see Family 4) | $(5,0)$ |

**A special mercy for $\lvert x \rvert$.** Because $\lvert bx \rvert = \lvert b\rvert\lvert x\rvert$, a horizontal compression by $\tfrac1b$ and a vertical stretch by $b$ give the *same graph* for this parent. I verified this. So $\lvert 2x-6 \rvert$ can also be described as "shift right 3, then stretch vertically by 2", and the picture is identical.

Two consequences. Under time pressure, you may convert any inside coefficient into an outside one and never touch horizontal scaling again. But do not do it for $x^2$, $\sqrt x$, $\sin x$ or $1/x$, where it is false: $\sqrt{2x} = \sqrt2\sqrt x$ works, $(2x)^2 = 4x^2$ works, but $\sin(2x) \ne 2\sin x$, and the marker will not accept the substitution as a general habit.

### Family 4 - the reflection that is invisible

**Trigger.** A minus sign on $x$ *inside* the bars: $\lvert -x \rvert$, $\lvert 2-x \rvert$, $\lvert -x+5 \rvert$.
**Tool.** Recognise that the parent is even, so the $y$-axis reflection changes nothing, then rewrite in standard form.

Verified identities:

- $\lvert -x \rvert = \lvert x \rvert$ for every $x$. Reflecting the parent V in the $y$-axis is a no-op.
- $\lvert 2-x \rvert = \lvert x-2 \rvert$ for every $x$.

So $\lvert 2-x \rvert$ is not "reflect in the $y$-axis then shift"; it is just "shift right 2".
I verified that inserting a $y$-axis reflection at the start of the Q2.2 chain leaves the answer unchanged.

**The trap.** The reflection is invisible only because the parent is symmetric, and only when it acts on the parent.
Once the graph has been shifted, a $y$-axis reflection is very much visible. I verified that `[shift right 2, stretch 3, reflect in the y-axis]` does **not** give $f$, because it produces $3\lvert x+4 \rvert$.

| Function | Rewrite as | Transformations | Vertex |
| :--- | :--- | :--- | :--- |
| $\lvert -x \rvert$ | $\lvert x \rvert$ | none | $(0,0)$ |
| $\lvert 2-x \rvert$ | $\lvert x-2 \rvert$ | right 2 | $(2,0)$ |
| $\lvert 2-x \rvert - 3$ | $\lvert x-2 \rvert - 3$ | right 2, down 3 | $(2,-3)$ |
| $-\lvert 5-x \rvert$ | $-\lvert x-5 \rvert$ | right 5, reflect in $x$-axis | $(5,0)$ |
| $\lvert -2x+8 \rvert$ | $2\lvert x-4 \rvert$ | compress $\tfrac12$, right 4 | $(4,0)$ |

**Always rewrite so the coefficient of $x$ inside the bars is positive.** It is free and it removes an entire class of error.

### Family 5 - the same grammar, a different parent

**Trigger.** The same $a\,f(b(x-h))+k$ shape, but the parent is not $\lvert x \rvert$. Q2.1 on Midterm 1 is exactly this with $x^2$.
**Tool.** Identical procedure. The only thing that changes is the parent's anchor points and what "vertex" means.

I verified the chain `[shift right 2, scale y by -3]` against each of these targets.

| Parent | Anchor points | $-3\,\text{parent}(x-2)$ | Key feature after |
| :--- | :--- | :--- | :--- |
| $\lvert x \rvert$ | $(0,0), (\pm1,1), (\pm2,2)$ | $-3\lvert x-2 \rvert$ | vertex $(2,0)$, corner, opens down |
| $x^2$ | $(0,0), (\pm1,1), (\pm2,4)$ | $-3(x-2)^2$ | vertex $(2,0)$, smooth, $f(0)=-12$ |
| $x^3$ | $(0,0), (\pm1,\pm1), (\pm2,\pm8)$ | $-3(x-2)^3$ | inflection at $(2,0)$, odd, so $y$-axis reflection is **not** a no-op |
| $\sqrt{x}$ | $(0,0),(1,1),(4,2),(9,3)$ | $-3\sqrt{x-2}$ | starts at $(2,0)$, **domain becomes $x \ge 2$**, $f(6)=-6$, $f(11)=-9$ |
| $1/x$ | $(\pm1,\pm1),(\pm2,\pm\tfrac12)$ | $-3/(x-2)$ | vertical asymptote moves to $x=2$, $f(3)=-3$, $f(5)=-1$ |
| $\sin x$ | $(0,0),(\tfrac\pi2,1),(\pi,0)$ | $-3\sin(x-2)$ | amplitude 3, phase shift 2, $f(2+\tfrac\pi2)=-3$ |

Read as structure: **the transformation list is character-for-character identical across all six rows.** Only the parent's shape and the meaning of the special point change.

Two rows deserve extra attention.
$\sqrt{x-2}$ is the one where the **domain** moves with the graph, so a shift changes the answer to a domain question.
$1/(x-2)$ is the one where an **asymptote** moves, which is the bridge to Q4.1.

### Family 6 - absolute value as a transformation, not as the parent

**Trigger.** Bars wrapped around something that is not bare $x$: $\lvert x^2-4 \rvert$, or bars around the input: $f(\lvert x \rvert)$.
**Tool.** A different pair of operations entirely. This is the family most likely to catch you out, because it looks like the same topic and is not.

There are two distinct operations and they are not interchangeable.

**Outer bars, $y = \lvert f(x) \rvert$: fold up.**
Keep everything at or above the $x$-axis. Reflect everything below the axis upward.
Verified on $\lvert x^2-4 \rvert$: never negative, $y$-intercept $+4$, corners at $x=\pm2$ where it touches zero.

**Inner bars, $y = f(\lvert x \rvert)$: mirror the right half.**
Discard the left half of the graph. Replace it with a mirror image of the right half. The result is always even.
Verified on $\lvert x \rvert^2 - 4$: it is even, and $y$-intercept $-4$, not $+4$.

$\lvert x^2-4 \rvert$ and $\lvert x \rvert^2 - 4$ are different functions. I verified they disagree.

| Function | Which operation | What it does | Verified landmark |
| :--- | :--- | :--- | :--- |
| $\lvert x^2-4 \rvert$ | outer, fold up | the dip between $\pm2$ flips above the axis | $f(0)=+4$, corners at $\pm 2$, never negative |
| $\lvert x \rvert^2 - 4$ | inner, mirror right half | already even, so nothing visibly changes | $f(0)=-4$, even |
| $\big\lvert -3\lvert x-2 \rvert \big\rvert$ | outer, on Q2.2 | folds the whole $\wedge$ back up to $3\lvert x-2\rvert$ | equals $3\lvert x-2 \rvert$ |
| $-3\big\lvert \lvert x \rvert - 2 \big\rvert$ | inner, on Q2.2 | a W upside down: two peaks | even; peaks $(\pm2,0)$; $f(0)=-6$ is now a local **min**; $f(5)=-9$ |
| $\lvert x^2-9 \rvert$ | outer, fold up | $y$-int 9, corners at $\pm 3$ | $f(0)=9$, $f(\pm3)=0$, never negative |

That fourth row is worth drawing once by hand. Applying $f(\lvert x \rvert)$ to $-3\lvert x-2 \rvert$ turns one $\wedge$ into two, joined at $(0,-6)$, and the point that was a maximum-adjacent value becomes a local minimum. It is the most interesting graph in this whole topic and it is a legitimate exam variation.

### Family 7 - the reverse direction, graph to formula

**Trigger.** A graph or a description is given and you must produce the equation, or name the transformations that were applied.
**Tool.** The vertex gives $h$ and $k$ immediately. One more point gives $a$.

**The procedure.**

1. Read the vertex: that is $(h, k)$.
2. Read the opening direction: down means $a<0$.
3. Take any other point $(x_1,y_1)$ on the graph and solve $y_1 = a\lvert x_1-h\rvert + k$, so $a = \dfrac{y_1-k}{\lvert x_1-h \rvert}$.
4. Sanity check with the mirror point.

Worked: vertex $(5,-2)$, passes through $(7,-8)$.
$a = \dfrac{-8-(-2)}{\lvert 7-5 \rvert} = \dfrac{-6}{2} = -3$, so $y = -3\lvert x-5 \rvert - 2$.
Verified: the formula gives $-2$ at $x=5$, $-8$ at $x=7$, and $-8$ at $x=3$ by symmetry, and the chain `[right 5, stretch 3, reflect, down 2]` reproduces it.

| Given | $a$ | Equation | Transformations |
| :--- | :--- | :--- | :--- |
| vertex $(5,-2)$, through $(7,-8)$ | $-3$ | $-3\lvert x-5 \rvert - 2$ | right 5, stretch 3, reflect, down 2 |
| vertex $(-3,5)$, through $(-1,1)$ | $-2$ | $-2\lvert x+3 \rvert + 5$ | left 3, stretch 2, reflect, up 5 |
| vertex $(0,4)$, through $(2,3)$ | $-\tfrac12$ | $-\tfrac12\lvert x \rvert + 4$ | compress $\tfrac12$, reflect, up 4 |
| vertex $(1,0)$, through $(2,-1)$ | $-1$ | $-\lvert x-1 \rvert$ | right 1, reflect |

**The one trap here.** Use $\lvert x_1 - h\rvert$ in the denominator, not $x_1-h$. If you pick a point to the *left* of the vertex and forget the bars, you get the sign of $a$ backwards.

### Family 8 - a named interval

**Trigger.** "on $[-1,5]$", "for $-1 \le x \le 5$", or the fragment in Q2.2's own wording.
**Tool.** The same chain, plus push the two endpoints through it, plus read off the extremes.

For $f(x) = -3\lvert x-2 \rvert$ on $[-1,5]$, verified:

| Item | Value |
| :--- | :--- |
| Left endpoint | $(-1,\,-9)$, drawn as a filled dot |
| Right endpoint | $(5,\,-9)$, filled dot |
| Maximum on the interval | $0$, at $x=2$ (the vertex) |
| Minimum on the interval | $-9$, at both endpoints |
| Range on the interval | $[-9,\,0]$ |

Two habits. Mark endpoints with filled dots for a closed interval and open circles for an open one.
And note that the maximum is at an interior point while the minimum is at the endpoints, which is exactly the Extreme Value Theorem shape you will need on the final. A corner is a critical point even though the derivative does not exist there.

### Family 9 - what the graph is then used for

**Trigger.** The transformation is not the question; it is step one of a limit, continuity, or differentiability question.
**Tool.** Split at the corner, then answer the real question.

For $f(x) = -3\lvert x-2 \rvert$, all verified:

| Question | Answer | Why |
| :--- | :--- | :--- |
| $f$ as a piecewise function | $3x-6$ for $x<2$; $-3x+6$ for $x \ge 2$ | the bars switch where the inside is 0 |
| $\lim_{x\to2^-}f(x)$ | $0$ | left arm reaches the vertex |
| $\lim_{x\to2^+}f(x)$ | $0$ | right arm reaches the vertex |
| $\lim_{x\to2}f(x)$ | $0$ | the one-sided limits agree |
| Is $f$ continuous at 2? | Yes | limit equals $f(2)=0$ |
| $f'(1)$, $f'(3)$ | $+3$, $-3$ | slopes of the two arms |
| $f'(2)$ | does not exist | one-sided slopes are $+3$ and $-3$, and they disagree |
| Is $f$ differentiable at 2? | No, a corner | continuous but not differentiable |

That last pair is the payload.
**MT1 item 5 and MT2 item 5 both ask you to sketch a function that is continuous but not differentiable at a point.** The answer is a corner, and the fastest corner in existence is $\lvert x - a \rvert$.
So if MT2 asks for a function continuous but not differentiable at $x=0$, write $y=\lvert x \rvert$, or $y=-3\lvert x \rvert$ if you want to look like you meant it, and move on.

The related distinction, which the note sheet also carries: a **corner** has two different finite one-sided slopes, a **cusp** has one-sided slopes going to $+\infty$ and $-\infty$, and a **vertical tangent** has both going to the same infinity. All three are non-differentiable; only the first two are cheap to draw.

## 9. The trap list

Ranked by how often each one actually costs marks on this specific question.

**1. Drawing a correct graph without naming the transformations.**
This is not a maths error and it is the number one way to score zero here.
The clause "no credit will be given if other method is used" makes the ordered list the answer.
Write the list before you draw.

**2. Shifting the wrong way.**
$\lvert x-2 \rvert$ moves right, not left.
The fix is mechanical: set the inside to zero and solve. $x-2=0 \Rightarrow x=2$. The vertex is at $+2$, so the shift was rightward.

**3. Reflecting in the wrong axis.**
$a<0$ is an $x$-axis reflection, which flips the graph upside down.
A $y$-axis reflection comes from $b<0$ and is invisible on this parent anyway. If you write "reflect in the $y$-axis" for the $-3$, you have shown the examiner you cannot tell inside from outside, which is the whole point of the question.

**4. Applying the bars after the multiplication when checking a point.**
$f(0) = -3\lvert 0-2 \rvert = -3(2) = -6$.
Not $-3(-2) = +6$. The bars run first.

**5. Reading the shift off an unfactored inside coefficient.**
$\lvert 2x-6 \rvert$ has its vertex at $3$, not $6$. Factor first, every time.

**6. Getting the order wrong once a vertical shift is present.**
$-3\lvert x-2\rvert + 4$ has its vertex at $(2,4)$; doing the $+4$ before the $\times(-3)$ draws a vertex at $(2,-12)$.
Stretch before shift, always, on the vertical side.

**7. Forgetting the stretch entirely.**
The commonest sketch error. Check with the magnitude test: 1 across from the vertex should be 3 down, not 1 down.

**8. Leaving the graph unlabeled.**
Axes with scales, the vertex with coordinates, and two more labeled points. Unlabeled graphs bleed marks even when the shape is perfect.

**9. Mistaking $\lvert f(x) \rvert$ for $f(\lvert x \rvert)$.**
Outer bars fold the graph up; inner bars mirror the right half onto the left. Family 6.

**10. Treating the missing interval in the question wording as a task.**
It is a typo in the paper. Graph on $\mathbb{R}$, label properly, move on.

### How to score yourself

Mark **sign** and **magnitude** separately, because they are different diseases with different cures.

- **Sign errors** (shifted the wrong way, reflected the wrong axis, opened the wrong direction) mean you have not internalised inside-versus-outside. Cure: re-read section 2.2 and redo Families 0, 1 and 4. Do not do more drills yet.
- **Magnitude errors** (forgot a stretch, used the unfactored shift, wrong intercept) mean the reading is fine and the arithmetic is rushed. Cure: the four checks in section 6, on every single drill.
- **Order errors** only show up in Family 2 and Family 3. If those are your only misses, you are in good shape; just write the canonical order mechanically.
- **Naming errors** (correct graph, no list) are the most dangerous because they feel like success. Cure: on every drill, write the numbered list *before* touching the graph.

## 11. The one-page decision tree

```
Given a formula to graph by transformations
|
+-- 1. STRIP the numbers. What parent is left?
|      |x| / x^2 / x^3 / sqrt(x) / 1/x / sin x
|      Draw it small with its anchor points.
|
+-- 2. Are the bars around bare x, or around something else?
|      |  around bare x (or the parent's own variable)  -> go to 3
|      |  around a whole function, y = |f(x)|           -> FOLD UP.  Family 6. done
|      +- around |x| as the input, y = f(|x|)           -> MIRROR RIGHT HALF. Family 6. done
|
+-- 3. Is x multiplied by anything INSIDE?
|      |  no  -> b = 1, skip horizontal scaling
|      +- yes -> FACTOR IT OUT first:  |bx+c| = |b| * |x + c/b|
|                then either fold |b| into the outside coefficient
|                (legal for |x| only), or keep it and use h = c/b
|
+-- 4. Is the coefficient of x inside NEGATIVE?
|      -> rewrite so it is positive.  |2-x| = |x-2|.  For |x| this is free.
|         (for x^3, sqrt, 1/x, sin it is a real y-axis reflection: keep it)
|
+-- 5. READ THE FOUR DIALS off  a*f(b(x-h)) + k
|      a = ?   b = ?   h = ?   k = ?      <- write these down as numbers
|
+-- 6. LIST, in this order, skipping every default:
|      1  shift right h            (left if h<0)
|      2  horizontal scale 1/b     (+ reflect in y-axis if b<0)
|      3  vertical scale |a|
|      4  reflect in x-axis        (only if a<0)
|      5  shift up k               (down if k<0)
|
+-- 7. PUSH 3 POINTS through the list, one stage per column.
|      vertex + one point on each side.  Keep the table.
|
+-- 8. DRAW: axes with scales, curve, vertex labeled, 2 more points labeled.
|      State the vertex and the range in words.
|
+-- 9. CHECK (8 seconds):
|      inside = 0 gives the vertex x
|      sign of a gives the opening direction
|      f(0) gives the y-intercept
|      1 across from the vertex = |a| down/up
|
+-- 10. PREVIEW any typed box.  abs(...) not |...|,  explicit *,  bracket the argument.
```
