Graph a shifted parabola by transformations

Sketch $g(x)=3(x+4)^2$ from a basic function. The whole question is one point map, and the marks are for the procedure, not the picture.

The grading clause, verbatim

“Give a labeled graph of the function $g(x)=3(x+4)^2$ by starting with the graph of a basic function, and then applying the appropriate transformations. Explain the procedure you are using. No credit will be given if any other method is used.”

In plain words: if you multiply the brackets out to $3x^2+24x+48$ and find the vertex with $x=-b/(2a)$, you will draw exactly the right parabola and score zero. That is not a trick. The question exists to force one specific skill, so the skill is what is being marked.

The answer

Start from the parent $y=x^2$. Shift it left 4, then stretch it vertically by 3.

Result: an upward parabola, vertex $(-4,0)$, axis of symmetry $x=-4$, through $(-3,3)$, $(-5,3)$, $(-2,12)$, $(-6,12)$, with $y$-intercept $48$.

Möbius  equation 3*(x+4)^2   vertex (-4,0)   and $h$ is -4, not 4.

Section 00

The 30-second version

If you remember one thing, remember this chain. It has to run from memory, with no lookup.

g(x) = 3(x+4)^2

  -> parent is y = x^2                 vertex (0,0), points (+/-1, 1), (+/-2, 4)
  -> (x+4) is x - (-4), so h = -4      shift LEFT 4:  vertex (-4, 0)
  -> the 3 sits OUTSIDE, so it hits y  stretch x3:    (-3,1) -> (-3,3)
  -> label vertex + 2 symmetric pairs  done

Everything below is that chain, justified and then generalised.

2.2  The canonical template

Every transformation question in this course fits one form. Get the expression into it and the question is over.

$$y = a\,f\big(b(x-h)\big) + k$$

ParamWhere it sitsWhat it doesDirection
$a$multiplies the outputvertical scale by $|a|$; reflect in $x$-axis if $a<0$as written
$k$added to the outputvertical shift up $k$as written
$b$multiplies the inputhorizontal scale by $1/|b|$; reflect in $y$-axis if $b<0$reciprocal

Why the horizontal shift looks backwards

Take $y=f(x-3)$ and ask what happens at $x=5$: you get $f(2)$. So the height the parent had at 2 now shows up at 5. Every height moved right 3, even though the expression says minus 3. It is not a convention to memorise, it is a consequence: to see the parent's value later, you have to ask for an earlier input.

For our question, $g(x)=3(x+4)^2$ gives $a=3$,   $b=1$,   $h=-4$ (because $x+4=x-(-4)$),   $k=0$.

2.3  The master point map

This is the single most useful line on this page. For $y=a\,f\big(b(x-h)\big)+k$, every parent point moves like this:

parent point
$(x_0,\;y_0)$
→
image point
$\left(\dfrac{x_0}{b}+h,\;\; a\,y_0+k\right)$

The $x$ is divided by $b$ then shifted by $h$; the $y$ is multiplied by $a$ then shifted by $k$. The reciprocal and the sign flip are already baked in, which is exactly why using the map beats reasoning verbally about “backwards”.

Section 03

The universal procedure

  1. Name the parent. Strip every constant until only the bare function of $x$ is left. Say its name and write its anchor points.
  2. Factor the input. If a coefficient multiplies $x$ and a constant sits inside, factor it out so the input reads $b(x-h)$. This is where most marks are lost, and it is skipped precisely when it matters.
  3. Read off $a$, $b$, $h$, $k$. Four numbers. Write them down explicitly.
  4. Build the point map $(x,y)\mapsto\left(\frac{x}{b}+h,\;ay+k\right)$.
  5. Push 3 to 5 anchors through it. For a parabola: the vertex and two symmetric pairs.
  6. State the transformations as an ordered list. This is what the “explain the procedure” marks pay for.
  7. Sketch and label the vertex, your computed pairs, and any intercepts on your scale.
  8. Check with Section 06, then type it with Section 07.
The order rule, in one sentence

On each side independently, do the multiplication before the addition. Vertically: scale and reflect, then shift. Horizontally: scale and reflect, then shift by $h$ with the input already factored. Across the two sides, order never matters at all (proved in Family 7).

The classification table to run at step 3

What you seeWhich parameterWhat it forces

a constant inside, no coefficient on $x$$h$horizontal shift, opposite sign
a coefficient on $x$ inside, nothing added$b$horizontal scale by $1/|b|$; reflect if negative
a coefficient on $x$ and a constant, inside$b$ and $h$factor first, then shift by $c/b$, never by $c$
Section 04

Q2.1 worked four ways

Route A  ·  shift first, then stretch  use this one

Same axes on all three panels, so the two transformations are visible as motion. The dashed grey curve is the previous stage.

Stage 1, horizontal shift. Replace $x$ by $x+4$. Since $x+4=x-(-4)$ we have $h=-4$, so the graph moves left 4. Every point keeps its height and loses 4 from its $x$.

parent$(-2,4)$$(-1,1)$$(0,0)$$(1,1)$$(2,4)$
after left 4$(-6,4)$$(-5,1)$$(-4,0)$$(-3,1)$$(-2,4)$

Stage 2, vertical stretch. Multiply the output by 3. Every point keeps its $x$ and triples its height.

after left 4$(-6,4)$$(-5,1)$$(-4,0)$$(-3,1)$$(-2,4)$
after $\times 3$$(-6,12)$$(-5,3)$$(-4,0)$$(-3,3)$$(-2,12)$
Why the vertex does not move in stage 2

Its height is $0$, and $3\times 0=0$. A vertical stretch fixes every point on the $x$-axis and moves everything else. Had the question been $3(x+4)^2+1$, the vertex would have moved, which is the whole reason order matters once a $+k$ appears.

The labeled answer

Route B  ·  stretch first, then shift

$x^2 \to 3x^2 \to 3(x+4)^2$. This gives exactly the same function, verified to agree everywhere on $[-12,4]$, because a vertical operation and a horizontal one never interfere. It is still the worse habit: it survives here only by luck, and the same instinct produces a wrong answer the moment a vertical shift appears.

Route C  ·  expand or use the vertex formula  scores zero

$3(x+4)^2=3x^2+24x+48$, then $x=-\frac{24}{6}=-4$, then $y=0$. Both steps verified correct. Mathematically flawless, and worth no marks, because the question forbids it in writing. It is on this page only so you recognise it as the trap it is: it is the route most students find faster, and it is the one being explicitly excluded.

Route D  ·  the two-point fit

If you already believe the vertex is $(-4,0)$, get $a$ from one more point: $a(-3+4)^2=3$ gives $a=3$, and $a(-2+4)^2=12$ also gives $a=3$. Both verified. This is not a solution method here, it is the check in Section 06 and the tool for Family 8.

Section 05

The exam-ready write-up

If the paper asks for method, these are the sentences that earn the marks. Copy the shape, not just the numbers.

  1. The basic function is $y=x^2$, the parabola with vertex at the origin through $(\pm1,1)$ and $(\pm2,4)$.
  2. Writing $g(x)=3\big(x-(-4)\big)^2$ puts it in the form $a\,f(x-h)+k$ with $a=3$, $h=-4$, $k=0$.
  3. First transformation: replacing $x$ by $x+4$ translates the graph 4 units left, moving the vertex from $(0,0)$ to $(-4,0)$ and $(\pm1,1)$ to $(-3,1)$ and $(-5,1)$.
  4. Second transformation: multiplying by 3 stretches vertically by a factor of 3, fixing $(-4,0)$ because its height is zero, and sending $(-3,1)$ and $(-5,1)$ to $(-3,3)$ and $(-5,3)$.
  5. The result is an upward parabola, vertex $(-4,0)$, axis $x=-4$, narrower than $y=x^2$ by a factor of 3, with $g(0)=48$.

Five things markers look for that students routinely skip, each of them free:

  • Naming the basic function, not just drawing it.
  • Writing $g(x)=3(x-(-4))^2$, which is what makes “left” defensible instead of asserted.
  • Saying the transformations are applied in that order, since a procedure was requested.
  • Labeling real coordinates, because “labeled graph” is in the question text.
  • Saying the stretch fixes the vertex, which shows you know why rather than that you noticed.

Do not write “shift 4” without a direction, and do not write “$h=4$”. Both lose the mark they were meant to earn.

Section 06

Verify before you commit

Eight seconds, and it catches nearly every error available on this question.

The five-second core check

Substitute your vertex back. You claim $(-4,0)$, so $g(-4)$ must be 0: $3(-4+4)^2=0$. That is the entire check for a shift, and it works because the vertex is the one point whose coordinates you asserted rather than computed.

InvariantFor Q2.1What a failure means
Direction$a=3>0$, opens upyou dropped or invented a minus sign
Widthone unit out the height is $|a|=3$; two units out, $4|a|=12$labels read $(-3,1)$ and $(-2,4)$: you forgot to stretch
$y$-intercept$g(0)=3(4)^2=48$a sketch crossing near the origin means the shift went the wrong way
Symmetry$g(-4+t)=g(-4-t)$, verified at $t=0.5,1,2,3.7,10$two labeled points at one height not equidistant from the axis
The two-second left-versus-right test

Ask which $x$ makes the inside zero. For $(x+4)^2$ that is $x=-4$, which is to the left of the origin, so the shift is left. This never fails and it needs no rule.

The numbers worth memorising. The parent heights $1,4,9$ at 1, 2 and 3 units from the vertex become $a,4a,9a$. For $a=3$ that is $3,\,12,\,27$. If a labeled height on your sketch is not 3, 12 or 27, you have either mislabeled or misread $a$.

The single most expensive typo

Entering 4 for $h$. The expression shows $+4$ and the shift is 4 units, so 4 feels right twice over. But the template is $a(x-h)^2+k$ and $x+4=x-(-4)$, so $h=-4$. The amount is 4 and the parameter is $-4$; the box is asking for one specific one of those. Read the field label before you type.

Two rules that are never wrong, so always use them: type the explicit * for every multiplication (valid in both parsers, so it can never cost you anything, while implicit multiplication fails silently in one of them), and bracket every function argument and every denominator. Then click preview: an empty preview modal means broken syntax, not wrong mathematics.

On a multiple-choice version, discriminate in this order

1. Direction (up or down) eliminates half the options from the sign of $a$ alone. 2. Vertex, read off the inside-zero, $x=-4$ here. 3. Width, check the height one unit from the vertex against $|a|$. Distractor graphs in this family are built by flipping exactly one of those three, so checking all three in that order is both necessary and sufficient.

Why order matters here and only here

With the input written as $b(x-h)$ you must scale then shift: that gives $f\big(b(x-h)\big)$. Shifting first gives $f(bx-h)$, which is a shift of $h/b$. Both orders work if you match the amount to the form, and mixing them is the error.

The trap disguised as good news

Both transformation questions on the past papers are order-insensitive. Q2.1's two orders were verified identical, and for Q2.2 all six orderings of {shift right 2, stretch 3, reflect in $x$} were verified to reproduce $f$ exactly. Neither has a vertical shift, so nothing can go wrong.

Which means you can practise both past questions with sloppy order, score full marks twice, and conclude order does not matter. Add a $+k$ and it does: $3(x+4)^2+6$ and $3\big((x+4)^2+6\big)$ are verified different functions, 12 apart everywhere.

From a graph: read the vertex for $h$ and $k$, then fit $a$ from any one other labeled point. Vertex $(2,-3)$ through $(3,-1)$ gives $a(1)^2-3=-1$, so $a=2$ and $y=2(x-2)^2-3$, verified through both $(3,-1)$ and $(1,-1)$. The same fit on Q2.1's vertex $(-4,0)$ and point $(-3,3)$ recovers $a=3$.

Section 09

The trap list

Ranked by how often each one actually costs marks on this question.

  1. Using the vertex formula or expanding. The question says no credit. The only trap here that scores zero with completely correct mathematics, which is why it is first.
  2. Getting the shift direction backwards. $(x+4)^2$ shifts left. Test it by asking which $x$ makes the inside zero.
  3. Not factoring a coefficient out of the input. $(2x-6)^2$ shifts right 3, not 6. The biggest silent error in the topic. F5
  4. Entering $h=4$ instead of $h=-4$. The amount is 4, the parameter is $-4$. Read the field label.
  5. Forgetting the stretch when labeling. Writing $(-3,1)$ instead of $(-3,3)$. One unit from the vertex, the height equals $|a|$.
  6. Applying a vertical shift before a vertical stretch. $2x^2+5$ is not $2(x^2+5)$. Multiply, then add. F7
  7. Treating a horizontal scale as a stretch when it is a compression. The factor is the reciprocal. F4
  8. Putting a minus on the wrong side of $f$. $-3|x-2|$ opens down; $3|-(x-2)|$ is just $3|x-2|$. F3
  9. Not naming the parent function. On a written paper this is an explicit part of “starting with the graph of a basic function”.
  10. Giving an unlabeled sketch. The question says “labeled graph”. A correct curve with no coordinates is an incomplete answer.
  11. Moving the curve and leaving the asymptote. F11
  12. Reversing an interval. $f(-x)$ on $[-1,3]$ lives on $[-3,1]$, not $[3,-1]$. F12

The one-page decision tree

Sketch y = <expression> by transformations?
|
+-- 0. Is a GRAPH or a POINT LIST given instead of a formula?
|      YES -> FAMILY 9. Apply the point map to the labeled points only.
|             Nothing else is possible and nothing else is needed.
|
+-- 1. NAME THE PARENT.  Strip all constants.  Write its anchor points.
|      x, x^2, x^3, |x|, sqrt(x), cbrt(x), 1/x, 1/x^2, sin, cos, e^x, ln
|      Note its PARITY: even -> a y-axis flip is invisible
|                       odd  -> the two flips are the same graph
|
+-- 2. FACTOR THE INPUT.   <- skipped exactly when it matters
|      Coefficient on x AND a constant inside?
|        YES -> rewrite as b(x - h).  The shift is c/b, NOT c.
|        NO  -> b is 1 or absent.  Carry on.
|
+-- 3. READ OFF FOUR NUMBERS from  y = a*f(b(x-h)) + k
|        a = outside multiplier   (|a| scales y;  a<0 flips vertically)
|        k = outside addend       (shift up k)
|        b = inside multiplier    (scale x by 1/|b|;  b<0 flips horizontally)
|        h = inside subtrahend    (shift RIGHT h;  x+4 means h = -4)
|
+-- 4. BUILD THE POINT MAP     (x, y) -> ( x/b + h ,  a*y + k )
|
+-- 5. PUSH 3-5 ANCHORS THROUGH IT.  Vertex/start, plus two pairs.
|
+-- 6. STATE THE ORDER, because "explain the procedure" is worth marks.
|      On EACH axis: MULTIPLY BEFORE ADD.  Across axes: order is free.
|      Safe recital: h-scale, h-flip, h-shift, v-scale, v-flip, v-shift.
|
+-- 7. SKETCH AND LABEL the vertex and every point from step 5.
|
+-- 8. CHECK, in eight seconds:
       a. substitute the vertex back: does it give the y you claimed?
       b. sign of a: does the sketch open the right way?
       c. one unit from the vertex, is the height |a|?
       d. set x = 0 in the ORIGINAL: does the sketch cross there?
       e. even parent? is it symmetric about x = h?

  Then TYPE it: explicit *, brackets on every argument,
  h is NEGATIVE for a left shift, and PREVIEW.
