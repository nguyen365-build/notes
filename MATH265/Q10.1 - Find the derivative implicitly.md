# Q10.1 - Find the derivative implicitly

**The question (Midterm Exam 1, item 8, 5 points).**
"Find $y'$ using implicit differentiation:"

$$x^3 y + x y^2 = 4xy + 7$$

**The answer.**

$$y' \;=\; \frac{4y - 3x^2 y - y^2}{x^3 + 2xy - 4x} \;=\; \frac{y\,(4 - 3x^2 - y)}{x\,(x^2 + 2y - 4)}$$

**What to type into Möbius:** `(4*y-3*x^2*y-y^2)/(x^3+2*x*y-4*x)`

**Provenance.** MT1 prints its point value inline at the end of the stem, which is that paper's convention, and item 8 is worth **5 points** out of the 64 that MT1 actually prints.
MT1 carries exactly one "no credit will be given" clause and it sits on item 3, so there is no method restriction here beyond the two words in the stem: *using implicit differentiation*.
Those two words are themselves a method instruction, and section 5 explains what they cost you if you ignore them.

**Verification.** 320 assertions, 0 failures, of which 15 are seeded controls proving the gates can bite.
The derivative is checked against **two arms that never see the claimed formula**: the implicit-function-theorem slope $-F_x/F_y$ built from complex-step partials of $F$, and a complex-step derivative of the curve's explicit branch functions.
A third arm, a Richardson centred-difference ladder, is checked for its convergence *order* as well as its value (measured ratios 15.94 to 16.62, want 16).
Every test point is confirmed to satisfy the relation to $10^{-9}$ *before* any slope is compared, at 44 points spread over 22 values of $x$ on **both branches and both sides** of the curve.

**Here is the one sentence that makes the whole topic easy.**
Implicit differentiation is not a new rule.
It is the chain rule, applied to a function you have not been given a formula for.

Everything else follows from that.
$y$ is secretly $y(x)$.
So $\dfrac{d}{dx}\left[y^2\right]$ is exactly the same computation as $\dfrac{d}{dx}\left[u^2\right]$ where $u = u(x)$, which is $2u \cdot u'$, which is $2y \cdot y'$.
The $y'$ is the inner derivative.
It is there for the same reason the $2x$ is there in $\dfrac{d}{dx}\sin(x^2) = \cos(x^2)\cdot 2x$.
You are not remembering a new fact, you are refusing to forget an old one.

## 0. The 30-second version

```
  1. d/dx BOTH SIDES, term by term.
     x-only term      ->  differentiate normally
     any y in a term  ->  differentiate normally, then MULTIPLY BY y'
     x and y in the SAME term  ->  PRODUCT or QUOTIENT rule first, then the above

  2. SPLIT the result: every term with a y' goes left, everything else goes right.

  3. FACTOR y' out of the left side.

  4. DIVIDE.   y' = (everything else) / (the y' coefficient)

  ANSWER MAY CONTAIN BOTH x AND y.  That is correct, not unfinished.
```

Q10.1 in five lines:

```
  x^3 y + x y^2 = 4xy + 7
  3x^2 y + x^3 y'  +  y^2 + 2xy y'  =  4y + 4x y'  +  0
  x^3 y' + 2xy y' - 4x y'  =  4y - 3x^2 y - y^2
  y' (x^3 + 2xy - 4x)      =  4y - 3x^2 y - y^2
  y' = (4y - 3x^2 y - y^2) / (x^3 + 2xy - 4x)
```

If you can reproduce those five lines from memory, you can do every question in this family.

## 2. The four things you must have cold

### 2.1 The chain rule, written in the form implicit differentiation uses

$$\frac{d}{dx}\Big[f\big(y(x)\big)\Big] = f'(y) \cdot y'$$

Read it as: *differentiate the outside as usual, then multiply by the derivative of the inside, and the inside is $y$, whose derivative is $y'$.*

| the $y$ expression | its $x$-derivative | the outer rule used |
| :--- | :--- | :--- |
| $y$ | $y'$ | none, this is the definition |
| $y^2$ | $2y\,y'$ | power |
| $y^3$ | $3y^2 y'$ | power |
| $y^n$ | $n y^{n-1} y'$ | power |
| $\sqrt{y}$ | $\dfrac{y'}{2\sqrt{y}}$ | power, $n = \tfrac12$ |
| $\dfrac{1}{y}$ | $-\dfrac{y'}{y^2}$ | power, $n = -1$ |
| $\sin y$ | $\cos y \cdot y'$ | chain, named outer |
| $\cos y$ | $-\sin y \cdot y'$ | chain, named outer |
| $\tan y$ | $\sec^2 y \cdot y'$ | chain, named outer |
| $(x+y)^3$ | $3(x+y)^2 (1 + y')$ | chain, inner is $x + y$ |

**Read that table as one fact, not ten.**
Every row is "the ordinary derivative, times $y'$".
The only row that looks different is the last, and it is not: the inner function there is $x + y$, whose derivative is $1 + y'$, so the $y'$ is still exactly the inner derivative.

### 2.2 The product rule, when one factor is $y$

$$\frac{d}{dx}\Big[u(x)\,y\Big] = u'(x)\,y + u(x)\,y'$$

| term | derivative | the trap |
| :--- | :--- | :--- |
| $xy$ | $y + x y'$ | writing $y'$ alone, forgetting the product rule entirely |
| $x^3 y$ | $3x^2 y + x^3 y'$ | writing $3x^2 y'$, which is both mistakes at once |
| $4xy$ | $4y + 4x y'$ | writing $4y$ alone, forgetting the $y'$ half |
| $x y^2$ | $y^2 + 2xy\,y'$ | writing $y^2 + 2xy$, forgetting the chain factor |
| $x^2 y^3$ | $2x y^3 + 3x^2 y^2 y'$ | dropping either half |

**A term holding both $x$ and $y$ always produces exactly two pieces**, one with $y'$ and one without.
If a mixed term gave you only one piece, you have lost half of it.
That is a two-second audit you can run on your own work.

### 2.3 The quotient rule, when $y$ is inside it

$$\frac{d}{dx}\left[\frac{y}{x}\right] = \frac{y' x - y}{x^2}, \qquad \frac{d}{dx}\left[\frac{x}{y}\right] = \frac{y - x y'}{y^2}$$

The mechanics are unchanged from Q8.1.
The only new thing is that $\frac{d}{dx}[y] = y'$ where you used to write $1$.

**Under exam pressure, do not use the quotient rule here.**
Multiply the whole equation by the denominator first, then differentiate.
Section 4's Route C works Q10.1's cousin that way and it is faster every time.

### 2.4 Why the answer contains $y$, and why that is not a failure

An implicit equation usually defines **more than one** function of $x$.
Q10.1's relation is a quadratic in $y$:

$$x\,y^2 + (x^3 - 4x)\,y - 7 = 0$$

so above almost every $x$ there are **two** points on the curve, with **two different slopes**.
No formula in $x$ alone could report both.
The $y$ in the answer is what tells the two apart.

Verified instance, the cleanest one on this curve.
At $x = 2$ the $x^3 y$ and $4xy$ terms cancel exactly ($8y = 8y$), leaving $2y^2 = 7$, so $y = \pm\frac{\sqrt{14}}{2}$:

| point | $y$ | $y'$ exact | $y'$ decimal |
| :--- | :--- | :--- | :--- |
| upper branch | $+\dfrac{\sqrt{14}}{2} \approx 1.870829$ | $-2 - \dfrac{\sqrt{14}}{8}$ | $-2.4677072$ |
| lower branch | $-\dfrac{\sqrt{14}}{2} \approx -1.870829$ | $-2 + \dfrac{\sqrt{14}}{8}$ | $-1.5322928$ |

Same $x$, same curve, two slopes, and the formula produces both.
That is the whole argument for keeping $y$ in the answer, and it is worth memorising as a sentence you can say to yourself when the answer looks unfinished.

## 3. The universal procedure

> 1. **Move nothing.** Differentiate the equation exactly as printed, both sides, term by term.
> 2. **Classify each term before you touch it** using the table below.
> 3. **Differentiate**, attaching a $y'$ to every piece that came from differentiating a $y$.
> 4. **Split**: $y'$ terms to the left, everything else to the right. Watch the signs as they cross.
> 5. **Factor** $y'$ out of the left side.
> 6. **Divide** by the bracket. Do not expand it, and do not cancel across a sum.
> 7. **Stop.** An answer in $x$ and $y$ is a finished answer.

### The classify table

Run this over every term before differentiating anything.

| the term contains | the rule you need | what it produces |
| :--- | :--- | :--- |
| only $x$, or a constant | power / sum, as in Q8.1 | no $y'$ |
| only $y$ | chain, outer rule then $\times\, y'$ | exactly one $y'$ piece |
| $x$ and $y$ multiplied | **product** first, then chain on the $y$ half | one piece with $y'$, one without |
| $x$ and $y$ divided | **quotient**, or clear the denominator first | one piece with $y'$, one without |
| $x$ and $y$ inside one bracket, e.g. $(x+y)^n$ | chain, inner derivative is $1 + y'$ | expands to both |
| $x$ and $y$ inside a named function, e.g. $\sin(xy)$ | chain, then **product** on the inner $xy$ | one piece with $y'$, one without |

Q10.1's four terms classify as: product, product-with-chain, product, constant.
There is not a single pure-$x$ term in the equation, which is why every term on the left contributes to both sides of step 4.

**The audit that catches most errors.**
Count the terms in the original equation, then count the terms after differentiating.
Each mixed term should have become two.
Q10.1 has three mixed terms and one constant, so $3 \times 2 + 0 = 6$ terms after differentiation.
Count them: $3x^2y$, $x^3y'$, $y^2$, $2xy\,y'$, $4y$, $4xy'$.
Six.
If you have five, you dropped one, and it will almost always be a $y'$ piece.

## 4. Q10.1 worked three ways

### Route A - straight implicit differentiation (use this one)

Differentiate both sides.

$$\frac{d}{dx}\left[x^3 y\right] + \frac{d}{dx}\left[x y^2\right] = \frac{d}{dx}\left[4xy\right] + \frac{d}{dx}[7]$$

Term by term, with the rule named:

| term | rule | result |
| :--- | :--- | :--- |
| $x^3 y$ | Product Rule, then $\frac{d}{dx}[y] = y'$ | $3x^2 y + x^3 y'$ |
| $x y^2$ | Product Rule, then Chain Rule on $y^2$ | $y^2 + 2xy\,y'$ |
| $4xy$ | Constant Multiple, then Product Rule | $4y + 4x y'$ |
| $7$ | constant | $0$ |

$$3x^2 y + x^3 y' + y^2 + 2xy\,y' = 4y + 4x y'$$

Split, moving the $4xy'$ left and the $3x^2y$ and $y^2$ right:

$$x^3 y' + 2xy\,y' - 4x\,y' = 4y - 3x^2 y - y^2$$

Factor:

$$y'\left(x^3 + 2xy - 4x\right) = 4y - 3x^2 y - y^2$$

Divide:

$$\boxed{\;y' = \frac{4y - 3x^2 y - y^2}{x^3 + 2xy - 4x}\;}$$

Optionally factor top and bottom, which costs one line and buys a much easier sanity check:

$$y' = \frac{y\left(4 - 3x^2 - y\right)}{x\left(x^2 + 2y - 4\right)}$$

Both forms were checked equal at all 44 verified on-curve points.

### Route B - the implicit function theorem, as a check only

Write the relation as $F(x,y) = 0$ with everything on one side:

$$F(x,y) = x^3 y + x y^2 - 4xy - 7$$

Then, wherever $F_y \neq 0$,

$$y' = -\frac{F_x}{F_y}, \qquad F_x = 3x^2 y + y^2 - 4y, \qquad F_y = x^3 + 2xy - 4x$$

$$y' = -\frac{3x^2 y + y^2 - 4y}{x^3 + 2xy - 4x} = \frac{4y - 3x^2 y - y^2}{x^3 + 2xy - 4x}$$

Identical, as it must be.

**$F_x$ is "differentiate treating $y$ as a constant" and $F_y$ is "differentiate treating $x$ as a constant".**
Neither one carries a $y'$, which is exactly why this route is a good check: it cannot make the mistake the exam is testing for.

Do not write this route as your exam answer.
The stem says *using implicit differentiation*, and partial derivatives are not on the MATH 265 syllabus.
Use it in the margin, in fifteen seconds, to confirm the answer you already wrote.

### Route C - solve for $y$ first, which is the route that fails

Since the relation is a quadratic in $y$, you *could* solve it:

$$y = \frac{-(x^3 - 4x) \pm \sqrt{(x^3-4x)^2 + 28x}}{2x}$$

and then differentiate that with the quotient and chain rules.

It works.
It is verified to agree with Route A at all 44 points, on both branches.
It is also four times the algebra, it forces you to choose a branch, and it is unavailable the moment the relation is anything but a quadratic in $y$.

**The real lesson of Route C is the reason implicit differentiation exists.**
Most relations cannot be solved for $y$ at all.
$x^3 + y^3 = 6xy$ cannot be untangled by hand, and $\sin y + x = y$ cannot be untangled at all, yet both have perfectly ordinary tangent lines everywhere.

### The route comparison

| route | lines of algebra | needs a branch choice | works on any relation | exam use |
| :--- | :--- | :--- | :--- | :--- |
| A, implicit | 5 | no | yes | **this is the answer** |
| B, $-F_x/F_y$ | 3 | no | yes | margin check only, not on the syllabus |
| C, solve then differentiate | ~20 | yes | almost never | do not attempt under time pressure |

**Use Route A. Check with Route B in the margin. Never Route C.**

## 5. The exam-ready write-up

### The short form, which is what to write if time is tight

> Differentiating both sides with respect to $x$, treating $y$ as $y(x)$:
> $$3x^2 y + x^3 y' + y^2 + 2xy\,y' = 4y + 4x y'$$
> Collecting the $y'$ terms:
> $$y'\left(x^3 + 2xy - 4x\right) = 4y - 3x^2 y - y^2$$
> $$y' = \frac{4y - 3x^2 y - y^2}{x^3 + 2xy - 4x}$$

Three displayed lines.
That is the whole answer, and on a 5-point item it should take under three minutes.

### The full-credit form, which adds the clauses a marker looks for

> Treat $y$ as a differentiable function of $x$ and differentiate both sides with respect to $x$.
> By the **Product Rule**, $\dfrac{d}{dx}\left[x^3 y\right] = 3x^2 y + x^3 y'$.
> By the **Product Rule** and then the **Chain Rule**, $\dfrac{d}{dx}\left[x y^2\right] = y^2 + 2xy\,y'$.
> By the **Product Rule**, $\dfrac{d}{dx}[4xy] = 4y + 4x y'$, and $\dfrac{d}{dx}[7] = 0$.
> Hence
> $$3x^2 y + x^3 y' + y^2 + 2xy\,y' = 4y + 4x y'.$$
> Collecting every term containing $y'$ on the left and everything else on the right,
> $$x^3 y' + 2xy\,y' - 4x y' = 4y - 3x^2 y - y^2,$$
> and factoring $y'$ out,
> $$y'\left(x^3 + 2xy - 4x\right) = 4y - 3x^2 y - y^2.$$
> Provided $x^3 + 2xy - 4x \neq 0$,
> $$y' = \frac{4y - 3x^2 y - y^2}{x^3 + 2xy - 4x} = \frac{y\left(4 - 3x^2 - y\right)}{x\left(x^2 + 2y - 4\right)}.$$

The three clauses that carry the method are "treat $y$ as a differentiable function of $x$", the named rules, and the proviso on the denominator.
Note that **no marking scheme exists in any of the four course files** (zero occurrences of "rubric", "marking scheme" or "part marks"), so which of those actually earns a mark is inference and not fact.
The proviso costs you seven words and it is the one line that shows you understand what the denominator is.

### Where correct calculus still loses marks here

| what happens | why it costs |
| :--- | :--- |
| you solve for $y$ first (Route C) and get the right slope | the stem says *using implicit differentiation*, and MT1's stem wording is a method instruction |
| you leave the answer as $y'(x^3+2xy-4x) = \ldots$ | the question asks for $y'$, not for an equation containing it |
| you substitute a number for $x$ | nothing in this stem gives you a point, so there is nothing to substitute |
| you "finish" by eliminating $y$ | it cannot be done, and the attempt eats the clock |

## 6. Verify before you commit

### The eight-second check, adapted from Q8.1 §6

You cannot use Q8.1's centred difference directly, because there is no $f(x)$ to evaluate.
The implicit version is just as fast, and it needs only a calculator.

> 1. Pick an $x$ where the relation is easy to solve for $y$. On Q10.1 that is $x = 2$, because the $x^3y$ and $4xy$ terms cancel and you are left with $2y^2 = 7$.
> 2. Take the two $y$ values, $\pm\sqrt{3.5} \approx \pm 1.870829$.
> 3. Substitute each into your $y'$ and compute.
> 4. Sanity-check the two numbers against each other.

At $x=2$ the general answer collapses beautifully:

$$y' \Big|_{x=2} = \frac{y(4 - 12 - y)}{2(4 + 2y - 4)} = \frac{y(-8-y)}{4y} = \frac{-8-y}{4}$$

so $y' = \frac{-8 \mp 1.870829}{4}$, giving $-2.4677072$ and $-1.5322928$.
Both were confirmed by three independent numeric methods.

**The single fastest structural check** is a substitution you can do in your head.
Set $x = 2$ in your $y'$ *before* simplifying and see whether the $x^3$ and the $-4x$ in the denominator cancel to leave $2xy$.
$8 + 4y - 8 = 4y$.
If they do not, you have mis-transcribed a coefficient.

### The cheap structural invariants, which cost no arithmetic

| invariant | why it must hold | what a violation means |
| :--- | :--- | :--- |
| six terms after differentiating | three mixed terms, each producing two | you dropped a $y'$ piece |
| the denominator is exactly the coefficient of $y'$ | that is what factoring means | you moved a term without a sign flip |
| every term of the denominator contains an $x$ | each came from differentiating a $y$ inside a term that had an $x$ in it | a bare constant in the denominator is a lost factor |
| every term of the numerator contains a $y$ | each came from differentiating an $x$ inside a term that had a $y$ in it | a $y$-free numerator term is a lost factor |
| numerator degree in $y$ is 2, denominator degree in $y$ is 1 | $y^2$ appears once in the relation | a $y^2$ in the denominator means you differentiated $y^2$ as if it were $x^2$ |
| the constant 7 contributes nothing | its derivative is 0 | a 7 anywhere in your answer is a copy error |

The last one is the cheapest and it catches a surprisingly common slip.
**A constant on the right-hand side never appears in $y'$.**

### The geometry check, which is worth understanding once

The denominator is $F_y$.
Where it vanishes, the tangent is **vertical** and $y'$ genuinely does not exist as a number.
That is a fact about the curve, not a mistake in your algebra.

On this curve, verified:

| feature | where | verified how |
| :--- | :--- | :--- |
| $x = 0$ is **not on the curve** | $F(0,y) = -7$ for every $y$ | checked at six values of $y$ |
| exactly one vertical tangent | $(x^*, y^*) = (-2.688358415,\, -1.613635484)$ | $x^*$ is the unique real root of $x^5 - 8x^3 + 16x + 28 = 0$, found two independent ways |
| exactly one horizontal tangent | $x = 1.346010603$, $y = -1.435234$ | from $6x^5 - 8x^3 - 7 = 0$, by a 240001-sample sign sweep with bisection |
| the curve exists only for $x > 0$ or $x \le x^*$ | the discriminant $x\left[x(x^2-4)^2 + 28\right]$ must be $\ge 0$ | this is why a "check point" at $x=-1$ is meaningless |

**That last row is the trap that bit this document's own verification run.**
The first draft of the checking script sampled $x = -0.3, -1, -1.6, -2, -2.2$, and every one of those is **off the curve** because the discriminant is negative there.
A slope comparison at a point that is not on the curve measures nothing.
Confirm the residual first, always.

At the vertical tangent the reciprocal is what behaves: $\dfrac{dx}{dy} = -\dfrac{F_y}{F_x} = 0$ there, verified to $10^{-16}$.

### Numbers worth holding

| quantity | value |
| :--- | :--- |
| $y'$ at $\left(2, \tfrac{\sqrt{14}}{2}\right)$ | $-2 - \dfrac{\sqrt{14}}{8} \approx -2.4677072$ |
| $y'$ at $\left(2, -\tfrac{\sqrt{14}}{2}\right)$ | $-2 + \dfrac{\sqrt{14}}{8} \approx -1.5322928$ |
| $y$ at $x=1$ | $\dfrac{3 \pm \sqrt{37}}{2}$, i.e. $4.5413813$ and $-1.5413813$ |
| $y'$ at $\left(1, \tfrac{3+\sqrt{37}}{2}\right)$ | $-1 - \dfrac{10}{\sqrt{37}} \approx -2.6439899$ |
| $y'$ at $\left(1, \tfrac{3-\sqrt{37}}{2}\right)$ | $\dfrac{10}{\sqrt{37}} - 1 \approx 0.6439899$ |
| the vertical tangent | $x^* = -2.688358415$ |
| the horizontal tangent | $x = 1.346010603$ |

Memorise only the first two.
The rest are here so that a drill answer can be checked.

## 7. Answer-entry rules

Both papers are Möbius, answer-only and machine-marked, so a right derivative with a bad keystroke scores zero.
The A1 block of `MATH265-Reference-Sheets` is the authority; this is the Q10.1-specific slice.

| do | do not |
| :--- | :--- |
| `(4*y-3*x^2*y-y^2)/(x^3+2*x*y-4*x)` | `4*y-3*x^2*y-y^2/x^3+2*x*y-4*x`, which is a completely different expression |
| bracket the **whole** numerator and the **whole** denominator | bracket only part of either |
| type every multiplication with `*`, including `2*x*y` | `2xy`, which one of the two Möbius parsers rejects |
| keep `y` as a variable in the answer | substitute anything for it, or try to eliminate it |
| enter the **unsimplified** form if you are unsure of a cancellation | guess at a factorisation you have not checked |
| `y^2`, not `y**2` or `y²` | mixed exponent notation |
| **preview the rendered expression before submitting** | submit unpreviewed |

**The single most expensive typo on this question is the missing bracket around the numerator.**
`4*y-3*x^2*y-y^2/(x^3+2*x*y-4*x)` renders as $4y - 3x^2y - \dfrac{y^2}{x^3+2xy-4x}$, which is plausible-looking and wrong.
The preview shows the difference in one glance, which is the entire reason to use it.

**The second most expensive is entering the factored form with a bracket error.**
`y*(4-3*x^2-y)/(x*(x^2+2*y-4))` is right.
`y*(4-3*x^2-y)/x*(x^2+2*y-4)` is a different expression, because the trailing bracket multiplies instead of dividing.
If the factored form makes you nervous, **enter the expanded form**: Möbius grades by algebraic equivalence, not string match, so both are accepted and the expanded one has fewer brackets to get wrong.

Four entries verified algebraically equivalent:

```
(4*y-3*x^2*y-y^2)/(x^3+2*x*y-4*x)          <- enter this one
y*(4-3*x^2-y)/(x*(x^2+2*y-4))
-(3*x^2*y+y^2-4*y)/(x^3+2*x*y-4*x)
(4*y-3*x^2*y-y^2)/(x*(x^2+2*y-4))
```

If the box asks for `dy/dx` in a related-rates-flavoured variant, the same bracketing rules apply and the variable name changes only in the prompt, never in what you type.

## 8. The variation catalog

**Read this section as structure, not as fifteen separate facts.**
Every family below is the same four steps from section 3.
What changes between them is only *which rule step 3 needs*, and there are exactly five possibilities: power, product, quotient, chain, and a nested combination of those.
The sign of the answer is always generated the same way, by moving non-$y'$ terms across the equals sign.

Every claimed derivative in the tables below was checked at a Newton-refined on-curve point against $-F_x/F_y$ from numerically computed partials, with the residual confirmed to $10^{-9}$ first.

### Family 0 - classify the terms

The variation that costs marks before any calculus happens.
Given a relation, say for each term which rule step 3 needs.

| relation | term classification |
| :--- | :--- |
| $x^2 + y^2 = 25$ | pure $x$; pure $y$ (power + chain); constant |
| $x^3 y + xy^2 = 4xy + 7$ | three mixed (product), one constant |
| $\dfrac{x}{y} + \dfrac{y}{x} = 3$ | two mixed quotients, one constant |
| $\sin(xy) = x$ | one mixed inside a named function (chain then product); one pure $x$ |
| $(x+y)^3 = x$ | one mixed inside a bracket (chain, inner $= 1 + y'$); one pure $x$ |

**The cue is where the $y$ sits relative to the $x$.** Beside it means product. Under it means quotient. Inside a bracket with it means chain-then-whatever-is-inside.

### Family 1 - pure powers, no mixed term

The easiest possible version, and the one every textbook opens with.

**Shape.** $x^m + y^n = c$ gives $m x^{m-1} + n y^{n-1} y' = 0$, so $y' = -\dfrac{m x^{m-1}}{n y^{n-1}}$.

| relation | $y'$ | verified at |
| :--- | :--- | :--- |
| $x^2 + y^2 = 25$ | $-\dfrac{x}{y}$ | $(3,4)$ |
| $\sqrt{x} + \sqrt{y} = 4$ | $-\dfrac{\sqrt{y}}{\sqrt{x}}$ | $(4,4)$ |
| $y^2 = x^3(2-x)$ | $\dfrac{6x^2 - 4x^3}{2y}$ | $(1,1)$ |

Note the circle's answer: $-x/y$, which contains both variables, on the simplest relation there is.
This is the family to reach for when you want to convince yourself that a $y$ in the answer is normal.

### Family 2 - one mixed product term, which is Q10.1

**Trigger.** A term where $x$ and $y$ sit side by side.
**Tool.** Product Rule, then Chain Rule on the $y$ factor.

| relation | $y'$ | verified at |
| :--- | :--- | :--- |
| $xy = 1$ | $-\dfrac{y}{x}$ | $(2, 0.5)$ |
| $x^2 + xy + y^2 = 7$ | $-\dfrac{2x+y}{x+2y}$ | $(1,2)$ |
| $x^3 + y^3 = 6xy$ (folium) | $\dfrac{6y - 3x^2}{3y^2 - 6x}$ | $(3,3)$ |
| $x^2 y^3 - x = 6$ | $\dfrac{1 - 2xy^3}{3x^2y^2}$ | $(1, 1.912931)$ |
| $x^3 y + xy^2 = 4xy + 7$ | $\dfrac{4y - 3x^2y - y^2}{x^3 + 2xy - 4x}$ | 44 points, both branches |

The folium is the classic exam version because it is symmetric, so the answer's symmetry is its own check: swap $x \leftrightarrow y$ and $y'$ becomes $1/y'$.

### Family 3 - a quotient containing $y$

**Trigger.** $y$ in a denominator.
**Tool.** Quotient Rule, or better, clear the denominator first.

$\dfrac{x}{y} + \dfrac{y}{x} = 3$ has $y' = \dfrac{y}{x}$, verified at $(1, 2.618034)$.

**That answer is worth a second look**, because it is a case where the geometry explains a surprising simplicity.
The relation is homogeneous: put $t = y/x$ and it becomes $t + 1/t = 3$, so $t$ is a *constant* on each branch.
The "curve" is a pair of straight lines through the origin, of slopes $\frac{3\pm\sqrt5}{2}$, and $y' = y/x$ is just the slope of whichever line you are on.

This entry is also the one that **failed** this document's first verification pass.
The draft claimed $-y^2/x^2$, the numeric arm returned $+2.618$ against the claimed $-6.854$, and the mathematics was wrong rather than the check.
It is recorded here because it is a real instance of the algebra trap in section 9, not a hypothetical one.

### Family 4 - $y$ inside a named function

**Trigger.** $\sin y$, $\cos y$, $\tan y$, $e^y$, $\ln y$.
**Tool.** Chain Rule, outer derivative times $y'$.

| relation | $y'$ | verified at |
| :--- | :--- | :--- |
| $\sin y + x = y$ | $\dfrac{1}{1 - \cos y}$ | $(0.5, 1.497300)$ |
| $x \sin y = y$ | $-\dfrac{\sin y}{x\cos y - 1}$ | $(2, 1.895494)$ |

The second one is Family 4 and Family 2 at once: a product whose second factor is a named function of $y$.
That combination is the most common way an examiner raises the difficulty without changing the topic.

### Family 5 - $x$ and $y$ inside the same bracket or function

**Trigger.** $(x+y)^n$, $\sin(xy)$, $\tan(xy)$, $e^{x+y}$.
**Tool.** Chain Rule, and the inner derivative is itself a sum or a product.

| relation | inner derivative | $y'$ | verified at |
| :--- | :--- | :--- | :--- |
| $(x+y)^3 = x$ | $1 + y'$ | $\dfrac{1 - 3(x+y)^2}{3(x+y)^2}$ | $(8,-6)$ |
| $\tan(xy) = x$ | $y + x y'$ | $\dfrac{1 - y\sec^2(xy)}{x\sec^2(xy)}$ | $(1, 0.785398)$ |

**This is the family people get wrong most often**, because the $y'$ arrives one level down and is easy to lose.
Write the inner derivative on its own line before you multiply.

### Family 6 - the slope at a given point

**Trigger.** "Find $y'$ at the point $(a,b)$", or "find the slope of the curve at ...".
**Tool.** Q10.1 unchanged, then substitute **both** coordinates.

**Do the substitution last, not first**, and always check the point is actually on the curve before you use it.
On Q10.1, $(1, 4.5413813)$ is on the curve and gives $-2.6439899$; $(1, 4)$ is not on the curve and any slope you compute there is meaningless.

A faster variant exists once you know it: substitute the numbers into the *equation* obtained in step 3, before collecting.
That turns the collection step into arithmetic instead of algebra and is measurably quicker under pressure.

### Family 7 - the tangent line, which is Q10.2

**Trigger.** "Find the equation of the tangent line to the curve ... at ...".
**Tool.** Family 6, then Q9.1 §2.4's point-slope form.

Q10.2 is $y^3 + yx^2 + x^2 = 3y^2$ at $(1,1)$.

$$3y^2 y' + y' x^2 + 2xy + 2x = 6y y' \quad\Longrightarrow\quad y' = \frac{-(2xy + 2x)}{3y^2 + x^2 - 6y}$$

At $(1,1)$ that is $\dfrac{-4}{3 + 1 - 6} = \dfrac{-4}{-2} = 2$, so the tangent is

$$y - 1 = 2(x-1), \qquad y = 2x - 1$$

Verified: the point satisfies the relation, and the slope agrees with $-F_x/F_y$ from numeric partials.
**Answer with the LINE, not the slope.** Q9.1 §7 has the full argument about answering with the wrong kind of object, and it applies verbatim here.

### Family 8 - horizontal and vertical tangents

**Trigger.** "Where is the tangent horizontal / vertical?", or "show that the curve has a vertical tangent at ...".
**Tool.** Set the numerator to zero for horizontal, the denominator to zero for vertical, and **in both cases also check the other one is not zero at the same point**.

| you want | set | and check | on Q10.1 |
| :--- | :--- | :--- | :--- |
| horizontal tangent | numerator $= 0$ | denominator $\neq 0$ | $x = 1.346010603,\; y = -1.435234$ |
| vertical tangent | denominator $= 0$ | numerator $\neq 0$ | $x = -2.688358415,\; y = -1.613635484$ |
| singular point | both $= 0$ | nothing, the test is inconclusive | none on Q10.1 |

`MATH265_Categorized.md` lists this exact variation for the cardioid:

> Use implicit differentiation to prove that the curve $x^2+y^2 = \left(2x^2+2y^2-x\right)^2$ has a vertical tangent line at the point $(1,0)$.

Verified: at $(1,0)$ that curve has $F_y = 0$ and $F_x \neq 0$, so the vertical tangent claim is true and the two-part test is what proves it.
**The proof is not "the denominator is zero".**
It is "the denominator is zero *and* the numerator is not", because $0/0$ proves nothing at all.

### Family 9 - the second derivative $y''$

**Trigger.** "Find $y''$", or "find $\frac{d^2y}{dx^2}$ in terms of $x$ and $y$".
**Tool.** Differentiate $y'$ with the quotient rule, then **substitute the expression for $y'$ back in**.

That last step is the whole family.
$y''$ comes out containing $y'$, and it is not finished until every $y'$ has been replaced.

On Q10.1, $y'' $ at $\left(2, \frac{\sqrt{14}}{2}\right)$ is $+1.4888703$ and at $\left(2, -\frac{\sqrt{14}}{2}\right)$ is $-3.4888703$, both verified against a Richardson-extrapolated second difference.
Per Q8.2's rule, **a second derivative needs its own numeric check**: re-differentiating your own $y'$ proves you were consistent, not that you were right.

The classic short version is the circle: $x^2+y^2=r^2$ gives $y' = -x/y$, then
$$y'' = -\frac{y - x y'}{y^2} = -\frac{y - x(-x/y)}{y^2} = -\frac{y^2+x^2}{y^3} = -\frac{r^2}{y^3}$$
and the substitution of $y'$ is what turns the middle expression into the last one.

### Family 10 - differentiate with respect to $y$ instead

**Trigger.** "Find $\dfrac{dx}{dy}$", or a vertical-tangent question phrased as a rate.
**Tool.** The same four steps with the roles swapped, or simply invert.

$$\frac{dx}{dy} = \frac{1}{\;y'\;} = -\frac{F_y}{F_x}$$

On Q10.1 that is $\dfrac{x^3+2xy-4x}{4y - 3x^2y - y^2}$.
At the vertical tangent it equals $0$, which is the clean way to state "vertical tangent" without dividing by zero, and it was verified to $10^{-16}$ there.

### Family 11 - a third variable, which is related rates

**Trigger.** Anything with "how fast", or a $t$.
**Tool.** Identical, except the chain factor is $\frac{dx}{dt}$ or $\frac{dy}{dt}$ rather than $y'$.

$$\frac{d}{dt}\left[x^2 + y^2\right] = 2x\frac{dx}{dt} + 2y\frac{dy}{dt}$$

MT1 item 7, the gravel cone, is exactly this with $V$ and $h$.
MT2's rocket question is exactly this with $D$ and $h$.
**If you can do Q10.1 you have already done the hard half of category 11**, and the remaining half is setting up the relation.

### Family 12 - logarithmic differentiation

**Trigger.** $y = f(x)^{g(x)}$, a variable in both the base and the exponent.
**Tool.** Take $\ln$ of both sides, then differentiate implicitly.

$$\ln y = g(x)\ln f(x) \quad\Longrightarrow\quad \frac{y'}{y} = g'(x)\ln f(x) + g(x)\frac{f'(x)}{f(x)}$$

The $\frac{y'}{y}$ on the left is implicit differentiation, arriving for exactly the reason section 2.1 gives.
`MATH265_Review.md` states this identity but never works an example of it, so treat it as a formula to recognise rather than one you have practised.

### Family 13 - prove an identity, or verify a given answer

**Trigger.** "Show that $y' = \ldots$", or "verify that the point lies on the curve and find the slope".
**Tool.** Work forward as normal, then reconcile with the printed form by algebra, not by hoping.

The reconciliation is where marks go.
$\dfrac{4y-3x^2y-y^2}{x^3+2xy-4x}$ and $\dfrac{y(4-3x^2-y)}{x(x^2+2y-4)}$ are the same expression, and a marker will accept either, but $\dfrac{-(3x^2y+y^2-4y)}{x^3+2xy-4x}$ is a third correct form and it is easy to talk yourself out of it.
All three were checked equal at 44 points.

### Family 14 - a parameter in the relation

**Trigger.** A letter that is not $x$ or $y$, e.g. $x^3y + xy^2 = kxy + 7$.
**Tool.** Treat it as a constant, exactly like the 4.

$$y' = \frac{ky - 3x^2y - y^2}{x^3 + 2xy - kx}$$

**The constant appears in both the numerator and the denominator**, because the term $kxy$ is mixed and therefore splits.
A parameter that shows up in only one of the two is a sign you dropped half of a product rule.

## 9. The trap list

Ranked by how often each actually costs marks.

| # | trap | what it looks like | the fix |
| :--- | :--- | :--- | :--- |
| 1 | **forgetting the $y'$ on one term** | you have five terms where you should have six | count terms; each mixed term must yield exactly two |
| 2 | **forgetting the product rule on a mixed term** | $\frac{d}{dx}[x^3y]$ written as $3x^2y'$ or as $3x^2y$ | a mixed term always produces two pieces, one with $y'$ and one without |
| 3 | **algebra when collecting** | a sign that did not flip crossing the equals sign | move one term at a time, and re-read the line you just wrote |
| 4 | **forgetting the chain factor inside $y^2$** | $\frac{d}{dx}[xy^2] = y^2 + 2xy$ | $y^2$ is a composite; its derivative is $2y \cdot y'$, always |
| 5 | **treating the answer as unfinished** | trying to eliminate $y$, or panicking | two branches, two slopes, so the $y$ must stay |
| 6 | **dividing by the wrong bracket** | the numerator and denominator swapped | the denominator is the coefficient of $y'$, by definition of factoring |
| 7 | **losing the $y'$ one level down** | $(x+y)^3$ differentiated as $3(x+y)^2$ | write the inner derivative $1+y'$ on its own line |
| 8 | **substituting the point too early** | you substitute, then cannot collect | collect first, substitute last, unless you deliberately choose the fast variant |
| 9 | **using a check point not on the curve** | your numeric check disagrees and you doubt correct work | verify the point satisfies the relation before you use it |
| 10 | **calling a vertical tangent an error** | denominator zero, so you assume you slipped | $F_y = 0$ with $F_x \neq 0$ is a real vertical tangent |
| 11 | **solving for $y$ first** | correct slope, method mark lost | the stem says *using implicit differentiation* |
| 12 | **leaving a constant in the answer** | a 7 appears in $y'$ | $\frac{d}{dx}[7] = 0$, always |

**Traps 1, 2 and 4 are one trap wearing three coats**, and together they are the majority of lost marks on this question.
All three are "a $y$ got differentiated as though it were a constant or as though it were $x$".

Here is the measured evidence, from this document's own seeded controls.
Five wrong answers were built by making exactly these mistakes and then compared against the true formula at 44 on-curve points:

| seeded mistake | worst relative deviation | has a hiding point on this curve? |
| :--- | :--- | :--- |
| no $y'$ on the $y$ in $x^3y$ | 15.5 | no |
| no chain factor on $y^2$ | 5.01 | no |
| no product rule on $x^3y$ | 1.96 | no |
| sign slip when collecting | 3.92 | no |
| no $y'$ on the $y$ in $4xy$ | 122 | no |

**Q10.1 is unusually forgiving to check, and the reason is worth knowing.**
The two "forgot the $y'$" mistakes differ from the truth only by an $x^3$ or a $-4x$ in the denominator, so they would agree with the correct answer exactly when $x = 0$.
And $x = 0$ is **not on this curve**: $F(0,y) = -7$ for every $y$.
So on this particular relation there is no blind spot, and a single numeric check at any legitimate point will catch every one of these five mistakes.

**That is a property of this curve, not of the topic.**
Control, verified: on $x^2 + y^2 = 25$ the analogous mistake (differentiating $y^2$ as $2y$, forgetting the $y'$) gives $y' = -x$ instead of $-x/y$, and those agree **exactly at $x = 0$**, which is the top of the circle and the most convenient point on it.
This is Q8.3's lesson in a new setting: the convenient input is the blind spot.
Check somewhere awkward.

## 11. The one-page decision tree

```
  START: an equation mixing x and y, and you are asked for y'
    |
    +-- Does the stem say "implicit"?  ------ yes --> you MUST use this method
    |                                  no  --> still use it; solving for y is almost never faster
    |
    +-- STEP 1: differentiate BOTH sides, term by term.
    |     For each term, ask: where is the y?
    |        no y at all           ->  ordinary derivative, no y'
    |        y alone               ->  outer rule, then  x y'
    |        y beside an x         ->  PRODUCT rule, then outer rule on the y half
    |        y under or over an x  ->  QUOTIENT rule  (or clear the fraction first)
    |        y inside a bracket    ->  CHAIN rule, inner derivative carries the y'
    |        y inside sin/cos/tan  ->  CHAIN rule, outer' (y) * y'
    |
    +-- AUDIT: every mixed term must have produced TWO pieces.  Count them.
    |
    +-- STEP 2: all y' terms LEFT, everything else RIGHT.  Flip signs as they cross.
    +-- STEP 3: factor y' out.
    +-- STEP 4: divide.   y' = RIGHT / (the bracket)
    |
    +-- Now: what was actually asked?
          "find y'"                  ->  STOP.  x and y in the answer is CORRECT.
          "at the point (a,b)"       ->  substitute BOTH; check (a,b) is on the curve first
          "tangent line"             ->  y - b = y'(a,b) * (x - a)      [Q9.1 s2.4]
          "vertical tangent"         ->  denominator = 0 AND numerator != 0
          "horizontal tangent"       ->  numerator = 0 AND denominator != 0
          "y''"                      ->  quotient-rule y', then SUBSTITUTE y' back in
          "dx/dy"                    ->  invert, or -F_y/F_x
          "how fast"                 ->  same method, d/dt, factor is dh/dt not y'
    |
    +-- CHECK (8 seconds): pick an x where y is easy; confirm the relation holds
    |                      there; substitute; compare against -F_x/F_y in the margin.
    +-- PREVIEW the Möbius rendering before submitting.
```
