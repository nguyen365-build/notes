# Q19.8 - Displacement and distance travelled

**The question (Final Exam 2, item 10, 5 points).** A particle moves along a line so that its velocity at time $t$ is $v(t) = t^2 - 3t + 2$ (meter/sec).

- a. Find the displacement of the particle during the time period $[0, 3]$.
- b. Find the distance traveled during this same time period.

**The answer.** (a) $\displaystyle\int_0^3 v\,dt = \dfrac{3}{2} = 1.5$ metres.
(b) $\displaystyle\int_0^3 \lvert v\rvert\,dt = \dfrac{11}{6} \approx 1.8333333333$ metres.

**What to type into Möbius:** `3/2` for part (a), `11/6` for part (b).

## 1. What this question is really testing

| The reflex | Where it comes back |
| :--- | :--- |
| A rate integrates to a **net change** in the quantity | Q19.3, which is this theorem with water instead of a particle |
| Keeping the sign gives net; dropping it gives total | Q19.9, and every "how far did it travel" wording |
| A sign change **inside** the interval is what separates them | Q19.1 and Q19.2, where the same split separates signed area from area |
| Recovering a quantity from its rate needs an initial condition | Q19.9, and every differential equation later |
| Units come from the integrand times the variable of integration | Q19.3 section 2a, Q6.1 section 2.2 |

**The single sentence this question exists to install** is that $\int v$ and $\int \lvert v\rvert$ are different numbers, and that the difference is created entirely by the intervals on which $v$ is negative.

> **Net Change Theorem.** If $x$ is position and $x' = v$, then $\displaystyle\int_a^b v(t)\,dt = x(b) - x(a)$.
> That is the **displacement**: the net change in position.
> The **distance travelled** is $\displaystyle\int_a^b \lvert v(t)\rvert\,dt$, which is the same accumulation with every piece counted as positive.

That first line is not a new theorem.
It is the Fundamental Theorem of Calculus Part 2 with the letters renamed, and `Q19.3 - Net change, water flowing from a tank.md` states it, proves the units, and works it eight ways.
**Read that page rather than re-deriving it here.**
Its Family 2 already forward-references this question by name, and says exactly the right thing: the two columns "agree exactly when the rate does not change sign inside the interval, and that is the only condition".

### Why Q19.3 could hide this and Q19.8 cannot

Q19.3's rate is $r = 180 - 6t$ on $[0,15]$, and $r$ is zero at $t = 30$, which is **outside** the interval.
So on Q19.3's own numbers the net change and the total moved are both 2025 litres, and a student who never learned the distinction still scores full marks.

This question is built to remove that escape.
$v = (t-1)(t-2)$ has **both** its zeros strictly inside $[0,3]$, so the two answers are forced apart, and the examiner asks for both in the same breath.

> **Do displacement and distance coincide on this stem?**
> **No.** $3/2$ against $11/6$, a gap of exactly $1/3$.
> That is the checked answer to the question the previous page in this category could not ask, and it is why Q19.8 is where the mark is actually decided.

### Why the marks are cheap and the trap is not

5 points out of 81 on Final Exam 2 is 6.1728 percent, and 5 is the second-cheapest value on that paper.
An examiner does not put a hard antiderivative in a two-part 5-point slot, and this one is a cubic you can write in your head.

## 2. The four things you must have cold

### 2a. The two integrals, side by side

| Asked for | Formula | Sign | Physical reading |
| :--- | :--- | :--- | :--- |
| **Displacement** | $\displaystyle\int_a^b v\,dt$ | signed, can be negative or zero | net change in position: start here, end there |
| **Distance travelled** | $\displaystyle\int_a^b \lvert v\rvert\,dt$ | never negative | the odometer, which never runs backwards |
| **Position** $x(b)$ | $x(a) + \displaystyle\int_a^b v\,dt$ | needs $x(a)$ | where it actually is on the line |
| **Average velocity** | $\dfrac{1}{b-a}\displaystyle\int_a^b v\,dt$ | signed | displacement per unit time |
| **Average speed** | $\dfrac{1}{b-a}\displaystyle\int_a^b \lvert v\rvert\,dt$ | never negative | distance per unit time |

The three inequalities worth carrying:

$$\lvert \text{displacement}\rvert \;\le\; \text{distance}, \qquad \lvert \text{avg velocity}\rvert \;\le\; \text{avg speed}, \qquad \left\lvert\int v\right\rvert \;\le\; \int \lvert v\rvert .$$

They are all the same inequality.
It is an **equality** exactly when $v$ does not change sign on the interval.

### 2b. Why the difference is twice the negative part

Split $[a,b]$ into the set $P$ where $v \ge 0$ and the set $N$ where $v < 0$.
Write $A = \int_P v \ge 0$ and $B = \int_N v \le 0$.

$$\text{displacement} = A + B, \qquad \text{distance} = A - B, \qquad \text{distance} - \text{displacement} = -2B = 2\lvert B\rvert .$$

On this question $B = -1/6$, so the gap is $2 \times 1/6 = 1/3$, and $3/2 + 1/3 = 11/6$.
**That is a free second route to part (b)** and it is checked in section 4 as Route D.

It also tells you the two answers agree if and only if $B = 0$, that is, if and only if $v$ never goes negative.

### 2c. $\lvert v\rvert$ is not a formula, it is three formulas

You cannot antidifferentiate $\lvert t^2-3t+2\rvert$ as a single expression, because it is not one expression.
On $[0,3]$ it is

$$\lvert v(t)\rvert = \begin{cases} t^2-3t+2 & 0 \le t \le 1 \\[2pt] -(t^2-3t+2) & 1 \le t \le 2 \\[2pt] t^2-3t+2 & 2 \le t \le 3 \end{cases}$$

so the integral is three integrals.
This is the entire technique, and the reason "find where $v$ changes sign" is step one rather than an optional check.

**$\lvert v\rvert$ has corners at $t=1$ and $t=2$.**
It is continuous there but not differentiable, which is why section 6's numerical check behaves the way it does and why a single antiderivative cannot exist.

### 2d. The constants are not optional

Two different constants get lost on two different questions, and they are not the same mistake.

| You are given | You want | What you need in addition | Why |
| :--- | :--- | :--- | :--- |
| $v(t)$ | displacement | **nothing** | it is a change, and the constant cancels |
| $v(t)$ | position $x(b)$ | $x(a)$, an initial position | $x(t) = x(a) + \int_a^t v$ |
| $a(t)$ | velocity $v(b)$ | $v(a)$, an initial velocity | $v(t) = v(a) + \int_a^t a$ |
| $a(t)$ | position $x(b)$ | **both** $v(a)$ and $x(a)$ | two integrations, two constants |

Part (a) asks for **displacement**, not position, and that is deliberate: it is the one quantity that can be asked without an initial condition.
A student who forgets $x(0)$ entirely gets part (a) right, which is exactly why the omission is invisible here and fatal on Q19.9.

## 3. The universal procedure

> **Step 1.** Read the noun. **Displacement, net change, "where does it end up"** means $\int v$. **Distance, total distance, "how far does it travel", odometer** means $\int \lvert v\rvert$.
> **Step 2.** Solve $v(t) = 0$ and keep only the roots **strictly inside** the interval.
> **Step 3.** If there are none, the two answers agree up to sign and you are done in one integral.
> **Step 4.** If there are some, they cut the interval into pieces. Integrate $v$ over each piece.
> **Step 5.** Displacement is the **sum** of the pieces. Distance is the sum of their **absolute values**.
> **Step 6.** Check: distance $\ge$ $\lvert$displacement$\rvert$, with strict inequality whenever step 2 found an interior root.

### The classify table

| The wording says | You are being asked for | Split at the zeros? |
| :--- | :--- | :---: |
| displacement, net change in position, net displacement | $\int v$ | no |
| how far is it from where it started | $\lvert\int v\rvert$ | no |
| distance travelled, total distance, total distance covered | $\int \lvert v\rvert$ | **yes** |
| position at time $b$ | $x(a) + \int_a^b v$ | no |
| average velocity | $\frac{1}{b-a}\int v$ | no |
| average speed | $\frac{1}{b-a}\int \lvert v\rvert$ | **yes** |
| how far forward does it get before turning back | $\max_t \int_a^t v$ | evaluate at the zeros |

Notice rows two and three.
"How far is it from where it started" is $\lvert\int v\rvert$ and "how far did it travel" is $\int\lvert v\rvert$, and those are different numbers ($3/2$ against $11/6$).
**The absolute value goes inside the integral, not outside.**

## 4. Q19.8 worked five ways

Every route below was evaluated independently in Python and agrees to better than $10^{-9}$.

### Route A - the antiderivative, split at the roots (the one to write down)

$v = (t-1)(t-2)$, zeros at $t=1$ and $t=2$, both in $(0,3)$.
$S(t) = \dfrac{t^3}{3} - \dfrac{3t^2}{2} + 2t$, and $S(0)=0$, $S(1)=\dfrac{5}{6}$, $S(2)=\dfrac{2}{3}$, $S(3)=\dfrac{3}{2}$.

| Piece | Sign of $v$ | $\int v$ | $\int \lvert v \rvert$ |
| :--- | :---: | ---: | ---: |
| $[0,1]$ | $+$ | $5/6$ | $5/6$ |
| $[1,2]$ | $-$ | $-1/6$ | $1/6$ |
| $[2,3]$ | $+$ | $5/6$ | $5/6$ |
| **total** | | $\mathbf{3/2}$ | $\mathbf{11/6}$ |

### Route B - one integral for (a), three for (b)

Part (a) needs no split at all: $\int_0^3 v = S(3)-S(0) = 9 - \frac{27}{2} + 6 = \frac{3}{2}$.
This is worth knowing because it is faster, and because it makes the point that **the split is a part (b) technique, not a part (a) one**.

### Route C - the reflected middle piece

Write part (b) as $\int_0^1 v - \int_1^2 v + \int_2^3 v$.
Same three numbers, no absolute-value bars in the working, and it is what a marker most likely wants to see.
$\frac{5}{6} - \left(-\frac{1}{6}\right) + \frac{5}{6} = \frac{11}{6}$.

### Route D - displacement plus twice the negative part

From section 2b: distance $=$ displacement $+\, 2\lvert B\rvert$ where $B$ is the sum of the negative pieces.
$\frac{3}{2} + 2 \times \frac{1}{6} = \frac{3}{2} + \frac{1}{3} = \frac{11}{6}$.
**This is the fastest check** because it reuses part (a)'s answer and one small number.

### Route E - numerical quadrature

Composite Simpson on $[0,3]$ with $n$ a multiple of 6 returns $3/2$ and $11/6$ exactly, to machine precision.
Section 6 explains why that "exactly" is an accident of where the corners land, and what happens when it is not.

### Route comparison

| Route | Work | Risk | Verdict |
| :--- | :--- | :--- | :--- |
| A, antiderivative split at roots | 4 evaluations of $S$ | none if the roots are right | **the one to write down** |
| B, single integral | 2 evaluations of $S$ | only answers part (a) | use it for (a), then extend |
| C, reflected middle | same as A | none; avoids writing bars | use it if the marker wants prose |
| D, displacement $+\,2\lvert B\rvert$ | one extra addition | needs A's pieces anyway | **use it as the check** |
| E, quadrature | a calculator you do not have | none mathematically | not available in the exam |

**Under pressure: Route A for the working, Route D for the check.**
Route A takes about forty seconds once the factorisation is written down, and Route D takes five.

## 5. The exam-ready write-up

This is what earns the method marks if part marks exist, which is inference: no marking scheme appears anywhere in the course files.

> Since $v(t) = t^2 - 3t + 2 = (t-1)(t-2)$, the velocity is zero at $t=1$ and $t=2$, and both lie in $[0,3]$.
> The velocity is positive on $[0,1)$, negative on $(1,2)$ and positive on $(2,3]$.
> Let $S(t) = \frac{t^3}{3} - \frac{3t^2}{2} + 2t$, so that $S' = v$.
>
> **(a)** The displacement is the net change in position, so
> $\displaystyle\int_0^3 v\,dt = S(3) - S(0) = \left(9 - \tfrac{27}{2} + 6\right) - 0 = \tfrac{3}{2}$ metres.
>
> **(b)** The distance travelled is $\int_0^3 \lvert v\rvert\,dt$, which must be split where $v$ changes sign:
> $\displaystyle\int_0^3 \lvert v\rvert\,dt = \lvert S(1)-S(0)\rvert + \lvert S(2)-S(1)\rvert + \lvert S(3)-S(2)\rvert = \tfrac{5}{6} + \tfrac{1}{6} + \tfrac{5}{6} = \tfrac{11}{6}$ metres.

Three sentences do the work: **factor, state the sign pattern, split**.
The single most valuable clause is "and both lie in $[0,3]$", because it is the sentence that proves you checked, and it is the one a student who is about to lose part (b) never writes.

## 6. Verify before you commit

### The eight-second checks, in the order they catch things

1. **Is the distance strictly bigger than the displacement?** It must be, because $v$ changes sign inside. $11/6 > 3/2$. **This one check rejects 15 of the 19 wrong values in section 9's census.**
2. **Is the gap exactly twice a piece you already computed?** $11/6 - 3/2 = 1/3 = 2 \times 1/6$. If it is not twice something, you dropped or duplicated a piece.
3. **Are both answers positive?** Displacement need not be, but here $S$ is increasing overall. Distance never can be negative, so a negative part (b) is wrong on sight.
4. **Is the answer in metres?** Section 8 does this dimensionally.
5. **Are the two answers different numbers?** If you wrote $3/2$ twice, you almost certainly did not split.

### The check that cannot fire here, and why you should know that

**Positivity rejects nothing on part (b).**
Of the nineteen wrong values in the census, **zero** are negative, so "is it positive?" is completely inert as a filter on part (b).
It does real work on part (a), where it rejects 5 of 10.

**And the units check cannot separate the two parts at all**, because displacement and distance carry the same dimension.
That is stated as a named blind spot in section 8, not left implicit.

### What the numerical check actually does, measured

$\lvert v\rvert$ has corners at $t=1$ and $t=2$, so its quadrature behaviour is not the textbook one, and it was measured rather than assumed.

| Rule | Alignment | Observed order | Evidence |
| :--- | :--- | :---: | :--- |
| Composite Simpson | $n$ a multiple of 6 | **exact**, error $0$ | $n = 6, 12, 24, \ldots, 768$, error $0$ at every one |
| Composite Simpson | $3 \nmid n$ | **3** | $\text{err}\times n^3 = 5.333333$ at $n = 200, 400, 800, 1600, 3200$ |
| Gauss-Legendre 16-point, unsplit | any | **2** | orders $1.9747, 2.0126, 1.9937, 2.0032$ |
| Any rule, split at $t=1,2$ | any | **exact** | error $2.2\times10^{-16}$ |

Three things in that table are worth carrying.

**First, Simpson is exact when the corners land on even node indices.**
With $h = 3/n$ the corner at $t=1$ sits at node index $n/3$.
Simpson pairs panels, so a corner only hurts if it lands strictly inside a pair.
When $6 \mid n$ the index $n/3$ is even, both corners fall on pair boundaries, and since $\lvert v\rvert$ is a quadratic on each piece Simpson integrates it exactly.

**Second, the off-alignment behaviour on this interval is order 3, not the order 2 you would expect**, and the reason is a genuine accident of this stem.
The local Simpson error on a pair of half-width $h$ containing a corner at offset $s\,h$ from the midpoint is

$$e(s) = \frac{h^2}{3}\left(4\lvert s\rvert - 1 - 3 s^2\right),$$

verified against the model at seven values of $s$.
That quadratic has a **root at $\lvert s\rvert = 1/3$**.
And on $[0,3]$ with a corner at $t=1$, the node index is always $n/3$, so for every even $n$ not divisible by 3 the corner sits at exactly $\lvert s\rvert = 1/3$ from the pair midpoint - checked for all 1334 such $n$ up to 4000, with zero exceptions.
The leading term therefore vanishes for **every** unaligned $n$ on this interval, and what is left is order 3.

**Third, order 2 is what you get generically**, and the control proves it: the same $\lvert v\rvert$ integrated over $[0,\pi]$ instead of $[0,3]$, where the corners are at irrational fractions of a panel, gives $\text{err}\times n^2$ oscillating in the band $[0.0094, 1.3000]$ and never settling - which is order 2 with a coefficient that depends on the alignment.

The practical lesson is one line: **split at the corners.**
Unsplit 16-point Gauss-Legendre, a rule that is exact for polynomials up to degree 31, is dragged down to order 2 by a single corner and still has an error of $3.1\times10^{-6}$ at 40 panels.
Splitting takes it to $2.2\times10^{-16}$, an improvement of ten orders of magnitude, for no extra work.

## 8. The units gate

Work in exponent vectors over $(L, T)$, length and time.
$v$ is $L\,T^{-1}$ and $dt$ is $T$.

| Quantity | Dimension | Reads as |
| :--- | :--- | :--- |
| $v$ | $L\,T^{-1}$ | m/s |
| $\int v\,dt$ | $L$ | **metres** |
| $\int \lvert v\rvert\,dt$ | $L$ | **metres** |
| $\frac{1}{b-a}\int v\,dt$ | $L\,T^{-1}$ | m/s |
| $a = v'$ | $L\,T^{-2}$ | m/s² |
| $\int a\,dt$ | $L\,T^{-1}$ | m/s, a **velocity**, not a distance |
| $\int\!\!\int a\,dt\,dt$ | $L$ | metres |

Five seeded rejections, each checked:

- $v(3) - v(0)$ offered as a displacement is $L\,T^{-1}$, not $L$. **Rejected.**
- $\int v\,dt$ reported in m/s. **Rejected**; integrating multiplied by a time.
- $\int v^2\,dt$ is $L^2 T^{-1}$. **Rejected.**
- dividing by the width, which turns the length back into a velocity. **Rejected.**
- $\int a\,dt$ offered as a distance. **Rejected.**

### The stem's own numerals are not pure numbers

$v(t) = t^2 - 3t + 2$ is, read literally, **dimensionally inhomogeneous**: three terms carrying three different dimensions.
For the sum to be a velocity, the coefficients must carry units:

$$\underbrace{1}_{L\,T^{-3}}\,t^2 \;-\; \underbrace{3}_{L\,T^{-2}}\,t \;+\; \underbrace{2}_{L\,T^{-1}} .$$

That is worth one sentence of your attention because it is the same observation that makes the conversion variations in section 9 tractable: **rescale $t$ and every coefficient changes by a different power.**

### The named blind spot

> **The units gate structurally cannot tell part (a) from part (b).**
> Displacement and distance are both lengths. Every one of the eleven cross-part errors passes this gate cleanly.
> Only the sign-change argument catches them.

### The magnitude pattern, which is a sixth behaviour

The earlier questions in this category produced five patterns: repair-rescues (Q19.1, Q19.3), repair-harms (Q19.2), positivity-inert-bracket-helps (Q19.4 to Q19.6), and Q19.7's positivity-active with a partial sign repair.

> **Eleven of the nineteen wrong part (b) values are exactly $3/2$: the correct answer to part (a).**

Call it a **cross-part collision**.
It is a genuinely nastier failure mode than a scattered wrong answer, because the number is one you have already written down, checked, and believe.
Every cheap sanity check you apply to it passes, since it is a real answer to a real question - just the wrong one.

The eleven are: report (a)'s answer for (b); never split; $\lvert\int v\rvert$ instead of $\int\lvert v\rvert$; split at $t=1$ only; split at $t=2$ only; split at the vertex $t=3/2$ instead of the roots; split correctly then forget the absolute values; wrong roots so no split; $\lvert S(3)\rvert-\lvert S(0)\rvert$; net change of $\lvert S\rvert$; and three times the average velocity.

Two of those deserve a second look.

**Splitting at only one of the two roots still gives $3/2$.** $\lvert\int_0^1\rvert + \lvert\int_1^3\rvert = \frac{5}{6} + \frac{2}{3} = \frac{3}{2}$, and $\lvert\int_0^2\rvert + \lvert\int_2^3\rvert = \frac{2}{3} + \frac{5}{6} = \frac{3}{2}$.
Half-doing the technique is worth exactly as much as not doing it at all.

**Splitting at the vertex $t=3/2$ also gives $3/2$.** That is where $a = 0$ and the speed is least, and it is a plausible-looking place to cut.
It is the wrong place: you split where $v$ is **zero**, not where $v$ is **slowest**.

## 10. The variation catalog

Read each table as **structure**, not as a list of facts.
In Family 0 there are only four distinct magnitudes in play - $5/6$, $1/6$, $2/3$ and $3/2$ - and every entry is a sum of them.
The signs are generated by one rule: a piece is negative exactly when it lies between $t=1$ and $t=2$.

### Family 0 - the same $v$, a different interval

**Trigger.** Same velocity, the interval moved or stretched.
**Tool.** Recount which of $t=1$ and $t=2$ are strictly inside.
That single count decides everything.

| Interval | Roots inside | Displacement | Distance | Agree? |
| :--- | :---: | ---: | ---: | :---: |
| $[0,3]$ **the exam** | $1, 2$ | $3/2 = 1.5000000000$ | $11/6 = 1.8333333333$ | no |
| $[0,2]$ | $1$ | $2/3 = 0.6666666667$ | $1 = 1.0000000000$ | no |
| $[0,1]$ | none | $5/6 = 0.8333333333$ | $5/6 = 0.8333333333$ | **yes** |
| $[1,2]$ | none | $-1/6 = -0.1666666667$ | $1/6 = 0.1666666667$ | **in magnitude** |
| $[0,4]$ | $1, 2$ | $16/3 = 5.3333333333$ | $17/3 = 5.6666666667$ | no |
| $[2,5]$ | none | $27/2 = 13.5000000000$ | $27/2 = 13.5000000000$ | **yes** |
| $[1,3]$ | $2$ | $2/3 = 0.6666666667$ | $1 = 1.0000000000$ | no |

Row four is the one to study: on $[1,2]$ the displacement is **negative** and the distance is its absolute value, because $v$ has one sign there.
Row seven shows a root **at** an endpoint counts for nothing; only $t=2$ is interior.

### Family 1 - $v$ does not change sign, so the two coincide

**Trigger.** $v(t) = 0$ has no solution strictly inside, or a solution where $v$ does not actually cross.
**Tool.** One integral, then take the absolute value at the end if distance was asked.

| Instance | Displacement | Distance |
| :--- | ---: | ---: |
| $v = t^2-3t+2$ on $[5/2, 4]$ | $+4.5000000000$ | $4.5000000000$ |
| $v = t^2-3t+2$ on $[6/5, 9/5]$ | $-0.1320000000$ | $0.1320000000$ |
| $v = t^2+1$ on $[0,3]$ | $+12.0000000000$ | $12.0000000000$ |
| $v = -4$ on $[0,3]$ | $-12.0000000000$ | $12.0000000000$ |
| $v = (t-3/2)^2$ on $[0,3]$ | $+2.2500000000$ | $2.2500000000$ |

The last row is the sharp case.
$v$ **is** zero at $t = 3/2$, an interior point, and the two answers still agree - because it is a **double** root, so $v$ touches zero without crossing.
**The condition is a sign change, not a zero.**
A zero of even multiplicity splits nothing.

### Family 2 - position, which needs the initial condition

**Trigger.** "Where is the particle at $t=3$", "find $x(t)$", "how far from the origin".
**Tool.** $x(t) = x(0) + S(t)$.
The displacement is unchanged; only the position moves.

| $x(0)$ | $x(3)$ | Displacement |
| ---: | ---: | ---: |
| $0$ | $3/2 = 1.5000000000$ | $3/2$ |
| $4$ | $11/2 = 5.5000000000$ | $3/2$ |
| $-2$ | $-1/2 = -0.5000000000$ | $3/2$ |
| $5/2$ | $4 = 4.0000000000$ | $3/2$ |

The right column never moves.
**That is the whole content of the family**: displacement is a difference, and a difference cannot see the constant.
It is also why part (a) is answerable without $x(0)$, and why forgetting $x(0)$ is invisible on this exact question and fatal the moment the wording changes to "position".

### Family 3 - velocity from acceleration, which needs its own constant

**Trigger.** You are given $a(t)$ and asked for $v$, or for a distance.
**Tool.** $v(t) = v(0) + \int_0^t a$.
Then everything above applies to that $v$.

This question's own acceleration is $a(t) = 2t - 3$, and $\int_0^3 a\,dt = 9 - 9 = 0$.
So $v(3) = v(0)$ whatever $v(0)$ is - and indeed $v(0) = v(3) = 2$.

| Given | Want | Constants needed |
| :--- | :--- | :--- |
| $a(t)$ | $v(3) - v(0)$ | none |
| $a(t)$ | $v(3)$ | $v(0)$ |
| $a(t)$ | displacement over $[0,3]$ | $v(0)$ |
| $a(t)$ | position $x(3)$ | $v(0)$ **and** $x(0)$ |

**Q19.9 is exactly this family with a piecewise $a$.**

### Family 4 - averages

**Trigger.** "Average velocity", "average speed".
**Tool.** Divide by the width.
Which integral you divide decides which average you get.

| Quantity | Formula | Value |
| :--- | :--- | ---: |
| average velocity | $\frac{1}{3}\int_0^3 v$ | $1/2 = 0.5000000000$ |
| average speed | $\frac{1}{3}\int_0^3 \lvert v\rvert$ | $11/18 = 0.6111111111$ |
| the gap | $\frac{1}{3}\times\frac{1}{3}$ | $1/9 = 0.1111111111$ |

Everything from parts (a) and (b) transfers by dividing by 3, so this family costs nothing extra once the two integrals exist.
This is the same average-value machinery as Q19.6 and Q19.7, applied to $v$ and to $\lvert v\rvert$.

### Family 5 - the motion vocabulary

**Trigger.** "When is it at rest", "when is it moving backwards", "when is it speeding up".
**Tool.** $v$ answers the first two; $v$ **and** $a$ together answer the third.

| Question | Rule | Answer here |
| :--- | :--- | :--- |
| at rest | $v = 0$ | $t = 1$ and $t = 2$ |
| moving forward | $v > 0$ | $[0,1)$ and $(2,3]$ |
| moving backward | $v < 0$ | $(1,2)$ |
| slowest speed | minimise $\lvert v\rvert$ | $1/4$ at $t = 3/2$ |
| **speeding up** | $v$ and $a$ have the **same** sign | $(1, 3/2)$ and $(2, 3)$ |
| **slowing down** | $v$ and $a$ have **opposite** signs | $(0, 1)$ and $(3/2, 2)$ |

"Speeding up" is the row that catches people.
It is **not** $a > 0$.
On $(1, 3/2)$ the acceleration is negative and the particle is speeding up, because it is moving backwards and getting faster at it.

### Family 6 - furthest forward, and the shape of the trip

**Trigger.** "How far does it get before turning back", "what is its maximum displacement".
**Tool.** Evaluate $S$ at the endpoints **and** at every interior zero of $v$, then take the extreme.

$S(0) = 0$, $S(1) = 5/6$, $S(2) = 2/3$, $S(3) = 3/2$.

So the trip is: forward $5/6$ m, back $1/6$ m, forward $5/6$ m again.
The furthest forward it ever gets is $3/2$ at the very end, and it never goes behind its starting point.
The forward-then-back-then-forward shape is what makes $11/6 = 5/6 + 1/6 + 5/6$ read as a physical odometer rather than a formula.

### Family 7 - more than two sign changes

**Trigger.** A trigonometric or higher-degree $v$.
**Tool.** Identical.
Find every zero, split at every one.

| Instance | Pieces | Displacement | Distance |
| :--- | :---: | ---: | ---: |
| $v = \sin(\pi t)$ on $[0,2]$ | 2 | $0$ | $4/\pi = 1.2732395447$ |
| $v = \sin(\pi t)$ on $[0,3]$ | 3 | $2/\pi = 0.6366197724$ | $6/\pi = 1.9098593171$ |
| $v = \sin(\pi t)$ on $[0,4]$ | 4 | $0$ | $8/\pi = 2.5464790895$ |

The first and third rows are the extreme case: **the displacement is exactly zero while the particle has travelled a positive distance**.
The ratio of distance to $\lvert$displacement$\rvert$ has no upper bound.
If you ever answer "distance = 0" for a moving particle, this row is why that is wrong.

### Family 8 - rescaling and units

**Trigger.** $v$ multiplied by a constant, or the time measured in different units.
**Tool.** Both integrals are linear in $v$, so both scale by the same factor.
That means **the ratio is invariant**.

| Instance | Displacement | Distance | Ratio |
| :--- | ---: | ---: | ---: |
| $v = t^2-3t+2$ on $[0,3]$ | $3/2$ | $11/6$ | $11/9$ |
| $v = 2t^2-6t+4$ on $[0,3]$ | $3 = 3.0000000000$ | $11/3 = 3.6666666667$ | $11/9$ |

Doubling the velocity doubles both answers and changes nothing else, because the roots are unmoved.
Rescaling **time**, though, is not a doubling: from section 8, the three coefficients carry three different powers of $T$, so each is rescaled differently.

### Family 9 - the graph or table version

**Trigger.** $v$ is given as a picture or a list of values rather than a formula.
**Tool.** Displacement is the **signed area** between the curve and the $t$-axis; distance is the **total area**, counting area below the axis as positive.

This is the same question wearing Q19.1's clothes.
Read the zeros off the picture, take the areas of the pieces, and the only new skill is estimating an area rather than integrating one.

## 11. The trap list

Ranked by how often each actually costs a mark, given that eleven of nineteen wrong methods land on the same number.

1. **Answering part (b) with part (a)'s number.** The defining mistake, and the reason this question exists. Eleven distinct wrong methods produce it. Nothing about the answer looks wrong.
2. **Not looking for the zeros at all.** The upstream cause of trap 1. The fix is a habit, not a technique: factor $v$ before you do anything else.
3. **Splitting at only one root.** Half the work, none of the benefit - it still returns $3/2$.
4. **Splitting at the vertex instead of the roots.** $t = 3/2$ is where the acceleration vanishes, not the velocity. Also returns $3/2$.
5. **Writing $\lvert\int v\rvert$ instead of $\int\lvert v\rvert$.** The bars belong inside. This is trap 1 in symbols.
6. **Forgetting the absolute values after correctly splitting.** The most painful one, because all the hard work is done and the answer is still $3/2$.
7. **Forgetting an initial condition** when the wording says "position" rather than "displacement". Invisible on this stem, fatal on Q19.9.
8. **Assuming a zero of $v$ forces a split.** A double root does not - see Family 1's last row.
9. **Reading "speeding up" as $a > 0$.** Costs Family 5 rows.
10. **Rounding $11/6$.** Möbius is machine-marked; `1.83` is not $11/6$.

## 12. Drill set

Score **sign** separately from **magnitude**.
They fail for different reasons and need different fixes: a wrong magnitude means an arithmetic slip in $S$, and a wrong sign means you did not track which pieces were negative.

Throughout, $v(t) = t^2 - 3t + 2$ m/s unless stated otherwise.

1. Displacement on $[0,2]$.
2. Distance travelled on $[0,2]$.
3. Displacement on $[1,2]$.
4. Distance travelled on $[1,2]$.

10. For $u(t) = \sin(\pi t)$ on $[0,2]$: displacement and distance.

## 13. The one-page decision tree

```
                 read the NOUN in the question
                              |
   +--------------+-----------+-----------+----------------+
   |              |                       |                |
displacement   distance /             position at b    average of ...
net change     total distance              |                |
   |              |                        |          divide the matching
   |              |                    x(a) + int v     integral by (b-a)
   |              |
   |         solve v(t) = 0
   |              |
   |     any root STRICTLY inside (a,b)
   |     where v CHANGES SIGN?
   |          /            \
   |        NO              YES
   |         |               |
   |    distance =      split at each one
   |    |int v|         integrate v on each piece
   |         |          add the ABSOLUTE VALUES
   |         |               |
   +---------+---------------+
                     |
              int v dt via S(b) - S(a)
                     |
      CHECK 1  distance > |displacement|  (strict if a sign change exists)
      CHECK 2  gap = 2 x |sum of negative pieces|
      CHECK 3  units are metres, not m/s

                     |
              PREVIEW in Mobius
```

The single most valuable node is "where $v$ **changes sign**".
Not "where $v = 0$", and not "where $a = 0$".
Getting that node right is worth the whole of part (b).
