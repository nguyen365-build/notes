# Q4.1 - Vertical and horizontal asymptotes of a rational function

**The question (MT2 Q6, 10 points).**
Find the vertical and horizontal asymptotes of the function

$$f(x) = \frac{x^{2} - 3x - 4}{x^{2} - 16}.$$

**The answer.**

$$\textbf{Vertical asymptote: } x = -4 \ \textbf{ only.}
\qquad
\textbf{Horizontal asymptote: } y = 1 \ \textbf{ in both directions.}$$

$$\text{And the thing the question is really about: } x = 4 \text{ is a }
\textbf{hole}\text{, not an asymptote, at height } \tfrac58 = 0.625.$$

| the vertical asymptote | `x=-4` |
| the horizontal asymptote | `y=1` |
| how many vertical asymptotes | `1` |
| the hole, if a box asks for it | `(4,5/8)` |
| the simplified function, if asked | `(x+1)/(x+4)` |
| the domain | `(-infinity,-4)U(-4,4)U(4,infinity)` |
| the one-sided behaviour at the asymptote | `infinity` from the left, `-infinity` from the right |

> A zero of the denominator is a vertical asymptote only if it **survives cancellation**.
> Factor both halves first, cancel what cancels, and only then read the asymptotes off what is left;

## 0. The 30-second version

The examiner wrote a numerator that shares a factor with the denominator.
That is the entire question.
Everything else is the two rules you already know.

```
Find the vertical and horizontal asymptotes of f(x) = (x^2-3x-4)/(x^2-16).

STEP 1  FACTOR BOTH.  Never solve "denominator = 0" before you factor.
        x^2 - 3x - 4 = (x-4)(x+1)          two numbers: sum 3, product -4  ->  4 and -1
        x^2 - 16     = (x-4)(x+4)          difference of squares

STEP 2  CANCEL.  f(x) = (x-4)(x+1) / [(x-4)(x+4)] = (x+1)/(x+4),  x != 4

STEP 3  VERTICAL = the zeros that SURVIVED.
        x + 4 = 0  ->  x = -4          numerator there is -3, not 0, so it really blows up
        x = 4 CANCELLED  ->  a HOLE at (4, 5/8),  NOT an asymptote

STEP 4  HORIZONTAL = the degree rule.  deg 2 over deg 2, leading coefficients 1 and 1.
        y = 1        and it is the same limit at +inf and at -inf

ANSWER  Vertical: x = -4 only.   Horizontal: y = 1.   Hole at (4, 5/8).
CHECK   f(-4.1) = +31 and f(-3.9) = -29   (blows up, opposite signs)
        f(3.999) = 0.6249 and f(4.001) = 0.6251   (does NOT blow up: a hole)
        f(100) = 101/104 = 0.971 and f(-100) = 99/96 = 1.031   (settling on 1 from both sides)
```

The whole thing is four lines and no calculator.
If you factored, you got it.
If you set $x^{2}-16=0$ and wrote "$x=4$ and $x=-4$", you got half of it, and the half you lost is the
half the examiner was aiming at.

## 2. The five things you must have cold

### 2.1 Both asymptotes are limit statements, and nothing else

Everything in this topic is a definition about limits wearing geometric clothes.

| Kind | The definition | What you compute |
| :--- | :--- | :--- |
| Vertical asymptote at $x=a$ | $\displaystyle\lim_{x \to a^{-}} f(x) = \pm\infty$ **or** $\displaystyle\lim_{x \to a^{+}} f(x) = \pm\infty$ | a one-sided limit at a finite point |
| Horizontal asymptote $y = L$ | $\displaystyle\lim_{x \to +\infty} f(x) = L$ **or** $\displaystyle\lim_{x \to -\infty} f(x) = L$ | a limit at infinity |
| Slant asymptote $y = mx+b$ | $\displaystyle\lim_{x \to \pm\infty}\bigl[f(x) - (mx+b)\bigr] = 0$ | the same limit, after subtracting a line |
| Hole (removable discontinuity) at $x=a$ | $\displaystyle\lim_{x \to a} f(x)$ exists and is **finite**, but $f(a)$ is undefined | a two-sided finite limit |

Three consequences of reading the definitions literally, which is where the marks are.

**One side is enough for a vertical asymptote.**
The word "or" is in the definition.
$\ln x$ has a vertical asymptote at $x=0$ even though it is not defined at all on the left.

**Both ends are separate questions for a horizontal asymptote.**
A function can have one, or two different ones, or none.
$\arctan x$ has two, at $y=\pi/2$ and $y=-\pi/2$.
For a rational function the two ends always agree, which is a convenience specific to rational
functions and not a general fact.

**A horizontal asymptote is an end-behaviour statement, not a fence.**
The graph is allowed to cross it, and many graphs do.
Only vertical asymptotes are barriers, and that is because the function is not defined there.

### 2.2 The degree rule, all four cases

Let $f(x) = \dfrac{N(x)}{D(x)}$ with $n = \deg N$ and $d = \deg D$, **after cancelling**.

| Case | Horizontal asymptote | Slant asymptote | Why |
| :--- | :--- | :--- | :--- |
| $n < d$ | $y = 0$ | none | the bottom outgrows the top |
| $n = d$ | $y = \dfrac{\text{leading coef of } N}{\text{leading coef of } D}$ | none | the two growths match, so the ratio settles |
| $n = d + 1$ | **none** | $y = mx+b$ from long division | the quotient is a line |
| $n > d + 1$ | **none** | none | it runs off faster than any line |

The rule reads **leading terms only**.
It does not read the constant terms, and it does not read how many terms there are.
For Q4.1 that means comparing $x^{2}$ with $x^{2}$, giving $1/1 = 1$, and the $-3x-4$ and the $-16$
have nothing to do with it.

Here is the same rule as the algebra it is short for, which is worth doing once so that you trust it.
Divide the top and the bottom by the highest power in the **denominator**.

$$\frac{x^{2}-3x-4}{x^{2}-16}
=\frac{1-\dfrac{3}{x}-\dfrac{4}{x^{2}}}{1-\dfrac{16}{x^{2}}}
\xrightarrow[\ x\to\pm\infty\ ]{}\frac{1-0-0}{1-0}=1$$

Every term with an $x$ underneath dies, and the sign of $x$ never enters, which is exactly why a
rational function has the same horizontal asymptote at both ends.

### 2.3 Factoring the two quadratics in five seconds each

You cannot do this question without factoring, and factoring is where the clock goes.

**$x^{2}-3x-4$.**
Find two numbers with **sum $+3$** and **product $-4$**, then write $(x-\text{first})(x-\text{second})$.
Opposite signs, because the product is negative.
$4$ and $-1$: sum $3$, product $-4$.
So $x^{2}-3x-4 = (x-4)(x+1)$.

**$x^{2}-16$.**
Difference of squares, $a^{2}-b^{2}=(a-b)(a+b)$, so $(x-4)(x+4)$.

| Pattern | Factored | Recognise it by |
| :--- | :--- | :--- |
| $x^{2}-16$ | $(x-4)(x+4)$ | a square minus a square, no middle term |
| $x^{2}-3x-4$ | $(x-4)(x+1)$ | sum $3$, product $-4$ |
| $x^{2}+3x-4$ | $(x+4)(x-1)$ | the same numbers, signs swapped |
| $x^{2}-5x+4$ | $(x-4)(x-1)$ | product positive, sum positive, both roots positive |
| $x^{2}-16$ vs $x^{2}+16$ | factors vs does **not** factor over the reals | a **sum** of squares has no real root |

That last row is a real exam trap in its own right.
$x^{2}+16$ is never zero, so a function with it in the denominator has no vertical asymptote at all.

**The five-second sanity check on any factoring.**
Multiply the two constants and compare with the constant term you started with.
$(-4)(+1) = -4$, which matches.
Then add them: $-4+1 = -3$, which matches the middle coefficient.

### 2.4 Hole against vertical asymptote: it is a multiplicity comparison

Write both halves in factored form and look at one root at a time.
Let $(x-a)$ appear to power $p$ upstairs and power $q$ downstairs.

| Comparison | What $x=a$ is | Example |
| :--- | :--- | :--- |
| $q > p$ | a **vertical asymptote**, of multiplicity $q-p$ | $\dfrac{x-1}{(x-1)^{2}}=\dfrac{1}{x-1}$ |
| $q = p$ | a **hole**, at the height the reduced function gives | $\dfrac{(x-4)(x+1)}{(x-4)(x+4)}$ at $x=4$ |
| $q < p$ | a **hole**, at height $0$ | $\dfrac{(x-1)^{2}}{x-1}=x-1$ at $x=1$ |
| $q \geq 1$, $p = 0$ | a **vertical asymptote** | the ordinary case, $\dfrac{1}{x-2}$ |

The row that catches people is the first one.
"A factor cancelled, so it is a hole" is **wrong** when the denominator had more copies than the
numerator.
In $\dfrac{x-1}{(x-1)^{2}}$ a factor does cancel and $x=1$ is still an asymptote, because one copy is
left downstairs.

**The height of a hole** is whatever the reduced function gives when you substitute.
For Q4.1 the reduced function is $\dfrac{x+1}{x+4}$, and at $x=4$ that is $\dfrac{5}{8}$.
This is exactly a $0/0$ limit computed by cancelling, which is Q3.1a and Q3.2a all over again.
The topic heading changed; the mathematics did not.

### 2.5 The sign test at a vertical asymptote

Once you know $x=a$ is an asymptote, saying *which* infinity is a separate piece of work, and on this
paper it is often a separate box.

> Write the reduced function.
> Substitute $x=a$ into the **numerator** and keep its sign.
> Then ask what sign the **denominator** takes just left of $a$, and just right of $a$.
> Divide the signs.

For $f = \dfrac{x+1}{x+4}$ at $a=-4$:

| side | numerator $x+1$ | denominator $x+4$ | quotient | limit |
| :--- | :--- | :--- | :--- | :--- |
| $x \to -4^{-}$, e.g. $x=-4.1$ | $-3.1$, negative | $-0.1$, negative | positive | $+\infty$ |
| $x \to -4^{+}$, e.g. $x=-3.9$ | $-2.9$, negative | $+0.1$, positive | negative | $-\infty$ |

$f(-4.1) = 31$ exactly, and $f(-3.9) = -29$ exactly, which is a check you can do in your head.

**The parity shortcut.**
If the surviving factor $(x-a)$ has **odd** multiplicity, the two sides have opposite signs.
If it has **even** multiplicity, they have the same sign.
Here the multiplicity is $1$, so the signs are opposite, so
$\lim_{x \to -4} f(x)$ **does not exist**, and writing "$= +\infty$" is wrong.
Contrast $\dfrac{1}{(x-2)^{2}}$, where the multiplicity is $2$ and the limit genuinely is $+\infty$ on
both sides.

## 3. The universal procedure

This works on every version of this question in Section 8.

> 1. **Factor the numerator and the denominator completely.** Do this before anything else. Every error in this topic that is not an arithmetic slip comes from skipping this step.
> 2. **Cancel every common factor, and write down what you cancelled.** The cancelled roots are your candidate holes and you will need them again in step 5.
> 3. **Vertical asymptotes: set the REDUCED denominator to zero.** Each real root is an asymptote. Confirm the reduced numerator is nonzero there, which after a full cancellation it always is.
> 4. **Horizontal asymptote: compare the degrees of the REDUCED numerator and denominator.** Use the four-case table in 2.2. If the gap is exactly one, do the long division and report a slant asymptote instead.
> 5. **Holes: for each factor you cancelled, substitute its root into the reduced function.** That value is the height. Compare multiplicities first, per 2.4, because a partial cancellation is still an asymptote.
> 6. **Sign test at each vertical asymptote, if the question or the box asks for behaviour.** Use 2.5, and remember odd multiplicity means the sides disagree and the limit does not exist.
> 7. **State the domain if asked.** Every root of the ORIGINAL denominator is excluded, holes included. The hole is still not in the domain.

Step 7 is worth a sentence because it is the one people get backwards.
Cancelling changes the formula, not the function.
$x=4$ is excluded from the domain of $f$ even though $\dfrac{x+1}{x+4}$ is perfectly happy there.

**Classify before you start.**
One look at the factored form tells you which family you are in and therefore what to write.

| What you see after factoring | Vertical | Horizontal | Family |
| :--- | :--- | :--- | :--- |
| no common factor, $\deg N = \deg D$ | every root of $D$ | ratio of leading coefficients | 0 |
| no common factor, $\deg N < \deg D$ | every root of $D$ | $y=0$ | 0 |
| a common factor cancels completely | the **surviving** roots only | degree rule on the reduced form | **1** |
| a repeated factor downstairs | still an asymptote, sign set by parity | unchanged | 2 |
| the denominator has no real root | **none** | degree rule | 3 |
| $\deg N = \deg D + 1$ | roots of $D$ | none, a **slant** instead | 4 |
| a square root or $\lvert x \rvert$ is present | roots of $D$ in the domain | possibly **two different** ones | 5 |
| the graph meets its own horizontal line | unchanged | still a horizontal asymptote | 6 |
| $e^{x}$, $\ln$, $\arctan$, $\tan$ | wherever it blows up | one, two, or none | 7 |
| $\lvert x \rvert$ inside a rational function | branch by branch, they can differ | branch by branch | 8 |
| the question gives the asymptotes and asks for a function | build $D$ from the roots | build the leading ratio | 9 |
| the whole denominator cancels | **none**, it is a polynomial with a hole | none | 10 |
| the question says "sketch the graph" | same work, step three of five | same | 11 |
| the question is phrased with $\lim$ | translate, then do the same work | translate | 12 |

**Q4.1 is Family 1**, and Family 1 exists precisely because the naive route gets Family 0's answer.

## 4. Q4.1 worked four ways

### Route A - factor, cancel, then read off (use this one)

$$f(x)=\frac{x^{2}-3x-4}{x^{2}-16}
=\frac{(x-4)(x+1)}{(x-4)(x+4)}
=\frac{x+1}{x+4},\qquad x \neq 4$$

**Vertical.**
The reduced denominator $x+4$ vanishes at $x=-4$.
The reduced numerator there is $-4+1=-3 \neq 0$, so the quotient is $-3/0$ and the function blows up.
$x=-4$ is a vertical asymptote.

**The cancelled factor.**
$x=4$ was cancelled once from a single copy upstairs and a single copy downstairs, so $p=q=1$ and it is
a hole.
Its height is $\dfrac{4+1}{4+4}=\dfrac58$.

**Horizontal.**
Reduced degrees are $1$ over $1$, leading coefficients $1$ and $1$, so $y=1$.
Or compare the original degrees, $2$ over $2$, same answer, because cancelling a common factor cannot
change the leading ratio.

**Answer.** Vertical $x=-4$; horizontal $y=1$; hole at $\left(4,\tfrac58\right)$.

### Route B - solve "denominator = 0" without factoring (the route that loses the marks)

$$x^{2}-16=0 \implies x = 4 \ \text{ or } \ x = -4$$

"Therefore there are vertical asymptotes at $x=4$ and $x=-4$."

This is wrong, and it is wrong in the most dangerous way: it is fast, it looks finished, and it gets
the horizontal asymptote right.
The degree rule still gives $y=1$, so half the answer is correct and nothing warns you about the
other half.

Here is the warning you should have generated yourself.
Substitute $x=4$ into the **numerator**: $16-12-4 = 0$.
A vertical asymptote needs the numerator to be nonzero there.
When both vanish you have $0/0$, which is the signature of a cancellation, and $0/0$ is a limit to be
computed, not an asymptote to be declared.

Route B is not useless.
It is Route A with step 1 skipped, and it is exactly right on every function where the numerator does
not share a root, which is most of them.
The fix is one substitution: **check the numerator at each root of the denominator before you call it
an asymptote.**

### Route C - straight from the limit definitions

If you distrust the shortcuts, or the question says "using limits", compute the four limits.

$$\lim_{x \to \infty}\frac{x^{2}-3x-4}{x^{2}-16}
=\lim_{x \to \infty}\frac{1-\frac{3}{x}-\frac{4}{x^{2}}}{1-\frac{16}{x^{2}}}
=\frac{1-0-0}{1-0}=1
\qquad\text{and the same as } x \to -\infty$$

$$\lim_{x \to 4}\frac{(x-4)(x+1)}{(x-4)(x+4)}
=\lim_{x \to 4}\frac{x+1}{x+4}=\frac58
\quad\text{finite, so a hole and not an asymptote}$$

$$\lim_{x \to -4^{-}}\frac{x+1}{x+4}=\frac{-3}{0^{-}}=+\infty,
\qquad
\lim_{x \to -4^{+}}\frac{x+1}{x+4}=\frac{-3}{0^{+}}=-\infty$$

This route produces the most complete answer, because the one-sided limits come out of it for free.
It is also the route the marker wants if the wording is "justify" or "using limits".

### Route D - rewrite as a shifted reciprocal

Do the division once and the whole graph appears.

$$\frac{x+1}{x+4}=\frac{(x+4)-3}{x+4}=1-\frac{3}{x+4}$$

Now read every feature straight off the form.

| feature | why |
| :--- | :--- |
| horizontal asymptote $y=1$ | the $\frac{3}{x+4}$ term vanishes at both ends |
| vertical asymptote $x=-4$ | that term blows up there |
| the graph **never** touches $y=1$ | $\frac{3}{x+4}=0$ has no solution |
| increasing on each branch | the derivative is $\frac{3}{(x+4)^{2}}>0$ |
| it is the graph of $-3/x$ shifted left $4$ and up $1$ | that is what the form says |

This is a hyperbola, not a mysterious object, and Route D is the one to use if the question continues
"and sketch it", which is the Family 11 follow-up.

### The route comparison

| | A: factor and cancel | B: denominator $=0$ | C: limits from the definition | D: rewrite as $1-\frac{3}{x+4}$ |
| :--- | :--- | :--- | :--- | :--- |
| Gets the horizontal asymptote | yes | yes | yes | yes |
| Gets the vertical asymptote | yes | **no, gives a false extra one** | yes | yes |
| Finds the hole | yes | no | yes | not directly |
| Gives the one-sided signs | after a sign test | no | **yes, for free** | yes |
| Gives the shape for a sketch | no | no | no | **yes** |
| Works on a slant-asymptote version | yes | partly | yes | yes, that *is* the division |
| Lines of work here | 4 | 2 | 8 | 5 |
| Risk | a factoring slip | a wrong answer that looks right | slow, and $0/0$ still needs Route A | you must do the division correctly |
| Verdict | **use this one under pressure** | never alone; use only as A's step 3 | use when the wording says "justify" | use when the question also says "sketch" |

**Under exam pressure: factor both, cancel, read the surviving roots and the leading ratio.**
Then spend the last ten seconds on the sign test at the asymptote and the height of the hole, because
those are usually the extra boxes.

## 5. The exam-ready write-up

If the paper you sit asks for method, these are the sentences that earn the marks.
Ten points wants roughly this much.

> Factoring gives
> $f(x)=\dfrac{(x-4)(x+1)}{(x-4)(x+4)}$, so for $x \neq 4$ we have $f(x)=\dfrac{x+1}{x+4}$.
>
> **Vertical.** The reduced denominator vanishes only at $x=-4$, where the numerator equals $-3 \neq 0$.
> Hence $\lim_{x\to-4^{-}}f(x)=+\infty$ and $\lim_{x\to-4^{+}}f(x)=-\infty$, and $x=-4$ is the only
> vertical asymptote.
> The two-sided limit at $-4$ therefore does not exist.
>
> **The other root of the denominator is not an asymptote.**
> The factor $(x-4)$ cancels, and $\lim_{x\to4}f(x)=\lim_{x\to4}\dfrac{x+1}{x+4}=\dfrac58$, which is
> finite.
> So $f$ has a removable discontinuity (a hole) at $\left(4,\tfrac58\right)$, not a vertical asymptote,
> although $x=4$ is still excluded from the domain.
>
> **Horizontal.** The numerator and denominator have equal degree with leading coefficients $1$ and
> $1$, so $\lim_{x\to\pm\infty}f(x)=1$ and $y=1$ is a horizontal asymptote in both directions.

Four things a marker looks for that students routinely skip.

**Saying why $x=-4$ survives**, by checking the numerator is nonzero there.
Without that sentence you have asserted an asymptote rather than shown one.

**Naming $x=4$ explicitly and disposing of it.**
An answer that lists only $x=-4$ and never mentions $x=4$ reads like a student who did not notice the
second root at all.
Say it out loud: the factor cancels, the limit is finite, it is a hole.

**Distinguishing "not an asymptote" from "in the domain".**
$x=4$ is not in the domain of $f$.
Cancelling produced a different function that happens to agree with $f$ everywhere else.

**Giving both one-sided limits at $x=-4$.**
This is where the last points live, and it is also the difference between "$\lim = \infty$" (wrong)
and "the limit does not exist; it is $+\infty$ from the left and $-\infty$ from the right" (right).

## 6. Verify before you commit

This takes about twenty seconds and it catches every error this question can produce.

**Test the asymptote by walking up to it.**
A vertical asymptote must produce a huge number, and the two sides must disagree if the multiplicity
is odd.

| $x$ | $f(x)$ | reading |
| :--- | :--- | :--- |
| $-4.1$ | $\dfrac{-3.1}{-0.1}=31$ | large and positive, so $+\infty$ from the left |
| $-3.9$ | $\dfrac{-2.9}{0.1}=-29$ | large and negative, so $-\infty$ from the right |
| $3.999$ | $\approx 0.6249$ | small, so **not** an asymptote |
| $4.001$ | $\approx 0.6251$ | small from the other side too, so a hole |

The contrast between rows two and three is the whole question in four arithmetic steps.
If $f(3.999)$ had come out in the thousands you would have been wrong about the hole.

**Test the horizontal asymptote by going far out, in both directions.**

$$f(100)=\frac{101}{104}\approx0.9712,\qquad f(-100)=\frac{99}{96}=1.03125$$

Both are close to $1$, and they approach from opposite sides, which matches
$f = 1 - \dfrac{3}{x+4}$: the correction is negative for $x>-4$ and positive for $x<-4$.

**Count the candidates.**
A quotient of two quadratics has at most two vertical asymptotes.
You found one, so exactly one factor must have cancelled, and you should be able to name it.
If you claim two asymptotes and no hole, check whether the numerator vanishes at either root.
If you claim one asymptote and no hole, you have lost a root somewhere.

**Check the hole height twice.**
Once from the reduced form, $\dfrac{4+1}{4+4}=\dfrac58$.
Once by walking in, $f(3.9999)=0.62498\ldots$, which rounds to $0.625$.
Two different computations, one number.

**The numbers worth memorising for this question.**

$$f(0)=\tfrac14,\qquad f(-1)=0,\qquad f\!\left(4^{\pm}\right)\to\tfrac58=0.625,\qquad
f(-5)=4,\qquad f(2)=\tfrac12$$

$$f(-4.1)=31,\qquad f(-3.9)=-29,\qquad f(100)=\tfrac{101}{104},\qquad f(-100)=\tfrac{99}{96}=1.03125$$

The first line is enough to sketch the right-hand branch from memory: it starts at $-\infty$ just
right of $-4$, crosses the $x$-axis at $-1$, passes $\left(0,\tfrac14\right)$, has a hole at
$\left(4,\tfrac58\right)$, and climbs towards $1$ without ever reaching it.

## 7. Answer-entry rules

Möbius is answer-only and machine-marked, so on a question whose mathematics is four lines the real
risk is the shape of the box.

| Rule | Do | Not |
| :--- | :--- | :--- |
| A vertical asymptote is an equation in $x$ | `x=-4` | `-4` alone, if the box shows `x =` already |
| A horizontal asymptote is an equation in $y$ | `y=1` | `x=1` |
| Exact heights | `5/8` | `0.625`, unless the box asks for decimals |
| The hole as a point | `(4,5/8)` | `4,5/8` without brackets |
| Infinity | `infinity`, `-infinity` | `inf`, `oo`, `∞` |
| No asymptote exists | `none` or `DNE`, whichever the item offers | a blank box |
| Two asymptotes in one box | `x=-4,x=4` if the item asks for a list | `x=-4 and x=4` |
| Multiplication | `3*x` | `3x` |
| The simplified function | `(x+1)/(x+4)` | `x+1/x+4` |
| The domain | `(-infinity,-4)U(-4,4)U(4,infinity)` | a comma between the intervals |

**The single most expensive answer on this question is `x=4, x=-4`.**
It is well formed, it parses, it is the answer to a question the examiner deliberately did not ask,
and it is what Route B produces.
Before you submit any vertical asymptote, substitute its $x$ into the **numerator** and confirm you do
not get zero.

**The second most expensive is `x+1/x+4`.**
Without brackets that parses as $x + \dfrac{1}{x} + 4$, which at $x=4$ gives $8.25$ instead of
$\dfrac58$.
Bracket the whole numerator and the whole denominator, every time.

**Two vertical asymptotes is a legitimate answer to other versions.**
Do not overcorrect.
$\dfrac{2x^{2}+5}{x^{2}-9}$ genuinely has asymptotes at $x=3$ and $x=-3$, because $2x^{2}+5$ is never
zero.
The rule is "check the numerator", not "expect a hole".

**The domain still excludes the hole.**
If a box asks for the domain, write three intervals, not two.
Removing two points always gives three intervals, and the point people drop is $4$, exactly the one
they just decided was "only a hole".

**Always click the preview icon.**
An empty preview means broken syntax, not wrong mathematics.

## 8. The variation catalog

This is the part that makes the question repeatable.
The families are organised by **what the factored form forces you to do**, not by what the function
looks like on the page.
Everything below was recomputed by two independent mechanisms.

Read the whole catalog as one idea seen thirteen times.
Only three things ever vary.
Whether a factor cancels, how the degrees compare, and whether the two ends of the graph behave the
same way.

### Family 0 - no common factor: the plain degree rule

**Trigger.** The numerator and denominator share no root. Substituting a root of the denominator into
the numerator gives something nonzero.
**Tool.** Roots of the denominator are all vertical asymptotes; the degree rule gives the horizontal one.
**The trap.** Assuming this family when you are actually in Family 1. The test is one substitution.

| function | vertical | horizontal | note |
| :--- | :--- | :--- | :--- |
| $\dfrac{3x^{2}+1}{x^{2}-4}$ | $x=2$, $x=-2$ | $y=3$ | $3x^{2}+1$ is never zero |
| $\dfrac{2x+1}{x^{2}-9}$ | $x=3$, $x=-3$ | $y=0$ | degree $1$ under degree $2$ |
| $\dfrac{x^{2}-1}{2x^{2}+3x}$ | $x=0$, $x=-\tfrac32$ | $y=\tfrac12$ | denominator is $x(2x+3)$ |
| $\dfrac{x^{2}-3x-4}{x^{2}+16}$ | **none** | $y=1$ | a **sum** of squares never vanishes |

Read this table as structure.
The vertical column is always just "solve $D=0$", and the horizontal column is always just "compare
two leading coefficients".
Row 4 is Q4.1 with one sign changed in the denominator, and that one sign removes both vertical
asymptotes and the hole at once.

### Family 1 - a factor cancels: a hole, not an asymptote. This is Q4.1

**Trigger.** A root of the denominator also makes the numerator zero. You have $0/0$ at that point.
**Tool.** Factor, cancel, then apply Family 0 to what is left. The cancelled roots are holes.
**The trap.** Reporting the cancelled root as an asymptote, which is Route B above.

| function | reduces to | horizontal | vertical | hole |
| :--- | :--- | :--- | :--- | :--- |
| $\dfrac{x^{2}-3x-4}{x^{2}-16}$ **(Q4.1)** | $\dfrac{x+1}{x+4}$ | $y=1$ | $x=-4$ | $\left(4,\tfrac58\right)$ |
| $\dfrac{x^{2}-1}{x^{2}-x}$ | $\dfrac{x+1}{x}$ | $y=1$ | $x=0$ | $(1,2)$ |
| $\dfrac{x^{2}-4}{x^{2}-5x+6}$ | $\dfrac{x+2}{x-3}$ | $y=1$ | $x=3$ | $(2,-4)$ |
| $\dfrac{x^{2}-9}{x^{2}+x-12}$ | $\dfrac{x+3}{x+4}$ | $y=1$ | $x=-4$ | $\left(3,\tfrac67\right)$ |
| $\dfrac{x^{2}-3x-4}{x^{2}-1}$ | $\dfrac{x-4}{x-1}$ | $y=1$ | $x=1$ | $\left(-1,\tfrac52\right)$ |
| $\dfrac{x^{2}+x-2}{x^{2}-4x+3}$ | $\dfrac{x+2}{x-3}$ | $y=1$ | $x=3$ | $\left(1,-\tfrac32\right)$ |
| $\dfrac{x-4}{x^{2}-16}$ | $\dfrac{1}{x+4}$ | $y=0$ | $x=-4$ | $\left(4,\tfrac18\right)$ |
| $\dfrac{x^{2}-16}{x^{2}-3x-4}$ | $\dfrac{x+4}{x+1}$ | $y=1$ | $x=-1$ | $\left(4,\tfrac85\right)$ |

Read this as structure rather than as eight facts.
The horizontal column is $y=1$ six times out of eight, because six of these are quadratic over
quadratic with matching leading coefficients, and that is not a coincidence: it is what "the examiner
wants the hole to be the interesting part" looks like.
Row 7 is the version where the numerator loses a degree in the cancellation, and it is the only row
where the horizontal asymptote moves, to $y=0$.
Row 8 is Q4.1 turned upside down: the same cancelled factor, so the same hole location, but a
completely different vertical asymptote, because the surviving factor is now the numerator's.

Row 5 deserves a second look.
It uses the **same numerator** as the exam question with a different denominator, so the shared factor
is now $(x+1)$ and not $(x-4)$.
A student who memorised "the hole is at $4$" instead of "the hole is where the factors match" gets
this one wrong.

### Family 2 - a repeated factor: the parity decides the signs

**Trigger.** A factor appears squared or cubed downstairs, or the same factor appears to different
powers on both sides.
**Tool.** Compare multiplicities per 2.4, then use parity for the sign pattern.
**The trap.** "Something cancelled, so it must be a hole." A partial cancellation is still an asymptote.

| function | at the root | left side | right side | two-sided limit |
| :--- | :--- | :--- | :--- | :--- |
| $\dfrac{1}{x-2}$ | asymptote, odd | $-\infty$ | $+\infty$ | does not exist |
| $\dfrac{1}{(x-2)^{2}}$ | asymptote, even | $+\infty$ | $+\infty$ | $=+\infty$ |
| $\dfrac{x}{(x-1)^{3}}$ | asymptote, odd | $-\infty$ | $+\infty$ | does not exist |
| $\dfrac{x+1}{(x-3)^{2}}$ | asymptote, even | $+\infty$ | $+\infty$ | $=+\infty$ |
| $\dfrac{x-1}{(x-1)^{2}}=\dfrac{1}{x-1}$ | **asymptote**, $q>p$ | $-\infty$ | $+\infty$ | does not exist |
| $\dfrac{(x-1)^{2}}{x-1}=x-1$ | **hole** at height $0$, $p>q$ | finite | finite | $=0$ |
| $\dfrac{\cos(\pi x)}{(x-2)^{2}}$ **[Q3.1f]** | asymptote, even | $+\infty$ | $+\infty$ | $=+\infty$ |

Rows 5 and 6 are the same two polynomials in the two possible orders and they land on opposite
verdicts.
That pair is the cheapest way to remember 2.4.

Note also that Q4.1's own answer sits in row 1's pattern: multiplicity one, so the sides disagree, so
the limit at $-4$ does not exist.
Saying "$\lim_{x\to-4}f(x)=\infty$" is a real error, not a shorthand.

### Family 3 - the denominator has no real root: no vertical asymptote at all

**Trigger.** The denominator is a sum of squares, or a quadratic with negative discriminant, or an
even power plus a positive constant.
**Tool.** Check the discriminant, or complete the square, and say so explicitly.
**The trap.** Solving $D=0$, getting complex numbers, and writing them down as asymptotes.

| function | why the denominator never vanishes | vertical | horizontal |
| :--- | :--- | :--- | :--- |
| $\dfrac{1}{x^{2}+1}$ | $x^{2}+1 \geq 1$ | none | $y=0$ |
| $\dfrac{2x^{2}+3}{x^{2}+4}$ | $x^{2}+4 \geq 4$ | none | $y=2$ |
| $\dfrac{x}{x^{2}+2x+5}$ | discriminant $4-20=-16<0$; minimum value $4$ | none | $y=0$ |
| $\dfrac{3x^{2}-4}{2x^{4}+2x+4}$ **[Q3.3a]** | no real root | none | $y=0$ |
| $\dfrac{x^{2}-3x-4}{x^{2}+16}$ | a sum of squares | none | $y=1$ |

The last row is worth thirty seconds against the exam question.
Changing $x^{2}-16$ to $x^{2}+16$ deletes the vertical asymptote, deletes the hole, and leaves the
horizontal asymptote untouched.
That is a very cheap reworking for an examiner to make, and it turns a 10-point question into a
one-liner whose only difficulty is noticing.

### Family 4 - degree gap of one: a slant asymptote instead of a horizontal one

**Trigger.** After cancelling, the numerator's degree is exactly one more than the denominator's.
**Tool.** Polynomial long division. The quotient is the slant asymptote; the remainder term vanishes.
**The trap.** Writing "no asymptote" because there is no horizontal one. There is one, it is just tilted.

| function | long division | slant | vertical | horizontal |
| :--- | :--- | :--- | :--- | :--- |
| $\dfrac{x^{2}+1}{x-1}$ | $x+1+\dfrac{2}{x-1}$ | $y=x+1$ | $x=1$ | none |
| $\dfrac{x^{2}-3x-4}{x+4}$ | $x-7+\dfrac{24}{x+4}$ | $y=x-7$ | $x=-4$ | none |
| $\dfrac{2x^{2}+1}{x}$ | $2x+\dfrac{1}{x}$ | $y=2x$ | $x=0$ | none |
| $\dfrac{5-2x^{3}}{x^{2}+2}$ **[Q3.1d]** | $-2x+\dfrac{4x+5}{x^{2}+2}$ | $y=-2x$ | none | none |
| $\dfrac{x^{3}+2}{x^{2}-1}$ | $x+\dfrac{x+2}{x^{2}-1}$ | $y=x$ | $x=1$, $x=-1$ | none |

Row 2 is Q4.1's numerator over Q4.1's denominator with one factor removed, so the cancellation no
longer happens and the degree gap opens up.
It is the most natural single edit an examiner can make to this question, and it changes the answer
completely: the hole disappears, $x=-4$ stays, and the horizontal asymptote becomes a slant.

Row 4 is the exam's own $\lim_{x\to\infty}\dfrac{5-2x^{3}}{x^{2}+2}$ from the six-limit question,
restated as an asymptote question.
The limit is $-\infty$, so there is no horizontal asymptote, but the graph does settle onto the line
$y=-2x$.

### Family 5 - the two ends disagree: two horizontal asymptotes

**Trigger.** A square root, an absolute value, or an exponential. Anything where replacing $x$ by $-x$
is not just a sign change in the leading term.
**Tool.** Do the two limits separately, and remember $\sqrt{x^{2}}=\lvert x \rvert$, which is $-x$ when
$x<0$.
**The trap.** Doing one limit and asserting the other by symmetry, which is only valid for rational functions.

| function | $x \to +\infty$ | $x \to -\infty$ | vertical |
| :--- | :--- | :--- | :--- |
| $\dfrac{\sqrt{x^{2}+1}}{x}$ | $y=1$ | $y=-1$ | $x=0$ |
| $\dfrac{3x}{\sqrt{4x^{2}+1}}$ | $y=\tfrac32$ | $y=-\tfrac32$ | none |
| $\dfrac{x}{\lvert x \rvert+1}$ | $y=1$ | $y=-1$ | none |
| $\dfrac{\sqrt{x^{2}-1}}{x^{2}-2x-8}$ | $y=0$ | $y=0$ | $x=4$, $x=-2$ |
| $\dfrac{x^{2}-3x-4}{x^{2}-16}$ **(Q4.1)** | $y=1$ | $y=1$ | $x=-4$ |

The last row is in the table on purpose.
Q4.1 belongs to the family where the two ends **agree**, and it agrees for a reason worth naming:
$\sqrt{x^{2}}$ never appears, so nothing distinguishes large positive $x$ from large negative $x$
except a sign that cancels top and bottom.
Every rational function is in that situation, which is why "the horizontal asymptote" (singular) is
safe language for rational functions and dangerous language for anything else.

Row 4 also carries a domain subtlety.
$\sqrt{x^{2}-1}$ needs $\lvert x \rvert \geq 1$, and both $4$ and $-2$ clear that, so both roots of
$x^{2}-2x-8=(x-4)(x+2)$ really are asymptotes.
Had a root fallen inside $(-1,1)$ it would not have been an asymptote, because the function does not
exist near it.

### Family 6 - a horizontal asymptote is not a barrier

**Trigger.** The question asks whether the graph can cross an asymptote, or a sketch appears to cross one.
**Tool.** Solve $f(x)=L$. Solutions are crossings, and crossings are perfectly legal.
**The trap.** Believing a graph is trapped on one side of its horizontal asymptote.

| function | horizontal | crosses it at | comment |
| :--- | :--- | :--- | :--- |
| $\dfrac{x}{x^{2}+1}$ | $y=0$ | $x=0$ | crosses once, then returns |
| $\dfrac{x^{2}-2x}{x^{2}+1}$ | $y=1$ | $x=-\tfrac12$ | crosses once |
| $\dfrac{2x^{2}-3x}{x^{2}+1}$ | $y=2$ | $x=-\tfrac23$ | crosses once |
| $\dfrac{\sin x}{x}$ | $y=0$ | $x=k\pi$, every one | crosses infinitely often |
| $\dfrac{x^{2}-3x-4}{x^{2}-16}$ **(Q4.1)** | $y=1$ | **never** | $1-\dfrac{3}{x+4}=1$ has no solution |

Q4.1 happens not to cross, and it is worth knowing *why* rather than assuming it is a rule.
The reason is visible only in Route D's form: reaching the asymptote would need $\dfrac{3}{x+4}=0$, and
a nonzero constant over anything is never zero.
A vertical asymptote is different and genuinely is a barrier, because the function is not defined
there at all.

### Family 7 - not a rational function

**Trigger.** $e^{x}$, $\ln$, $\arctan$, $\tan$, or a logistic-shaped quotient.
**Tool.** The definitions in 2.1 directly. The degree rule does not apply and must not be quoted.
**The trap.** Reaching for degrees when there are no degrees.

| function | horizontal | vertical | comment |
| :--- | :--- | :--- | :--- |
| $e^{x}$ | $y=0$ at $-\infty$ only | none | one end has an asymptote, the other does not |
| $e^{-x}$ | $y=0$ at $+\infty$ only | none | the mirror image |
| $\ln x$ | none | $x=0$, from the right | one-sided, and still an asymptote |
| $\arctan x$ | $y=\tfrac{\pi}{2}$ and $y=-\tfrac{\pi}{2}$ | none | **two** horizontal asymptotes |
| $\tan x$ | none | $x=\tfrac{\pi}{2}+k\pi$, infinitely many | **[Q3.3b]** |
| $\dfrac{1}{e^{x}-1}$ | $y=0$ at $+\infty$, $y=-1$ at $-\infty$ | $x=0$, sides disagree | two different horizontal asymptotes |
| $\dfrac{2^{x}}{2^{x}+1}$ | $y=1$ at $+\infty$, $y=0$ at $-\infty$ | none | the logistic shape |

Row 5 is Q3.3(b) on the same paper, which asks for $\lim_{x\to5\pi/2}\tan x$.
That limit does not exist precisely because $5\pi/2 = \pi/2 + 2\pi$ is one of $\tan$'s vertical
asymptotes and the two sides disagree, which is the same sentence as Q4.1's answer at $x=-4$ with a
different function in it.

### Family 8 - an absolute value splits the function into branches

**Trigger.** $\lvert x \rvert$ or $\lvert x-a \rvert$ appears anywhere.
**Tool.** Split into $x \geq 0$ and $x < 0$ (or at the point inside the bars) and analyse each branch
separately. Use $x^{2}=\lvert x \rvert^{2}$ when it helps.
**The trap.** Treating $\lvert x \rvert$ as $x$, which is the same trap as Q1.3.

| function | branch $x>0$ | branch $x<0$ | net result |
| :--- | :--- | :--- | :--- |
| $\dfrac{x^{2}-3\lvert x \rvert-4}{x^{2}-16}$ | $\dfrac{x+1}{x+4}$ | $\dfrac{x-1}{x-4}$ | **no vertical asymptote at all**; holes at $\left(4,\tfrac58\right)$ and $\left(-4,\tfrac58\right)$; $y=1$ both ends |
| $\dfrac{\lvert x \rvert}{x-2}$ | $\dfrac{x}{x-2}$ | $\dfrac{-x}{x-2}$ | asymptote $x=2$; $y=1$ at $+\infty$ and $y=-1$ at $-\infty$ |
| $\dfrac{x^{2}-4}{\lvert x-2 \rvert}$ | $x+2$ for $x>2$ | $-(x+2)$ for $x<2$ | at $x=2$ a **jump** from $-4$ to $4$, neither hole nor asymptote |

Row 1 is the single most instructive variation in this whole document.
It is Q4.1 with three characters changed, and it has **no vertical asymptote**.
For $x>0$ the numerator factors as $(x-4)(x+1)$, cancelling the $(x-4)$; for $x<0$ it becomes
$x^{2}+3x-4=(x+4)(x-1)$, cancelling the $(x+4)$.
Each branch cancels the root that lives in it, so both roots of $x^{2}-16$ turn into holes, and both
holes sit at the same height $\tfrac58$.

Row 3 is the reminder that "the denominator is zero" has a third possible meaning.
The two one-sided limits are finite and different, so there is a jump discontinuity, which is neither
of the two things this question asks about.

### Family 9 - the reverse question: build a function with given asymptotes

**Trigger.** "Give an example of a function with ...", or "find $k$ so that ...".
**Tool.** Put the vertical asymptotes in the denominator as factors, and set the leading ratio to the
horizontal asymptote.
**The trap.** Building a function whose numerator accidentally shares a root with the denominator, so
your asymptote is a hole.

| specification | one answer | check |
| :--- | :--- | :--- |
| vertical $x=3$, horizontal $y=2$ | $\dfrac{2x}{x-3}=2+\dfrac{6}{x-3}$ | $2x$ is nonzero at $3$ |
| vertical $x=\pm1$, horizontal $y=0$ | $\dfrac{1}{x^{2}-1}$ | numerator never zero |
| vertical $x=-4$, horizontal $y=1$, hole at $x=4$ | $\dfrac{(x-4)(x+1)}{(x-4)(x+4)}$ | **this is Q4.1**, built backwards |
| vertical $x=2$, slant $y=x$ | $x+\dfrac{1}{x-2}=\dfrac{(x-1)^{2}}{x-2}$ | degree $2$ over degree $1$ |
| horizontal $y=3$ and $y=0$, no vertical | $\dfrac{3}{1+e^{-x}}$ | denominator $>1$ always |
| find $k$: $\dfrac{kx^{2}+1}{x^{2}-4}$ has $y=5$ | $k=5$ | the leading ratio is $k/1$ |
| find $a$: $\dfrac{x^{2}-a}{x-3}$ has a hole at $3$ | $a=9$ | the numerator must vanish at $3$ |

Row 3 is the exam question stated in reverse, and building it once is the fastest way to understand
why it was set.
The examiner chose a numerator that shares exactly one root with the denominator, which is the minimum
edit that turns a routine Family 0 question into a discriminating one.

### Family 10 - degenerate cases

**Trigger.** The denominator divides the numerator completely, or the function is already a polynomial.
**Tool.** Divide it out and look at what you have. Often the honest answer is "no asymptotes".
**The trap.** Assuming every question in this topic must have an answer of each kind.

| function | what it really is | vertical | horizontal |
| :--- | :--- | :--- | :--- |
| $\dfrac{x^{2}-16}{x-4}=x+4$, $x \neq 4$ | a **line** with a hole at $(4,8)$ | none | none |
| $\dfrac{(x-4)^{2}}{x-4}=x-4$, $x \neq 4$ | a line with a hole at $(4,0)$ | none | none |
| $\dfrac{x-4}{(x-4)^{2}}=\dfrac{1}{x-4}$ | a hyperbola | $x=4$ | $y=0$ |
| $x^{2}-3x-4$ | a parabola | none | none |
| $\dfrac{x^{2}+1}{x^{2}+1}=1$ | the constant $1$ | none | $y=1$, and the graph *is* the line |

Rows 1 and 3 are the same two factors in the two possible orders, and they land on opposite answers,
which is 2.4 restated one final time.
Row 5 is the pedantic case: the limit at infinity is $1$, so by the definition $y=1$ is a horizontal
asymptote, even though the graph coincides with it rather than approaching it.
Most textbooks accept this; if a question ever hinges on it, say what you mean rather than just
writing the equation.

### Family 11 - asymptotes as step three of a curve sketch

**Trigger.** "Sketch the graph. State all critical points, cusps, vertical asymptotes and points of
inflection."
**Tool.** The same work as Q4.1, dropped into a fixed five-step order.
**The trap.** Sketching from the derivative alone and never establishing the frame.

> The order that never fails: **domain, intercepts, asymptotes, $f'$, $f''$.**
> Asymptotes come third because they are the frame the rest of the curve hangs on.

| function | vertical | horizontal | source |
| :--- | :--- | :--- | :--- |
| $\dfrac{x^{2}}{x^{2}-1}$ | $x=1$, $x=-1$ | $y=1$ | Final Exam 1, Q4a, 20 points |
| $x+\sin x$ | none | none | Final Exam 1, Q4b |
| $\dfrac{x^{2}-3x-4}{x^{2}-16}$ | $x=-4$ | $y=1$ | Q4.1, plus a hole at $\left(4,\tfrac58\right)$ |

$\dfrac{x^{2}}{x^{2}-1}$ is the closest relative of the exam question on the final paper, and it is
Family 0 rather than Family 1: the numerator $x^{2}$ does not vanish at $\pm1$, so both roots really
are asymptotes.
Working the two side by side is the best single drill for this topic, because they differ only in
whether the cancellation happens.

For Q4.1 the finished sketch is two branches of a hyperbola.
Left branch, $x<-4$: comes down from $+\infty$ just left of $-4$ and decreases towards $y=1$ from
above, passing $(-5,4)$ and $(-8,1.75)$.
Right branch, $x>-4$: rises from $-\infty$ just right of $-4$, crosses the $x$-axis at $(-1,0)$,
passes $\left(0,\tfrac14\right)$, has an open circle at $\left(4,\tfrac58\right)$, and climbs towards
$y=1$ from below without reaching it.

### Family 12 - the same facts written as limit statements

**Trigger.** The question gives conditions like "$\lim_{x\to3}f(x)=\infty$" and asks you to interpret
or to sketch, which is Q5.1, Q5.2 and Q5.3 on this paper.
**Tool.** Translate each statement into a feature, then draw.
**The trap.** Reading "$\lim = \infty$" as "the limit exists".

| Statement | Feature |
| :--- | :--- |
| $\displaystyle\lim_{x\to\infty}f(x)=L$ | horizontal asymptote $y=L$ on the right |
| $\displaystyle\lim_{x\to-\infty}f(x)=L$ | horizontal asymptote $y=L$ on the left |
| $\displaystyle\lim_{x\to a}f(x)=\infty$ | vertical asymptote $x=a$, **same** sign on both sides |
| $\displaystyle\lim_{x\to a^{-}}f=+\infty$ and $\displaystyle\lim_{x\to a^{+}}f=-\infty$ | vertical asymptote $x=a$, and the two-sided limit does **not exist** |
| $\displaystyle\lim_{x\to a}f(x)=L$ but $f(a)$ undefined | a **hole** at $(a,L)$ |
| $\displaystyle\lim_{x\to a}f(x)$ does not exist, both sides finite | a **jump**, not an asymptote |

Row 4 is Q4.1's own answer at $x=-4$, and row 5 is Q4.1's own answer at $x=4$.
The exam asks the same two facts twice on the same paper, once as an asymptote question and once as a
sketching question, so the translation table is worth memorising in both directions.

## 9. The trap list

Ranked by how often each one actually costs marks on this question.

1. **Solving $x^{2}-16=0$ and declaring both roots to be vertical asymptotes.** This is the error the question was built to catch. Factor the numerator too, or at minimum substitute each root of the denominator into the numerator and confirm you do not get zero. At $x=4$ the numerator is $16-12-4=0$, which is the whole story.
2. **Calling $x=4$ a hole and then also putting it back in the domain.** Cancelling changes the formula, not the function. $f(4)$ is still undefined, so the domain is $(-\infty,-4)\cup(-4,4)\cup(4,\infty)$, three intervals, not two.
3. **Writing $\lim_{x\to-4}f(x)=+\infty$.** The two sides disagree in sign, so no single infinite value is correct. The limit does not exist; quote $+\infty$ from the left and $-\infty$ from the right.
4. **Assuming that because something cancelled, there is no asymptote there.** In $\dfrac{x-1}{(x-1)^{2}}$ a factor cancels and $x=1$ is still an asymptote. Compare multiplicities, do not just look for a cancellation.
5. **Using the constant terms in the degree rule.** The rule reads leading terms only. For Q4.1 that is $x^{2}$ against $x^{2}$, so $y=1$; the $-3x-4$ and the $-16$ are irrelevant to it.
6. **Reporting "no asymptote" when the degrees differ by one.** There is one, it is slanted, and you get it from long division. This is Family 4, and $\dfrac{x^{2}-3x-4}{x+4}$ is the exam question one edit away from it.
7. **Assuming both ends give the same horizontal asymptote.** They do for every rational function, and they do not once a square root, an absolute value or an exponential appears. $\dfrac{\sqrt{x^{2}+1}}{x}$ has two.
8. **Thinking a graph cannot cross a horizontal asymptote.** It often does. Only vertical asymptotes are barriers.
9. **Not doing the sign test at all.** Once you have $-3/0$ the sign work *is* the remaining question, and on a 10-point item it is usually a separate box.
10. **Getting the factoring signs backwards.** $x^{2}-3x-4=(x-4)(x+1)$, not $(x+4)(x-1)$, which is $x^{2}+3x-4$. Multiply back and check both the constant and the middle coefficient.
11. **Treating a sum of squares as factorable.** $x^{2}+16$ has no real root, so $\dfrac{x^{2}-3x-4}{x^{2}+16}$ has no vertical asymptote at all.
12. **Treating a jump as an asymptote.** $\dfrac{x^{2}-4}{\lvert x-2 \rvert}$ has finite one-sided limits $-4$ and $4$ at $x=2$. Nothing blows up, so nothing is an asymptote.
13. **Forgetting the hole entirely.** On a 10-point question that asks only for "asymptotes", the hole is still the discriminating observation, and the marker is looking for the sentence that disposes of $x=4$.

## 10. Drill set

No answers beside the questions.
Do all twelve on paper in under twenty minutes, then check.
For each one, give **every** vertical asymptote, the horizontal asymptote (or the slant, or "none"),
and any hole with its height.

1. $f(x)=\dfrac{x^{2}-2x-8}{x^{2}-4}$
2. $f(x)=\dfrac{2x^{2}+5}{x^{2}-9}$

## 11. The one-page decision tree

```
"Find the vertical and horizontal asymptotes of f(x) = N(x)/D(x)."
|
+-- STEP 0.  IS IT RATIONAL?
|      no  -> exponential / log / arctan / tan / |x| / sqrt   -> FAMILY 7, 8, or 5.
|             Use the LIMIT DEFINITIONS directly.  Do the two ends SEPARATELY.
|             There is no degree rule for these.
|      yes -> continue.
|
+-- STEP 1.  FACTOR BOTH.  Always.  Before anything else.
|             quadratics: two numbers, sum = -b, product = c
|             a^2 - b^2 = (a-b)(a+b)          a^2 + b^2 does NOT factor
|
+-- STEP 2.  CANCEL, and WRITE DOWN what you cancelled.
|             for each shared root a, compare the powers  p (top) and q (bottom):
|                  q > p   -> STILL A VERTICAL ASYMPTOTE  (partial cancel)
|                  q = p   -> HOLE, height = reduced f(a)
|                  q < p   -> HOLE, height = 0
|
+-- STEP 3.  VERTICAL = real roots of the REDUCED denominator.
|             no real roots?  (sum of squares, negative discriminant)  -> NONE.   [F3]
|             For each root, the SIGN TEST:
|                  numerator sign at a  /  denominator sign on each side
|                  multiplicity ODD  -> sides DISAGREE -> limit DOES NOT EXIST
|                  multiplicity EVEN -> sides AGREE    -> limit = +inf or -inf
|
+-- STEP 4.  HORIZONTAL = degrees of the REDUCED fraction.
|                  deg N <  deg D      ->  y = 0
|                  deg N =  deg D      ->  y = (lead N)/(lead D)
|                  deg N =  deg D + 1  ->  NO horizontal.  LONG-DIVIDE -> SLANT.  [F4]
|                  deg N >  deg D + 1  ->  NO horizontal, NO slant.
|             Rational function -> both ends give the SAME answer.
|             Anything else     -> do BOTH ends.                                  [F5]
|
+-- STEP 5.  DOMAIN, if asked.  Exclude EVERY root of the ORIGINAL denominator,
|             including the holes.  n removed points -> n+1 intervals.
|
+-- STEP 6.  CHECK, by arithmetic, in about fifteen seconds.
|             at each claimed VA:   f(a - 0.1) and f(a + 0.1) must be HUGE
|             at each claimed hole: f(a - 0.001) and f(a + 0.001) must be NORMAL
|             far out:              f(100) and f(-100) must sit near the claimed L
|             count:                deg-2 over deg-2 gives AT MOST 2 vertical asymptotes
|
+-- STEP 7.  TYPE IT.  x=-4  for a vertical,  y=1  for a horizontal,
             (4,5/8) for a hole, exact fractions not decimals, "infinity" spelled out,
             every numerator and denominator bracketed.  Then PREVIEW.
```
