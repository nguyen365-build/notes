# Q19.1 - Area between a line and a parabola

**The question (Final Exam 1, item 10, 8 points).** Find the area between the curves $y = x$ and $y = 2 - x^2$.

**The answer.** $\dfrac{9}{2} = 4.5000$

**What to type into Möbius:** `9/2`

Provenance: parsed out of `notes\MATH265\MATH265.md`, Final Exam 1 block, where the value is printed inline at the end of the stem in that paper's convention.
Final Exam 1 prints 14 values summing to 124, so this item is 6.45 percent of that paper.
Every number below was recomputed in Python before it was written: 18 wrong-answer candidates, five independent routes to the area, and a root census controlled in both directions.

## 0. The 30-second version

```
1. SET THE CURVES EQUAL      x = 2 - x^2   ->   x^2 + x - 2 = 0   ->   x = -2, x = 1
2. PICK A POINT BETWEEN      at x = -1/2 : parabola 1.7500 , line -0.5000 -> parabola on top
3. INTEGRATE (TOP - BOTTOM)  A = int_{-2}^{1} ( (2 - x^2) - x ) dx
4. EVALUATE                  [ 2x - x^3/3 - x^2/2 ]_{-2}^{1} = 7/6 - (-10/3) = 9/2
```

Four lines, and none of them needs a lookup.
Step 2 is the one students skip, and it is the one that costs the sign.

## 1. What this question is really testing

This question **opens the applications-of-integration block**, which is the largest category in the whole bank at nine questions (Q19.1 through Q19.9).
Everything in section 3 below is the foundation those other eight sit on, so it is worth over-learning here rather than re-learning eight times.

| The reflex it wants | Where it comes back |
| :--- | :--- |
| An integral of a *difference* measures the region between two graphs | Q19.2, and every area question ever set |
| Find the interval yourself when the question does not give one | Q19.1 and Q19.7 (where you solve for the endpoint) |
| Decide which curve is on top by evaluating, not by squinting | Q19.2, where the answer changes three times across the interval |
| An integral of a rate gives an accumulated amount | Q19.3, Q19.8, Q19.9 |
| Set up an integral from a physical description | Q19.4, Q19.5 |
| Divide an integral by the length of the interval | Q19.6, Q19.7 |
| Antidifferentiate a polynomial and evaluate | all nine |

The single sentence about its purpose: **the examiner is checking that you can turn a picture into a definite integral, in that order, and not the other way round.**
The integration itself is a two-term polynomial and is the easy part.

At 8 points it is one of the heavier items on Final Exam 1 (4 of the 14 items carry more, and the heaviest carries 20).
That weight is almost certainly for the setup rather than for the arithmetic, though no marking scheme exists anywhere in the course files, so treat that as inference and not as fact.

## 2. The five things you must have cold

**(a) Solving a quadratic, exactly.**

| Form | Method | Worked here |
| :--- | :--- | :--- |
| $x^2 + bx + c = 0$ with integer roots | factor | $x^2 + x - 2 = (x+2)(x-1)$ |
| anything else | quadratic formula | $x = \dfrac{-b \pm \sqrt{b^2-4ac}}{2a}$ |
| check | Vieta | sum of roots $= -b$, product $= c$ |

Here the sum is $-2 + 1 = -1 = -b$ and the product is $-2 \times 1 = -2 = c$, both correct.
That check costs three seconds and catches a sign slip in the factoring.

**(b) The three antiderivatives this question needs.**

| $f(x)$ | $\int f\,dx$ |
| :--- | :--- |
| $k$ (a constant) | $kx$ |
| $x$ | $x^2/2$ |
| $x^2$ | $x^3/3$ |

**(c) The Fundamental Theorem, part 2.** $\int_a^b f = F(b) - F(a)$, upper minus lower, in that order.
Reversing it flips the sign, and section 6 shows that on this question a flipped sign still has the right magnitude.

**(d) What "the area between the curves" means when no interval is given.**
It means the *bounded* region the two curves enclose between themselves.
The endpoints are therefore the intersection points, and finding them is part of the question.

**(e) The sign convention.**
$\int_a^b (\text{top} - \text{bottom})\,dx$ is positive.
$\int_a^b (\text{bottom} - \text{top})\,dx$ is the negative of it.
Area is a positive number, so if your integral comes out negative you have the order backwards, not a wrong area.

## 3. The universal procedure - the foundation for all nine Q19 questions

> **1. Sketch, roughly.** You are not being marked on the picture; you are using it to see how many pieces the region has.
>
> **2. Find the intersections exactly.** Set the two expressions equal and solve algebraically. Never read them off the sketch.
>
> **3. Decide which curve is on top, by evaluating both at one point strictly between consecutive intersections.** Write the comparison down.
>
> **4. Write the definite integral before you evaluate it.** $A = \int_a^b (\text{top} - \text{bottom})\,dx$.
>
> **5. Antidifferentiate and evaluate**, upper limit minus lower limit.
>
> **6. Check the sign and the magnitude.** A negative answer means step 3 went the wrong way.

### 3.1 Why it is (top minus bottom), and never a careless absolute value

A vertical strip at position $x$ has height $\text{top}(x) - \text{bottom}(x)$ and width $dx$.
Adding up the strips is exactly $\int (\text{top} - \text{bottom})\,dx$.
The height of a strip is a length, so it must be positive, which is the whole reason the order matters.

The textbook formula is often written $A = \int_a^b |f(x) - g(x)|\,dx$, and that is correct.
It is also useless as written, because you cannot antidifferentiate an absolute value directly.
What the absolute value is really telling you is: **find where $f - g$ changes sign, and split the integral there.**

On Q19.1 there is nothing to split.
The difference $D(x) = (2 - x^2) - x = -(x+2)(x-1)$ has its only two zeros at the endpoints $-2$ and $1$, and it is strictly positive at every one of the 20,000 interior points tested.
So $\int_{-2}^{1} |D| = \int_{-2}^{1} D$ here, and the absolute value is invisible.

**That is exactly why the absolute value is dangerous on this question.** It is a rule you are told, that you never see fire, on the question that introduces the topic. Q19.2 is where it fires, and section 3.5 shows what it costs there.

**The rule to carry:** the absolute value matters *only* when the curves cross **strictly inside** the interval.
Two intersection points that are the interval's own endpoints never need a split.
So the split test is one question: **are there any crossings strictly between $a$ and $b$?**

### 3.2 Finding the intersections exactly rather than reading them off a graph

Set the expressions equal and solve.

$$x = 2 - x^2 \quad\Longrightarrow\quad x^2 + x - 2 = 0 \quad\Longrightarrow\quad (x+2)(x-1) = 0 \quad\Longrightarrow\quad x = -2,\ 1$$

Three reasons never to read them off the sketch:

1. **A slightly wrong endpoint is almost free, and that is the trap.** This document's first draft claimed a 1.5 percent endpoint error becomes a 4.5 percent area error; the verification refuted it outright. Integrating from $-1.97$ instead of $-2$, a 1.5 percent endpoint error, changes the area by **0.0298 percent**. The reason is worth knowing: $\dfrac{dA}{da} = -D(a)$, and $D$ *vanishes* at a true intersection, so the area is **stationary** in the endpoint and the error is second order. The measured order in the offset is 1.9870, 1.9935, 1.9968, 1.9984. So a sketch-read endpoint that is nearly right gives an answer that is nearly right, you never notice the method was wrong, and you carry it to Q19.2 where the endpoints are $\pm\pi/4$ and there is nothing to nearly-read.
2. **Irrational intersections exist and look like nothing.** Family 1 in section 8 has a pair whose intersections are $\dfrac{-1 \pm \sqrt{33}}{4}$, which no sketch will ever hand you.
3. **A tangency looks like a crossing.** Two curves that touch without crossing produce a *repeated* root, which the algebra shows and the picture does not. See family 4.

**The independent check, and a warning about it.** A numerical root census that hunts for sign changes was run on this difference over $[-6, 6]$ and returned exactly two roots, $-2$ and $1$.
That census was proved honest in both directions before its verdict was trusted: it returns **zero** on $y = x$ against $y = -2 - x^2$ (no real intersections), **three** on $y = x$ against $y = x^3$, and **four** on $y = 0$ against $y = x^4 - 5x^2 + 4$.
It also returns **zero** on a tangency, $y = 2x - 1$ against $y = x^2$, which is the honest failure of the method: a curve that touches without crossing has no sign change to find.
Worse, whether such a touch is found at all depends on the arithmetic of the grid.
On $y = x^2$ against $y = x^4$ the same census reported **three** roots on an even grid, which happens to land on $x = 0$, and **two** on an odd grid, which does not.
**A sign-change census is not a root-finder at a tangency**, and the algebra is what settles it.

### 3.3 Vertical strips versus horizontal strips

| | Vertical strips ($dx$) | Horizontal strips ($dy$) |
| :--- | :--- | :--- |
| Strip height / width | $\text{top}(x) - \text{bottom}(x)$ | $\text{right}(y) - \text{left}(y)$ |
| You need | both curves as $y = f(x)$ | both curves as $x = g(y)$ |
| Limits are | the $x$ of the intersections | the $y$ of the intersections |
| Reach for it when | the top and bottom boundaries each stay the same curve all the way across | the left and right boundaries each stay the same curve all the way up |

**The decision is not about taste, it is about how many pieces each choice needs.**
Count the pieces, and pick the smaller count.

On Q19.1, vertical wins **1 integral to 2**:

- **Vertical.** The top is the parabola for the whole span $-2 \le x \le 1$ and the bottom is the line for the whole span. One integral.
- **Horizontal.** Solving gives $x = \pm\sqrt{2 - y}$ for the parabola and $x = y$ for the line. For $-2 \le y \le 1$ the region runs from the parabola's left branch across to the line. For $1 \le y \le 2$ it runs from the parabola's left branch across to its right branch. The right-hand boundary **changes curve at $y = 1$**, so that is two integrals.

Section 4 works the horizontal route anyway, because doing it once is how you learn to recognise the questions where it is the *shorter* count.
Family 5 in section 8 has one: $x = y^2$ against $x = y + 2$ is one integral in $y$ and two in $x$, exactly the mirror image of this question.

**The cue.** Write both curves as $y = f(x)$ and ask whether the top boundary is a single formula across the whole span. Then write them as $x = g(y)$ and ask the same about the right boundary. Whichever gives a single formula, use that variable. If a sideways-opening parabola or a curve like $x = y^2$ appears, that is the strongest single hint that $y$ is the easier variable.

### 3.5 What generalises to Q19.2, and what each later sub-family adds

Q19.1 and Q19.2 are the same question shape.
The whole of section 3 transfers unchanged.
Three things change:

1. **The interval is given** on Q19.2 (it is $[-\pi/2, \pi/2]$), so step 2 stops being "find the endpoints" and becomes "find the crossings *inside* the given endpoints".
2. **The curves are transcendental**, so the intersections come from $\cos x = 1/\sqrt 2$ rather than from a quadratic, and there are two of them at $\pm\pi/4$.
3. **The split fires.** Both crossings are strictly interior, so the region is three pieces, and the top curve alternates.

That third point is the one worth measuring.
Integrating Q19.2 in one go over $[-\pi/2, \pi/2]$ without splitting gives **-0.2214414691**, which is *negative* and therefore obviously not an area.
Splitting at $\pm\pi/4$ and adding the three magnitudes gives **0.8284271247**, which is exactly $2\sqrt 2 - 2 = 0.8284271247$ (the $\pi$ terms in the three pieces cancel).
So on Q19.2 the mistake is loud. On Q19.1 it does not exist. Learn the rule here where it is quiet, so it is already a habit there.

The rest of the category adds one new idea each:

| Question | What it adds on top of section 3 |
| :--- | :--- |
| Q19.2 area, cosine vs a horizontal line | the interval is given, and the split fires |
| Q19.3 net change | the integrand is a **rate**, and $\int_a^b r(t)\,dt$ is the accumulated amount |
| Q19.4, Q19.5 work | you must **build** the integrand from a physical description; the strip is a slice of chain or a stretch of spring |
| Q19.6, Q19.7 average value | $\dfrac{1}{b-a}\int_a^b f$; Q19.7 inverts it and solves for the endpoint |
| Q19.8, Q19.9 displacement and distance | **displacement is $\int v$, distance is $\int \lvert v \rvert$** - which is section 3.1's split rule in physics clothing |

Note the last row. Displacement against distance is exactly the difference between $\int (f-g)$ and $\int |f-g|$, so Q19.8 is Q19.1's absolute-value question asked again with velocity instead of curves. That is the single strongest reason to get section 3.1 solid here.

## 4. Q19.1 worked five ways

### Route A - vertical strips, the exact antiderivative (use this one)

Intersections: $x = 2 - x^2$, so $x^2 + x - 2 = 0$, so $(x+2)(x-1) = 0$, giving $x = -2$ and $x = 1$.

Orientation at $x = -\tfrac12$: the parabola gives $2 - \tfrac14 = 1.7500$, the line gives $-0.5000$.
The parabola is above, by $2.2500$.

$$A = \int_{-2}^{1}\Big( (2 - x^2) - x \Big)\,dx = \int_{-2}^{1} (2 - x - x^2)\,dx$$

$$= \Big[\, 2x - \frac{x^2}{2} - \frac{x^3}{3} \,\Big]_{-2}^{1}
= \Big( 2 - \tfrac12 - \tfrac13 \Big) - \Big( -4 - 2 + \tfrac83 \Big)
= \frac{7}{6} - \left(-\frac{10}{3}\right) = \frac{27}{6} = \frac{9}{2}$$

### Route B - the parabola shortcut

When the difference of the two curves is a quadratic $D(x) = a(x - x_1)(x - x_2)$, the enclosed area is

$$A = \frac{|a| \, (x_2 - x_1)^3}{6}$$

Here $D(x) = -(x+2)(x-1)$, so $a = -1$, $x_2 - x_1 = 3$, and $A = \dfrac{1 \cdot 27}{6} = \dfrac92$.
Computed: **4.5000000000**.

This is worth knowing as a **check**, not as a method to show.
It was verified against quadrature on the 114 two-root quadratics in a 196-triple coefficient sweep (the other 82 have no two real roots and were skipped), and on a second pair ($y = 3x+1$ against $y = x^2 - 2x + 5$) where it also holds.

**Its trap is live here and invisible.** The $|a|$ is $1$ on Q19.1, so a student who forgets it entirely still gets $9/2$.
On $y = x$ against $y = 4 - 2x^2$ the same omission is wrong by a factor of exactly $2$. See family 1.

### Route C - Archimedes, the two-thirds law

A parabolic segment fills exactly $\tfrac23$ of the parallelogram built on its chord.

$$A = \frac{2}{3} \times (\text{span}) \times (\text{maximum vertical gap})$$

The maximum gap is at the midpoint $x = -\tfrac12$ and equals $2.2500$; the span is $3$.
So $A = \tfrac23 \times 3 \times 2.2500 = $ **4.5000000000**.

This is algebraically identical to route B, since the maximum gap of $a(x-x_1)(x-x_2)$ is $|a|(x_2-x_1)^2/4$.
It is the better one to remember, because it doubles as a **magnitude check on any area question**: the enclosing parallelogram here has area $3 \times 2.2500 = 6.7500000000$, and $9/2$ is two-thirds of that. Note the shape is a parallelogram standing on the chord, not an axis-aligned rectangle; a rectangle of the same width and height would not even contain the region.
It is specific to a parabola, though. On $y = \sqrt x$ against $y = x^2$ the two-thirds law is wrong, and the harness proves it there rather than assuming it.

### Route D - horizontal strips

Solve each curve for $x$: the parabola is $x = \pm\sqrt{2-y}$, the line is $x = y$.
The intersections in $y$ are $y = -2$ and $y = 1$, and the parabola's vertex is at $y = 2$.

$$A = \underbrace{\int_{-2}^{1}\Big( y - \big(-\sqrt{2-y}\big) \Big)dy}_{\text{line on the right}} \; + \; \underbrace{\int_{1}^{2} 2\sqrt{2-y}\;dy}_{\text{both parabola branches}}$$

First piece: $\left[\tfrac{y^2}{2}\right]_{-2}^{1} + \int_{1}^{4}\sqrt u\,du$ with $u = 2-y$, which is $-\tfrac32 + \tfrac{14}{3} = \tfrac{19}{6}$.
Second piece: $2\int_0^1 \sqrt u\,du = \tfrac43$.
Total $\tfrac{19}{6} + \tfrac43 = \tfrac{27}{6} = \tfrac92$.

Computed: **3.1666666667** $+$ **1.3333333333** $=$ **4.5000000000**.

The strip description was not assumed; it was checked by sampling points inside each strip and confirming they satisfy both inequalities, and by sampling points just outside and confirming they do not.

### Route E - numerical quadrature (a check, never an answer)

Tanh-sinh quadrature of $(2 - x^2 - x)$ over $[-2, 1]$ gives **4.5000000000000**, and levels 12 and 13 agree to 1.599e-14.
Composite Simpson at $n = 512$ sits 0.000e+00 from the exact value.

**A digit-lock inherits the precision of the method that produced it, so the method's order was measured rather than assumed.**
On *this* integrand the measurement is degenerate, and that is worth saying plainly: the integrand is a **quadratic**, Simpson's rule is exact on every cubic, so the error is 0.000e+00 at every $n$ from 16 to 512 and **no convergence order can be measured on this question at all**.
The order was therefore measured on a separate curved control, $\sin(t^2)$ over $[0,1]$: **4.0030, 4.0008, 4.0002, 4.0001, 4.0006**, which is 4 as advertised.
The same routine on a cusp integrand, $|t|^{2/3}$ over $[-1,1]$, measures **1.6663, 1.6666, 1.6667, 1.6667, 1.6667**, which proves the measurement can report something other than 4 rather than always printing the answer you hoped for.

One more measured fact, because it reinforces section 3.1 from an unexpected direction.
Integrating $|D|$ over $[-2, 2]$ in one piece, straight through the kink at $x = 1$, is wrong by 4.790e-07.
Splitting at the kink first brings that to 1.243e-14.
**Even the numerics want you to split at the crossing.**

### Route comparison

| Route | Time under pressure | Risk | Verdict |
| :--- | :--- | :--- | :--- |
| **A - vertical strips** | ~2 min | a sign slip in orientation, or an arithmetic slip at $x=-2$ | **use this one** |
| B - the $\lvert a\rvert s^3/6$ shortcut | ~20 s | forgetting $\lvert a\rvert$; only works when the difference is a quadratic | check with it |
| C - Archimedes two-thirds | ~20 s | same as B; parabolas only | best magnitude check |
| D - horizontal strips | ~5 min | two integrals, a square root, and a boundary change at $y=1$ | wrong tool here |
| E - quadrature | not available | no calculator does this in Möbius | verification only |

**Under exam pressure, do route A and check with route C.**
Route C is twenty seconds and it catches a wrong interval, a wrong orientation and a dropped term at once, because all three change the magnitude away from two-thirds of the box.

## 5. The exam-ready write-up

The version to reproduce on paper, in six sentences:

> The curves meet where $x = 2 - x^2$, that is where $x^2 + x - 2 = 0$, so $(x+2)(x-1) = 0$ and $x = -2$ or $x = 1$.
> Between those values, at $x = -\tfrac12$, the parabola is at $1.7500$ and the line is at $-0.5000$, so the parabola is the upper curve throughout.
> There are no other intersections, so no split is needed.
> Therefore $A = \displaystyle\int_{-2}^{1}\big( (2-x^2) - x \big)\,dx$.
> An antiderivative is $F(x) = 2x - \dfrac{x^2}{2} - \dfrac{x^3}{3}$, so $A = F(1) - F(-2) = \dfrac76 - \left(-\dfrac{10}{3}\right)$.
> $A = \dfrac{27}{6} = \dfrac92$.

The three sentences that carry the reasoning are the first, the second and the fourth: the interval, the orientation, and the integral written before it is evaluated.
This is the same discipline `Q16.1 - Five integrals.md` sets for choosing a technique: name what you are doing before you do it, so the check has something to check against.

**All five agree to 2.1e-14.**
That tolerance is the honest one: it is what the floating-point routes actually achieved, not a round number chosen to make the table look tidy.

### 6.2 Three checks worth eight seconds each

**The box check.** The region sits inside the parallelogram on the chord, width $3$ (the span) and height 2.2500 (the largest gap), area 6.7500000000. Your answer must be smaller than that, and for a parabolic segment it should be exactly two-thirds of it. $9/2$ is.

**The sign check.** If the integral came out negative, you subtracted in the wrong order. The magnitude is still right, so **do not redo the integral** - just drop the minus sign and understand why.

**The endpoint check.** Put each intersection back into *both* original equations. At $x = 1$: the line gives $1$, the parabola gives $2 - 1 = 1$. At $x = -2$: the line gives $-2$, the parabola gives $2 - 4 = -2$. Both match, so the interval is right. This is `Q16.1`'s differentiate-back check in its algebraic form: undo the step and see whether you land where you started.

**The headline: a sign error on this question keeps the correct magnitude.**
Three different mistakes all land on exactly $-9/2$ - reversing the orientation, dropping the absolute value in the shortcut, and evaluating $F(a) - F(b)$ instead of $F(b) - F(a)$.
Every one of them produces $4.5$ the moment the student writes "area, so it is positive" and drops the sign.
**So the sign error hides completely here, and there is no arithmetic check that can find it.** The only defence is the one-line orientation statement in section 3.4, which fixes the order before the integration rather than after it.

A fourth candidate is identical even in sign: splitting at $x = 0$ for no reason and adding the pieces gives $9/2$ exactly, because there is no sign change at $0$ to be wrong about. An unnecessary split is harmless. A missing necessary one is not.

Of the 14 caught mistakes, the closest miss is off by 0.7287638337, which is 16 percent of the answer.
So **any** mistake that actually changes the region is loud, and every quiet one is a sign.
That is a clean partition and it tells you exactly where to spend your checking time.

## 7. Answer-entry rules

Both exams are Möbius: answer-only, machine-marked, and a correct method with a bad keystroke scores zero.

| Do | Do not |
| :--- | :--- |
| `9/2` | `9\2` (wrong slash) |
| `4.5` (if a decimal is accepted) | `4.5 units^2` - units are not part of a numeric answer |
| `27/6` will usually be accepted as equal | leaving it as `27/6` when the box wants lowest terms |
| Preview the rendered answer before submitting | assuming the parser read `2-x^2` the way you meant |

**The single most expensive typo on this question is a leading minus.** `-9/2` is a different number, and the grader has no way to know you meant the area.
If your working produced a negative, fix the reasoning, then type the positive.

If the box asks for the *setup* rather than the value, the integral is `int(2-x^2-x, x=-2..1)` in Möbius syntax. Preview it: an unbracketed `2-x^2-x` is fine, but `2-x^2-x` typed as `2-x**2-x` is not universally accepted.

## 8. The variation catalog

Read each table as **structure**, not as a list of facts.
Every row is the same four steps from section 3; what changes between families is only **which step becomes the hard one**.

### Family 1 - polynomial against polynomial, interval not given

**Trigger.** Two polynomial curves, no interval stated.
**The hard step is step 2**, finding the intersections.
**Tool.** Factor or the quadratic formula. If the difference is a quadratic, route B and route C both apply as checks.

| Curves | Area | Notes |
| :--- | ---: | :--- |
| $y = x$, $y = 2 - x^2$ (the question) | 4.5000000000 | roots $-2, 1$; $\lvert a\rvert = 1$ |
| $y = 2x$, $y = x^2$ | 1.3333333333 | roots $0, 2$; $\lvert a\rvert = 1$ |
| $y = x + 6$, $y = x^2$ | 20.8333333333 | roots $-2, 3$; $\lvert a\rvert = 1$ |

Read the structure: five of the six have integer intersections and one does not, and the two rows with $|a| = 2$ are the ones where forgetting the $|a|$ in the shortcut costs you a factor of exactly $2$.
On Q19.1 itself $|a| = 1$, so that error is invisible - which is why the row with $|a| = 2$ is in the table.

### Family 2 - the curves cross inside the interval, so the region splits

**Trigger.** An interval is given, and solving $f = g$ produces a solution **strictly between** the endpoints.
**The hard step is step 3**, because the answer to "which is on top" changes partway across.
**Tool.** Find every interior crossing, then integrate $(top - bottom)$ separately on each sub-interval, choosing the orientation afresh on each one. Equivalently, take the absolute value of each piece and add.

| Curves and interval | Area | Notes |
| :--- | ---: | :--- |
| $y = x^3$, $y = x$ on $[-1,1]$ | 0.5000000000 | crosses at $0$; unsplit gives $0$ |
| $y = \cos x$, $y = 1/\sqrt 2$ on $[-\pi/2, \pi/2]$ (Q19.2) | 0.8284271247 | crosses at $\pm\pi/4$; unsplit gives -0.2214414691 |
| $y = \sin x$, $y = \cos x$ on $[0,\pi]$ | 2.8284271247 | crosses at $\pi/4$ |

Read the structure: in every row the unsplit integral is smaller than the true area, and in two of the three it is *negative* or *zero*, which is a free tell. **A negative or suspiciously small "area" is almost always a missed split.**

### Family 3 - the interval is given and there is no interior crossing

**Trigger.** An interval is given and $f - g$ has no zero strictly inside it.
**This is the easiest family and it is the one that lulls you**, because it looks exactly like family 2 until you check.
**Tool.** Check for interior crossings, find none, then integrate straight through.

| Curves and interval | Area | Notes |
| :--- | ---: | :--- |
| $y = e^x$, $y = 1$ on $[0,1]$ | 0.7182818285 | no interior crossing |
| $y = 1$, $y = 1/x$ on $[1,2]$ | 0.3068528194 | no interior crossing |
| $y = \cos x$, $y = \sin x$ on $[0,\pi/4]$ | 0.4142135624 | crossing sits ON the right endpoint |

The third row is the instructive one: the crossing sits exactly *on* the right endpoint, which needs no split. **On the boundary is not inside.**

### Family 4 - a tangency

**Trigger.** Setting the curves equal produces a **repeated** root.
**The hard step is step 2 again**, but for a different reason: the algebra shows a double root and the sketch shows what looks like a crossing.
**Tool.** Factor fully and count multiplicities. A double root is a touch, and a touch is **not** a crossing, so it needs no split.

| Curves | Area | Notes |
| :--- | ---: | :--- |
| $y = x^2$, $y = x^4$ | 0.2666666667 | touch at $0$; no split needed |
| $y = x^2$, $y = 2x - 1$ | 0.0000000000 | tangent: the region is a single point, area $0$ |

The second row is the degenerate case worth having seen once: a line tangent to a parabola encloses no region at all, and the correct answer is $0$.

### Family 5 - horizontal strips are the shorter route

**Trigger.** One or both curves is naturally $x$ as a function of $y$ (a sideways parabola, $x = y^2$, $x = \sqrt y$), or the region's top boundary changes curve while its right boundary does not.
**The hard step is step 1**, seeing which variable to use.
**Tool.** Solve both for $x$, find the intersections in $y$, integrate $(\text{right} - \text{left})\,dy$.

| Setup | Area | Notes |
| :--- | ---: | :--- |
| $x = y^2$, $x = y + 2$ in $y$ | 4.5000000000 | one integral in $y$, two in $x$ |
| the same region in $x$: $[0,1]$ piece | 1.3333333333 | lower boundary is $-\sqrt x$ |
| the same region in $x$: $[1,4]$ piece | 3.1666666667 | lower boundary is the line |

Read the structure: the same region costs one integral in $y$ and two in $x$, and the two $x$-pieces are $4/3$ and $19/6$ - the very same two numbers that appeared in Q19.1's own horizontal route, with the roles swapped. **The two routes are mirror images, and the count of pieces is the only thing that should decide between them.**

### Family 6 - solve for a parameter from a required area

**Trigger.** The area is given and a constant in one of the curves is not.
**The hard step is step 5 run backwards.**
**Tool.** Do the integration with the letter in place, set the result equal to the given area, solve.

| Setup | Value | Notes |
| :--- | ---: | :--- |
| $y = k - x^2$ over $y = 0$, area $= 36$ | 36.0000000000 | $k = 9$ |
| the same with $k = 4$ | 10.6666666667 | $32/3$, so $k=4$ is refuted |

$\int_{-\sqrt k}^{\sqrt k}(k - x^2)\,dx = \tfrac43 k^{3/2}$, so $\tfrac43 k^{3/2} = 36$ gives $k^{3/2} = 27$ and $k = 9$.
**This is the family Q19.7 belongs to**, with an average value in place of an area, so it is worth doing once here.

## 9. The trap list

Ranked by how often each one actually costs a mark, worst first.

1. **Reading the intersections off the sketch instead of solving.** Not because a nearly-right endpoint is costly - measured above, it is nearly free, at 0.0298 percent for a 1.5 percent endpoint error. Because the habit is what fails, and it fails loudly the moment the intersections are not integers: mistaking them for $\pm\sqrt 2$ here is 16.1948 percent off, over 543 times worse.
2. **Getting the orientation backwards, and then hiding it.** Verified above: three separate versions of this mistake all give exactly $-9/2$, and all three become the correct $4.5$ the moment the minus sign is dropped as "obviously area is positive". Decide the orientation by *evaluating at an interior point*, in writing, before integrating.
3. **Using the parabola's own roots as the interval.** $2 - x^2 = 0$ gives $x = \pm\sqrt2$, which are where the parabola meets the *$x$-axis*, not where it meets the line. That gives 0.7287638337 too much. The line is not the $x$-axis.
4. **Not splitting when the curves cross inside a given interval.** Latent on Q19.1, fatal on Q19.2, where the unsplit answer is -0.2214414691 against a true 0.8284271247.
5. **Splitting when nothing crosses.** Harmless arithmetically, as verified, but it burns two minutes you do not have and doubles the chance of an evaluation slip.
6. **Sign errors evaluating at a negative limit.** $F(-2) = 2(-2) - \frac{(-2)^2}{2} - \frac{(-2)^3}{3} = -4 - 2 + \frac83 = -\frac{10}{3}$. The $-x^3/3$ term becomes **positive** at a negative $x$. This is where most of the arithmetic marks are lost on this specific question.
7. **Dropping the $|a|$ in the shortcut.** Invisible here because $|a| = 1$; a factor-of-2 error on the family-1 row where $|a| = 2$.
8. **Forgetting that "area between curves" with no interval means the enclosed region.** Integrating over some interval you invented gives a number that is not the answer to any question.
9. **Reporting a negative number.** Area is a magnitude. If the arithmetic gives $-9/2$, the area is $9/2$.

## 11. The one-page decision tree

```
Q: "area between/enclosed by ..." ?
 |
 +-- Is an INTERVAL given?
 |     |
 |     NO  -> the endpoints ARE the intersections. Solve f(x) = g(x) exactly.        [F1]
 |     |     Two solutions -> that is your interval.
 |     |     Repeated root -> tangency; check whether a region exists at all.        [F4]
 |     |
 |     YES -> solve f(x) = g(x) anyway, and ask: any solution STRICTLY inside?
 |             NO  -> one integral, straight through.                                [F3]
 |             YES -> SPLIT at every interior crossing.                              [F2]
 |
 +-- Which variable?
 |     Top boundary one formula all the way across?   -> vertical strips, dx
 |     Right boundary one formula all the way up?     -> horizontal strips, dy       [F5]
 |     Both work? -> count the pieces each needs, take the smaller count.
 |
 +-- ORIENTATION: evaluate BOTH curves at one point strictly between
 |     consecutive intersections. Write the comparison down. Do not squint at a sketch.
 |
 +-- SET UP:  A = int_a^b (TOP - BOTTOM) dx      <- write this line before evaluating
 |
 +-- EVALUATE: F(b) - F(a), upper minus lower.
 |
 +-- CHECK:  sign positive?                       (negative = orientation reversed)
 |           smaller than span x max-gap?         (box check)
 |           about 2/3 of the box, if a parabola? (Archimedes)
 |           endpoints satisfy BOTH equations?
 |
 +-- PREVIEW the Möbius entry before submitting.
```
