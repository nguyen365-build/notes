# Q19.7 - Find k from an average value

**The question (Final Exam 2, item 12, 10 points).**
"Find a positive number $k$ such that the average value of the function $f(x) = \dfrac{5}{x^2}$ over the interval between $1$ and $k$ is $32$."

**The answer.**
$$f_{\text{avg}}(k) \;=\; \frac{1}{k-1}\int_1^k \frac{5}{x^2}\,dx \;=\; \frac{1}{k-1}\Big[-\frac{5}{x}\Big]_1^k \;=\; \frac{1}{k-1}\cdot\frac{5(k-1)}{k} \;=\; \frac{5}{k}$$
so $\dfrac{5}{k} = 32$ and therefore
$$\boxed{k \;=\; \frac{5}{32} \;=\; 0.15625}$$

**What to type into Möbius:** `5/32`

## 0. The 30-second version

```
average value of f on the interval between a and k
  = (the total) / (the width)
  = (1/(k-a)) * INTEGRAL from a to k of f(x) dx

SET IT EQUAL to the given average, then solve for k.

  f(x) = 5/x^2,  a = 1,  target = 32
  INTEGRAL 5/x^2 dx = -5/x
  (1/(k-1)) * [ -5/k + 5 ]  =  (1/(k-1)) * 5(k-1)/k  =  5/k     <- (k-1) CANCELS
  5/k = 32   ->   k = 5/32 = 0.15625

check by substitution: average of 5/x^2 over [5/32, 1]
        integral = 27,  width = 27/32,  27 / (27/32) = 32       OK
check the interval: 5/32 < 1, so the interval is [5/32, 1]
check uniqueness: 5/k is strictly decreasing, so there is exactly one k
```

That is the whole method.
The one line worth memorising is that $(k-1)$ cancels, because it is what turns a messy-looking rational equation into $5/k = 32$.

## 2. The four things you must have cold

### 2.1 The formula, read as a constraint

$$f_{\text{avg}} \;=\; \frac{1}{b-a}\int_a^b f(x)\,dx$$

In Q19.6 every symbol on the right was known and you computed the left.
Here the left is given, one endpoint is unknown, and the equation is a **constraint on $k$**.
Nothing about the formula changes.
What changes is that you now carry $k$ symbolically all the way through the integration, and only substitute numbers at the very end.

### 2.2 The antiderivative, and the cancellation it produces

$$\int \frac{5}{x^2}\,dx \;=\; \int 5x^{-2}\,dx \;=\; 5\cdot\frac{x^{-1}}{-1} \;=\; -\frac{5}{x} + C$$

so

$$\int_1^k \frac{5}{x^2}\,dx \;=\; \Big[-\frac{5}{x}\Big]_1^k \;=\; -\frac{5}{k} + 5 \;=\; \frac{5(k-1)}{k}$$

and dividing by the width $(k-1)$ gives $\dfrac{5}{k}$.

**The $(k-1)$ cancels exactly.**
That is not a coincidence of this stem, it is the shape of $1/x^2$, and section 8's Family 0 gives the general statement.

### 2.3 The master formula for this family

$$\text{average of } \frac{c}{x^2} \text{ over the interval between } a \text{ and } k \;=\; \frac{c}{a\,k}$$

Verified on 92 instances spanning $c \in \{1, 5, 12, 0.25\}$, $a \in \{0.5, 1, 2, 7\}$ and $k \in \{0.1, 0.3, 0.9, 1.4, 3, 11\}$, both orientations, worst relative mismatch below $10^{-9}$.
A control confirms the formula is **false** for $c/x^3$, so it is not a tautology.

With $c = 5$ and $a = 1$ this reads $f_{\text{avg}} = 5/k$, which is the exam's own equation.
It is worth carrying because it makes every rescaling of this question a one-line divide.

### 2.4 The interval is "between", not "from 1 to"

The stem says **between** $1$ and $k$.
That word is doing real work, because the answer turns out to be $\frac{5}{32} < 1$.
The interval is therefore $\left[\frac{5}{32},\, 1\right]$, of width $\frac{27}{32} = 0.84375$.

Here is the fact that rescues you if you did not notice:

$$\frac{1}{k-1}\int_1^k \frac{5}{x^2}\,dx \;=\; \frac{1}{1-k}\int_k^1 \frac{5}{x^2}\,dx$$

Reversing the limits flips the sign of the integral **and** the sign of the width, and the two flips cancel.
Verified at 501 sampled values of $k$ on $[0.02, 3]$, worst mismatch below $10^{-9}$.
So a student who wrongly assumes $k > 1$ writes the identical equation and gets the identical answer.
Section 9 measures exactly how much that costs, and the answer is: nothing.

## 3. The universal procedure

> 1. **Write the constraint.** $\dfrac{1}{k-a}\displaystyle\int_a^k f(x)\,dx = T$, with $T$ the given average.
> 2. **Integrate symbolically.** Get $F(k) - F(a)$ with $k$ still a letter.
> 3. **Simplify before solving.** Look for a factor of $(k-a)$ in the numerator; in the $1/x^2$ family it is always there.
> 4. **Classify the equation in $k$** using the table below, then solve it by the matching tool.
> 5. **Count the solutions.** Decide whether $f_{\text{avg}}(k)$ is monotone; if it is, there is at most one, and the stem's extra words ("positive", "greater than 1") pick which.
> 6. **Substitute back.** Recompute the average at your $k$ from scratch and compare with $T$.
> 7. **Sanity-check the interval.** If $k < a$ the interval is $[k, a]$; say so.

**Classify step 4 like this.**

| What $k$ does in the simplified equation | Tool | Example |
| :--- | :--- | :--- |
| Appears once, to the first power | one divide | $5/k = 32$, this question |
| Appears linearly after clearing | linear solve | average of $2x+1$ between 1 and $k$ |
| Appears to the second power | quadratic formula, then discard by the stem's wording | average of $5/x^3$, average of $x^2$ |
| Appears inside $e^k$, $\ln k$, $\sin k$ | no closed form; numerical, or the stem is rigged | average of $e^x$ on $[0,k]$ |
| Appears in the integrand **and** a limit | simplify first; it often cancels completely | average of $k/x^2$ between 1 and $k$ |

## 4. Q19.7 worked five ways

### Route A - FTC part 2, symbolically (use this one)

$$\frac{1}{k-1}\Big[-\frac{5}{x}\Big]_1^k = \frac{1}{k-1}\left(5 - \frac{5}{k}\right) = \frac{1}{k-1}\cdot\frac{5(k-1)}{k} = \frac{5}{k} = 32 \quad\Longrightarrow\quad k = \frac{5}{32}$$

Three lines.
The only step that needs care is factoring $5 - \frac{5}{k} = \frac{5(k-1)}{k}$.

### Route B - the master formula

Average of $\dfrac{c}{x^2}$ between $a$ and $k$ is $\dfrac{c}{ak}$.
Here $\dfrac{5}{1\cdot k} = 32$, so $k = \dfrac{5}{32}$.
One line, if you carry section 2.3.

### Route C - assume the orientation, then check it

Write the interval as $[k, 1]$ from the start, because you suspect $k < 1$:

$$\frac{1}{1-k}\int_k^1 \frac{5}{x^2}\,dx = \frac{1}{1-k}\left(\frac{5}{k} - 5\right) = \frac{1}{1-k}\cdot\frac{5(1-k)}{k} = \frac{5}{k}$$

Identical equation.
This route is worth knowing because it shows the orientation cannot hurt you, which frees you to stop worrying about it during the exam.

### Route D - the mean-value point first

By the Mean Value Theorem for Integrals there is a $c$ in the interval with $f(c) = 32$.
$$\frac{5}{c^2} = 32 \quad\Longrightarrow\quad c = \sqrt{\frac{5}{32}} = 0.3952847075$$
For $f(x) = c/x^2$ the mean-value point is the **geometric mean** of the endpoints (section 8, Family 6), so $\sqrt{1\cdot k} = \sqrt{5/32}$ gives $k = 5/32$ directly.
Elegant, and it is the route that generalises furthest, but it needs the geometric-mean fact, which is not in the course notes.

### Route E - numerical, as a check rather than a method

Define $g(k) = f_{\text{avg}}(k) - 32$ using quadrature only, with no antiderivative anywhere.
Scanning $g$ on $(0.01, 0.999)$ at both $n = 999$ and $n = 1000$ grid points finds **exactly one** sign change, and bisecting it returns $0.15625$ to within $10^{-11}$.
Scanning $(1.001, 60)$ at both parities finds **zero** roots.
This is not an exam method; it is how the page was checked.

### Route W - the natural wrong answers

Setting the **integral** equal to 32 rather than the average gives $\frac{5}{k} - 5 = 32$, so $k = \frac{5}{37} = 0.1351351351$.
Solving $\frac{5}{k} = 32$ and writing $k = \frac{32}{5} = 6.4$ is the reciprocal slip.
Section 9 has all 24.

### Route comparison

| Route | Lines | Needs | Fails when | Exam speed |
| :--- | ---: | :--- | :--- | ---: |
| A - FTC symbolically | 3 | $\int x^{-2}$ and one factorisation | never | fast |
| B - master formula | 1 | section 2.3 memorised | the integrand is not $c/x^2$ | fastest |
| C - orientation first | 3 | the same work, other way round | never | fast |
| D - mean-value point | 2 | the geometric-mean fact | the integrand is not $c/x^2$ | fast |
| E - numerical | many | a computer | in an exam | unusable |

**Use Route A under pressure.**
It needs nothing you do not already have, it works for every integrand in the category rather than just this one, and its one risky step - the factorisation - is also the step that makes the algebra collapse, so you will notice if you get it wrong.
Route B is strictly faster but only if you are certain the integrand is $c/x^2$; check the exponent before you use it.

## 5. The exam-ready write-up

These are the sentences that earn the method marks, in order.
This is an **inference** about grading, since no marking scheme exists.

> The average value of $f$ over the interval with endpoints $1$ and $k$ is $\dfrac{1}{k-1}\displaystyle\int_1^k \dfrac{5}{x^2}\,dx$.
>
> Since $\displaystyle\int \frac{5}{x^2}dx = -\frac{5}{x}$, this equals $\dfrac{1}{k-1}\left(5 - \dfrac{5}{k}\right) = \dfrac{1}{k-1}\cdot\dfrac{5(k-1)}{k} = \dfrac{5}{k}$.
>
> Setting $\dfrac{5}{k} = 32$ gives $k = \dfrac{5}{32}$, which is positive as required.
>
> Since $\dfrac{5}{k}$ is strictly decreasing for $k > 0$, this $k$ is the only solution.
>
> Check: on $\left[\frac{5}{32}, 1\right]$ the integral is $\left[-\frac{5}{x}\right]_{5/32}^{1} = -5 + 32 = 27$ and the width is $\frac{27}{32}$, so the average is $27 \div \frac{27}{32} = 32$.

Five sentences.
The fourth one is the one almost nobody writes, and on a 10-point item it is plausibly worth having.

## 6. Verify before you commit

**The substitution check, and what it can and cannot catch.**

Put $k = \frac{5}{32}$ back and recompute:

$$\int_{5/32}^{1}\frac{5}{x^2}\,dx = \Big[-\frac{5}{x}\Big]_{5/32}^{1} = -5 - (-32) = 27, \qquad \text{width} = 1 - \frac{5}{32} = \frac{27}{32}$$
$$\frac{27}{27/32} = 27 \cdot \frac{32}{27} = 32 \quad\checkmark$$

Measured against 24 wrong methods, substituting into the **correct** average formula rejects 23 of them.
The one it accepts is the orientation flip, and it accepts it because the orientation flip is the same equation.

**But it is a check on the solve, not on the setup.**
If you set up the wrong equation and then verify by substituting into your own wrong equation, it agrees with itself every time.
Concretely: a student who set the *integral* equal to 32, got $k = \frac{5}{37}$, and then checked by recomputing the *integral* would see $32$ and be satisfied.
The check only bites if you recompute the **average** - integral divided by width - from scratch.

**Cheap invariants, in the order they are worth doing.**

| Check | On this question | Rejects how many of the 24 |
| :--- | :--- | ---: |
| $k > 0$, because the stem says "positive" | $\frac{5}{32} > 0$ | 6 |
| $0 < k < 1$, because $f_{\text{avg}} \to 5$ as $k \to 1$ and $32 > 5$ | $0.15625 < 1$ | 11 |
| Sandwich: $32$ must lie between $\min f$ and $\max f$ | needs $\frac{5}{k^2} \ge 32$, so $k \le 0.3952847075$ | 13 |
| Substitution into the true average | $32$ | 23 |

The sandwich is Q17.1's property, and Q17.1 sits on Final Exam 1 rather than this paper, so it is a cross-paper cross-reference here rather than the same-paper one Q19.6 enjoyed.
It is the strongest check you can run **before** solving, because it tells you $k$ must be under $0.3953$ while you still have the option of changing your setup.

**Numbers worth memorising for this question.**

| Quantity | Value |
| :--- | ---: |
| $k$ | $\frac{5}{32} = 0.15625$ |
| interval | $\left[\frac{5}{32},\, 1\right]$ |
| width | $\frac{27}{32} = 0.84375$ |
| $\int_{5/32}^{1} 5x^{-2}dx$ | $27$ |

## 8. The variation catalog

Read each table as **structure**, not as a list of facts.
Family 0 has exactly one moving part - the product $a\cdot k$ - so every row is the same divide.
Families 1 through 4 are graded by **what power of $k$ survives the simplification**, which is the only thing that changes the tool you need.

### Family 0 - rescalings of the exam's own stem

Trigger: integrand is $c/x^2$, one endpoint given, average given.
Tool: $\dfrac{c}{ak} = T$, so $k = \dfrac{c}{aT}$.

| Stem | $c$ | $a$ | target $T$ | $k$ | substitution check |
| :--- | ---: | ---: | ---: | ---: | ---: |
| the exam's own | 5 | 1 | 32 | $\frac{5}{32} = 0.15625$ | 32 |
| average is 2 instead | 5 | 1 | 2 | $\frac{5}{2} = 2.5$ | 2 |
| $12/x^2$, average 48 | 12 | 1 | 48 | $0.25$ | 48 |
| between 2 and $k$ | 5 | 2 | 32 | $0.078125$ | 32 |
| average is $\frac12$ | 5 | 1 | 0.5 | $10$ | 0.5 |
| $1/x^2$ between 4 and $k$ | 1 | 4 | 1 | $0.25$ | 1 |
| average is 20 | 5 | 1 | 20 | $0.25$ | 20 |
| $3/x^2$, average 12 | 3 | 1 | 12 | $0.25$ | 12 |

Note the structure: four different stems land on $0.25$, because only the product $c/(aT)$ matters.
**The degenerate row**: target exactly $5$ with $a = 1$ forces $k = 1$, and then there is no interval at all.
Any target above $5$ gives $k < 1$; any target below $5$ gives $k > 1$.

### Family 1 - $k$ enters linearly (affine integrand)

Trigger: $f$ is a straight line.
Tool: the average of an affine function is its value at the midpoint, so the equation is linear in $k$.

| Stem | equation | $k$ | check |
| :--- | :--- | ---: | ---: |
| average of $2x+1$ between 1 and $k$ is 10 | $k + 2 = 10$ | $8$ | 10 |
| average of $3x$ on $[0,L]$ is 9 (this is Q19.6 inverted) | $\frac{3L}{2} = 9$ | $L = 6$ | 9 |
| average of $4-x$ between 2 and $k$ is $\frac12$ | $4 - \frac{2+k}{2} = \frac12$ | $5$ | 0.5 |
| average of $6x$ between 0 and $k$ is 15 | $3k = 15$ | $5$ | 15 |

This is the family Q19.6 lives in, run backwards.
Because the average of an affine $f$ equals the endpoint mean, **the endpoint-average shortcut is exact here and only here** - Q19.6's section on the affine shortcut, confirmed at 31.3 of the carryover, is the same result.

### Family 2 - $k$ enters quadratically

Trigger: the integrand is $c/x^3$, or a polynomial of degree $\ge 2$.
Tool: quadratic formula, then discard roots using the stem's own words.

| Stem | equation | roots | kept | check |
| :--- | :--- | :--- | ---: | ---: |
| average of $\frac{5}{x^3}$ between 1 and $k$ is 32 | $\frac{5(k+1)}{2k^2} = 32$, i.e. $64k^2 - 5k - 5 = 0$ | $\frac{5 \pm \sqrt{1305}}{128}$ | $0.3212873729$ | 32 |
| average of $x^2$ between 1 and $k$ is $\frac73$ | $\frac{k^2+k+1}{3} = \frac73$ | $2$ and $-3$ | $2$ | $\frac73$ |

In both rows the discarded root is negative, and the single word "positive" in the stem is what discards it.
The $5/x^3$ negative root is $-0.2431623729$.
**This is where the inverse problem starts to bite**: a quadratic can have two admissible roots, and this integrand happens not to.
Family 5 is where it does.

### Family 3 - the parameter is in the integrand, not in a limit

Trigger: both endpoints are given and a constant inside $f$ is unknown.
Tool: the average is linear in that constant, so the solve is a single divide.

| Stem | equation | answer | check |
| :--- | :--- | ---: | ---: |
| average of $\frac{c}{x^2}$ on $[1,4]$ is 3 | $\frac{c}{4} = 3$ | $c = 12$ | 3 |
| average of $x^2 + c$ on $[0,2]$ is 6 | $\frac43 + c = 6$ | $c = \frac{14}{3} = 4.6666666667$ | 6 |
| average of $c\sin x$ on $[0,\pi]$ is 4 | $\frac{2c}{\pi} = 4$ | $c = 2\pi = 6.2831853072$ | 4 |

These are strictly easier than Family 0 and they are the most likely "same idea, different wrapper" restatement.

### Family 4 - transcendental, no closed form for $k$

Trigger: $e^x$, $\sin x$, $\ln x$ with the unknown in a limit.
Tool: recognise that there is no algebraic answer, and either the stem is rigged to cancel or it wants a numerical value.

| Stem | equation | $k$ | check |
| :--- | :--- | :--- | ---: |
| average of $e^x$ on $[0,k]$ is 10 | $\frac{e^k - 1}{k} = 10$ | $3.6149504271$, numerically | 10 |
| average of $\sin x$ on $[0,k]$ is $\frac12$ | $\frac{1-\cos k}{k} = \frac12$ | $1.1091441817$ **and** $3.6981536729$ | 0.5 each |

The sine row is the warning: **two admissible positive solutions**, because $\frac{1-\cos k}{k}$ rises then falls.
If a stem like this appears, "find all $k$" is a live possibility and one answer is not enough.

### Family 5 - genuinely non-unique, and genuinely empty

Trigger: $f$ dips below its own running average somewhere inside the interval.
Tool: the monotonicity criterion in section 8.5 below, then count.

Take $f(x) = (x-2)^2$ and the interval between 1 and $k$.
The average simplifies to $\dfrac{k^2 - 5k + 7}{3}$, verified at 7 values of $k$ on both sides of 1.

| target | solutions | values | check |
| :--- | ---: | :--- | ---: |
| $\frac32$ | **two** | $\frac{5-\sqrt{15}}{2} = 0.5635083269$ and $\frac{5+\sqrt{15}}{2} = 4.4364916731$ | 1.5 each |
| $\frac14$ | one | $k = \frac52$, the minimum | 0.25 |
| $\frac18$ | **none** | below the minimum | - |

The minimum of the average is $\frac14$, at $k = \frac52$.
The reason there can be two is that $f$ vanishes at $x = 2$, which lies **inside** the interval, so pushing $k$ further right first drags the average down and then pushes it back up.
**The exam's own $f = 5/x^2$ can never do this**, because it is strictly decreasing on $(0,\infty)$, so $f(k)$ crosses the running average exactly once.
That is the whole uniqueness argument, and section 8.5 states it as a rule.

### 8.5 The monotonicity criterion - the uniqueness engine

Differentiating the average with respect to the moving endpoint gives

$$\frac{d}{dk}\,f_{\text{avg}}(k) \;=\; \frac{f(k) - f_{\text{avg}}(k)}{k - a}$$

Verified numerically at 14 points across three different integrands, worst absolute mismatch $7.702\times10^{-9}$.

Read it in words: **the average moves toward the value you are adding.**
If the new endpoint value $f(k)$ is above the current average, extending the interval in the $+k$ direction raises the average.

On this question, at $k = \frac{5}{32}$: $f(k) = 204.8$, the average is $32$, and $k - a = -\frac{27}{32} < 0$, so the derivative is $-204.8$, which matches $-5/k^2$ exactly.
Negative everywhere on $(0,1)$ and on $(1,\infty)$, so $f_{\text{avg}}$ is strictly decreasing on each piece and the solution is unique.

### Family 6 - the mean-value point asked for instead of the endpoint

Trigger: "find $c$ such that $f(c)$ equals the average".
Tool: solve $f(c) = f_{\text{avg}}$ on the interval.

There is a clean pattern here that the course notes do not state, verified on 12 instances:

| integrand | the mean-value point is | on $[5/32, 1]$ |
| :--- | :--- | ---: |
| affine, $\alpha x + \beta$ | the **arithmetic** mean $\frac{a+b}{2}$ | $0.578125$ |
| $c/x$ | the **logarithmic** mean $\frac{b-a}{\ln(b/a)}$ | $0.4545337033$ |
| $c/x^2$ | the **geometric** mean $\sqrt{ab}$ | $0.3952847075$ |

For this question the mean-value point is $\sqrt{1 \cdot \frac{5}{32}} = \sqrt{\frac{5}{32}} = 0.3952847075$, and it does lie inside $\left[\frac{5}{32}, 1\right]$.
Note the ordering geometric $<$ logarithmic $<$ arithmetic, which is the AM-GM chain, and note that Q19.6's mean-value point **was** the midpoint precisely because its $f$ was affine.

| stem | mean-value point |
| :--- | ---: |
| $5/x^2$ on $[5/32, 1]$ | $0.3952847075$ |
| $3x$ on $[0,6]$ (Q19.6) | $3$ |
| $5/x$ on $[1,4]$ | $\frac{3}{\ln 4} = 2.1640425613$ |
| $x^2$ on $[0,3]$ | $\sqrt{3} = 1.7320508076$ |

### Family 7 - the parameter appears in the integrand **and** a limit

Trigger: the same letter shows up twice.
Tool: simplify first, because it usually collapses.

Average of $\dfrac{k}{x^2}$ over the interval between 1 and $k$ is $\dfrac{k}{1 \cdot k} = 1$, **identically, for every $k$**.
Verified at $k = 0.3, 0.7, 2, 9$.
So "find $k$ such that this average is 32" has **no solution at all**, and "find $k$ such that it is 1" has infinitely many.
This is the cheapest way an examiner can test whether you simplify before solving.

### Family 8 - feasibility before solving

Trigger: "for which targets does a solution exist".
Tool: the range of $f_{\text{avg}}$.

For this question: on $(0,1)$ the average sweeps $(5, \infty)$; on $(1,\infty)$ it sweeps $(0,5)$; $5$ itself is never attained because it would need $k=1$.
So a solution exists for **every positive target except 5**, and its side of 1 is decided by whether the target exceeds 5.

Combined with the sandwich $m \le f_{\text{avg}} \le M$, this also gives a pre-solve bound: $32 \le \max f = 5/k^2$ forces $k \le 0.3952847075$.

### Family 9 - units and rescaling

Trigger: the stem attaches physical units.
Tool: exponent bookkeeping.

Write $[x] = L$ and $[f] = F$.
Then the constant $5$ must carry $F\cdot L^2$, the integral carries $F\cdot L$, the average carries $F$, and **$k$ carries $L$** - it is a length, not a pure number, so the answer is "$\frac{5}{32}$ of whatever unit $x$ is measured in".

A dimensional gate over these vectors accepts the correct relation and rejects four seeded candidates: $\int f\,dx$ offered as an average, the sum $f + x$, $k$ declared dimensionless, and - the interesting one - **the expression "$5 - \frac{5}{k}$" exactly as written**, because $5$ carries $F L^2$ and $\frac{5}{k}$ carries $F L$.
The line is only legal as $\frac{5}{x_0} - \frac{5}{k}$ with $x_0 = 1$ understood as a **length**.
That is a good thing to know: the numeral 1 in "between 1 and $k$" is not a pure number.

A conversion arm confirms it.
Re-measure $x$ in centimetres, so the interval runs from $100$ to $15.625$ and $f$ becomes $50000/x^2$; the average is still $32$.
Forgetting to rescale the constant gives $0.0032$, a factor of $10^4$ out.

**The gate's blind spot, stated so silence is not mistaken for coverage.**
Dividing by $k$ instead of by the width $(1-k)$ is **dimensionally legal** - both are lengths - so the units gate structurally cannot see that error.
Only the substitution check can.

### Family 10 - the orientation trap by itself

Trigger: the stem says "between $a$ and $k$" and the answer lands on the far side of $a$.
Tool: none needed - it cancels.

| stem | naive interval | true interval | does the answer change |
| :--- | :--- | :--- | :--- |
| average of $5/x^2$ between 1 and $k$ is 32 | $[1,k]$ | $\left[\frac{5}{32}, 1\right]$ | no |
| average of $5/x^2$ between 1 and $k$ is 2 | $[1,k]$ | $[1, 2.5]$ | no |
| average of $5/x^2$ between 2 and $k$ is 32 | $[2,k]$ | $\left[\frac{5}{64}, 2\right]$ | no |

The answer never changes.
What changes is whether you can **describe** the interval correctly if the stem asks a follow-up, such as "over what interval" or "find the mean-value point".
That is the only place the orientation costs you marks, and it is why the identity in section 2.4 is worth stating rather than just relying on.

### Family 11 - the forward question (this is Q19.6)

Trigger: everything is given except the average.
Tool: compute.

This is the other half of the pair, and section 11 maps the two against each other.

It hides **structurally**, not by luck: reversing the limits flips the sign of the integral and of the width together, so the quotient is unchanged.
It is also not really a mistake in the arithmetic - it is a wrong belief about where $k$ sits that the algebra forgives.

**This stem does NOT inherit Q19.6's degeneracies, and that was swept rather than assumed.**

Neither holds here.
$5/x^2$ is not affine, so the endpoint mean gives $104.9$ and the midpoint value gives $14.9598246896$ where the truth is $32$.
The fixed endpoint is $1$, not $0$, so dividing by the endpoint instead of the width agrees with the truth at **zero of 500** positive left endpoints swept over $[0,5]$ at the exam's own width - with a control confirming it does agree in the limit $a \to 0$, which is exactly Q19.6's case.
**The inverse problem inherits the shape of the question but none of its degeneracies.**

### 9.0.1 The magnitude pattern

This is a **fifth** distinct behaviour for this category, and it is not any of the four already recorded.

- Positivity is **not** inert here: 6 of the 24 wrong values are negative, so the single word "positive" in the stem does real work. That separates this question from Q19.4, Q19.5 and Q19.6, where positivity rejected almost nothing.
- A **sign repair rescues 2 of those 6**. C9 and C10 both produce exactly $-0.15625$, so taking the absolute value hands back the right answer. The other four negatives - $-0.1851851852$, $-0.4810561549$, $-0.2094305850$, $-1.7905694150$ - are not rescued.
- The bracket helps a great deal: the sandwich rejects **13 of 24**, against Q19.6's 3 of 23. That is because the target $32$ is far outside the range of $f$ near $x=1$, so it constrains $k$ hard.
- **Four values are reached by more than one method**, covering 8 of the 25 candidate values: $-0.15625$ from C9 and C10, $0.1351351351$ from C1 and C4, $0.15625$ from C0 and C21, and $6.4$ from C7 and C19. A wrong answer therefore does not identify its own cause.

So: **positivity active, sign repair partial, bracket strong.**

### 9.1 Ranked traps

1. **Reporting $\frac{32}{5} = 6.4$.**
   The reciprocal slip at the last step.
   Two separate census rows land on it.
   Killed by the sentence "a bigger average needs a smaller endpoint".
2. **Setting the integral equal to 32 instead of the average.**
   Gives $\frac{5}{37} = 0.1351351351$, which is positive, less than 1, and passes the sandwich - it survives every cheap check and only substitution catches it.
   This is the single most dangerous wrong answer on the question.
3. **Not noticing $k < 1$.**
   Costs nothing on the answer itself, but wrecks any follow-up that names the interval or asks for the mean-value point.
4. **Concluding "no solution" because $k>1$ was assumed.**
   The C18 row.
   On a 10-point item this is the worst outcome available.
5. **Failing to cancel $(k-1)$** and then wrestling with $\frac{5(k-1)}{k(k-1)}$ under time pressure, often ending at C14's $0.1207843891$.
6. **Dividing by $k$ rather than by the width**, C3's $0.3248061549$. Dimensionally legal, band-legal, sandwich-legal. Only substitution sees it.
7. **Setting $f(k) = 32$**, C15's $0.3952847075$. Note this lands **exactly on the mean-value point**, which makes it feel right; it is the value of $x$ where $f$ equals its average, not the endpoint.
8. **Antiderivative slips**: $5\ln x$ (C11) and $+5/x$ (C10). The second changes only a sign and lands on $-0.15625$, which absolute value silently repairs.
9. **Forgetting the 5**, C13's $0.03125$. Passes positivity, band and sandwich.
10. **Rounding $0.15625$ to $0.16$.** The decimal terminates; rounding it is a pure loss with no upside.

## 11. Closing the pair - one procedure for Q19.6 and Q19.7

Both questions are the same formula read in opposite directions.

```
                  f, a, b  KNOWN                    f, a, T  KNOWN, one endpoint UNKNOWN
                       |                                        |
              Q19.6: COMPUTE                          Q19.7: SOLVE
                       |                                        |
        (1/(b-a)) * INT f dx  =  ?              (1/(k-a)) * INT f dx  =  T
                       |                                        |
                 arithmetic                          integrate SYMBOLICALLY
                       |                                        |
                       |                          simplify - look for (k-a) to cancel
                       |                                        |
                       |                          classify the equation in k, solve
                       |                                        |
                       |                          COUNT the solutions (monotone?)
                       |                                        |
                       |                          apply the stem's wording ("positive")
                       |                                        |
                 check: m <= avg <= M             check: substitute k back, recompute
                 check: units                     check: which side of a does k sit
```

### Which question teaches what

| | Q19.6 (Final Exam 1, item 14, 3 pts) | Q19.7 (Final Exam 2, item 12, 10 pts) |
| :--- | :--- | :--- |
| Direction | forward: compute the average | inverse: recover a parameter |
| Integrand | $3x$, affine | $5/x^2$, strictly decreasing |
| Fixed endpoint | $a = 0$ | $a = 1$ |
| Answer | $9$ | $\frac{5}{32}$ |
| Mean-value point | midpoint, $3$ | geometric mean, $\sqrt{5/32}$ |
| Wrong methods that hide | **8 of 23** | **1 of 24**, and it is not an arithmetic error |
| What a right answer proves | very little | the setup, the cancellation, and the orientation |
| Positivity as a check | inert | rejects 6 of 24 |
| Sandwich as a check | rejects 3 of 23 | rejects 13 of 24 |
| Its own lesson | **a correct answer is not evidence** | **a correct answer is evidence, but only substitution can give it to you** |

Q19.6 is the question where getting the right number tells you almost nothing, because its stem is degenerate in two ways at once.
Q19.7 is the question where getting the right number tells you a great deal, because its stem is degenerate in none.
That is why they belong together: the pair teaches that **the informativeness of an answer is a property of the stem, not of the student**.

Practically: use Q19.6 to drill the formula and Q19.7 to drill the check.
