# Q1.3 - Which equations define a function of x

**The question (MT2 Q1, 4 points).**
Determine which of the following equations are well defined functions with an independent variable $x$.
Explain.

- a. $\dfrac{2y}{x^{2}-3\lvert x\rvert}=1$
- b. $y^{2}+x^{2}=10$

**The answers.**

$$\text{a.}\quad\textbf{YES, a function.}\qquad y=\frac{x^{2}-3\lvert x\rvert}{2},
\qquad \text{domain } x\neq 0,\ x\neq 3,\ x\neq-3$$

$$\text{b.}\quad\textbf{NO, not a function.}\qquad y=\pm\sqrt{10-x^{2}},
\qquad \text{at } x=1 \text{ both } y=3 \text{ and } y=-3 \text{ work}$$

| b | the verdict | `no` / `is not a function` / leave the box unticked |
| b | the two branches, if asked | `sqrt(10-x^2)` and `-sqrt(10-x^2)` |
| b | the relation's $x$-range, if asked | `[-sqrt(10),sqrt(10)]` |

## 0. The 30-second version

This is a counting question wearing algebra's clothes.
You are not being asked to solve anything; you are being asked **how many** solutions there are.

```
Does the equation define y as a function of x?
  ONE test: fix an x, count the y that solve it.  1 -> yes.  2 or more -> no.

a)  2y/(x^2 - 3|x|) = 1
  -> y appears ONCE, to the FIRST power.  Solve it, no choices appear:
        y = (x^2 - 3|x|)/2                        exactly one y, every time
  -> but the ORIGINAL has a denominator, so x^2 - 3|x| != 0
        x^2 - 3|x| = |x|(|x| - 3)   (because x^2 = |x|^2)
        -> x != 0,  x != 3,  x != -3            THREE holes, not two
     ANSWER   YES, a function.
              domain (-inf,-3) U (-3,0) U (0,3) U (3,inf)

b)  y^2 + x^2 = 10
  -> y appears SQUARED.  Solving needs a square root, and a square root brings +-:
        y = +- sqrt(10 - x^2)                     two y whenever 10 - x^2 > 0
  -> ONE counterexample finishes it.  x = 1:   y = 3 and y = -3, since 9 + 1 = 10.
     ANSWER   NO.  It is the circle of radius sqrt(10) centred at the origin,
              and the vertical line x = 1 cuts it twice.
```

Both parts are four lines, and neither needs a calculator.
The entire difficulty of part a lives in the words `|x|` and `THREE`, and the entire difficulty of
part b is resisting the urge to write anything longer than one counterexample.

## 1. What this question is really testing

Question 1 is worth 4 of the 94 points on Midterm 2, and it is the cheapest four points on the paper
if you know what is being counted.
It is also the first question, which means the examiner is using it to check a definition before
spending the rest of the paper assuming you have it.

| Reflex | Where it comes back |
| :--- | :--- |
| One input, at most one output | every derivative, every limit, the whole course |
| Reading exclusions off a denominator | Q1.2 composite domains, Q1.4 the cone domain, Q4.1 asymptotes |
| $x^{2}=\lvert x\rvert^{2}$, so $x^{2}-3\lvert x\rvert$ factors as $\lvert x\rvert(\lvert x\rvert-3)$ | Q2.2 the reflected absolute value, and every $\lvert x\rvert$ limit |
| A $\pm$ appears exactly when you take an even root | implicit differentiation, inverse functions, arc length |
| Killing a universal claim with one counterexample | Q3.x "if a limit does not exist, explain why" |
| The vertical line test | Q5.x sketch-from-conditions, where you must draw a *function* |

**The instruction is "Explain".**
Half the marks are the explanation, and the two halves need opposite kinds of evidence.

- Part a is a claim that something is **always** true, so the explanation must be a **general argument**: solve for $y$ and point out that no choice ever appeared.
- Part b is a claim that something **fails**, so the explanation must be **one specific counterexample**. A general argument is not needed and wastes time.

Getting that asymmetry right is worth more than any algebra on this question.
A student who writes "b is a circle" has described the picture without ever demonstrating the failure,
and a student who writes out $y=\pm\sqrt{10-x^{2}}$ and stops has done the algebra without saying what
it proves.

**Format warning.**
The sample paper prints "(4 points)" and reads like a written exam where you would write prose.
The live delivery is Möbius, answer-only and machine-marked.
There the verdict is usually a tick box or a dropdown, and the *explanation* becomes a separate box
asking for the solved form, the domain, or the counterexample $y$-values.
Prepare for both: have the verdict instantly, and have the one-line justification ready in the form of
a formula plus a domain, or a single pair of numbers.

## 2. The five things you must have cold

### 2.1 The definition, in the only form worth memorising

> An equation defines $y$ as a function of $x$ when every $x$ in the domain produces
> **exactly one** $y$.

Two clauses do all the work, and students usually only remember one of them.

The **"exactly one"** clause is what part b fails.
The **"in the domain"** clause is what part a survives.
An $x$ that produces no $y$ at all does not break the function; it is simply not in the domain.
An $x$ that produces two $y$ does break it, and one such $x$ is enough.

That asymmetry is the single most useful fact in this section.

| At a given $x$ the equation has | Effect on the verdict |
| :--- | :--- |
| exactly one $y$ | fine, that $x$ is in the domain |
| no $y$ at all | fine, that $x$ is **not** in the domain |
| two or more $y$ | **fatal**, it is not a function |
| every $y$ | **fatal**, it is not a function |

The graphical name for the same statement is the **vertical line test**: no vertical line may meet the
curve more than once.
A vertical line that misses the curve entirely is allowed, and is exactly what "not in the domain"
looks like.

### 2.2 The $y$-triage table: how $y$ appears decides how many $y$ there are

You can answer this whole question type from the shape of the equation, before doing any algebra.
Look only at how the **dependent** variable appears.

| How $y$ appears | How many $y$ per $x$ | Function? | Why |
| :--- | :--- | :--- | :--- |
| $y$ to the first power only, as $A(x)\,y=B(x)$ | one, wherever $A(x)\neq0$ | **yes** | dividing by $A(x)$ offers no choice |
| $y^{2}$, $y^{4}$, any even power | two | **no** | the even root brings $\pm$ |
| $\lvert y\rvert$ | two | **no** | $\lvert y\rvert=c$ has solutions $y=\pm c$ |
| $y^{3}$, $y^{5}$, any odd power alone | one | **yes** | odd roots of a real number are unique |
| a strictly increasing or decreasing expression in $y$ | one | **yes** | monotone means it hits each value once |
| a non-monotone polynomial in $y$ | up to its degree | **no** | it doubles back |
| $\sqrt{y}$, $\sqrt[4]{y}$, an even root **of $y$** | one | **yes** | $\sqrt{y}=R$ forces $y=R^{2}$, no choice |
| $e^{y}$, $a^{y}$, $\ln y$ | one | **yes** | exponentials and logs are strictly monotone |
| $\sin y$, $\cos y$, $\tan y$ | infinitely many | **no** | periodic, so it repeats every $2\pi$ or $\pi$ |

Two rows are worth staring at because they look alike and behave oppositely.

$y^{2}=x$ is **not** a function, because you must take an even root to free $y$ and the root brings a
sign choice.
$\sqrt{y}=x$ **is** a function, because the even root is already applied to $y$ and undoing it is
squaring, which offers no choice at all.
The even root is dangerous only when you are the one who has to take it.

The other pair worth separating is $\lvert y\rvert=x$, which fails, against $y\lvert y\rvert=x$, which
passes.
The second is strictly increasing through zero, so it never doubles back.

### 2.3 The identity this question is built on: $x^{2}=\lvert x\rvert^{2}$

Part a's denominator is $x^{2}-3\lvert x\rvert$, and it is written that way on purpose.

$$x^{2}-3\lvert x\rvert=\lvert x\rvert^{2}-3\lvert x\rvert=\lvert x\rvert\left(\lvert x\rvert-3\right)$$

$$\lvert x\rvert\left(\lvert x\rvert-3\right)=0
\iff \lvert x\rvert=0 \ \text{ or } \ \lvert x\rvert=3
\iff x=0,\ x=3,\ x=-3$$

**Three** values, not two.
The single most common way to lose this question is to treat the $\lvert x\rvert$ as an $x$, factor
$x^{2}-3x=x(x-3)$, and report $x=0$ and $x=3$.
That answer is wrong, and it is wrong in a way that looks completely finished.
Substituting $x=-3$ into the *wrong* factorisation gives $9-(-9)=18$, comfortably nonzero, which is
why nothing warns you.
Substituting $x=-3$ into the *actual* denominator gives $9-3(3)=0$.

If the absolute value makes you nervous, there is a route that never uses it.
Set $x^{2}=3\lvert x\rvert$, square both sides to get $x^{4}=9x^{2}$, then
$x^{2}\left(x^{2}-9\right)=0$, so $x=0$ or $x=\pm3$.
Squaring is safe here because both sides are already non-negative, so it cannot introduce a false
solution.

A third route is to split by sign, which you need anyway if you are going to graph the thing.

| region | $\lvert x\rvert$ is | the equation becomes | $y$ equals |
| :--- | :--- | :--- | :--- |
| $x>0$ | $x$ | $\dfrac{2y}{x^{2}-3x}=1$ | $\dfrac{x(x-3)}{2}$ |
| $x<0$ | $-x$ | $\dfrac{2y}{x^{2}+3x}=1$ | $\dfrac{x(x+3)}{2}$ |

Both branches are parabolas, and they are mirror images, because replacing $x$ by $-x$ leaves
$x^{2}-3\lvert x\rvert$ unchanged.
So $y$ is an **even** function of $x$.

### 2.4 The restriction triggers

Four things, and only four things, remove points from a domain in this course.

| What you see | The condition it forces | Bracket at the boundary |
| :--- | :--- | :--- |
| a denominator $D(x)$ | $D(x)\neq 0$ | the point is **removed**, always |
| an even root $\sqrt[2n]{R(x)}$ | $R(x)\geq 0$ | **closed**, the boundary is included |
| a logarithm $\ln A(x)$ | $A(x)>0$ | **open**, the boundary is excluded |
| a physical quantity (radius, length, time) | usually $>0$ | open, and stated in words |

For part a only the first row fires, and it fires three times.

Read the condition off the **original** equation, never off whatever you simplified it to.
That is the same rule as Q1.2, and it matters here for a specific reason covered in Section 9, trap 2.

### 2.5 Interval notation, written the way Möbius wants it

| The set | Interval notation | Möbius |
| :--- | :--- | :--- |
| all reals | $(-\infty,\infty)$ | `(-infinity,infinity)` |
| all reals except $0,\pm3$ | $(-\infty,-3)\cup(-3,0)\cup(0,3)\cup(3,\infty)$ | `(-infinity,-3)U(-3,0)U(0,3)U(3,infinity)` |
| $-\sqrt{10}\leq x\leq\sqrt{10}$ | $\left[-\sqrt{10},\sqrt{10}\right]$ | `[-sqrt(10),sqrt(10)]` |
| $x\geq 0$ | $[0,\infty)$ | `[0,infinity)` |
| $x>3$ | $(3,\infty)$ | `(3,infinity)` |

Removing $n$ isolated points always produces $n+1$ intervals.
Part a removes three points, so the answer has **four** intervals.
If you wrote three, you dropped one, and it is almost always the $-3$.

## 3. The universal procedure

This works on every version of this question in Section 8.

> 1. **Find $y$ and only $y$.** Ignore the $x$ side entirely for a moment. Ask: to what power does $y$ appear, and is it inside an absolute value, a root, or a trig function?
> 2. **Read the triage table in 2.2 and predict the count.** You now already know the verdict. Everything after this is producing evidence for it.
> 3. **If the prediction is "one", solve for $y$ and show that no choice appeared.** Write the formula. That formula *is* the explanation.
> 4. **If the prediction is "two or more", stop solving and find one concrete counterexample.** Pick the $x$ that makes the arithmetic cleanest, produce two explicit $y$, and check both in the original equation.
> 5. **Only if the answer was "yes": get the domain, from the ORIGINAL equation.** Apply the trigger table in 2.4 and count the intervals.
> 6. **Write the one sentence.** "Yes, because solving gives $y=\ldots$, one value for each $x$ with $\ldots$", or "No, because $x=\ldots$ gives both $y=\ldots$ and $y=\ldots$".

Step 4 is where most of the wasted time on this question goes.
Once you know it fails, a general formula is worth nothing extra.
Two integers are a complete proof, and they take five seconds.

**Classify before you start.**
One look at the equation tells you which family you are in and therefore what to write.

| What you see in the equation | Count | Verdict | Family |
| :--- | :--- | :--- | :--- |
| $y$ already alone on one side | one | function | 0 |
| $y$ to the first power, coefficient $A(x)$ | one, where $A\neq0$ | function | 1 |
| $y^{2}$, $y^{4}$, $y^{2n}$ | two | not a function | 2 |
| $y^{3}$, $y^{5}$, $y^{2n+1}$ alone | one | function | 3 |
| a monotone mix such as $y^{3}+y$ | one | function | 4 |
| a non-monotone mix such as $y^{3}-3y$ | up to three | not a function | 5 |
| $\lvert y\rvert$ | two | not a function | 6 |
| $\sqrt{y}$, $\sqrt[4]{y}$ | one | function | 7 |
| $e^{y}$ or $\ln y$ / $\sin y$ or $\cos y$ | one / infinitely many | function / not | 8 |
| $\lvert x\rvert$, $x^{3}$, anything on the $x$ side only | unchanged | domain only | 9 |
| the equation collapses, as in $x^{2}+y^{2}=0$ | 1, 0 or all | case by case | 10 |
| a graph, a table or a list of pairs | count the repeats | vertical line test | 11 |
| a piecewise definition | check the seam | function iff the branches agree there | 12 |
| the question asks about $x$ as a function of $y$ | swap the roles | horizontal line test | 13 |

Part a is Family 1 with a Family 9 decoration.
Part b is Family 2.
The examiner picked one of each so that the two halves test opposite reflexes, exactly as in Q1.2.

## 4. Q1.3 worked, four ways

### Part a - $\dfrac{2y}{x^{2}-3\lvert x\rvert}=1$

**Route A: solve for $y$.**

Multiply both sides by the denominator, which is legal precisely because we are going to record that
the denominator is nonzero:

$$2y=x^{2}-3\lvert x\rvert \qquad\Longrightarrow\qquad
\boxed{\,y=\frac{x^{2}-3\lvert x\rvert}{2}\,}$$

Nowhere in that line did a choice appear.
No square root was taken, no $\pm$ was introduced, no branch was picked.
Every $x$ that survives the denominator produces one and only one $y$, so it is a function.

**The domain, from the original.**

$$x^{2}-3\lvert x\rvert=\lvert x\rvert\left(\lvert x\rvert-3\right)=0
\quad\Longrightarrow\quad x=0,\ 3,\ -3$$

$$\boxed{\operatorname{dom}=\left\{x\in\mathbb{R}: x\neq 0,\pm3\right\}
=(-\infty,-3)\cup(-3,0)\cup(0,3)\cup(3,\infty)}$$

**Route B: count the roots.**

Write the equation as $F(x,y)=0$ with

$$F(x,y)=\frac{2}{x^{2}-3\lvert x\rvert}\,y-1=A(x)\,y-1$$

This is a **linear** equation in $y$ with coefficient $A(x)=\dfrac{2}{x^{2}-3\lvert x\rvert}$.
A linear equation $Ay=B$ has exactly one root when $A\neq0$, no root when $A=0$ and $B\neq0$, and
every $y$ when $A=B=0$.
Here $A(x)$ is a nonzero number divided by something, so $A(x)$ is never zero anywhere it is defined.
Exactly one root, always.
This route is worth knowing because it generalises: it is the same argument you use in Families 4, 5
and 10, where there is no clean solved form to point at.

**Route C: the graph.**

For $x>0$ the branch is $y=\dfrac{x(x-3)}{2}$, an upward parabola through $(0,0)$ and $(3,0)$ with its
minimum at $x=\dfrac32$, where $y=\dfrac{1.5(1.5-3)}{2}=-\dfrac98=-1.125$.
For $x<0$ it is the mirror image, minimum at $x=-\dfrac32$, also $-\dfrac98$.

Now the detail that makes this question memorable.
The three excluded $x$-values are $0$, $3$ and $-3$, and those are exactly the three places where the
solved formula would have given $y=0$.
So the picture is a smooth pair of parabolic arcs with **three holes punched in it, all three sitting
on the $x$-axis**, at $(-3,0)$, $(0,0)$ and $(3,0)$.

Every vertical line meets that picture at most once, so it passes the vertical line test.
The three lines $x=-3$, $x=0$ and $x=3$ meet it zero times, which is allowed.

**Route D: the sign of $\partial F/\partial y$.**

$$\frac{\partial}{\partial y}\left(\frac{2y}{x^{2}-3\lvert x\rvert}-1\right)
=\frac{2}{x^{2}-3\lvert x\rvert}$$

This is never zero, so for a fixed $x$ the left side is strictly monotone in $y$ and can cross zero at
most once.
Overkill here, but it is the only route that works on Family 4, where no formula for $y$ exists.

### Part b - $y^{2}+x^{2}=10$

**Route A: solve for $y$.**

$$y^{2}=10-x^{2} \qquad\Longrightarrow\qquad y=\pm\sqrt{10-x^{2}}$$

That $\pm$ is the whole answer.
Because you had to take an even root to free $y$, both signs are genuine solutions whenever
$10-x^{2}>0$.

**Route B: the counterexample, which is what you should actually write.**

Take $x=1$.

$$y^{2}+1^{2}=10 \;\Longrightarrow\; y^{2}=9 \;\Longrightarrow\; y=3 \ \text{ and } \ y=-3$$

Check both in the original equation: $3^{2}+1^{2}=10$ and $(-3)^{2}+1^{2}=10$.
Two different $y$ for the same $x$, so it is **not** a function.
Done, in one line.

$x=1$ is the right choice because $10-1=9$ is a perfect square.
$x=3$ works just as well, giving $y=\pm1$.
Avoid $x=0$, which gives the correct but ugly $y=\pm\sqrt{10}\approx\pm3.1623$.

**Route C: the discriminant.**

Read $y^{2}+\left(x^{2}-10\right)=0$ as a quadratic in $y$ with $a=1$, $b=0$, $c=x^{2}-10$:

$$\Delta=b^{2}-4ac=0-4\left(x^{2}-10\right)=40-4x^{2}$$

| $x$ | $\Delta=40-4x^{2}$ | roots | meaning |
| :--- | :--- | :--- | :--- |
| $0$ | $40$ | two | $y=\pm\sqrt{10}$ |
| $1$ | $36$ | two | $y=\dfrac{0\pm\sqrt{36}}{2}=\pm3$ |
| $2$ | $24$ | two | $y=\pm\sqrt{6}\approx\pm2.4495$ |
| $3$ | $4$ | two | $y=\pm1$ |
| $\pm\sqrt{10}$ | $0$ | one (repeated) | $y=0$, the tangent point |
| $4$ | $-24$ | none | $x=4$ is outside the relation |

$\Delta>0$ on the whole open interval $-\sqrt{10}<x<\sqrt{10}$, which is an infinite supply of
counterexamples, and one is enough.

**Route D: the graph.**

$y^{2}+x^{2}=10$ is the circle centred at the origin with radius $\sqrt{10}\approx3.1623$.
The vertical line $x=1$ enters at $(1,3)$ and leaves at $(1,-3)$, so it meets the circle twice and the
vertical line test fails immediately.

The two points where a vertical line touches the circle exactly once are $x=\pm\sqrt{10}$, where it is
tangent and $y=0$.
Those two exceptions do not rescue anything.
The definition demands *every* $x$ give one $y$, and the interior $x$ all give two.

**The standard follow-up, worth having ready.**
"Restrict it so that it does become a function."
Take the upper half only:

$$y=\sqrt{10-x^{2}},\qquad \operatorname{dom}=\left[-\sqrt{10},\sqrt{10}\right],
\qquad \text{range } \left[0,\sqrt{10}\right]$$

The lower half $y=-\sqrt{10-x^{2}}$ is the other valid answer.
Brackets are **closed** at $\pm\sqrt{10}$, because $\sqrt{0}=0$ exists.

### The route comparison

| | A: solve for $y$ | B: count roots / discriminant | C: the graph | D: sign of $\partial F/\partial y$ |
| :--- | :--- | :--- | :--- | :--- |
| Works on part a | yes | yes | yes | yes |
| Works on part b | yes | yes | yes | yes |
| Works when $y$ cannot be isolated (Family 4) | **no** | yes | hard | **yes** |
| Works from a picture with no equation (Family 11) | **no** | no | **yes** | no |
| Gives you the domain as a by-product | yes | no | yes | no |
| Lines of work on this question | 2 | 3 | 5 | 3 |
| Risk | forgetting the $\pm$ | mis-signing $\Delta$ | slow, and a sketch can lie | you must know the derivative |
| Verdict | **use this one under pressure** | the fallback when A stalls | use to explain, not to decide | the specialist tool |

**Under exam pressure: solve for $y$, watch for a $\pm$, then get the domain from the original.**
If the equation refuses to be solved for $y$, switch to D and ask whether the expression in $y$ is
monotone.

## 5. The exam-ready write-up

If the paper you sit asks for method, these are the sentences that earn the marks.
Note that part a needs four sentences and part b needs one.

> **a.** Multiplying both sides by $x^{2}-3\lvert x\rvert$ gives $2y=x^{2}-3\lvert x\rvert$, so
> $y=\dfrac{x^{2}-3\lvert x\rvert}{2}$.
> No even root or absolute value was applied to $y$, so no sign choice arises and each admissible $x$
> determines exactly one $y$.
> The original equation has $x^{2}-3\lvert x\rvert=\lvert x\rvert\left(\lvert x\rvert-3\right)$ in a
> denominator, which vanishes at $x=0$ and $x=\pm3$, so those three values are excluded.
> Therefore the equation **does** define $y$ as a function of $x$, with domain
> $(-\infty,-3)\cup(-3,0)\cup(0,3)\cup(3,\infty)$.
>
> **b.** At $x=1$ the equation becomes $y^{2}=9$, which is satisfied by both $y=3$ and $y=-3$, so a
> single $x$ has two outputs and the equation **does not** define $y$ as a function of $x$.
> (It is the circle of radius $\sqrt{10}$ about the origin, which fails the vertical line test.)

Four things a marker looks for that students routinely skip.

**Naming the reason no choice appeared** in part a, rather than just displaying the formula.
The formula alone shows you can do algebra; the sentence shows you know what "function" means.

**Listing all three excluded values**, and in particular writing $-3$.
This is the single discriminating step in part a.

**Giving numbers, not a picture, in part b.**
"It is a circle" is a description. "$x=1$ gives $y=3$ and $y=-3$" is a proof.

**Not writing that part a "is not a function because it is undefined at three points".**
Being undefined somewhere shrinks the domain; it does not disqualify a function.
That distinction is what part a is actually testing.

## 6. Verify before you commit

This takes about twenty seconds and it catches every error this question can produce.

**The one-$x$ test, which is the important one.**
Pick an easy $x$ and count the $y$ by hand, from the original equation.

Part a at $x=4$: $\dfrac{2y}{16-12}=1$, so $\dfrac{2y}{4}=1$, so $y=2$.
One value, and the formula agrees: $\dfrac{16-3(4)}{2}=\dfrac{4}{2}=2$.

Part b at $x=3$: $y^{2}+9=10$, so $y^{2}=1$, so $y=1$ or $y=-1$.
Two values, which is the verdict.

**Confirm each excluded point actually breaks something.**
An exclusion you cannot justify is an exclusion you invented, and a missing one is a lost mark.

| $x$ | denominator $x^{2}-3\lvert x\rvert$ | equation becomes | conclusion |
| :--- | :--- | :--- | :--- |
| $0$ | $0-0=0$ | $\dfrac{2y}{0}=1$ | undefined for every $y$, excluded |
| $3$ | $9-9=0$ | $\dfrac{2y}{0}=1$ | undefined for every $y$, excluded |
| $-3$ | $9-9=0$ | $\dfrac{2y}{0}=1$ | undefined for every $y$, excluded |
| $2.999$ | $-0.002999$ | fine | tiny but nonzero, so **included** |

That last row is the point.
The denominator gets arbitrarily close to zero without any additional $x$ being excluded.
Only the three exact roots come out.

**Count the intervals.**
Three removed points give four intervals.
If your interval notation has three pieces, you dropped one, and it is $-3$.

**Check the evenness, which is free.**
$y(4)=2$ and $y(-4)=2$.
$y(5)=5$ and $y(-5)=5$.
Since $x^{2}$ and $\lvert x\rvert$ are both even, $y$ must be even, so any answer where $y(-a)\neq
y(a)$ has an arithmetic slip in it.

**Check part b by substitution, both signs.**
$3^{2}+1^{2}=9+1=10$ and $(-3)^{2}+1^{2}=9+1=10$.
Two ticks, and the question is finished.

**The numbers worth memorising for this question.**

$$y(1)=y(2)=-1,\qquad y(4)=2,\qquad y(5)=5,\qquad
\min y=-\frac98=-1.125 \text{ at } x=\pm\frac32$$

$$\sqrt{10}\approx3.1623,\qquad \sqrt{6}\approx2.4495,\qquad 2\sqrt{3}\approx3.4641$$

The first line is part a's own values, and $y(1)=y(2)=-1$ is also the fastest proof that $x$ is *not*
a function of $y$ here, which is the Family 13 follow-up.
The second line covers part b and the two most common reworkings of it.

## 7. Answer-entry rules

Möbius is answer-only and machine-marked, so the risk on a conceptual question is not the mathematics
but the **shape** of the box you are typing into.

| Rule | Do | Not |
| :--- | :--- | :--- |
| Absolute value | `abs(x)` | `\|x\|`, `mod(x)` |
| Multiplication | `3*abs(x)` | `3abs(x)` |
| Whole numerator bracketed | `(x^2-3*abs(x))/2` | `x^2-3*abs(x)/2` |
| Powers | `x^2` | `x**2`, `x2` |
| Exact endpoints | `sqrt(10)` | `3.162` |
| Infinity | `infinity` | `inf`, `oo`, `∞` |
| Union | `U` between intervals | a comma, or the word "or" |
| Excluding a point, if an inequality box | `x != 0` | `x =/= 0` |
| The two branches | `sqrt(10-x^2)`, `-sqrt(10-x^2)` | `+-sqrt(10-x^2)` in one box |

**The single most expensive typo on this question is `x^2-3*abs(x)/2`.**
It parses as $x^{2}-\dfrac{3\lvert x\rvert}{2}$, because division binds tighter than the subtraction.
At $x=4$ that gives $16-6=10$ where the true value is $2$.
At $x=5$ it gives $25-7.5=17.5$ where the true value is $5$.
Nothing about either output looks like a typo, which is why it costs the whole mark.
Bracket the entire numerator before you divide, every time.

**The second most expensive is a three-interval domain.**
`(-infinity,0)U(0,3)U(3,infinity)` is a well-formed, parseable, confidently wrong answer.
It is what you get by factoring $x^{2}-3x$ instead of $x^{2}-3\lvert x\rvert$.
Count the pieces against the rule "three removed points, four intervals" before you submit.

**Verdict boxes.**
If the verdict is a dropdown, read the wording carefully.
"Is a function of $x$" and "defines $y$ implicitly" are not the same claim, and some Möbius items ask
which of the two equations is a function, expecting you to tick a) only.

**Always click the preview icon.**
An empty preview modal means broken syntax, not wrong mathematics.
For part a these are all accepted as equivalent, so pick the one you can type without a slip:
`(x^2-3*abs(x))/2`, `(abs(x)^2-3*abs(x))/2`, `abs(x)*(abs(x)-3)/2`.

## 8. The variation catalog

This is the part that makes the question repeatable.
The families are organised by **where $y$ sits in the equation**, because that alone decides the
verdict, not by what the equation looks like on the page.
Everything below has been checked by an independent root count.

Read the whole catalog as one idea seen fourteen times: *fix $x$, count the $y$*.
Only three things ever vary between families.
Whether solving for $y$ forces a sign choice, whether the expression in $y$ doubles back, and whether
the $x$ side removes points from the domain without affecting the verdict.

### Family 0 - $y$ is already alone: always a function, only the domain is work

**Trigger.** The equation is already $y=\ldots$, or becomes so in one step.
**Tool.** None for the verdict. Apply the trigger table from 2.4 for the domain.
**The trap.** Answering the verdict and forgetting the domain, which is usually where the marks are.

| equation | function? | domain |
| :--- | :--- | :--- |
| $y=\dfrac{x^{2}-3\lvert x\rvert}{2}$ | yes | $(-\infty,\infty)$, **note this differs from Q1.3a** |
| $y=\sqrt{x-1}$ | yes | $[1,\infty)$ |
| $y=\dfrac{1}{x^{2}-4}$ | yes | $x\neq\pm2$ |
| $y=\ln x$ | yes | $(0,\infty)$ |
| $y=\dfrac{x}{x^{2}+1}$ | yes | $(-\infty,\infty)$ |

Row 1 is the sharpest item in the whole catalog and it is worth thirty seconds.
The **solved form** $y=\dfrac{x^{2}-3\lvert x\rvert}{2}$ is defined for every real $x$, including
$0$ and $\pm3$, where it quietly returns $0$.
The **original equation** is defined nowhere near those three points.
They are different functions, and the exam gave you the second one.
That is why Section 3 step 5 says to read the domain from the original.

### Family 1 - linear in $y$: $A(x)\,y=B(x)$, a function wherever $A(x)\neq0$

**Trigger.** $y$ appears once, to the first power, possibly multiplied or divided by an expression in $x$.
**Tool.** Divide by $A(x)$, then exclude the $x$ that make $A(x)$ zero or undefined.
**This is Q1.3 part a.**

| equation | function? | solved $y$ | domain |
| :--- | :--- | :--- | :--- |
| $\dfrac{2y}{x^{2}-3\lvert x\rvert}=1$ | yes | $\dfrac{x^{2}-3\lvert x\rvert}{2}$ | $x\neq0,\pm3$ |
| $xy=1$ | yes | $\dfrac1x$ | $x\neq0$ |
| $(x-2)y=x+1$ | yes | $\dfrac{x+1}{x-2}$ | $x\neq2$ |
| $\dfrac{3y}{x^{2}-4}=1$ | yes | $\dfrac{x^{2}-4}{3}$ | $x\neq\pm2$ |
| $\lvert x\rvert\,y=4$ | yes | $\dfrac{4}{\lvert x\rvert}$ | $x\neq0$ |
| $\dfrac{2y}{x^{2}-5\lvert x\rvert}=1$ | yes | $\dfrac{x^{2}-5\lvert x\rvert}{2}$ | $x\neq0,\pm5$ |
| $\dfrac{3y}{\lvert x\rvert-2}=1$ | yes | $\dfrac{\lvert x\rvert-2}{3}$ | $x\neq\pm2$ |
| $\dfrac{2y}{x^{3}-4x}=1$ | yes | $\dfrac{x^{3}-4x}{2}$ | $x\neq0,\pm2$ |
| $x^{2}y+y=x$ | yes | $\dfrac{x}{x^{2}+1}$ | $(-\infty,\infty)$ |

Read the table as structure rather than as nine facts.
The verdict column is the same word nine times, because linear-in-$y$ *always* wins.
All the variety is in the domain column, and every entry there is just "where is the coefficient
zero".
Rows 6 and 8 are the two most likely reworkings of the exam question: $x^{2}-5\lvert x\rvert$ moves the
holes from $\pm3$ to $\pm5$, and $x^{3}-4x=x(x-2)(x+2)$ swaps the absolute value for a cubic that
happens to produce three zeros the same way.
Row 9 is the reminder that a coefficient can have no zeros at all: $x^{2}+1\geq1$ always, so nothing
is excluded, and the correct answer is "all real numbers" rather than a blank.

### Family 2 - an even power of $y$: the $\pm$ makes it fail

**Trigger.** $y^{2}$, $y^{4}$, or any even power, anywhere in the equation.
**Tool.** One counterexample. Solve for $y^{2}$, pick an $x$ making it a perfect square, and quote both roots.
**This is Q1.3 part b.**

| equation | function? | a counterexample | the shape |
| :--- | :--- | :--- | :--- |
| $y^{2}+x^{2}=10$ | no | $x=1$: $y=\pm3$ | circle, radius $\sqrt{10}$ |
| $y^{2}=x$ | no | $x=4$: $y=\pm2$ | sideways parabola |
| $y^{2}=x^{3}$ | no | $x=4$: $y=\pm8$ | cusp at the origin |
| $\dfrac{x^{2}}{9}+\dfrac{y^{2}}{4}=1$ | no | $x=0$: $y=\pm2$ | ellipse |
| $y^{4}=x^{2}$ | no | $x=4$: $y=\pm2$ | two crossing curves |
| $x^{2}-y^{2}=9$ | no | $x=5$: $y=\pm4$ | hyperbola |
| $y^{2}=(x-1)^{2}$ | no | $x=4$: $y=\pm3$ | the two lines $y=\pm(x-1)$ |
| $y^{2}+4x^{2}=16$ | no | $x=1$: $y=\pm2\sqrt3\approx\pm3.4641$ | ellipse |
| $3y^{2}=x$ | no | $x=3$: $y=\pm1$ | sideways parabola |
| $y^{2}+y=x$ | no | $x=6$: $y=2$ and $y=-3$ | **a hidden quadratic** |
| $xy^{2}=1$ | no | $x=4$: $y=\pm\dfrac12$ | two hyperbola branches |

Look at the counterexample column as a single technique, not eleven separate answers.
In every row the author of the question has arranged for one convenient $x$ to make $y^{2}$ a perfect
square, and finding that $x$ is the whole job.
Only two magnitudes ever appear per row, and the signs are always $+$ and $-$ of each other, except in
row 10.

Row 10 deserves its own look because it is the one that catches people.
$y^{2}+y=x$ has no visible $\pm$ and the two roots are **not** negatives of each other: at $x=6$ they
are $2$ and $-3$.
Complete the square or use the quadratic formula, $y=\dfrac{-1\pm\sqrt{1+4x}}{2}$, and the $\pm$
reappears.
Any equation that is quadratic in $y$ fails, whether or not the $y$ term is there.

Row 11 also has a domain twist on top of the verdict: $xy^{2}=1$ has two $y$ when $x>0$ and none at
all when $x\leq0$, so it fails, but only on the half-line where it exists.

### Family 3 - an odd power of $y$: unique real root, so it is a function

**Trigger.** $y^{3}$, $y^{5}$, or any odd power, appearing alone.
**Tool.** The odd root, which is single-valued on the reals. Say so explicitly.

| equation | function? | solved $y$ | check |
| :--- | :--- | :--- | :--- |
| $y^{3}=x$ | yes | $\sqrt[3]{x}$ | $x=-8\Rightarrow y=-2$ |
| $y^{3}+x=1$ | yes | $\sqrt[3]{1-x}$ | $x=-7\Rightarrow y=2$ |
| $y^{3}=x^{2}$ | yes | $\sqrt[3]{x^{2}}$ | $x=8\Rightarrow y=4$ |
| $y^{5}=x-2$ | yes | $\sqrt[5]{x-2}$ | $x=34\Rightarrow y=2$ |
| $2y^{3}=x$ | yes | $\sqrt[3]{x/2}$ | $x=16\Rightarrow y=2$ |

The single sentence that explains the entire family: **every real number has exactly one real cube
root, but a positive real number has two real square roots.**
That is the whole difference between Family 2 and Family 3, and it is why $y^{2}=x$ fails while
$y^{3}=x$ passes.
Note row 3: the right side $x^{2}$ is even and the *outputs* repeat, since $y(2)=y(-2)$, but that is
harmless.
Repeated outputs are allowed; repeated outputs for the same input are not.

### Family 4 - $y$ cannot be isolated, but the expression is monotone

**Trigger.** A mix of $y$ powers, or $y$ inside and outside a function, with no clean algebra available.
**Tool.** Differentiate with respect to $y$. If $\partial F/\partial y$ never changes sign, there is at most one root.

| equation | $\partial/\partial y$ | sign | function? |
| :--- | :--- | :--- | :--- |
| $y^{3}+y=x$ | $3y^{2}+1$ | $\geq1>0$ | yes |
| $y+e^{y}=x$ | $1+e^{y}$ | $>1>0$ | yes |
| $y^{5}+3y=x$ | $5y^{4}+3$ | $\geq3>0$ | yes |
| $2y+\sin y=x$ | $2+\cos y$ | $\geq1>0$ | yes |
| $y^{3}+2y-5=x$ | $3y^{2}+2$ | $\geq2>0$ | yes |

You will never be asked for a formula in this family, only for the verdict and the reason.
The reason is one sentence: the left side is strictly increasing in $y$, so it takes each value once.
Useful spot values: $y^{3}+y$ equals $2$ at $y=1$, $10$ at $y=2$, and $30$ at $y=3$.
Row 4 is the prettiest, because $\cos y$ oscillates and yet $2+\cos y$ never reaches zero, so the wobble
never becomes a doubling back.

### Family 5 - odd degree but non-monotone: it still fails

**Trigger.** An odd power of $y$ with a **negative** lower-order $y$ term, such as $y^{3}-3y$.
**Tool.** Find where $\partial F/\partial y=0$; if the expression has a local max above a local min, it takes some values three times.

| equation | critical $y$ | local max / min | how many $y$ at $x=0$ | function? |
| :--- | :--- | :--- | :--- | :--- |
| $y^{3}-3y=x$ | $y=\pm1$ | $2$ / $-2$ | 3, namely $0,\pm\sqrt3$ | no |
| $y^{3}-y=x$ | $y=\pm\dfrac{1}{\sqrt3}$ | $\approx0.385$ / $\approx-0.385$ | 3, namely $0,\pm1$ | no |
| $y^{3}-4y=x$ | $y=\pm\dfrac{2}{\sqrt3}$ | $\approx3.079$ / $\approx-3.079$ | 3, namely $0,\pm2$ | no |
| $y^{3}-12y=x$ | $y=\pm2$ | $16$ / $-16$ | 3, namely $0,\pm2\sqrt3$ | no |
| $y^{4}-y^{2}=x$ | $y=0,\pm\dfrac{1}{\sqrt2}$ | $0$ / $-\dfrac14$ | 3, namely $0,\pm1$ | no |

This family is the reason Family 3's rule is stated as "an odd power **alone**".
$y^{3}=x$ passes and $y^{3}-3y=x$ fails, and the only difference is a linear term with a minus sign.
Notice how the counterexample is built in every row: put $x=0$, factor out a $y$, and the remaining
quadratic hands you the other two roots.
$y^{3}-3y=0$ gives $y\left(y^{2}-3\right)=0$, so $y=0,\pm\sqrt3$.
That trick works for every row here, which is why $x=0$ is always the $x$ to pick.

The three-root window is bounded: $y^{3}-3y=x$ has three $y$ only for $-2<x<2$, two at the
endpoints, and one outside.
One $x$ inside that window is a complete disproof, so you never need the window itself.

### Family 6 - $\lvert y\rvert$ is present: the $\pm$ is back

**Trigger.** An absolute value wrapped around $y$ or around an expression containing $y$.
**Tool.** $\lvert u\rvert=c$ has two solutions when $c>0$, one when $c=0$, none when $c<0$. Pick an $x$ making the right side positive.

| equation | function? | at $x=$ | the $y$ |
| :--- | :--- | :--- | :--- |
| $\lvert y\rvert=x$ | no | $5$ | $5$ and $-5$ |
| $\lvert y\rvert+x=3$ | no | $2$ | $1$ and $-1$ |
| $\lvert y\rvert=x^{2}+1$ | no | $0$ | $1$ and $-1$ |
| $\lvert y\rvert=\lvert x\rvert$ | no | $7$ | $7$ and $-7$ |
| $\lvert y-1\rvert=x$ | no | $4$ | $5$ and $-3$ |
| $y\lvert y\rvert=x$ | **yes** | $9$ | $3$ only |
| $\lvert y\rvert=0$ | **yes** | any | $0$ only |

Row 5 is the one to look at twice, because the two answers are not negatives of each other.
$\lvert y-1\rvert=4$ means $y-1=4$ or $y-1=-4$, giving $5$ and $-3$, which average to the shift $1$
rather than to $0$.
The $\pm$ attaches to whatever is inside the bars, not to $y$.

Rows 6 and 7 are the exceptions that prove the rule and both are fair game as a "tricky" version.
$y\lvert y\rvert$ equals $y^{2}$ for $y\geq0$ and $-y^{2}$ for $y<0$, which is strictly increasing
through zero, so it passes.
$\lvert y\rvert=0$ forces $y=0$, a single value, because zero is the one right side that does not
produce a pair.

### Family 7 - an even root **of $y$**: a function, but the $x$ side sets the domain

**Trigger.** $\sqrt{y}$ or $\sqrt[4]{y}$, with $y$ under the root rather than the thing being rooted.
**Tool.** Square (or fourth-power) both sides. That is a one-way operation with no sign choice, so the verdict is "yes". Then require the other side $\geq0$.

| equation | function? | solved $y$ | domain |
| :--- | :--- | :--- | :--- |
| $\sqrt{y}=x$ | yes | $x^{2}$ | $[0,\infty)$ |
| $\sqrt{y}=x-1$ | yes | $(x-1)^{2}$ | $[1,\infty)$ |
| $\sqrt{y}=x^{2}+1$ | yes | $\left(x^{2}+1\right)^{2}$ | $(-\infty,\infty)$ |
| $\sqrt[4]{y}=x$ | yes | $x^{4}$ | $[0,\infty)$ |
| $\sqrt{y}+\sqrt{x}=3$ | yes | $\left(3-\sqrt{x}\right)^{2}$ | $[0,9]$ |

This family is the exact mirror of Family 2 and it is the most reliable way for an examiner to catch
someone who pattern-matched on "there is a square root, therefore $\pm$".
The direction matters.
In Family 2 *you* take the root, so *you* choose a sign.
Here the root is already taken and you undo it by squaring, which is deterministic.

Row 5 is worth doing once.
$\sqrt{y}=3-\sqrt{x}$ needs $x\geq0$ for the left root and $3-\sqrt{x}\geq0$ for the right side, so
$\sqrt{x}\leq3$ and $x\leq9$.
Both brackets are closed: at $x=0$, $y=9$; at $x=9$, $y=0$.
Also useful: at $x=1$, $y=4$; at $x=4$, $y=1$.

### Family 8 - exponentials and logs pass, trig fails

**Trigger.** $y$ inside $e^{\ \cdot}$, $a^{\ \cdot}$, $\ln$, $\sin$, $\cos$ or $\tan$.
**Tool.** Ask whether the outer function is one-to-one. Exponentials and logs are strictly monotone; trig functions are periodic.

| equation | function? | why | domain |
| :--- | :--- | :--- | :--- |
| $e^{y}=x$ | yes | $y=\ln x$, one value | $x>0$ |
| $2^{y}=x$ | yes | $y=\log_{2}x$ | $x>0$ |
| $e^{y}=x^{2}$ | yes | $y=2\ln\lvert x\rvert$ | $x\neq0$ |
| $e^{y}=x-3$ | yes | $y=\ln(x-3)$ | $x>3$ |
| $\ln y=x$ | yes | $y=e^{x}$ | $(-\infty,\infty)$ |
| $\sin y=x$ | **no** | $\pi/6$ and $5\pi/6$ both give $\tfrac12$ | $-1\leq x\leq1$ |
| $\cos y=x$ | **no** | $\pi/3$ and $-\pi/3$ both give $\tfrac12$ | $-1\leq x\leq1$ |
| $\tan y=x$ | **no** | $0$ and $\pi$ both give $0$ | $(-\infty,\infty)$ |
| $\cos y=\dfrac{x}{2}$ | **no** | at $x=1$: $\pi/3$, $-\pi/3$, $\pi/3+2\pi$ | $-2\leq x\leq2$ |

The exponential rows are the one place in this catalog where the domain restriction comes from the
**verdict side** rather than the $x$ side.
$e^{y}$ is always positive, so $e^{y}=x$ simply has no solution when $x\leq0$, and that is a domain
statement rather than a failure.
Compare rows 1 and 6: both have a restricted domain, but row 1 has one $y$ on its domain and row 6
has infinitely many, and only the second breaks the definition.

For the trig rows, quote **three** $y$-values rather than two.
Two could look like a coincidence; three separated by a period makes the point that there are
infinitely many.

### Family 9 - decorations on the $x$ side: the verdict never changes, only the domain

**Trigger.** $\lvert x\rvert$, $x^{3}$, $\sqrt{x}$, or anything else complicated, appearing only where $x$ does.
**Tool.** Ignore it for the verdict. Use it only for the domain.

| equation | function? | domain |
| :--- | :--- | :--- |
| $y=\lvert x\rvert$ | yes | $(-\infty,\infty)$ |
| $y\left(\lvert x\rvert-2\right)=1$ | yes | $x\neq\pm2$ |
| $y=\dfrac{\lvert x\rvert}{x}$ | yes | $x\neq0$ |
| $\dfrac{2y}{\lvert x\rvert-4}=1$ | yes | $x\neq\pm4$ |
| $y=\sqrt{\lvert x\rvert}$ | yes | $(-\infty,\infty)$ |
| $y\lvert x\rvert=x$ | **no** | fails at $x=0$, where every $y$ works |

The lesson of this family is that **$\lvert x\rvert$ is scary in the wrong place**.
It never affects whether the thing is a function, because it does not touch $y$.
All it ever does is double the number of excluded points, because $\lvert x\rvert=c$ has two solutions
where $x=c$ has one.
That doubling is precisely what turns Q1.3a's two obvious holes into three.

Row 6 is the exception and it is a Family 10 case in disguise.
At $x=0$ the equation becomes $0=0$, which every $y$ satisfies, so a single input has infinitely many
outputs.
Row 3 looks similar but is not: at $x=0$ it becomes $y=\dfrac{0}{0}$, which is undefined rather than
universally true, so $0$ is merely excluded.

### Family 10 - degenerate cases: no $y$, every $y$, or a one-point domain

**Trigger.** Substituting a value makes the equation collapse to $0=0$ or to $5=0$.
**Tool.** Check the collapse point by hand. $0=0$ means every $y$, which fails. $5=0$ means no $y$, which is just a domain exclusion.

| equation | function? | what happens |
| :--- | :--- | :--- |
| $x^{2}+y^{2}=0$ | **yes** | only $x=0$ works at all, and it forces $y=0$; domain is the single point $\{0\}$ |
| $x^{2}+y^{2}=-1$ | vacuously | no $(x,y)$ at all, the relation is empty |
| $y=3$ | yes | the horizontal line, one output for every input |
| $x=3$ | **no** | at $x=3$ every $y$ works; a vertical line is never a function |
| $xy=0$ | **no** | fine for $x\neq0$, but at $x=0$ every $y$ works |
| $x^{2}y=x$ | **no** | cancels to $y=\dfrac1x$, yet at $x=0$ the original reads $0=0$ |
| $(x-1)^{2}+(y-2)^{2}=0$ | **yes** | domain $\{1\}$, forcing $y=2$ |

Rows 1 and 4 are the pair worth memorising because they are the two extremes.
A function may have a domain consisting of one single point and still be a perfectly good function.
A relation with a full vertical line of outputs at one input is not a function no matter how well
behaved it is everywhere else.

Row 6 is the cancellation trap, and it is Family 0 row 1 wearing a different disguise.
Dividing $x^{2}y=x$ by $x$ gives $y=\dfrac1x$, which looks merely undefined at $0$.
The original is not undefined at $0$; it is *satisfied by everything* at $0$, which is a much worse
failure.
Cancelling a factor of $x$ hides the difference, which is why you check collapse points in the
original.

### Family 11 - given as a graph, a table, or a list of pairs

**Trigger.** No equation at all. A picture, a set of ordered pairs, or a two-column table.
**Tool.** The vertical line test, or equivalently: does any $x$-value appear twice?

| the data | function? | why |
| :--- | :--- | :--- |
| $\{(1,2),(2,4),(3,6)\}$ | yes | three distinct $x$ |
| $\{(1,2),(1,5),(3,6)\}$ | **no** | $x=1$ appears twice with different $y$ |
| $\{(1,7),(2,7),(3,7)\}$ | yes | repeated **outputs** are fine |
| $\{(0,0),(4,2),(4,-2)\}$ | **no** | $x=4$ appears twice |
| the circle $x^{2}+y^{2}=10$ | **no** | the line $x=1$ crosses twice |
| the parabola $y=x^{2}$ | yes | every vertical line crosses once |
| the sideways parabola $x=y^{2}$ | **no** | the line $x=4$ crosses twice |

Row 3 is the one people get wrong.
A function is allowed to send many inputs to the same output; that is just a function that is not
one-to-one.
It is repeated *inputs* with different outputs that break it.
Rows 6 and 7 are the same curve rotated, and the rotation is the entire difference between passing and
failing, which is the cleanest possible statement that "function of $x$" is a claim about direction.

### Family 12 - a piecewise definition: check the seam

**Trigger.** A definition split by cases where two cases both claim the same boundary value, usually written with two $\leq$ signs.
**Tool.** Substitute the seam value into both branches and compare.

| definition | at the seam | function? |
| :--- | :--- | :--- |
| $x+1$ for $x\leq2$, $3x$ for $x\geq2$ | $3$ vs $6$ | **no** |
| $x+1$ for $x\leq2$, $2x-1$ for $x\geq2$ | $3$ vs $3$ | yes |
| $\sqrt{x}$ for $x\geq0$, $-x$ for $x\leq0$ | $0$ vs $0$ | yes |
| $x$ for $x\leq3$, $5$ for $x\geq3$ | $3$ vs $5$ | **no** |
| $x^{2}$ for $x\leq1$, $2x-1$ for $x\geq1$ | $1$ vs $1$ | yes |
| $2x$ for $x\leq1$, $x^{2}+2$ for $x\geq1$ | $2$ vs $3$ | **no** |
| $3x$ for $x\leq1$, $x+3$ for $x\geq1$ | $3$ vs $4$ | **no** |

The whole family is one subtraction.
Note that a mismatch here is a *different* failure from a jump discontinuity: if the intervals were
written $x<2$ and $x\geq2$ the definition would be a perfectly good function with a jump.
It is the overlapping $\leq$ and $\geq$ that assigns two outputs to one input.
Read the inequality signs before you read the formulas.

### Family 13 - the reverse question: is $x$ a function of $y$?

**Trigger.** "Is $x$ a function of $y$", "is the relation one-to-one", "does it have an inverse".
**Tool.** The same counting, with the roles swapped. Graphically this is the **horizontal** line test.

| equation | $y$ a function of $x$? | $x$ a function of $y$? |
| :--- | :--- | :--- |
| $y=x^{3}$ | yes | yes |
| $y=x^{2}$ | yes | **no**, $y=9$ gives $x=\pm3$ |
| $y^{2}+x^{2}=10$ | **no** | **no** |
| $\dfrac{2y}{x^{2}-3\lvert x\rvert}=1$ | **yes** | **no**, $y=2$ gives $x=4$ and $x=-4$ |
| $y=e^{x}$ | yes | yes, on $y>0$ |
| $y=\sin x$ | yes | **no**, periodic |

Row 4 is the exam question itself, read backwards, and it is the most likely follow-up.
The answer is short: $y$ is an **even** function of $x$, so $y(4)=y(-4)=2$, and one $y$ comes from two
different $x$.
An even cheaper witness is $y(1)=y(2)=-1$, which does not even need the symmetry.
Row 3 is the only row failing in both directions, which is what "circle" means.

## 9. The trap list

Ranked by how often they actually cost marks.

1. **Factoring $x^{2}-3x$ instead of $x^{2}-3\lvert x\rvert$, and missing $x=-3$.** This is the number one error and the reason the absolute value is in the question at all. Use $x^{2}=\lvert x\rvert^{2}$ and factor $\lvert x\rvert\left(\lvert x\rvert-3\right)$, or square the equation $x^{2}=3\lvert x\rvert$ and solve $x^{2}\left(x^{2}-9\right)=0$. Then count: three points, four intervals.
2. **Reading part a's domain off the solved formula.** $y=\dfrac{x^{2}-3\lvert x\rvert}{2}$ is defined everywhere, including at $0$ and $\pm3$ where it returns $0$. The exclusions live in the original equation's denominator and are erased the moment you multiply through. Same trap as Q1.2, different question.
3. **Concluding that part a is "not a function" because it is undefined at three points.** A function is not required to be defined everywhere. Missing inputs shrink the domain; duplicate outputs break the function. Only the second is disqualifying.
4. **Writing a general formula for part b instead of a counterexample.** $y=\pm\sqrt{10-x^{2}}$ is correct but is not yet an explanation. The mark is for naming a specific $x$ with two specific $y$.
5. **Assuming any square root means $\pm$.** $\sqrt{y}=x$ is a function; $y^{2}=x$ is not. The $\pm$ appears only when *you* apply the even root to free $y$, never when the root is already sitting on $y$.
6. **Assuming any odd power is safe.** $y^{3}=x$ passes, but $y^{3}-3y=x$ fails, because the second doubles back. Check monotonicity, not just the leading power.
7. **Missing a hidden quadratic.** $y^{2}+y=x$ has no visible $\pm$, and its two roots at $x=6$ are $2$ and $-3$, not a matched pair. Anything quadratic in $y$ fails.
8. **Giving a three-interval domain.** Three removed points must produce four intervals. `(-infinity,0)U(0,3)U(3,infinity)` is the exact answer you get from trap 1, and it parses perfectly.
9. **Not bracketing the numerator on entry.** `x^2-3*abs(x)/2` parses as $x^{2}-\dfrac{3\lvert x\rvert}{2}$ and gives $10$ at $x=4$ where the answer is $2$.
10. **Treating "every $y$ works" as harmless.** In $xy=0$ and $x^{2}y=x$, the point $x=0$ admits every $y$, which is a failure, not an exclusion. Distinguish $0=0$ from $5=0$ at any collapse point.
11. **Cancelling a factor before checking the collapse point.** $x^{2}y=x$ becomes $y=\dfrac1x$, and the cancellation converts a fatal "every $y$" into a benign "undefined".
12. **Forgetting that repeated outputs are legal.** $\{(1,7),(2,7),(3,7)\}$ is a function. Only repeated *inputs* with different outputs break it.
13. **Answering part b's follow-up with the wrong brackets.** The restricted semicircle $y=\sqrt{10-x^{2}}$ has domain $\left[-\sqrt{10},\sqrt{10}\right]$, closed at both ends, because $\sqrt{0}$ exists.

## 11. The one-page decision tree

```
"Does this equation define y as a function of x?"
|
+-- STEP 1. LOOK ONLY AT y.  Where does the dependent variable sit?
|            Ignore everything on the x side for now.
|
+-- STEP 2. READ THE COUNT off the shape.
|      y to the FIRST power only, A(x)*y = B(x)  -> ONE     -> FUNCTION   [F1]
|      y^2, y^4, any EVEN power                  -> TWO     -> not        [F2]
|      |y|  anywhere                             -> TWO     -> not        [F6]
|      y^3, y^5, odd power ALONE                 -> ONE     -> FUNCTION   [F3]
|      odd power PLUS a negative lower term      -> up to 3 -> not        [F5]
|      sqrt(y), 4th-root(y)   (root ON y)        -> ONE     -> FUNCTION   [F7]
|      e^y, a^y, ln(y)                           -> ONE     -> FUNCTION   [F8]
|      sin y, cos y, tan y                       -> MANY    -> not        [F8]
|      y won't isolate -> differentiate in y:
|             dF/dy never changes sign           -> ONE     -> FUNCTION   [F4]
|             dF/dy changes sign                 -> MANY    -> not        [F5]
|
+-- STEP 3a. IF NOT A FUNCTION: stop solving.  Find ONE counterexample.
|            Pick the x that makes the arithmetic clean (a perfect square,
|            or x = 0 to factor out a y).  Give TWO explicit y.
|            Check BOTH in the ORIGINAL equation.  You are done.
|
+-- STEP 3b. IF A FUNCTION: solve for y and say "no choice appeared".
|
+-- STEP 4. THE DOMAIN, from the ORIGINAL equation, never the solved form.
|            denominator D(x)   -> D(x) != 0     removed points
|            even root sqrt(R)  -> R(x) >= 0     CLOSED bracket
|            log ln(A)          -> A(x) >  0     OPEN bracket
|            |x| present        -> EVERY solution comes in a +- pair
|            n removed points   -> n+1 intervals.  COUNT THEM.
|
+-- STEP 5. CHECK THE COLLAPSE POINTS.  At each excluded x, substitute:
|            "5 = 0"  -> no y      -> just not in the domain, still a FUNCTION
|            "0 = 0"  -> every y   -> NOT a function
|
+-- STEP 6. CHECK.  Fix one easy x and count the y by hand from the original.
             Confirm each excluded x really breaks it.
             Count the intervals.  Then type it, bracket the whole numerator,
             and PREVIEW.
```
