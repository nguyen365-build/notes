# Q1.4 - Volume of a cone as a function of its radius

**The question (MT2 Q2, 4 points).**
Consider a cone whose height is double the size of its radius.

- a. Express the volume $V$ of the cone as a function of radius $r$.
- b. Find the domain of the function in *a.*
- c. Use the function in *a.* to compute the volume of the cone for $r = 3$.

*Hint:* The volume of a cone is $V = \dfrac{\pi r^2 h}{3}$.

**The answers.**

$$\textbf{a.}\quad V(r)=\frac{2\pi r^{3}}{3}
\qquad\qquad \textbf{b.}\quad (0,\infty)
\qquad\qquad \textbf{c.}\quad V(3)=18\pi\approx 56.5486677646$$

**What to type into Möbius:** `2/3*Pi*r^3`, then `(0,infinity)`, then `18*Pi`

## 1. What this question is really testing

This is question 2 of Midterm 2 and it is worth 4 of the paper's points, split across three parts.
It looks like arithmetic.
It is actually a reading test with an arithmetic tail.

| Reflex | Where it comes back |
| :--- | :--- |
| Turning an English constraint into an equation | related rates, optimization, every applied word problem |
| Eliminating a variable so the formula has exactly one input | optimization (you cannot differentiate a two-variable expression), related rates |

## 2. The three things you must have cold

### 2.1 The solid formulas

The paper hands you the cone formula, so this question does not test recall.
A reworded version will not always hand it to you, so know these anyway.

| Solid | Volume | Surface area |
| :--- | :--- | :--- |
| Cone (radius $r$, height $h$) | $\dfrac{\pi r^2 h}{3}$ | base $\pi r^2$, lateral $\pi r \sqrt{r^2+h^2}$ |
| Cylinder | $\pi r^2 h$ | $2\pi r^2 + 2\pi r h$ |
| Sphere | $\dfrac{4\pi r^3}{3}$ | $4\pi r^2$ |
| Box, square base $x$, height $h$ | $x^2 h$ | $2x^2 + 4xh$ |
| Square pyramid, base $s$ | $\dfrac{s^2 h}{3}$ | - |

The single most useful relationship on this list: **a cone is exactly one third of the cylinder that
wraps it.**
That is where the $/3$ comes from, and Section 6 turns it into a free check.

### 2.2 The English-to-algebra dictionary

This is the actual content of the question.
Read the sentence, put the *subject* on the left of the equals sign, and translate.

| English | Equation |
| :--- | :--- |
| "the height is double the radius" | $h = 2r$ |
| "the height is half the radius" | $h = \tfrac{r}{2}$ |
| "the height is triple the radius" | $h = 3r$ |
| "the radius is double the height" | $r = 2h$, so $h = \tfrac{r}{2}$ |
| "the radius is one third the height" | $r = \tfrac{h}{3}$, so $h = 3r$ |
| "the diameter equals the height" | $2r = h$ |
| "the height is double the diameter" | $h = 2(2r) = 4r$ |
| "the diameter is double the height" | $2r = 2h$, so $h = r$ |
| "the height exceeds the radius by 3" | $h = r + 3$ |
| "the height is 2 less than the radius" | $h = r - 2$ |
| "the radius and height sum to 10" | $r + h = 10$, so $h = 10 - r$ |

**The direction test, which takes two seconds and prevents the most expensive error on this question.**
Put in a number.
If "the height is double the radius" and $r = 1$, is $h = 2$ or $h = 0.5$?
A cone twice as tall as its radius is tall and narrow, so $h = 2$.
Written the wrong way round you would get $h = r/2$ and the answer $\pi r^3/6$, which is four times
too small.

**Diameter is the second-most-expensive word in these questions.**
Any sentence containing "diameter" gets a $d = 2r$ substitution *before* you translate anything else.

### 2.3 The two domains, which are different things

| | What it is | How you find it |
| :--- | :--- | :--- |
| **Algebraic domain** | every input the *formula* can accept | denominators nonzero, even roots non-negative, logs positive |
| **Contextual domain** | every input the *situation* can accept | every physical length strictly positive, plus any bound the geometry forces |

The answer to a modelling question is the **intersection** of the two.

For this question the algebraic domain of $\frac{2\pi r^3}{3}$ is all of $\mathbb{R}$, because a
polynomial accepts anything.
So the algebra contributes nothing at all, and the context does one hundred percent of the work.
That is exactly why part b is worth asking, and exactly why people answer $\mathbb{R}$ and lose it.

## 3. The universal procedure

Every "express $Q$ as a function of $x$" question on this course is this procedure.

> 1. **Write the formula** that contains the quantity you are asked for. If the paper gives you a hint formula, use its letters exactly, so your work lines up with the marker's.
> 2. **Count the variables.** The target is one. The formula here has two, $r$ and $h$.
> 3. **Write every constraint sentence as an equation.** One constraint kills one variable.
> 4. **Solve each constraint for the variable you want to remove**, not for the one you are keeping.
> 5. **Substitute and simplify** to one clean expression in the requested variable.
> 6. **Domain:** start from the algebraic domain, then intersect every physical requirement. Each length must be strictly greater than zero, and that includes lengths that are not the variable you kept.
> 7. **Evaluate** if asked, and keep it exact.
> 8. **Check** with Section 6 before you commit.

### Classify before you start

Step 2 versus step 3 tells you which kind of problem you are holding.

| Variables in the formula | Constraints given | What that means |
| :--- | :--- | :--- |
| 2 | 1, of the form $h = cr$ | one substitution, answer is a monomial. **This question.** |
| 2 | 1, of the form $h = ar+b$ | one substitution, answer is a polynomial, and the domain gains a second edge |
| 2 | 1, but it is a fixed *total* (a volume, a perimeter, a budget) | solve the constraint by **division**; expect a $1/r$ term in the answer |
| 2 | 1, but it is Pythagorean | the answer contains a square root and the domain becomes a bounded interval |
| 3 | 2 | substitute twice; do the substitution that cancels most first |
| 2 | 0 | you have missed a sentence. Re-read for "always", "fixed", "constant", "remains" |

## 4. Q1.4 worked three ways

### Route A - substitute the constraint straight into the hint (use this one)

The constraint sentence is "height is double the radius", so

$$h = 2r.$$

Put that into the given formula, changing nothing else.

$$V = \frac{\pi r^2 h}{3} = \frac{\pi r^2 (2r)}{3} = \frac{2\pi r^3}{3}.$$

Domain: $r$ is a length, so $r > 0$; and $h = 2r$ is then automatically positive, so it adds no new
restriction.
The domain is $(0,\infty)$.

Evaluate at $r = 3$, where $h = 6$:

$$V(3) = \frac{2\pi (3)^3}{3} = \frac{2\pi \cdot 27}{3} = 18\pi \approx 56.549.$$

Three lines of algebra and no opportunity to go wrong after line one.

### Route B - go through the height first, then convert back

Solve the constraint the other way, $r = \dfrac{h}{2}$, and eliminate $r$ instead:

$$V = \frac{\pi}{3}\left(\frac{h}{2}\right)^2 h = \frac{\pi h^3}{12}.$$

That is a function of $h$, not of $r$, so it does not answer part a as written.
Put $h = 2r$ back in to finish:

$$V = \frac{\pi (2r)^3}{12} = \frac{8\pi r^3}{12} = \frac{2\pi r^3}{3}. \checkmark$$

This route is longer and it squares a fraction, which is one extra place to drop a factor.
**Learn it anyway**, because $V = \dfrac{\pi h^3}{12}$ is the exact form Midterm 1 question 7 needs,
and it is the form you want whenever the *height* is the thing changing.

### Route C - use the fact that the shape is fixed

"Height is double the radius" pins the *shape* of the cone completely; only the size varies.
Every length therefore scales together, so the volume must scale as the cube of any one length:

$$V = k\,r^3 \quad\text{for some constant } k.$$

Find $k$ from a single easy instance. At $r = 1$ the height is $2$, so
$V = \pi(1)^2(2)/3 = 2\pi/3$, which gives $k = \dfrac{2\pi}{3}$ and

$$V(r) = \frac{2\pi r^3}{3}.$$

This is the fastest route if you already trust the scaling argument, and it is the one that makes
part c's sanity check obvious.
It is a poor route to *write down* on a paper that asks you to show method, because "the shape is
fixed" needs a sentence of justification that the substitution does not.

### Which route, and why

| Route | Lines of algebra | Where it can go wrong | Use it when |
| :--- | :--- | :--- | :--- |
| **A - substitute $h = 2r$** | 3 | only the translation of the sentence | **always, on this question** |
| B - via $V = \pi h^3/12$ | 5 | squaring $h/2$, then cubing $2r$ | the question asks in terms of $h$, or anything is changing with time |
| C - scaling constant | 2 | needs the shape to be genuinely fixed; fails the moment a constraint is affine like $h = r+3$ | checking Route A, or when the constraint is a pure ratio |

**Under exam pressure, use Route A.**
It has the fewest steps, it uses the letters the paper gave you, and its only failure mode is the one
failure mode you have already checked with the direction test.
Route C is worth thirty seconds afterwards as an independent confirmation, because it reaches the
same answer without repeating Route A's algebra - and a check that repeats the work it is checking is
not a check.

## 5. The exam-ready write-up

If the paper you sit wants method, these are the sentences that earn it.
If it is Möbius, you still want them in your head, because they are the order of operations.

> **a.** The height is double the radius, so $h = 2r$.
> Substituting into $V = \dfrac{\pi r^2 h}{3}$ gives $V = \dfrac{\pi r^2(2r)}{3} = \dfrac{2\pi r^3}{3}$.
>
> **b.** $r$ is the radius of a physical cone, so $r > 0$; the expression itself is a polynomial and
> places no further restriction, and $h = 2r > 0$ follows automatically.
> The domain is $(0, \infty)$.
>
> **c.** $V(3) = \dfrac{2\pi (3)^3}{3} = 18\pi$ cubic units.

Three things that pick up marks in part b specifically.
Say *why* $r>0$ (it is a length), say that the polynomial adds nothing, and say that $h$ needed
checking too even though it turned out free.
That last clause is the one that shows you would have caught the $h = r - 2$ version.

## 6. Verify before you commit

This takes eight seconds and it catches every error this question can produce.

**The cylinder check, which is the good one.**
A cone is one third of the cylinder around it.
At $r = 3$ the height is $6$, so the cylinder has volume $\pi r^2 h = \pi \cdot 9 \cdot 6 = 54\pi$.
A third of $54\pi$ is $18\pi$. $\checkmark$
This reaches the answer without touching your formula at all, which is what makes it a real check.

**The degree check.**
$V$ must come out as degree **3** in $r$, always, whenever the constraint is $h = cr$.
Two powers come from $r^2$ and one comes from the $h$.
If you have written $r^2$, you substituted a constant for $h$ instead of something proportional to
$r$, and if you have $r^4$ you squared something you should not have.

**The coefficient check.**
$h = 2r$ doubles the height, so the answer must be exactly **twice** $\dfrac{\pi r^3}{3}$, which is
the $h = r$ cone.
$\dfrac{2\pi r^3}{3}$ is. $\dfrac{\pi r^3}{6}$ is not - that is the constraint read backwards.

**The scaling check.**
Volume goes as $r^3$, so doubling the radius must multiply the volume by $8$ and tripling it by $27$.
$V(3)/V(1) = 18\pi \div \frac{2\pi}{3} = 27$. $\checkmark$

**The numbers worth memorising outright.**

$$V(1)=\frac{2\pi}{3}\approx 2.094,\qquad V(2)=\frac{16\pi}{3}\approx 16.755,\qquad
V(3)=18\pi\approx 56.549,\qquad V(6)=144\pi\approx 452.389$$

If your part c is not $18\pi$, you have not found a new cone, you have made an arithmetic error.

## 7. Answer-entry rules

Möbius grades by mathematical equivalence, so a correct answer is never rejected for its *form*.
It is rejected for being *parsed* differently from how you meant it, silently, with no error message.

| Rule | Do | Not |
| :--- | :--- | :--- |
| Multiplication | `2/3*Pi*r^3` | `2/3 Pi r^3` |
| The constant $\pi$ | `Pi` | `pi` (see the flag below) |
| Powers | `r^3` | `r**3`, `r3` |
| Fractions | `2/3*Pi*r^3` or `2*Pi*r^3/3` | `2*Pi*r^(3/3)` |
| Exact value | `18*Pi` | `56.55` |
| Interval | `(0,infinity)` | `(0,∞)` pasted as a glyph |
| Inequality box | `r>0` | `r>=0` |

**The recommended form is `2/3*Pi*r^3`.**
Putting the fraction at the front means there is no `/3` left dangling at the end for the parser to
attach to the wrong thing, and no exponent adjacent to a slash.

**The single most expensive typo on this question** is `2*Pi*r^(3/3)`, which is $2\pi r$ and is not
close to anything.
The second most expensive is answering part b with `R` or `(-infinity,infinity)` because the
polynomial accepts it.

**A flag on `pi` versus `Pi`, and the one trap preview does not catch.**
Möbius sits on top of Maple, and Maple treats `Pi` as the constant $3.14159\ldots$ while plain `pi`
is just an unassigned Greek letter - a *variable*.
Standard Möbius questions accept `pi`; Maple-graded ones do not, and nothing in the interface tells
you which engine you are in.
Worse, the preview renders both as the same $\pi$ glyph, so **previewing does not distinguish them**.
Type `Pi`, which is the constant under Maple and is accepted by Möbius, and confirm the behaviour on
a practice question before the exam rather than during it.

**Always click the preview icon anyway.**
An empty preview modal means broken syntax, not wrong mathematics.
It will catch every bracket error in the table above, which is most of them.

## 8. The variation catalog

This is the part that makes the question repeatable.
Read each table as *structure*, not as a list of facts.

In Family 0, for instance, there are only **four distinct coefficients** in play -
$\tfrac{\pi}{6}, \tfrac{\pi}{3}, \tfrac{2\pi}{3}, \pi$ and their multiples - and every one of them is
just $\tfrac{\pi}{3}$ multiplied by whatever number the sentence attaches to $r$.
You are not memorising ten answers.
You are memorising one substitution and reading ten sentences correctly.

Everything below was verified numerically against the hint formula.

### Family 0 - a proportional constraint $h = c\,r$ (this question's family)

**Trigger:** the constraint is a pure multiple, with no added or subtracted constant.
**Tool:** one substitution. The answer is always $\dfrac{c\,\pi r^3}{3}$.
**Domain:** always $(0,\infty)$, because a positive multiple of a positive $r$ is positive.

| The sentence | Constraint | $V(r)$ | $V(3)$ |
| :--- | :--- | :--- | :--- |
| height is **double** the radius | $h = 2r$ | $\dfrac{2\pi r^3}{3}$ | $18\pi$ |
| height **equals** the radius | $h = r$ | $\dfrac{\pi r^3}{3}$ | $9\pi$ |
| height is **triple** the radius | $h = 3r$ | $\pi r^3$ | $27\pi$ |
| height is **half** the radius | $h = \tfrac{r}{2}$ | $\dfrac{\pi r^3}{6}$ | $4.5\pi$ |
| height is double the **diameter** | $h = 4r$ | $\dfrac{4\pi r^3}{3}$ | $36\pi$ |
| **diameter equals** the height | $h = 2r$ | $\dfrac{2\pi r^3}{3}$ | $18\pi$ |
| **diameter is double** the height | $h = r$ | $\dfrac{\pi r^3}{3}$ | $9\pi$ |
| **radius is double** the height | $h = \tfrac{r}{2}$ | $\dfrac{\pi r^3}{6}$ | $4.5\pi$ |
| height is three times the **diameter** | $h = 6r$ | $2\pi r^3$ | $54\pi$ |
| radius is **one third** the height | $h = 3r$ | $\pi r^3$ | $27\pi$ |

Rows 1, 6 and 8 are the ones to stare at.
"Height is double the radius", "diameter equals the height" and "radius is double the height" are
three different English sentences, the first two describe the *same* cone, and the third describes a
different one - four times smaller.

### Family 0b - the same cone, asked in terms of $h$ instead

**Trigger:** the question says "as a function of the height", or anything is changing with time.
**Tool:** solve the constraint for $r$ rather than $h$, then substitute.

| Constraint | $V$ as a function of $r$ | $V$ as a function of $h$ |
| :--- | :--- | :--- |
| $h = 2r$ | $\dfrac{2\pi r^3}{3}$ | $\dfrac{\pi h^3}{12}$ |
| $h = 3r$ | $\pi r^3$ | $\dfrac{\pi h^3}{27}$ |
| $r = 2h$ | $\dfrac{\pi r^3}{6}$ | $\dfrac{4\pi h^3}{3}$ |

Check the first row against itself: $V(r=3) = 18\pi$ and $V(h=6) = \pi \cdot 216/12 = 18\pi$.
Same cone, two spellings.

### Family 1 - an affine constraint $h = ar + b$

**Trigger:** the constraint contains a "+", a "-", "exceeds by", "less than", or a fixed sum.
**Tool:** the same substitution, but the answer is a polynomial rather than a monomial, and **the
domain gains a second edge from $h > 0$.**
This family exists to test whether you checked $h$ as well as $r$.

| Constraint | $V(r)$ | Domain | Why |
| :--- | :--- | :--- | :--- |
| $h = r + 3$ | $\dfrac{\pi r^2 (r+3)}{3}$ | $(0,\infty)$ | $h>0$ is free once $r>0$ |
| $h = 2r - 1$ | $\dfrac{\pi r^2 (2r-1)}{3}$ | $\left(\tfrac12,\infty\right)$ | $h>0$ needs $r>\tfrac12$ |
| $h = r - 2$ | $\dfrac{\pi r^2 (r-2)}{3}$ | $(2,\infty)$ | $h>0$ needs $r>2$ |
| $r + h = 10$, so $h = 10-r$ | $\dfrac{\pi r^2 (10-r)}{3}$ | $(0,10)$ | $h>0$ caps $r$ from above |

The last row is the one examiners like, because it is the first time the domain is **bounded on both
sides** and neither bound comes from the algebra.

### Family 2 - a Pythagorean constraint

**Trigger:** a slant height, a ladder, a diagonal, a sphere the cone sits inside, "the distance from".
**Tool:** $r^2 + h^2 = L^2$ or similar, so $h = \sqrt{L^2 - r^2}$. Now the algebra *does* restrict,
and it agrees with the geometry.

| Setup | $V(r)$ | Domain |
| :--- | :--- | :--- |
| slant height $L$ fixed | $\dfrac{\pi r^2 \sqrt{L^2-r^2}}{3}$ | $(0,L)$ |
| slant $L = 10$, in terms of $h$ | $\dfrac{\pi h (100-h^2)}{3}$ | $(0,10)$ |
| cone inscribed in a sphere of radius $R$ | $\dfrac{\pi r^2\left(R+\sqrt{R^2-r^2}\right)}{3}$ | $(0,R]$ |

The friendly instance to know: slant $10$, radius $6$, height $8$ - the 6-8-10 triangle - gives
$V = 96\pi$.

**A warning this family teaches and no other family does.**
The square root looks like it is protecting you, and it is not.
$\sqrt{100 - r^2}$ is perfectly happy at $r = -0.5$, because $r$ is squared before the root sees it.
The algebra supplies only the *upper* edge $r < 10$.
The lower edge $r > 0$ is still pure context.

### Family 3 - a fixed total, so you divide instead of multiply

**Trigger:** "has volume 500", "with 200 metres of fencing", "on a budget of", "of fixed area".
**Tool:** solve the constraint for the unwanted variable, which requires a **division**, so the
resulting function has a $1/r$ or $1/r^2$ term.
That term is the whole signature of this family, and it is why these questions always become
optimization questions later.

| Setup | Eliminate with | Answer |
| :--- | :--- | :--- |
| cone of fixed volume $100$, lateral area as a function of $r$ | $h = \dfrac{300}{\pi r^2}$ | $S(r)=\pi r\sqrt{r^2+\dfrac{90000}{\pi^2 r^4}}$ |
| cylindrical can of volume $355$, total area | $h = \dfrac{355}{\pi r^2}$ | $S(r)=2\pi r^2 + \dfrac{710}{r}$ |
| box, square base, volume $32$, surface area | $h = \dfrac{32}{x^2}$ | $S(x)=x^2 + \dfrac{128}{x}$ |
| rectangle of perimeter $40$, area | $y = 20 - x$ | $A(x)=x(20-x)$, domain $(0,20)$ |
| can of volume $500$, ends at \$0.04, side at \$0.02 | $h = \dfrac{500}{\pi r^2}$ | $C(r)=0.08\pi r^2 + \dfrac{20}{r}$ |

Note what the division does to the domain: $r = 0$ becomes an **algebraic** exclusion for the first
time in this catalog, not merely a physical one.

### Family 4 - a different solid, the identical script

**Trigger:** the word "cone" is replaced.
**Tool:** unchanged. Only the formula in step 1 changes.
The point of this table is that there is nothing new to learn here.

| Ask | Answer |
| :--- | :--- |
| sphere volume as a function of diameter | $V = \dfrac{\pi d^3}{6}$ |
| sphere volume as a function of surface area $A$ | $V = \dfrac{A^{3/2}}{6\sqrt{\pi}}$ |
| cylinder with $h = 2r$, volume | $V = 2\pi r^3$ |
| cylinder with $h = 2r$, total surface area | $S = 6\pi r^2$ |
| cube volume as a function of surface area $S$ | $V = \left(\dfrac{S}{6}\right)^{3/2}$ |
| square pyramid with $h = 2s$, volume | $V = \dfrac{2s^3}{3}$ |
| equilateral triangle area as a function of side | $A = \dfrac{\sqrt3\,s^2}{4}$ |

Rows 2 and 5 are worth practising because they run the procedure *backwards*: the constraint is
solved for $r$ or $s$ using a square root, and the answer carries a fractional exponent.

### Family 5 - the model is not geometric at all

**Trigger:** money, numbers, distance, population, a rate.
**Tool:** identical. One relationship eliminates one unknown.

| Ask | Answer | Domain |
| :--- | :--- | :--- |
| two positive numbers sum to $20$; their product | $P(x)=x(20-x)$ | $(0,20)$ |
| $200$ m of fence, three sides of a rectangle against a river | $A(x)=x(200-2x)$ | $(0,100)$ |
| distance from the origin to a point on $y=x^2+1$ | $d(x)=\sqrt{x^4+3x^2+1}$ | $\mathbb{R}$ |
| cost of the can in Family 3 | $C(r)=0.08\pi r^2+\dfrac{20}{r}$ | $(0,\infty)$ |

Row 3 is the exception that proves the rule: $x$ is a *coordinate*, not a length, so it is allowed to
be negative and the contextual domain is everything.
Do not apply "lengths are positive" to a variable that is not a length.

### Family 6 - the question is only about the domain

**Trigger:** "state the domain", "for what values of $r$ is this model valid".
**Tool:** the two-column split from Section 2.3. Write both, then intersect.

| Model | Algebraic domain | Contextual domain | Answer |
| :--- | :--- | :--- | :--- |
| $\dfrac{2\pi r^3}{3}$ | $\mathbb{R}$ | $r>0$ | $(0,\infty)$ |
| $\dfrac{\pi r^2(12-r)}{3}$ | $\mathbb{R}$ | $0<r<12$ | $(0,12)$ |
| $\dfrac{\pi r^2\sqrt{100-r^2}}{3}$ | $[-10,10]$ | $r>0$ | $(0,10)$ |
| $\dfrac{300}{\pi r^2}$ | $r \ne 0$ | $r>0$ | $(0,\infty)$ |
| $2\pi r^2+\dfrac{710}{r}$ | $r \ne 0$ | $r>0$ | $(0,\infty)$ |

Read the middle column down.
In rows 1 and 2 the algebra contributes **nothing** and every restriction is physical.
In row 3 the algebra supplies one edge and the context supplies the other.
In rows 4 and 5 they overlap.
A question is testing you precisely when those two columns disagree.

### Family 7 - evaluate, invert, or scale

**Trigger:** a number is supplied instead of asked for.
**Tool:** for inversion, a cube root; for scaling, the exponent.

| Ask | Answer |
| :--- | :--- |
| $V(1),V(2),V(3),V(4),V(5),V(6)$ | $\dfrac{2\pi}{3},\ \dfrac{16\pi}{3},\ 18\pi,\ \dfrac{128\pi}{3},\ \dfrac{250\pi}{3},\ 144\pi$ |
| for which $r$ is $V = 486\pi$ | $r = 9$ |
| for which $r$ is $V = 48\pi$ | $r = \sqrt[3]{72} \approx 4.1602$ |
| for which $r$ is $V = 100$ | $r = \sqrt[3]{150/\pi} \approx 3.6278$ |
| the radius doubles; the volume is multiplied by | $8$ |
| the radius triples; the volume is multiplied by | $27$ |
| which $r$ doubles $V(3)$ | $3\sqrt[3]{2} \approx 3.7798$ |

Inverting is one rearrangement: $r = \sqrt[3]{\dfrac{3V}{2\pi}}$.
The last row is the one people get wrong, because doubling the volume needs a factor of
$\sqrt[3]{2} \approx 1.26$ on the radius, not $2$.

### Family 8 - the same cone with calculus bolted on

**Trigger:** "how fast", "at what rate", "the largest", "approximate".
**Tool:** the model from part a is now the *input* to a derivative.
This family is the reason the question is on the paper at all.

| Ask | Working | Answer |
| :--- | :--- | :--- |
| $\dfrac{dV}{dr}$ | differentiate $\tfrac{2\pi r^3}{3}$ | $2\pi r^2$ |
| $\dfrac{dV}{dr}$ at $r=3$ | $2\pi(9)$ | $18\pi \approx 56.549$ |
| $\dfrac{dV}{dr}$ at $r=2$ | $2\pi(4)$ | $8\pi \approx 25.133$ |
| $\dfrac{dV}{dt}$ if $\dfrac{dr}{dt}=0.2$ at $r=3$ | $2\pi r^2 \dfrac{dr}{dt}$ | $3.6\pi \approx 11.310$ |
| **MT1 Q7:** $\dfrac{dV}{dt}=0.5$, find $\dfrac{dh}{dt}$ at $h=4$ | $V=\tfrac{\pi h^3}{12}$, so $\tfrac{dV}{dt}=\tfrac{\pi h^2}{4}\tfrac{dh}{dt}$ | $\dfrac{1}{8\pi}\approx 0.0398$ m/min |
| approximate $V(3.1)$ linearly | $18\pi + 18\pi(0.1)$ | $19.8\pi \approx 62.204$ (true value $62.394$) |
| largest cone inscribed in a sphere of radius $R$ | $h=\tfrac{4R}{3}$, $r^2=\tfrac{8R^2}{9}$ | $V_{\max}=\dfrac{32\pi R^3}{81}$ |

**A coincidence worth knowing about so it does not fool you.**
At $r = 3$ it happens that $V = 18\pi$ *and* $V' = 18\pi$.
That is an accident of $r=3$ - it holds because $V/V' = r/3$ - and it is false everywhere else.
At $r = 4$, $V = \tfrac{128\pi}{3} \approx 134.0$ while $V' = 32\pi \approx 100.5$.
If you are checking part c against a derivative you computed, you are checking nothing at $r=3$.

## 9. The trap list

Ranked by how often they actually cost marks.

1. **Reading the constraint backwards.** $r = 2h$ instead of $h = 2r$ gives $\frac{\pi r^3}{6}$, four times too small, and it destroys all three parts at once. Use the direction test in Section 2.2.
2. **Answering part b with $\mathbb{R}$.** The polynomial genuinely accepts every real number. The cone does not. This is the most commonly dropped single mark on the question.
3. **Including the endpoint, writing $[0,\infty)$.** A cone of radius zero is a point, not a cone with volume zero. The interval is open.
4. **Leaving $h$ in the answer.** "As a function of $r$" means no $h$ may appear. $\frac{\pi r^2 h}{3}$ with a note that $h=2r$ is not an answer to part a.
5. **Missing the second domain edge** in the Family 1 and Family 2 variations. You must check that *every* length is positive, not just the one you kept.
6. **Diameter read as radius.** Any sentence containing "diameter" needs $d=2r$ applied before anything else.
7. **Giving a decimal for part c.** $18\pi$ is the answer; $56.55$ is a rounding of it.
8. **Typing `pi` where the engine wants `Pi`,** which the preview cannot show you.
9. **Using the cylinder formula,** that is, forgetting the $/3$. The cylinder check in Section 6 catches this instantly.
10. **Squaring only $r$ and not the whole of $h/2$** on Route B, giving $\frac{\pi h^3}{6}$ instead of $\frac{\pi h^3}{12}$.

```
"Express Q as a function of x"
|
+-- 1. Write the formula for Q.  Use the hint's letters if one is given.
|
+-- 2. How many variables does it contain?
|       ONE already -> you are done with step 3, go to the domain.
|       TWO or more -> you need one constraint per extra variable.
|
+-- 3. Translate each constraint sentence.  Subject on the LEFT.
|       Contains "diameter"?      substitute d = 2r FIRST.
|       Contains "double/half/triple"?  it is Family 0, answer is c*pi*r^3/3.
|       Contains "+ / - / exceeds / sum"? it is Family 1, expect a second domain edge.
|       Contains "slant / diagonal / inscribed"? it is Family 2, expect a square root.
|       Contains "has volume / has perimeter / budget"? it is Family 3, expect a 1/x term.
|       DIRECTION TEST: put x = 1 into the sentence.  Is the other one 2, or 0.5?
|
+-- 4. Solve the constraint for the variable you want to REMOVE, then substitute.
|
+-- 5. Simplify.  Check the DEGREE: h = c*r always gives degree 3.
|
+-- 6. Domain = ALGEBRAIC and CONTEXTUAL, intersected.
|       Algebraic:  denominator != 0,  even root >= 0,  log > 0.
|       Contextual: EVERY length > 0 - including the one you eliminated.
|       Endpoints are OPEN unless a zero length is genuinely allowed.  It is not.
|
+-- 7. Evaluate if asked.  Keep pi symbolic.
|
+-- 8. CHECK: a cone is 1/3 of its cylinder.  Degree 3.  Doubling r gives x8.
|
+-- 9. Type it: 2/3*Pi*r^3 , (0,infinity) , 18*Pi .  Then PREVIEW.
```
