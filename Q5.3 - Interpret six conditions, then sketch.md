# Q5.3 - Interpret six conditions, then sketch

**The question (Final Exam 2, item 4, 10 points).**
Give the interpretation in terms of the graph of the function $f(x)$ if

- a. $f(0) = -3$
- b. $\displaystyle\lim_{x \to \infty} f(x) = -2$
- c. $\displaystyle\lim_{x \to 3^-} f(x) = \infty$
- d. $f'(x) < 0$ on the interval $[3, \infty)$
- e. $f'(x) < 0$ on the interval $(-\infty, -2)$
- f. $f''(x) > 0$ on the interval $[4, \infty)$

Give a sketch of the graph of $f(x)$.

> **Two transcription conflicts, both found by comparing the sources, both recorded before anything was drawn.**
> Condition (c) carries a **minus superscript** on the original paper: it is $\lim_{x\to3^-}$, a one-sided limit.
> `notes\MATH265.md` and `MATH265_Review.md` both print it as the two-sided $\lim_{x\to3}$.
> Condition (d) is written on a **closed** interval $[3,\infty)$, and $f'(3)$ cannot exist for any function satisfying (c), so that bracket has to be read as $(3,\infty)$.
> Section 2.3 and section 2.4 deal with each of these, and the answer below is built so that it satisfies **every** reading of both.

**The answer.**
There is no unique answer, and that is the point.
Any function with these six features scores full marks, and the marks are spread over the six conditions plus the picture.
This tutorial ships one, chosen because both branches are single rational expressions and because every landmark is a whole number or a small fraction.

$$f(x)=\begin{cases}
-3+\dfrac{x^{2}}{3-x}, & x<3\\[10pt]
-2+\dfrac{6}{x-3}, & x>3
\end{cases}$$

$$f(0)=-3 \text{ (the minimum)}
\quad
x=3 \text{ is a vertical asymptote, } +\infty \text{ both sides}
\quad
y=-2 \text{ as } x\to\infty, \textbf{ from above}
\quad
f(4)=4,\; f(6)=0$$

## 1. What this question is really testing

Item 4 is worth 10 of the 81 points on Final Exam 2, tied with the optimization box and the average-value question for the largest single award on the paper.
It is the joint-largest award per unit of algebra, and there is no algebra in it at all.

The ten points are for **two deliverables**, and the first sentence of the question is the one students skip.

| Deliverable | What it is | How it is marked |
| :--- | :--- | :--- |
| "Give the interpretation in terms of the graph" | six written statements, one per condition | one per condition, on whether you name the **feature** |
| "Give a sketch of the graph" | one labelled picture satisfying all six | on whether each feature is **visible** and labelled |

Q5.2 had the same two-deliverable structure with five conditions.
What is new here is the **kind** of condition.

| Reflex | Where it comes back |
| :--- | :--- |
| $f' < 0$ on $I$ means falling, and says **nothing** about height | curve sketching, the First Derivative Test, the Mean Value Theorem |
| $f'' > 0$ on $I$ means the **slope** is rising, not the function | the Second Derivative Test, inflection points, concavity sign charts |
| A falling branch with a horizontal asymptote sits **above** it | this question, every rational-function sketch, Q4.1 |
| $\lim_{x\to a^-}f = \infty$ constrains **one** branch | Q3.3b, Q5.1's Family 9, Q3.2 |
| A bracket endpoint that is a pole cannot be included | this question, EVT questions where $f$ is not continuous |
| An unmentioned interval is still bound by the Intermediate Value Theorem | Q5.2's Family 3, every "sketch a curve through these features" item |
| Writing the feature's **name**, not a description of the picture | every "interpret" and "explain" item on all four papers |

**Why the interpretation half is where the easy marks are.**
A sketch can be marked down for being unclear.
A sentence that says "$f'' > 0$ on $[4,\infty)$, so the graph is concave up there: it bends like a cup, and combined with $f' < 0$ that is what lets it flatten onto its horizontal asymptote instead of accelerating away from it" cannot be misread.
Write the sentences first, then draw the picture from your own sentences, and the picture inherits their precision.

**Format warning.**
The sample paper is a written, constructed response asking for prose and a drawing.
The live delivery is Möbius, which is answer-only and machine-marked, and a machine can mark neither.
So the live version almost certainly asks for the same content in a machine-readable form: boxes for the asymptotes, interval boxes for where $f$ is decreasing or concave up, a yes/no on continuity at $3$, a word for the side the tail approaches from, or a multiple-choice item showing four candidate graphs.
Section 7 prepares for all of those, and the reasoning behind that expectation is stated there rather than presented as a fact about the platform.

## 2. The five things you must have cold

Q5.1's section 2 built the translation dictionary, the three ways a two-sided limit can fail, and the four-way non-differentiability list.
Q5.2's section 2 built the same-$x$ reconciliation matrix and the equality-versus-denial reading of $\infty$.
This section does not repeat either.
It covers the five things Q5.3 needs **that neither of them did**, and all five are consequences of a condition being stated on an *interval*.

### 2.1 An interval condition is about shape, never about height

This is the single idea behind conditions (d), (e) and (f), and it is where most of the lost marks are.

| Notation | What it constrains | What it does **not** constrain |
| :--- | :--- | :--- |
| $f'(x) < 0$ on $I$ | the **direction** of travel across $I$ | any value of $f$, the sign of $f$, the steepness |
| $f'(x) > 0$ on $I$ | the direction, the other way | the same list |
| $f''(x) > 0$ on $I$ | the **bend**: the slope is increasing | whether $f$ itself rises or falls, and where $f$ sits |
| $f''(x) < 0$ on $I$ | the bend, the other way | the same list |
| $f(a) = b$ | one **height**, at one place | the direction, the bend, or anything nearby |
| $\lim_{x\to\infty} f = L$ | the **end behaviour** of one tail | any finite part of the graph |

Read the second column and the third together.
A function can be negative and increasing.
A function can be increasing and concave down.
A function can be decreasing while sitting entirely above a level it is heading for, which is exactly what the shipped answer's right branch does.

**The confusion that actually happens.**
$f' < 0$ gets read as $f < 0$, and the student draws the branch below the $x$-axis.
Condition (d) says the right branch **falls**, and in the shipped answer that branch is above the $x$-axis from $x=3$ to $x=6$ and below it after that.
Both halves of that branch satisfy (d) equally, because (d) never mentions height.

### 2.2 The $f'$ and $f''$ pair, and which side of an asymptote you arrive on

Two sign conditions on the same interval do fix the shape completely, and there are only four combinations.
This table answers most of Q5.3 on its own.

| $f'$ | $f''$ | Shape | With $\lim_{x\to\infty}f=L$ |
| :--- | :--- | :--- | :--- |
| $<0$ | $>0$ | falling, flattening out | settles onto $y=L$ **from above** |
| $>0$ | $<0$ | rising, flattening out | settles onto $y=L$ **from below** |
| $<0$ | $<0$ | falling and steepening | **cannot** settle: it runs away to $-\infty$ |
| $>0$ | $>0$ | rising and steepening | **cannot** settle: it runs away to $+\infty$ |

**Row 1 is Q5.3's conditions (b), (d) and (f) taken together.**
That is the whole right-hand half of the picture, in one row.

Two things in this table are worth proving to yourself rather than memorising, because a Möbius item can ask for either.

**Why "falling onto $L$" forces "above $L$".**
Suppose $f$ is decreasing on $(3,\infty)$ and $f(x_0) \le L$ for some $x_0 > 3$.
Then for every $x > x_0$ we have $f(x) < f(x_0) \le L$, so the limit is at most $f(x_1)$ for any $x_1 > x_0$, which is strictly below $L$.
That contradicts $\lim_{x\to\infty}f = L$.
So $f(x) > L$ everywhere on $(3,\infty)$.
This was checked on all six routes in section 4, at $x$ up to $10^{6}$.

**Why rows 3 and 4 cannot settle.**
If $f' < 0$ and $f'' \le 0$ on the whole of $[c,\infty)$ then $f'$ is decreasing, so $f'(x) \le f'(c) < 0$ for every $x \ge c$.
Integrating, $f(x) \le f(c) + f'(c)(x-c)$, and the right side runs to $-\infty$.
A function below a line that goes to $-\infty$ has no finite limit.
The consequence for Q5.3 is worth stating plainly: given (b) and (d), it is **impossible** for $f''$ to be negative on the whole of $[4,\infty)$.
Condition (f) therefore states the strongest version of something the other conditions had already half-forced.

**The qualifier that keeps this honest.**
"Concave down" by itself is not banned near a horizontal asymptote.
$f(x) = -2 - \frac1x$ is increasing, concave down, and settles onto $y=-2$ from below; that is row 2.
What is banned is the **pair** $f' < 0$ and $f'' < 0$ on an entire tail.
Q5.2's tutorial compresses this into "a tail that settles onto a horizontal asymptote must be concave the opposite way from its direction of travel", which is right in spirit and slightly too strong as written: a tail may be concave the same way on part of itself, just never on all of it.

### 2.3 A one-sided infinite limit, and what it leaves free

Condition (c) on the original paper is $\lim_{x\to3^-} f(x) = \infty$.
That superscript minus is the whole content of this subsection.

| Written condition | Left branch at $3$ | Right branch at $3$ |
| :--- | :--- | :--- |
| $\lim_{x\to3}f=+\infty$ | up | up |
| $\lim_{x\to3^-}f=+\infty$ | up | **free** |
| $\lim_{x\to3^+}f=+\infty$ | free | up |
| $\lim_{x\to3}f$ DNE, with a pole | the two disagree | the two disagree |

So, taken literally, (c) says nothing at all about what happens just to the **right** of $3$.
Something else in the list does.

**Conditions (b) and (d) do most of the right side's work anyway.**
$f$ falls on $(3,\infty)$ and tends to $-2$.
Reading that backwards, as $x$ comes down towards $3$ the function **rises**, so $\lim_{x\to3^+}f$ is either $+\infty$ or some finite number above $-2$.
It cannot be $-\infty$, and it cannot be a number at or below $-2$.
Route F in section 4 is the legal picture where that limit is finite: the right branch starts at height $3$ and slides down to $-2$, so there is an asymptote on the left of $x=3$ and a gap on the right.
Route F satisfies the paper exactly as printed and fails the two-sided transcription, and it is the only reason the missing minus sign matters at all.

**What to draw.**
Draw both branches going up.
That picture satisfies the one-sided reading, the two-sided reading, and any marker's expectation, and it costs nothing.
This is the same advice Q5.2 gives for its condition (d), reached from the opposite direction: there the equality forced both sides, here the equality only claims one side and the other is worth volunteering.

### 2.4 What a bracket means when its endpoint is a pole

Condition (d) is written on the **closed** interval $[3,\infty)$ and condition (f) on the closed $[4,\infty)$.
Only one of those is satisfiable as written.

$f'(3)$ requires $\lim_{h\to0}\frac{f(3+h)-f(3)}{h}$ to exist as a single finite number.
Condition (c) makes $f$ unbounded just to the left of $3$.
Whatever value you assign to $f(3)$, the numerator runs to $+\infty$ as $h\to0^-$ while $h$ is negative, so the quotient runs to $-\infty$ and no finite slope exists.
So $f'(3) < 0$ is false for **every** function satisfying (c), and the condition set is inconsistent if you insist on the bracket.

| Condition | Endpoint | Is $f$ defined there? | Verdict |
| :--- | :--- | :--- | :--- |
| (d) $f' < 0$ on $[3,\infty)$ | $x=3$ | no, it is a pole | read as $(3,\infty)$ |
| (f) $f'' > 0$ on $[4,\infty)$ | $x=4$ | yes | leave the bracket alone |
| (e) $f' < 0$ on $(-\infty,-2)$ | none | not applicable | already open |

**What to do about it in the exam.**
Read (d) as $(3,\infty)$, draw the picture, and add one clause to your interpretation sentence: "on $(3,\infty)$, since $f$ is not defined at $3$ and so has no derivative there".
That clause costs four seconds and it is the difference between a student who read the condition and one who copied it.
Do not spend time arguing that the question is wrong.

### 2.5 The unconstrained middle is not unconstrained

No condition mentions the interval $(-2,3)$.
Three things are nevertheless forced there, and every one of them is a place a marker can look.

| What is forced on $(-2,3)$ | Why |
| :--- | :--- |
| the curve **turns around** at least once | it arrives falling, from (e), and must leave rising to reach $+\infty$ at $3^-$ |
| it **crosses** $y=-2$ | $f(0)=-3$ is below that line and the branch runs to $+\infty$, so the Intermediate Value Theorem forces every height above $-3$ |
| it takes **every** height above $-3$ on $[0,3)$ | the same theorem, stated in full |

All three assume you draw that stretch **without lifting the pen**, which is what "sketch the graph of a single function" invites but does not require.
A graph that jumps on $(-2,3)$ escapes all three, and that is exactly why the forcing is stated for an unbroken branch.

**What is genuinely free on $(-2,3)$.**
Where the turning point sits, whether it is a smooth minimum or a corner, how many times the curve wiggles, and whether $f$ is even continuous there.
The shipped answer puts a single smooth minimum at $(0,-3)$, which is the cheapest choice because the marked point doubles as the vertex.

**Q5.3 is the first question in this family with no differentiability condition at all.**
Q5.1 required a non-differentiable point, Q5.2 required a continuous non-differentiable point.
Q5.3 requires neither, so a smooth curve is now the safe default and a corner is merely allowed.
Route B in section 4 uses a corner on purpose, to prove the point.

## 3. The universal procedure

> 1. **Split the list into POINT conditions and INTERVAL conditions.** Write the $x$-value or the interval beside each one. This is the step Q5.1 and Q5.2 did not need.
> 2. **Sort the point conditions onto the axis, and reconcile any that collide.** Use Q5.2's matrix. In Q5.3 nothing collides: $0$, $3$ and the right tail are three different places.
> 3. **Check every interval condition's endpoints.** If an endpoint is a pole or a hole, the bracket has to be read open. Say so in one clause.
> 4. **Translate each condition into a feature**, and write the sentence while you do it. The interpretation half is finished at this point.
> 5. **Draw the frame only.** Axes, a dashed line for each asymptote labelled with its equation, a tick at every constrained value. No curves yet.
> 6. **Place the marks.** Solid dot where a value exists, hollow circle where a limit is approached but not attained.
> 7. **Shape each constrained interval**, using the $f'$ and $f''$ pair table in 2.2. Direction first, then bend.
> 8. **Route the unconstrained gaps**, asking what the Intermediate Value Theorem forces rather than what looks nice.
> 9. **Check, condition by condition, in the order given.**
> 10. **Label everything.**

**Classify before you start.**

| The condition looks like | It is about | It constrains |
| :--- | :--- | :--- |
| $f(a)=b$, or $f(a)$ undefined | the **value** | one point |
| $\lim_{x\to a}f = L$ finite | the **neighbours** | two branches, not the point |
| $\lim_{x\to a}f = \pm\infty$ | the **neighbours** | both branches, and the value is undefined |
| $\lim_{x\to a^{\pm}}f = \pm\infty$ | **one** neighbour | that branch only |
| $\lim_{x\to\pm\infty}f = L$ | one **tail** | that end only |
| continuous at $a$ | value **and** neighbours | ties them together |
| differentiable / not at $a$ | the **slope** | the tangent line |
| $f'$ sign on an interval | the **direction** | which way it travels, never the height |
| $f''$ sign on an interval | the **bend** | which way it curves, never the height or direction |

**Q5.3 is three point conditions and three interval conditions, with no collisions and one bad bracket.**

**Step 7 in detail, because it is what is new.**
Take each constrained interval and read the direction and the bend off the table in 2.2, then attach the result to whatever the interval's ends are doing.

| Interval in Q5.3 | Direction | Bend | The resulting arc |
| :--- | :--- | :--- | :--- |
| $(3,\infty)$ | falling, from (d) | up on $[4,\infty)$, from (f) | comes down from $+\infty$, flattens, hugs $y=-2$ from above |
| $(-\infty,-2)$ | falling, from (e) | free | comes in from the upper left and descends |
| $(3,4)$ | falling, from (d) | free, but effectively up | a steep descent off the asymptote |
| $(-2,3)$ | free | free | must turn around and cross $y=-2$ |

The third row is worth a note.
Nothing says $f''>0$ on $(3,4)$, but very close to the pole it has to be: a branch falling from $+\infty$ has a slope running from $-\infty$ up towards $0$, and a rising slope is exactly what $f''>0$ means.
You are free to wiggle the concavity in the middle of $(3,4)$ if you want to, and nobody ever does.

## 4. Q5.3 worked seven ways

Every function below was audited against all six conditions by the same automated checker.
Each condition is tested the way its own definition is written: a monotonicity claim is tested both by the sign of a numerical derivative **and** by whether the values actually decrease, never by one lucky sample.
Route F is audited against the paper's one-sided (c); every other route satisfies both readings.

### Route A - two rational expressions (use this one)

$$f(x)=\begin{cases}
-3+\dfrac{x^{2}}{3-x}, & x<3\\[10pt]
-2+\dfrac{6}{x-3}, & x>3
\end{cases}$$

**Why this shape.**
The left branch is one expression covering everything to the left of the pole, and the $x^{2}$ in its numerator does two jobs at once: it makes $f(0)=-3$ automatic, and it puts the vertex exactly at the marked point.
The right branch is the cheapest falling hyperbola with the right asymptote.

**At $x=0$.** $f(0) = -3 + 0 = -3$, and $f'(0)=0$, so the marked point **is** the minimum.
That is a choice, not a requirement; route D moves it.

**On $(-\infty,-2)$.** $f'(x) = \dfrac{x(6-x)}{(3-x)^{2}}$.
For $x<0$ the factor $x$ is negative and $(6-x)$ is positive, so $f' < 0$.
That covers $(-\infty,-2)$ with room to spare: the shipped answer is falling on the whole of $(-\infty,0)$.

**At $x=3$.** From the left the numerator tends to $9$ and $3-x$ shrinks to $0^{+}$, so $f\to+\infty$.
From the right $\dfrac{6}{x-3}$ has a denominator shrinking to $0^{+}$, so it also runs to $+\infty$.
Both sides up, so the picture satisfies (c) under either transcription.

**On $(3,\infty)$.** $f'(x) = -\dfrac{6}{(x-3)^{2}}$, negative everywhere, and $f''(x) = \dfrac{12}{(x-3)^{3}}$, positive everywhere.
Falling and concave up, which is row 1 of the table in 2.2.

**As $x\to\infty$.** $f(x)+2 = \dfrac{6}{x-3}$ exactly, so the gap to $y=-2$ is positive and tends to zero.
Approached from above, and never reached.

**Why these numbers.**
The right branch gives a landmark ladder that needs no arithmetic: $f\!\left(3+\tfrac{6}{g}\right) = g-2$.
Read off $g=6,3,2,1,\tfrac12,\tfrac14$ and you get $f(4)=4$, $f(5)=1$, $f(6)=0$, $f(9)=-1$, $f(15)=-\tfrac32$, $f(27)=-\tfrac74$.
The left branch has two exact coincidences worth using: $f(-6)=f(2)=1$ and $f(-3)=f(\tfrac32)=-\tfrac32$.
So five labelled points on each side cost no work.

**A bonus that costs nothing.**
$f''(x) = \dfrac{18}{(3-x)^{3}}$ on $x<3$, which is positive for every $x<3$.
The shipped answer is therefore concave up on **both** branches, everywhere it is defined, so condition (f) is visibly satisfied and the picture is a cup, a wall, and a second cup.

### Route B - three pieces, with a corner at the marked point

$$f(x)=\begin{cases}
-x-3, & x\le0\\[6pt]
-3+\dfrac{3x}{3-x}, & 0<x<3\\[6pt]
-2+\dfrac{6}{x-3}, & x>3
\end{cases}$$

A straight line down to $(0,-3)$, then a hyperbola up to the pole.
The one-sided slopes at $0$ are $-1$ and $+1$, so this has a **corner** at the marked point.
Q5.3 says nothing about differentiability, so the corner is entirely legal, and this route exists to make that concrete.
Landmarks are round: $f(-3)=0$, $f(-2)=-1$, $f(1)=-\tfrac32$, $f(2)=3$.

This is also the route where the centred-difference trap reappears.
$\dfrac{f(h)-f(-h)}{2h}$ at this corner returns about $1.7\times10^{-7}$, which reads as zero and certifies a corner as differentiable.
Test one side at a time, always.

### Route C - one closed formula, six conditions

$$f(x) = -2 + \frac{6x-9}{(x-3)^{2}}$$

One expression covers everything, and it is worth seeing once because it shows how the conditions fix the coefficients.
Write $f(x) = -2 + \dfrac{ax+b}{(x-3)^{2}}$.
The $-2$ comes from (b), and the degree of the numerator has to be at most $1$ or the limit would not be $-2$.
$f(0) = -2 + \dfrac{b}{9} = -3$ gives $b = -9$.
The squared denominator makes the pole $+\infty$ on both sides provided the numerator is positive at $3$, which needs $3a-9>0$, so $a>3$.
Working out $f'$ shows that (d) needs $a>3$ again and (e) needs $a<18$, so any $a$ strictly between $3$ and $18$ works, and $a=6$ was chosen.

Its landmarks: $f(0)=-3$ (the minimum), $f(4)=13$, $f(6)=1$, and it crosses its own asymptote at exactly $x=\tfrac32$, where $6x-9=0$.
It also has $y=-2$ as a horizontal asymptote at **both** ends, which is allowed because only the $x\to+\infty$ tail was constrained.

### Route D - the minimum moved off the marked point

$$f(x)=\begin{cases}
-3+\dfrac{x(x+2)}{3-x}, & x<3\\[10pt]
-2+\dfrac{6}{x-3}, & x>3
\end{cases}$$

Same right branch, and the left branch still passes through $(0,-3)$ because of the factor $x$.
Its minimum is at $x = 3-\sqrt{15} \approx -0.873$, with $f \approx -3.254$.
So $(0,-3)$ now sits on the **rising** part of the curve rather than at its bottom.
This route exists to kill the belief that $f'(0)=0$ is required.
Nothing in Q5.3 mentions $x=0$ except its height.

### Route E - the left tail settles on a horizontal asymptote

$$f(x)=\begin{cases}
-3+\dfrac{5x}{x-1}, & x\le0\\[10pt]
-3+\dfrac{x^{2}}{3-x}, & 0<x<3\\[10pt]
-2+\dfrac{6}{x-3}, & x>3
\end{cases}$$

The left piece is decreasing, passes through $(0,-3)$, and tends to $2$ as $x\to-\infty$, approaching that level from **below** because it is falling as $x$ increases.
So this graph has two horizontal asymptotes, $y=2$ on the left and $y=-2$ on the right.
Condition (b) constrains only one end, so a second one is a free choice.
It also has a corner at $0$, slopes $-5$ and $0$, which is legal here.

### Route F - the paper's literal one-sided reading

$$f(x)=\begin{cases}
-3+\dfrac{x^{2}}{3-x}, & x<3\\[10pt]
-2+\dfrac{5}{x-2}, & x>3
\end{cases}$$

The left branch is unchanged and still runs to $+\infty$ at $3^-$, so condition (c) holds exactly as printed.
The right branch has $\lim_{x\to3^+}f = 3$, a **finite** number: it is falling, concave up, and tends to $-2$, so (b), (d) and (f) all hold.
The picture is a wall on the left of $x=3$ and a curve beginning in mid-air on the right of it.

Route F satisfies all six conditions **as the original paper writes them** and fails the two-sided version that `notes\MATH265.md` prints.
It is the whole reason to notice the superscript, and it is also the reason to draw both branches up anyway: route A satisfies both readings and route F satisfies one.

### Route W - the natural wrong answer

$$f(x)=\begin{cases}
-x-3, & x\le0\\[6pt]
-3-\dfrac{3x}{3-x}, & 0<x<3\\[6pt]
-2+\dfrac{6}{x-3}, & x>3
\end{cases}$$

One sign changed in the middle branch, and it is the shape most students reach for, because $\dfrac1{x-a}$ is the hyperbola everybody knows and it goes **down** on the left of its pole.
Conditions (a), (b), (d), (e) and (f) all still hold.
Condition (c) fails, and only condition (c): the left branch runs to $-\infty$ instead of $+\infty$.
Verified: this function breaks exactly one condition, which is what makes it dangerous.

### The route comparison

## 5. The exam-ready write-up

Here is the sketch, plotted from the shipped function rather than drawn by hand.
`*` is the curve, `@` is a solid dot, the dotted row is the horizontal asymptote $y=-2$ and the `:` column is the vertical asymptote $x=3$.

Five things a marker looks for in that picture.
The solid dot at $(0,-3)$, at the bottom of the left branch.
Both branches climbing on **both** sides of the dashed line $x=3$.
The right branch falling and flattening onto the dashed line $y=-2$ **from above**, never dipping below it.
The far left descending as you read left to right, which is condition (e).
The left branch crossing the dashed line $y=-2$ twice on its way down and back up, which is not a mistake.

Now the interpretation half.
These are the six sentences, and they are worth writing out in full because the question asked for them by name.

> **(a) $f(0)=-3$.**
> The function is defined at $x=0$ and its value there is $-3$, so the point $(0,-3)$ lies on the graph and is the $y$-intercept.
> On its own this places a single dot and says nothing about the curve on either side of it.
>
> **(b) $\lim_{x\to\infty}f(x)=-2$.**
> The line $y=-2$ is a horizontal asymptote of the graph at the right-hand end.
> As $x$ increases without bound the curve settles onto that line and the vertical gap between them tends to zero.
> Nothing is claimed about the behaviour as $x\to-\infty$, and the graph is free to cross $y=-2$ anywhere other than in the tail.
>
> **(c) $\lim_{x\to3^-}f(x)=\infty$.**
> The line $x=3$ is a vertical asymptote.
> As $x$ approaches $3$ from the **left** the curve rises without bound, and $f$ is not defined at $3$.
> The statement is one-sided, so on its own it says nothing about the branch to the right of $3$; conditions (b) and (d) settle that branch instead.
>
> **(d) $f'(x)<0$ on $[3,\infty)$.**
> The graph is decreasing across that interval: read left to right it falls.
> Strictly this must be read on the open interval $(3,\infty)$, because $f$ is not defined at $x=3$ and so has no derivative there.
> Combined with (b), a branch that falls all the way onto $y=-2$ must lie **above** $y=-2$ throughout, so the asymptote is approached from above.
>
> **(e) $f'(x)<0$ on $(-\infty,-2)$.**
> The graph is decreasing on that interval too, so far out on the left the curve is coming down as $x$ increases.
> Read the other way, the curve rises as $x\to-\infty$.
> This constrains only the direction, not the height, and nothing is said about $f$ on $(-2,3)$.
>
> **(f) $f''(x)>0$ on $[4,\infty)$.**
> The graph is concave up there: it bends like a cup, and the slope, though negative, is increasing towards zero.
> Together with (d) this is what allows the branch to flatten onto its horizontal asymptote instead of accelerating away from it.
> A falling branch that were concave **down** on the whole of $[4,\infty)$ could not have a finite limit at all.

And then the function itself, with the justification a ten-point item expects.

> Take $f(x) = -3 + \dfrac{x^{2}}{3-x}$ for $x<3$, and $f(x) = -2 + \dfrac{6}{x-3}$ for $x>3$.
>
> $f(0) = -3$, which is (a).
> As $x\to\infty$, $f(x)+2 = \dfrac{6}{x-3}\to0^{+}$, so $f\to-2$ from above and $y=-2$ is a horizontal asymptote, which is (b).
> As $x\to3^-$ the numerator tends to $9$ and $3-x\to0^{+}$, so $f\to+\infty$; as $x\to3^{+}$ the same happens on the other branch, so $x=3$ is a vertical asymptote with both branches rising, which is (c) and more.
> On $(3,\infty)$, $f'(x) = -\dfrac{6}{(x-3)^{2}} < 0$, which is (d).
> On $x<3$, $f'(x) = \dfrac{x(6-x)}{(3-x)^{2}}$, which is negative for every $x<0$ and so in particular on $(-\infty,-2)$, which is (e).
> On $(3,\infty)$, $f''(x) = \dfrac{12}{(x-3)^{3}} > 0$, which gives (f) on $[4,\infty)$ and in fact on the whole branch.

Four things students routinely skip.

**Answering the first sentence at all.**
"Give the interpretation in terms of the graph" is an instruction, not a preamble.
A perfect sketch with no interpretation is at best half the marks.

**Naming the feature rather than describing the drawing.**
"It goes down on the right" and "$f$ is decreasing on $(3,\infty)$, so combined with the horizontal asymptote at $y=-2$ the branch lies above that line throughout" describe the same picture and are not worth the same.

**Saying which side the tail approaches from.**
It is one clause, it follows from (b) and (d) together, and it is the only place in the question where two conditions have to be combined.

**Saying that the bracket in (d) has to be read open.**
One clause, and it proves you know what a derivative needs in order to exist.

## 6. Verify before you commit

Go through the conditions **one at a time, in the order given**, and point at the feature.
Budget forty seconds of a four-minute answer for this.

**Condition (a), the dot.**
There must be exactly **one** solid dot on the vertical line $x=0$, and it must sit three units below the $x$-axis.
Count the marks in that column. If there are two, your graph is not a function.

**Condition (b), the tail.**
Walk right and read three heights.

| $x$ | $f(x)$ | gap to $y=-2$ |
| :--- | :--- | :--- |
| $4$ | $4$ | $6$ |
| $9$ | $-1$ | $1$ |
| $15$ | $-\tfrac32$ | $\tfrac12$ |
| $27$ | $-\tfrac74$ | $\tfrac14$ |
| $51$ | $-\tfrac{15}8$ | $\tfrac18$ |

The gap must **shrink**, not merely be small, and it must stay **positive**.
A branch that flattens out at $-2.2$ and stays there has limit $-2.2$, and on a hand sketch it is indistinguishable from a correct one.
A branch that dips below $-2$ and comes back up is not decreasing.

**Condition (c), the left branch at $3$.**
Cover the right half of the picture with your hand and check the branch beside $x=3$ runs **up**.
This is the check that catches route W, and it takes two seconds.
Then uncover and confirm you drew the right-hand branch going up too.

**Condition (d), the direction on the right.**
Put a finger at $x=3.5$ and drag it right along the curve.
Your finger must go **down** the whole way, without ever rising.

**Condition (e), the direction on the far left.**
Put a finger at $x=-6$ and drag it right to $x=-2$.
Your finger must go **down** the whole way.
Do not check this by looking at whether the curve is above or below the axis; that is a different question.

**Condition (f), the bend on the right.**
Lay a straight edge across the branch between $x=4$ and $x=9$.
The curve must sit **below** the chord, which is what concave up means.
Equivalently, the branch is steep near the asymptote and gentle far away: the slope is negative and getting less negative.

**The check nobody does: is it a function at all?**
Sweep a vertical line across the whole picture.
It must meet the graph at most once everywhere, and it must miss it entirely at $x=3$.

### Three traps in the checking itself

**A centred difference cannot see a corner.**
If you check a slope by sampling either side and averaging, you are computing $\dfrac{f(h)-f(-h)}{2h}$, and for route B's corner that returns about $1.7\times10^{-7}$: a stable, plausible zero.
It is just the average of $-1$ and $+1$.
The residue is **truncation** error and it scales with the second derivative, not with roundoff, which is why a tolerance calibrated on a straight-armed corner is the wrong tolerance for a curved one.
Test one side at a time, which is what the definition says.

**A sampling grid coarser than the defect reports the defect as clean.**
A monotonicity claim on an interval is only as good as the spacing of the points you look at.
While building this tutorial a deliberately broken function was constructed with a climb $0.6$ units wide inside $(3,4)$, and the default checking grid, which stepped $0.90$ units at a time over $(3.05,40)$, walked straight over it and reported the function as decreasing.
On paper the equivalent mistake is checking three points and concluding a shape.
Drag your finger along the whole branch instead of sampling it.

**A sign change is not a crossing.**
Looking for the graph to pass from below $y=-2$ to above it catches a genuine crossing and also catches a **jump** that steps over the line without ever taking the value.
If you want to claim the graph crosses $y=-2$, point at the place where it is actually **on** the line.

## 7. Answer-entry rules

The sample paper wants prose and a drawing.
A machine can mark neither, so on Möbius the same ten points have to be collected some other way.
The forms that can be machine-marked are **feature boxes**, **interval boxes**, **yes/no items**, and **graph selection**, and preparing for all four costs nothing because the content is identical.

| Rule | Do | Not |
| :--- | :--- | :--- |
| An infinite limit | `infinity` | `inf`, `oo`, `∞`, or a blank box |
| A negative infinite limit | `-infinity` | `neg infinity` |
| The horizontal asymptote | `y=-2` | `-2`, or `x=-2` |
| The vertical asymptote | `x=3` | `3`, or `y=3` |
| $\lim_{x\to3^-}f$ | `infinity` | `DNE`, which is a weaker and different claim |
| $\lim_{x\to3^+}f$ | `infinity` for the shipped answer | whatever **your** graph does, if you drew route F |
| $\lim_{x\to3}f$ | `infinity` if both sides rise | `DNE`, unless your two sides disagree |
| $f(0)$ | `-3` | `3` |
| $f(3)$ | `undefined` or `DNE` | any number |
| Where $f$ is decreasing | `(-infinity,0)U(3,infinity)` for the shipped answer | `[3,infinity)`, which includes a point where $f'$ does not exist |
| Where $f$ is concave up | `(3,infinity)` at minimum, `(-infinity,3)U(3,infinity)` for the shipped answer | `[4,infinity)` if the box wants the largest interval |
| Interval union | `U` between intervals, no spaces | a comma, unless the box shows one |
| Continuity at $3$ | `no` | `yes` |
| Differentiability at $3$ | `no` | `yes` |
| Differentiability at $0$ | `yes` for routes A, C, D; `no` for B and E | whichever your own picture shows |
| The side the tail is approached from | `above` | `below` |
| The left branch | `-3+x^2/(3-x)` | `-3+x^2/3-x`, which parses as $-3+\frac{x^{2}}3-x$ |
| The right branch | `-2+6/(x-3)` | `-2+6/x-3`, which parses as $-2+\frac6x-3$ |
| Multiplication and powers | `x^2`, `-2*x` | `x2`, `-2x` |

**The single most expensive answer on this question is a graph whose right branch approaches $y=-2$ from below.**
It looks like a textbook hyperbola arriving at its asymptote, and it silently contradicts condition (d), because a branch below $-2$ that keeps falling can never come back up to $-2$.
Before you submit anything, check that every point of the right branch is **above** the dashed line.

**The second most expensive is drawing the left of $x=3$ going down.**
Condition (c) names $+\infty$, and $\dfrac1{x-3}$ dives on the left of its pole.
Use an even power in the denominator, or two pieces, and never a bare $\dfrac1{x-a}$.

**The third is answering `[3,infinity)` to "where is $f$ decreasing".**
The exam wrote that bracket, and the exam is wrong: $f$ has no derivative at $3$ and is not even defined there.
An interval of decrease cannot contain a point outside the domain.

**The fourth is reading $f'<0$ as $f<0$.**
The shipped answer is positive on part of the interval where (d) applies and negative on the rest, and (d) is satisfied on all of it.

**If the item is multiple choice, eliminate rather than select.**
Take the conditions in the order that kills candidates fastest, which is not the order they are printed.

1. Look at the right tail first. A graph arriving at $y=-2$ from below dies on (d) plus (b). This usually removes half the options.
2. Look at the left of $x=3$. A branch going down dies on (c).
3. Look at the far left. A branch that rises left to right dies on (e).
4. Look at the bend on $[4,\infty)$. A branch that is steepening rather than flattening dies on (f).
5. Only then check the height at $x=0$.

**If the item asks for the formula, bracket every denominator.**
`-2+6/(x-3)` evaluates to $4$ at $x=4$; `-2+6/x-3` evaluates to $-3.5$.

## 8. The variation catalog

Q5.1's tutorial owns Families 0 to 13 of the base condition-sketching catalog: value conditions, finite limits, jumps, poles, limits at infinity, non-differentiability, the $f'$ and $f''$ sign rows at table depth, one-sided conditions, impossibility, the reverse question, given-formula questions, and parameter fitting.
Q5.2's tutorial owns the interpretation half, the same-$x$ reconciliation matrix, the equality-versus-denial reading of $\infty$, routing between marked points, tail freedom, and its own parametric generator.
**This catalog repeats neither.**
It covers the twelve things that can vary in a question whose conditions are stated on **intervals**, which is the axis Q5.3 introduces and the last one in this family.

Read each table as **structure**, not as a list of facts.
In most of them the number of genuinely different pictures is two or four, and everything else is those pictures with the numbers changed.

### Family 0 - the six-sentence interpretation, sentence by sentence

**Trigger.** "Give the interpretation in terms of the graph", "state what each condition tells you", "explain what this says about $f$".
**Tool.** The dictionary below, read from the notation to the feature name, plus one clause naming what the condition leaves free.
**The trap.** Describing the picture in ordinary words. "It goes down" is worth less than "$f$ is decreasing on that interval, so the graph falls from left to right across it".

| Notation | The sentence that earns the mark | The sentence that does not |
| :--- | :--- | :--- |
| $f(a)=b$ | "the point $(a,b)$ lies on the graph; $f$ is defined at $a$ and its value there is $b$" | "the graph starts at $b$" |
| $\lim_{x\to\infty}f=L$ | "$y=L$ is a horizontal asymptote at the right-hand end; the vertical gap tends to zero, and the left end is unconstrained" | "the graph goes to $L$" |
| $\lim_{x\to a^-}f=\infty$ | "$x=a$ is a vertical asymptote; the curve rises without bound as $x$ approaches $a$ from the left, and $f$ is undefined at $a$. The right branch is not constrained by this statement" | "it blows up at $a$" |
| $f'<0$ on $I$ | "$f$ is decreasing across $I$: read left to right the graph falls. This constrains direction only, not height" | "$f$ is negative on $I$" |
| $f'>0$ on $I$ | "$f$ is increasing across $I$" | "$f$ is positive on $I$" |
| $f''>0$ on $I$ | "$f$ is concave up on $I$: it bends like a cup, and the slope is increasing across $I$" | "it curves upwards" |
| $f''<0$ on $I$ | "$f$ is concave down on $I$: it bends like a cap, and the slope is decreasing" | "it curves downwards" |
| $f'(c)=0$ | "the graph has a horizontal tangent at $x=c$: a turning point or a flat spot" | "$f$ is zero at $c$" |
| $f''(c)=0$ and $f''$ changes sign | "$x=c$ is an inflection point: the concavity changes there" | "$f''$ is zero" |

**A sentence template that always earns the mark.** *"\<feature name\> on \<where\>, which means \<what the curve does\>, and which does not constrain \<what it leaves free\>."*
The third clause is the one nobody writes and it is usually where the mark is.

### Family 1 - the four $f'$ and $f''$ combinations

**Trigger.** A sign condition on $f'$ and a sign condition on $f''$ that overlap.
**Tool.** The four-row table in 2.2. Direction first, then bend.
**The trap.** Believing concave up means increasing.

| $f'$ | $f''$ | Picture | Reached by |
| :--- | :--- | :--- | :--- |
| $<0$ | $>0$ | falling, flattening | $3+\tfrac1x$ for $x>0$; **Q5.3's right branch** |
| $<0$ | $<0$ | falling, steepening | $-x^{2}$ for $x>0$ |
| $>0$ | $>0$ | rising, steepening | $x^{2}$ for $x>0$; $e^{x}$ |
| $>0$ | $<0$ | rising, flattening | $\sqrt{x}$; $3-\tfrac1x$ for $x>0$ |

**Only two of these four are shapes; the other two are the same two reflected.**
Rows 1 and 4 flatten out and can therefore have a horizontal asymptote.
Rows 2 and 3 steepen and therefore cannot.
The sign of $f'$ then tells you which side of the asymptote you are on: falling means above it, rising means below it.

### Family 2 - the interval endpoint that is not in the domain

**Trigger.** A closed bracket whose endpoint is a pole, a hole, or the edge of the domain.
**Tool.** Check whether $f$ is defined and differentiable at the endpoint before you accept the bracket.
**The trap.** Copying the bracket into your answer and losing a mark for claiming a derivative that does not exist.

| Written | Endpoint | Verdict |
| :--- | :--- | :--- |
| $f'<0$ on $[3,\infty)$ with a pole at $3$ | not in the domain | read as $(3,\infty)$; this is **Q5.3 (d)** |
| $f'<0$ on $[3,\infty)$ with $f(3)$ defined and smooth | in the domain | the bracket is fine |
| $f''>0$ on $[4,\infty)$ | in the domain | the bracket is fine; this is **Q5.3 (f)** |
| $f$ continuous on $[a,b]$ for the Extreme Value Theorem | both in the domain | the bracket is the whole point of the theorem |
| $f$ increasing on $[a,b]$ with a corner at $a$ | in the domain, no derivative | monotonicity is fine, $f'(a)<0$ is not |

The last row is the distinction worth carrying: **monotonicity on a closed interval does not need a derivative at the endpoints, but a condition written as $f'(x)<0$ does.**
Q5.3 (d) is written the second way, which is why it has to be read open.

### Family 3 - which parts of the graph the conditions actually reach

**Trigger.** Any condition list whose intervals do not cover the axis.
**Tool.** Draw the axis, shade every mentioned interval, and look at what is left white.
**The trap.** Treating the white stretches as forbidden, or as free.

| Region of Q5.3's axis | Mentioned by | Status |
| :--- | :--- | :--- |
| $(-\infty,-2)$ | (e) | direction fixed, height free |
| $x=-2$ | nothing | free |
| $(-2,0)$ | nothing | free, but constrained by routing |
| $x=0$ | (a) | one height fixed |
| $(0,3)$ | nothing | free, but constrained by routing |
| $x=3$ | (c) | a pole; $f$ undefined |
| $(3,4)$ | (d) | direction fixed, bend free |
| $[4,\infty)$ | (d) and (f) | direction and bend both fixed |
| the right tail | (b) | the level is fixed |
| the left tail | (e) only | monotone, so a limit exists in $(f(-2^-),+\infty]$, but its value is free |

The last row is subtle and worth having: **a monotonicity condition on an unbounded interval partially constrains a tail that no limit condition mentions.**
Because $f$ falls on $(-\infty,-2)$, it rises as $x\to-\infty$, so that limit exists as a number or as $+\infty$ and can never be below a value $f$ already takes on that interval.
Route A realises $+\infty$; route E realises the finite value $2$.

### Family 4 - routing: what the gaps still force

**Trigger.** Three or more constrained places with unconstrained stretches between them.
**Tool.** Between two consecutive constraints, ask what the Intermediate Value Theorem forces on a branch drawn without lifting the pen.
**The trap.** Treating the picture as six independent features and joining them with a curve that quietly breaks one.

| Situation on an interval where $f$ is continuous | What is forced |
| :--- | :--- |
| $f$ arrives falling and must leave rising | a **local minimum** in between |
| $f$ arrives rising and must leave falling | a local maximum in between |
| $f$ runs from height $c$ up to $+\infty$ | it takes **every** height above $c$, asymptote heights included |
| $f$ runs from $+\infty$ down to $L$ | it takes every value above $L$ and none at or below it |
| $f'<0$ throughout a tail with $\lim f = L$ | $f>L$ everywhere on that tail |
| $f'>0$ throughout a tail with $\lim f = L$ | $f<L$ everywhere on that tail |
| $f''<0$ throughout a tail with $f'<0$ | no finite limit exists |

**In Q5.3 this bites three times.**
A local minimum is forced somewhere in $[-2,3)$.
A crossing of $y=-2$ is forced on $(0,3)$.
And the whole right branch is pinned above $y=-2$.
None of the three is written in the question, and a marker who notices is checking whether you understand what the conditions imply rather than what they say.

### Family 5 - a seventh condition added on top

**Trigger.** The same list plus one more line, often phrased as "and in addition".
**Tool.** Check the new line against the region table in Family 3 and the forcing table in Family 4.
**The trap.** Assuming the set is still satisfiable and drawing something that quietly fails an earlier condition.

| Seventh condition | Verdict | Why |
| :--- | :--- | :--- |
| "$f(3)=5$" | **satisfiable** | a value at a pole is legal; the limit never looks at the point |
| "$f''>0$ on $(-\infty,3)$ as well" | satisfiable | the shipped answer already is |
| "$\lim_{x\to-\infty}f=2$" | satisfiable | route E |
| "$\lim_{x\to-\infty}f=-5$" | satisfiable | nothing constrains $(-2,3)$, so the climb can happen there |
| "$f'>0$ on $(-2,3)$" | satisfiable | the minimum then sits exactly at $x=-2$ |
| "$f$ is differentiable everywhere except $x=3$" | satisfiable | routes A, C and D already are |
| "$f$ has a corner at $x=0$" | satisfiable | routes B and E |
| "$\lim_{x\to3^+}f$ is finite" | satisfiable | route F, under the paper's one-sided (c) |
| "$f$ is continuous at $3$" | **impossible** | continuity needs a finite value equal to a finite limit |
| "$f$ is differentiable at $3$" | **impossible** | there is no value there to differentiate |
| "$f$ is bounded" | **impossible** | (c) drives $f$ above every bound |
| "$f$ is a polynomial" | **impossible** | polynomials are defined everywhere, so they have no poles |
| "$f'<0$ on the whole of $(-\infty,3)$" | **impossible** | $f$ must rise from $-3$ to $+\infty$ somewhere on $(0,3)$ |
| "$f'>0$ on $(3,\infty)$" | **impossible** | an increasing branch cannot start at $+\infty$ |
| "$f''<0$ on $[4,\infty)$" | **impossible** | a falling concave-down tail has no finite limit |
| "the graph never crosses $y=-2$" | **impossible** | $f(0)=-3$ is below it and the branch runs to $+\infty$ |
| "$f(x)>-2$ for every $x$" | **impossible** | $f(0)=-3$ |
| "$\lim_{x\to\infty}f=+\infty$" | **impossible** | a limit is unique, and (b) already fixed it |

**The first row is the interesting one, and it is a direct counterexample to a claim in the course notes.**
`MATH265\MATH265.md` states, in its walkthrough of Midterm 1 item 10, that "since $f(0)=0$ is defined, a vertical asymptote is ruled out".
That is false, and here it is false again in a different shape: defining $f(3)=5$ puts one isolated solid dot on the asymptote's own column and changes nothing about the limits, because a limit never looks at the point itself.
Q5.1's tutorial already records this error with its own counterexample; the reason to record it twice is that Q5.3 is the question where a student is most likely to be tempted by it, since (c) and (d) both mention $x=3$.

### Family 6 - the reverse question: read the sign conditions off a graph or a formula

**Trigger.** "State the conditions this graph satisfies", or a formula plus "describe the graph", or "on what intervals is $f$ increasing and concave up".
**Tool.** Evaluate and differentiate; do not translate. Build a sign chart for $f'$ and one for $f''$.
**The trap.** Reading the sign of $f$ where the sign of $f'$ was asked for.

Worked example, route C: $f(x) = -2 + \dfrac{6x-9}{(x-3)^{2}}$.

| Reading | Answer | Why |
| :--- | :--- | :--- |
| $\lim_{x\to\pm\infty}f$ | $-2$ at **both** ends | degree $1$ over degree $2$, so the fraction vanishes |
| behaviour at $x=3$ | $+\infty$ on both sides | the denominator is squared and the numerator is $9>0$ there |
| $f(0)$ | $-3$ | substitute |
| where $f$ is decreasing | $(-\infty,0)$ and $(3,\infty)$ | $f' = -\dfrac{6x}{(x-3)^{3}}$, whose sign is $\operatorname{sign}(x)$ for $x<3$ and negative for $x>3$ |
| where $f$ is increasing | $(0,3)$ | the same sign chart |
| where $f$ is concave up | $\left(-\tfrac32,3\right)$ and $(3,\infty)$ | $f'' = \dfrac{12x+18}{(x-3)^{4}}$, positive when $x>-\tfrac32$ |
| where it meets its own asymptote | exactly $x=\tfrac32$ | $6x-9=0$ |

The sign-chart rows are the whole exercise.
A squared denominator alone does not decide the sign of $f'$ or $f''$; the numerator does.

### Family 7 - given $f$, sketch $f'$, or given $f'$, sketch $f$

**Trigger.** "Sketch $f$ and $f'$", or a graph of $f'$ with "describe $f$".
**Tool.** Every feature of $f$ has a matching feature one derivative up or down.
**The trap.** Confusing a zero of $f'$ with a zero of $f$.

| Feature of $f$ | Corresponding feature of $f'$ |
| :--- | :--- |
| local minimum | $f'$ crosses zero from negative to positive |
| local maximum | $f'$ crosses zero from positive to negative |
| inflection point | $f'$ has a local extremum |
| concave up | $f'$ is increasing |
| decreasing | $f'$ is below the axis |
| corner | $f'$ has a jump discontinuity |
| vertical asymptote | $f'$ has a vertical asymptote too, and a steeper one |
| horizontal asymptote | $f'\to0$, if $f'$ settles at all |

For the shipped answer this reads: $f'$ is negative on $(-\infty,0)$, zero at $0$, positive on $(0,3)$, has a pole at $3$, and is negative and rising towards zero on $(3,\infty)$.
`MATH265_Categorized.md` carries an instance of this family with an explicit piecewise $f$, and Q5.1's Family 12 works it in full.

### Family 8 - the sign chart stated as a table

**Trigger.** A table of intervals with $+$ and $-$ entries for $f'$ and $f''$, and "sketch a possible $f$".
**Tool.** Read each column as one of the four shapes in Family 1, then join them at the boundaries.
**The trap.** Forgetting that a change in the sign of $f''$ has to be an inflection point, so the joins are not free.

| $f'$ | $f''$ | on $(-\infty,1)$ | on $(1,\infty)$ | The picture |
| :--- | :--- | :--- | :--- | :--- |
| $-$ then $+$ | $+$ throughout | falling, cup | rising, cup | a smooth minimum at $1$: $(x-1)^{2}$ shifted |
| $-$ then $+$ | $+$ then $-$ | falling, cup | rising, cap | a minimum at $1$ and an inflection later |
| $+$ throughout | $+$ then $-$ | rising, cup | rising, cap | an inflection at $1$, no extremum |
| $-$ throughout | $-$ then $+$ | falling, cap | falling, cup | an inflection at $1$, no extremum |

Rows 3 and 4 are the ones students get wrong: a sign change in $f''$ with no sign change in $f'$ produces an **inflection point and no turning point at all**.

### Family 9 - impossible interval sets

**Trigger.** Two interval conditions that overlap, or an interval condition that fights a limit condition.
**Tool.** Say which two conditions clash and why, and do **not** draw.
**The trap.** Drawing something that satisfies most of them and hoping.

| The set | Why it is impossible |
| :--- | :--- |
| $f'<0$ and $f'>0$ on overlapping intervals | a direct contradiction, often disguised by different interval notation |
| $f'<0$ on $[a,\infty)$ with $a$ a pole | no derivative exists at a pole; this is **Q5.3 (d)** as literally written |
| $f'<0$ and $f''<0$ on $[c,\infty)$ with $\lim_{x\to\infty}f = L$ finite | the branch is below a line running to $-\infty$ |
| $f'>0$ on $(a,\infty)$ with $\lim_{x\to a^+}f = +\infty$ | an increasing branch cannot start above everything it reaches |
| $f'<0$ on $(a,\infty)$, $\lim_{x\to\infty}f = L$, and $f(x_0)<L$ for some $x_0>a$ | a decreasing function stays below $f(x_0)$ forever |
| $f'<0$ on $(-\infty,a)$ with $\lim_{x\to-\infty}f = M$ and $f(x_0)>M$ for some $x_0<a$ | the same statement, reflected |
| $f''>0$ on $\mathbb{R}$ with two distinct local minima | a concave-up function has at most one |
| $f$ bounded with $\lim_{x\to a}f = \infty$ | unbounded is the opposite of bounded |

Rows 3, 4, 5 and 6 are the four interval-versus-limit clashes, and they are all the same idea: **a monotone branch is trapped on one side of its own limit.**

### Family 10 - which conditions are redundant, and which do all the work

**Trigger.** "Which of these conditions is implied by the others", or a question that drops one condition and asks what changes.
**Tool.** Ask what would still be true if the condition were deleted.
**The trap.** Assuming every printed condition is independent, and drawing six separate features when three of them are one feature.

| Condition | If it were deleted | Verdict |
| :--- | :--- | :--- |
| (a) $f(0)=-3$ | the graph would have no anchor between the two asymptotes | independent |
| (b) $\lim_{x\to\infty}f = -2$ | (d) would allow the branch to fall to $-\infty$ | independent |
| (c) $\lim_{x\to3^-}f = \infty$ | there would be no vertical asymptote at all | independent |
| (d) $f'<0$ on $(3,\infty)$ | the tail could arrive at $y=-2$ from either side, and could wiggle | independent, and it is the condition that does the most work |
| (e) $f'<0$ on $(-\infty,-2)$ | the far left would be entirely free | independent |
| (f) $f''>0$ on $[4,\infty)$ | the tail would still have to be concave up **somewhere** on every tail | **nearly** redundant: it names the only shape available, and pins it everywhere rather than somewhere |

Row 6 is the honest version of a tempting claim.
Condition (f) is not derivable from the others, because a falling tail with a finite limit may alternate its concavity forever.
What is derivable is that it cannot be concave **down** on the whole of $[4,\infty)$.

### Family 11 - the parametric generator for any numeric reword

**Trigger.** The same six conditions with different numbers: a different marked point, a different pole, a different asymptote.
**Tool.** Substitute into the generator below. Nothing has to be re-derived.
**The trap.** Rebuilding from scratch each time and making a sign slip in the left branch.

For the condition set *"$f(a)=v$; $\lim_{x\to\infty}f = H$; $\lim_{x\to p^-}f = +\infty$ with $p>a$; $f'<0$ on $(p,\infty)$; $f'<0$ on $(-\infty,q)$ with $q\le a$; $f''>0$ on $[r,\infty)$ with $r>p$"*:

$$f(x)=\begin{cases}
v + \dfrac{k(x-a)^{2}}{p-x}, & x<p\\[10pt]
H + \dfrac{m}{x-p}, & x>p
\end{cases}
\qquad k>0,\ m>0$$

The left branch has its minimum at $x=a$, with value $v$, and $f'(x) = \dfrac{k(x-a)(2p-x-a)}{(p-x)^{2}}$, which is negative for every $x<a$.
The right branch has $f' = -\dfrac{m}{(x-p)^{2}}$ and $f'' = \dfrac{2m}{(x-p)^{3}}$, so (d) and (f) hold on the whole of $(p,\infty)$ and $r$ can be anything greater than $p$.
Every instance below was audited against its own six conditions.

| $a$ | $v$ | $p$ | $H$ | $k$ | $m$ | The function |
| ---: | ---: | ---: | ---: | ---: | ---: | :--- |
| $0$ | $-3$ | $3$ | $-2$ | $1$ | $6$ | the shipped answer |
| $0$ | $1$ | $2$ | $4$ | $1$ | $4$ | $1+\frac{x^{2}}{2-x}$ / $4+\frac{4}{x-2}$ |
| $0$ | $0$ | $1$ | $3$ | $1$ | $1$ | $\frac{x^{2}}{1-x}$ / $3+\frac{1}{x-1}$ |
| $-1$ | $2$ | $4$ | $0$ | $1$ | $8$ | $2+\frac{(x+1)^{2}}{4-x}$ / $\frac{8}{x-4}$ |
| $0$ | $-3$ | $3$ | $-2$ | $2$ | $3$ | $-3+\frac{2x^{2}}{3-x}$ / $-2+\frac{3}{x-3}$ |
| $1$ | $-1$ | $5$ | $2$ | $1$ | $4$ | $-1+\frac{(x-1)^{2}}{5-x}$ / $2+\frac{4}{x-5}$ |
| $0$ | $5$ | $2$ | $-4$ | $3$ | $2$ | $5+\frac{3x^{2}}{2-x}$ / $-4+\frac{2}{x-2}$ |
| $-2$ | $0$ | $1$ | $-1$ | $1$ | $3$ | $\frac{(x+2)^{2}}{1-x}$ / $-1+\frac{3}{x-1}$ |

**The one restriction, and it is the only way to get this wrong.**
The generator puts the vertex at $x=a$, so it is decreasing only to the **left** of $a$.
If the reword's left interval endpoint $q$ is greater than $a$, the generator fails, because $f$ is increasing on $(a,p)$.
Verified: with $a=0$ the shipped shape is increasing on $(0.05, 2.9)$, so a condition "$f'<0$ on $(-\infty,1)$" would need the vertex moved to $x\ge1$ instead.
Move it by replacing $(x-a)^{2}$ with $(x-a)(x-2q+a)$, which is what route D does.

### Family 12 - graph selection and elimination order

**Trigger.** "Which of the following graphs satisfies all the conditions?"
**Tool.** Eliminate on the condition that kills the most candidates first, which is almost never condition (a).
**The trap.** Checking the conditions in the printed order and running out of time.

| Order | Check | Typical kill rate |
| :--- | :--- | :--- |
| 1 | the right tail lies **above** $y=-2$ and falls onto it | half the options |
| 2 | the branch on the **left** of $x=3$ goes up, not down | most of the rest |
| 3 | the far left falls as you read left to right | usually one more |
| 4 | the branch on $[4,\infty)$ flattens rather than steepens | tie-breaker |
| 5 | the marked point is at the right height | last |

The six near-miss functions used to test this tutorial's own checker are exactly the six distractors an examiner would build: a value at the wrong height, a tail at the wrong height, a finite limit where the pole should be, a right branch that climbs somewhere, a far left that rises, and a concave-down stretch inside $[4,\infty)$.
Each fails exactly one condition and passes the other five, which is what makes a good distractor.

### Family 13 - the same content asked as a curve-sketching question

**Trigger.** "Sketch $f(x)=\dfrac{x^{2}}{x^{2}-1}$, stating all critical points, cusps, vertical asymptotes and points of inflection."
**Tool.** The same six features, found by calculation instead of read off a list.
**The trap.** Treating this as a different topic. It is Q5.3 with the conditions withheld.

| Q5.3 gives you | The curve-sketching version makes you find it |
| :--- | :--- |
| $f(0)=-3$ | substitute $x=0$ |
| $\lim_{x\to\infty}f=-2$ | compare degrees, or divide by the highest power |
| $\lim_{x\to3^-}f=\infty$ | set the denominator to zero **after simplification** |
| $f'<0$ on an interval | build a sign chart for $f'$ |
| $f''>0$ on an interval | build a sign chart for $f''$ |
| the sketch | the same sketch |

`MATH265_Categorized.md` carries this exact pairing: Q5.3 sits under "Sketch the graph" alongside "Sketch the graph of each of the functions below. State all critical points, cusps, vertical asymptotes and points of inflection."
That is not a coincidence.
The examiner is testing one skill in two directions, and being fluent in the direction Q5.3 asks for is the cheaper half.

## 9. The trap list

Ranked by how often each one actually costs marks on this question.

1. **Drawing the right branch arriving at $y=-2$ from below.** Conditions (b) and (d) together forbid it: a decreasing branch that ever dips to or below $-2$ can never come back up to it, so its limit would be strictly less than $-2$. This is the single most heavily signalled fact on the item and the one that a hyperbola drawn from memory gets wrong.
2. **Skipping the interpretation half.** The question opens with "Give the interpretation in terms of the graph". A perfect sketch and no sentences is at best half of ten points.
3. **Reading $f'<0$ as $f<0$.** The right branch of the shipped answer is above the $x$-axis on $(3,6)$ and below it after $x=6$, and condition (d) holds on all of it. Direction is not height.
4. **Drawing the left of $x=3$ going down.** Condition (c) names $+\infty$. A student who reaches for $\frac{1}{x-3}$ because it is the hyperbola they know loses condition (c) while satisfying everything else, which is route W.
5. **Copying the bracket $[3,\infty)$ into the answer.** $f$ is undefined at $3$, so it has no derivative there and no interval of decrease can contain it. Write $(3,\infty)$ and say why in one clause.
6. **Believing concave up means increasing.** Condition (f) is about the **slope** increasing. The shipped answer's right branch is concave up and decreasing at the same time, everywhere.
7. **Believing the graph cannot cross $y=-2$.** It must, on $(0,3)$, if that branch is drawn unbroken, and it does so twice in the shipped answer. Only vertical asymptotes are barriers, and only because the function is undefined there.
8. **Forcing the left tail onto $y=-2$ as well.** Only $x\to+\infty$ was constrained. Extra work, extra risk, no marks.
9. **Ignoring the superscript minus in condition (c).** It is a one-sided statement, so on its own it says nothing about the right of $3$. Draw both branches up anyway, because that satisfies both readings, but know which one the paper actually printed.
10. **Assuming $f'(0)=0$.** Nothing says the marked point is a turning point. Route D puts the minimum at $3-\sqrt{15}$ and passes through $(0,-3)$ on the way up.
11. **Leaving $(-2,3)$ entirely blank or entirely arbitrary.** It is not mentioned and it is not free: an unbroken branch must turn around there and must cross $y=-2$.
12. **Checking a slope with a centred difference.** $\frac{f(h)-f(-h)}{2h}$ returns $1.7\times10^{-7}$ at route B's corner, which reads as a clean zero. One side at a time, always.
13. **Checking a monotonicity claim at three points.** A branch can climb inside a gap between your samples. Drag a finger along the whole interval instead.
14. **Leaving it unlabelled.** On a ten-point picture the marker is looking for six features. Dash both asymptotes and write their equations, mark the dot at $(0,-3)$, write "decreasing" on each of the two constrained intervals, and write "concave up" on $[4,\infty)$.
15. **Failing the vertical line test.** Sweep a vertical line across the finished picture. It must meet the graph at most once, and it must miss it entirely at $x=3$.

## 11. The one-page decision tree

```
"Interpret the conditions, then sketch a single function satisfying them."
|
+-- STEP 0.  ANSWER THE FIRST SENTENCE.  For each condition write:
|            "<FEATURE NAME> on <where>, which means <what the curve does>,
|             and which does NOT constrain <what it leaves free>."
|            That is half the marks and it needs no drawing.
|
+-- STEP 1.  SPLIT THE LIST.        POINT conditions  vs  INTERVAL conditions.
|              POINT:    f(a)=b ; lim at a ; lim at +-infinity
|              INTERVAL: f' sign ; f'' sign ; "increasing/decreasing on I"
|
+-- STEP 2.  POINTS FIRST.  Sort them onto the axis.  Reconcile any two that
|            share an x (Q5.2's matrix).  Q5.3 has none sharing.
|              lim = +-infinity AT a   -> VERTICAL ASYMPTOTE at a
|                  "= +inf" two-sided   -> BOTH branches UP
|                  "= +inf" ONE-sided   -> that branch UP, other side FREE
|              lim at +-infinity = L   -> HORIZONTAL ASYMPTOTE, THAT END ONLY
|              f(a) = b                -> one solid dot, and nothing else
|
+-- STEP 3.  CHECK EVERY INTERVAL ENDPOINT.
|              endpoint IN the domain     -> the bracket is fine
|              endpoint is a POLE or HOLE -> read the bracket OPEN and say so
|
+-- STEP 4.  DRAW THE FRAME ONLY.  Axes.  Dashed line for each asymptote,
|            labelled with its equation.  A tick at every constrained x.
|
+-- STEP 5.  PLACE THE MARKS.  Solid dot where a value exists, hollow circle
|            where a limit is approached but not attained.
|            EXACTLY ONE solid dot on any vertical line.  NONE at a pole,
|            unless the question puts one there, which is legal.
|
+-- STEP 6.  SHAPE EACH CONSTRAINED INTERVAL.  Direction, then bend:
|              f' < 0 , f'' > 0  -> falling, flattening -> settles FROM ABOVE
|              f' > 0 , f'' < 0  -> rising,  flattening -> settles FROM BELOW
|              f' < 0 , f'' < 0  -> falling, steepening -> CANNOT settle
|              f' > 0 , f'' > 0  -> rising,  steepening -> CANNOT settle
|            A sign condition NEVER says anything about HEIGHT.
|
+-- STEP 7.  ROUTE THE GAPS.  For each unmentioned stretch ask what is FORCED
|            on a branch drawn WITHOUT LIFTING THE PEN:
|              arrives falling, must leave rising -> a MINIMUM in between
|              mark -> +inf   -> it crosses EVERY height above the mark
|              +inf -> level L -> the branch must come DOWN and stay above L
|
+-- STEP 8.  CHECK, condition by condition, in the order given.
|              f(a) = b        -> exactly one solid dot, at the right height
|              lim at inf = L  -> read f at 3 growing x.  GAP must SHRINK,
|                                 and stay on ONE side
|              lim at a = +inf -> cover each half; the named branch goes UP
|              f' < 0 on I     -> drag a finger the WHOLE way; never sample
|              f'' > 0 on I    -> the curve sits BELOW its own chord
|              is it a function? -> vertical line test, everywhere
|
+-- STEP 9.  LABEL.  Both asymptote equations, the height at the marked point,
             the word "decreasing" on each constrained interval and
             "concave up" on the concavity interval.  An unlabelled correct
             sketch and an unlabelled wrong one look the same to a marker.
```
